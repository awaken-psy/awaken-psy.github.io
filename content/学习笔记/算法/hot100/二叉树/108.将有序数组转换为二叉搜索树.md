# 108. 将有序数组转换为二叉搜索树

题目：[LeetCode 108](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/)

源码：[108.将有序数组转换为二叉搜索树.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/108.将有序数组转换为二叉搜索树.cpp)

## 题面

把一个严格递增数组转换成一棵高度平衡的二叉搜索树。

## 核心思路：每次选择中点作为根

二叉搜索树要求左边小、右边大；数组本身已有序，所以选择中间元素作为根，左右区间分别递归建树即可。

中点让左右节点数量尽量接近，从而保证高度平衡。递归时传下标区间，不要反复创建子数组。

## C++ 题解

```cpp
#include <vector>

class Solution {
private:
    TreeNode* build(const std::vector<int>& nums, int left, int right) {
        if (left > right) return nullptr;

        int mid = left + (right - left) / 2;
        TreeNode* root = new TreeNode(nums[mid]);
        root->left = build(nums, left, mid - 1);
        root->right = build(nums, mid + 1, right);
        return root;
    }

public:
    TreeNode* sortedArrayToBST(std::vector<int>& nums) {
        return build(nums, 0, static_cast<int>(nums.size()) - 1);
    }
};
```

**时间复杂度 $O(n)$，递归栈空间 $O(\log n)$。**
