# 104. 二叉树的最大深度

题目：[LeetCode 104](https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/)

源码：[104.二叉树的最大深度.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/104.二叉树的最大深度.cpp)

## 题面

返回二叉树从根节点到最远叶子节点所经过的节点数。

## 核心思路：当前深度由左右子树决定

空树深度为 0。非空节点的最大深度为：

```text
1 + max(左子树深度, 右子树深度)
```

递归返回值表示“以当前节点为根的子树深度”，这是最基础的树形递归。

## C++ 题解

```cpp
#include <algorithm>

class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);
        return 1 + std::max(leftDepth, rightDepth);
    }
};
```

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
