# 199. 二叉树的右视图

题目：[LeetCode 199](https://leetcode.cn/problems/binary-tree-right-side-view/description/)

源码：[199.二叉树的右视图.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/199.二叉树的右视图.cpp)

## 题面

站在二叉树右侧观察，返回从上到下每一层能看到的节点值。

## 核心思路：层序遍历取每层最后一个节点

按从左到右的顺序进行 BFS，每层最后弹出的节点就是这一层最右侧的节点。

和 102 题相同，先固定 `levelSize`，避免把刚入队的下一层节点混入当前层。

## C++ 题解

```cpp
#include <queue>
#include <vector>

class Solution {
public:
    std::vector<int> rightSideView(TreeNode* root) {
        if (root == nullptr) return {};

        std::vector<int> answer;
        std::queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();

                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);

                if (i == levelSize - 1) {
                    answer.push_back(node->val);
                }
            }
        }
        return answer;
    }
};
```

**时间复杂度 $O(n)$，额外空间 $O(n)$。**
