# 543. 二叉树的直径

题目：[LeetCode 543](https://leetcode.cn/problems/diameter-of-binary-tree/description/)

源码：[543.二叉树的直径.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/543.二叉树的直径.cpp)

## 题面

返回二叉树中任意两个节点之间最长路径的边数，路径不一定经过根节点。

## 核心思路：求高度时顺便更新直径

递归函数返回当前子树的高度。若最长路径以当前节点为最高点，它会连接左、右子树最深处，边数为：

```text
左子树高度 + 右子树高度
```

这个值用于更新全局答案；返回父节点时只能选择更高的一侧。

## C++ 题解

```cpp
#include <algorithm>

class Solution {
private:
    int answer = 0;

    int height(TreeNode* node) {
        if (node == nullptr) return 0;

        int leftHeight = height(node->left);
        int rightHeight = height(node->right);
        answer = std::max(answer, leftHeight + rightHeight);

        return 1 + std::max(leftHeight, rightHeight);
    }

public:
    int diameterOfBinaryTree(TreeNode* root) {
        answer = 0;
        height(root);
        return answer;
    }
};
```

高度按节点数计算，但 `leftHeight + rightHeight` 恰好就是跨过当前节点的边数。

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
