# 230. 二叉搜索树中第 K 小的元素

题目：[LeetCode 230](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/description/)

源码：[230.二叉搜索树中第-k-小的元素.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/230.二叉搜索树中第-k-小的元素.cpp)

## 题面

给定二叉搜索树和从 1 开始计数的 `k`，返回第 `k` 小的节点值。

## 核心思路：BST 的中序遍历严格递增

按照“左、根、右”中序遍历 BST，访问顺序就是从小到大。用栈模拟中序遍历，每弹出一个节点就让 `k` 减一；减到 0 时立即返回，不需要保存完整序列。

## C++ 题解

```cpp
#include <stack>

class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        std::stack<TreeNode*> pending;

        while (root != nullptr || !pending.empty()) {
            while (root != nullptr) {
                pending.push(root);
                root = root->left;
            }

            root = pending.top();
            pending.pop();

            if (--k == 0) return root->val;
            root = root->right;
        }
        return -1;
    }
};
```

**时间复杂度 $O(h+k)$，额外空间 $O(h)$。**

> [!example]- 进阶：频繁插入、删除和查询
>
> 给每个节点增加 `size`，记录当前子树的节点总数。设左子树大小为 `leftSize`：
>
> - `k <= leftSize`：进入左子树。
> - `k == leftSize + 1`：当前节点就是答案。
> - 否则进入右子树，并执行 `k -= leftSize + 1`。
>
> 插入、删除以及平衡树旋转后，都要重新计算：
>
> ```cpp
> node->size = 1 + size(node->left) + size(node->right);
> ```
>
> 配合 AVL、红黑树或 Treap 保持平衡后，查询、插入、删除都能达到 $O(\log n)$。这种结构称为顺序统计树。
