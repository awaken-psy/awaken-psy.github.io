# 105. 从前序与中序遍历序列构造二叉树

题目：[LeetCode 105](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

源码：[105.从前序与中序遍历序列构造二叉树.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/105.从前序与中序遍历序列构造二叉树.cpp)

## 题面

给定一棵无重复值二叉树的前序遍历和中序遍历，重建并返回这棵树。

## 核心思路：前序确定根，中序划分左右子树

前序顺序是“根、左、右”，所以每次取出的前序元素就是当前子树的根。

在中序序列中找到根的位置后，左边属于左子树，右边属于右子树。用哈希表预存“节点值 → 中序下标”，避免每次线性查找。

必须先递归构造左子树，再构造右子树，因为前序指针也是按“根、左、右”移动。

## C++ 题解

```cpp
#include <unordered_map>
#include <vector>

class Solution {
private:
    int preorderIndex = 0;
    std::unordered_map<int, int> inorderIndex;

    TreeNode* build(const std::vector<int>& preorder,
                    int inLeft, int inRight) {
        if (inLeft > inRight) return nullptr;

        // 前序中的下一个元素是当前子树的根
        int rootValue = preorder[preorderIndex++];
        TreeNode* root = new TreeNode(rootValue);
        int split = inorderIndex[rootValue];

        root->left = build(preorder, inLeft, split - 1);
        root->right = build(preorder, split + 1, inRight);
        return root;
    }

public:
    TreeNode* buildTree(std::vector<int>& preorder,
                        std::vector<int>& inorder) {
        preorderIndex = 0;
        inorderIndex.clear();
        for (int i = 0; i < static_cast<int>(inorder.size()); ++i) {
            inorderIndex[inorder[i]] = i;
        }
        return build(preorder, 0, static_cast<int>(inorder.size()) - 1);
    }
};
```

`unordered_map` 提供平均 $O(1)$ 的按键查找，这里用节点值直接找到它在中序数组中的位置。

**时间复杂度 $O(n)$，哈希表与递归栈共占 $O(n)$ 空间。**
