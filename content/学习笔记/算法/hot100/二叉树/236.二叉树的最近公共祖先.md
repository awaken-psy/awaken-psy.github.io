# 236. 二叉树的最近公共祖先

题目：[LeetCode 236](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

源码：[236.二叉树的最近公共祖先.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/236.二叉树的最近公共祖先.cpp)

## 题面

给定二叉树中的两个不同节点 `p`、`q`，返回它们最近的公共祖先。节点也可以是自己的祖先。

## 核心思路：让找到的节点向上返回

递归返回值表示：当前子树中找到的 `p`、`q` 或它们的公共祖先。

- 当前节点为空，返回空。
- 当前节点就是 `p` 或 `q`，直接返回当前节点。
- 左右子树都返回非空，说明 `p`、`q` 分居两侧，当前节点就是最近公共祖先。
- 只有一侧非空，把那一侧的结果继续向上传递。

## C++ 题解

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root,
                                   TreeNode* p,
                                   TreeNode* q) {
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        if (left != nullptr && right != nullptr) {
            return root;
        }
        return left != nullptr ? left : right;
    }
};
```

遇到 `p` 或 `q` 就返回，也能处理其中一个节点是另一个节点祖先的情况。

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
