# 102. 二叉树的层序遍历

题目：[LeetCode 102](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

源码：[102.二叉树的层序遍历.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/102.二叉树的层序遍历.cpp)

## 题面

按从上到下、从左到右的顺序，逐层返回二叉树节点值。

## 核心思路：BFS，并冻结当前层大小

队列中先放根节点。每轮开始时记录 `levelSize = queue.size()`，此时队列里恰好是当前层的节点。

随后只弹出 `levelSize` 个节点；过程中加入的孩子属于下一层，不能在本轮继续处理。

## C++ 题解

```cpp
#include <queue>
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> levelOrder(TreeNode* root) {
        if (root == nullptr) return {};

        std::vector<std::vector<int>> answer;
        std::queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            std::vector<int> level;

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                level.push_back(node->val);

                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);
            }
            answer.push_back(level);
        }
        return answer;
    }
};
```

`queue.front()` 取得队首，`queue.pop()` 删除队首。队列先进先出，正好保证同层从左到右访问。

**时间复杂度 $O(n)$，额外空间 $O(n)$。**
