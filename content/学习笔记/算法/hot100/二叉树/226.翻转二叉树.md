# 226. 翻转二叉树

题目：[LeetCode 226](https://leetcode.cn/problems/invert-binary-tree/description/)

源码：[226.翻转二叉树.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/226.翻转二叉树.cpp)

## 题面

交换二叉树中每个节点的左右子树，返回翻转后的根节点。

## 核心思路：每个节点做同一件事

当前节点只负责交换自己的左右孩子，再递归处理两棵子树。交换前递归或交换后递归都可以，只要两边都被处理一次。

## C++ 题解

```cpp
#include <utility>

class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;

        std::swap(root->left, root->right);
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

`std::swap(a, b)` 直接交换两个变量，这里交换的是两个子树根指针。

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
