# 114. 二叉树展开为链表

题目：[LeetCode 114](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/description/)

源码：[114.二叉树展开为链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/114.二叉树展开为链表.cpp)

## 题面

原地把二叉树展开成只使用 `right` 指针的链表，节点顺序与前序遍历一致；所有 `left` 必须置空。

## 核心思路：把原右子树接到左子树末尾

前序顺序为“根、左、右”。若当前节点存在左子树：

1. 找到左子树最右侧的节点 `predecessor`，它是左子树按前序展开后的最后连接位置。
2. 把当前节点原来的右子树接到 `predecessor->right`。
3. 把整棵左子树移动到当前节点右边，并清空左指针。

随后沿 `right` 继续处理即可，整个过程不需要额外容器。

## C++ 题解

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->left != nullptr) {
                TreeNode* predecessor = current->left;
                while (predecessor->right != nullptr) {
                    predecessor = predecessor->right;
                }

                // 原右子树排在左子树之后
                predecessor->right = current->right;
                current->right = current->left;
                current->left = nullptr;
            }
            current = current->right;
        }
    }
};
```

**时间复杂度 $O(n)$，额外空间 $O(1)$。**
