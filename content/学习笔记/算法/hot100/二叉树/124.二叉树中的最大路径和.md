# 124. 二叉树中的最大路径和

题目：[LeetCode 124](https://leetcode.cn/problems/binary-tree-maximum-path-sum/description/)

源码：[124.二叉树中的最大路径和.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/124.二叉树中的最大路径和.cpp)

## 题面

路径可以从任意节点开始和结束，但相邻节点必须有边连接，并且同一个节点最多出现一次。求最大的路径节点和。

## 核心思路：返回单边贡献，更新完整路径

递归函数返回“从当前节点出发，向下延伸的最大贡献”。这条路径要交给父节点继续使用，因此只能选择左、右其中一边：

```text
返回值 = 当前值 + max(0, 左贡献, 右贡献)
```

但以当前节点作为最高点的完整路径可以同时连接左右两边：

```text
当前完整路径 = 当前值 + max(0, 左贡献) + max(0, 右贡献)
```

负贡献只会让路径变差，所以按 0 处理。全局答案必须初始化为负无穷，以处理所有节点都为负数的情况。

## C++ 题解

```cpp
#include <algorithm>
#include <climits>

class Solution {
private:
    int answer = INT_MIN;

    int gain(TreeNode* node) {
        if (node == nullptr) return 0;

        int leftGain = std::max(0, gain(node->left));
        int rightGain = std::max(0, gain(node->right));

        // 在当前节点拐弯的完整路径，用来更新全局答案
        answer = std::max(answer, node->val + leftGain + rightGain);

        // 返回给父节点的路径不能分叉，只能选择一边
        return node->val + std::max(leftGain, rightGain);
    }

public:
    int maxPathSum(TreeNode* root) {
        answer = INT_MIN;
        gain(root);
        return answer;
    }
};
```

这道题要区分“递归返回给父节点的单边路径”和“用于更新答案的完整路径”。

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
