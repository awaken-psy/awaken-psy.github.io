# 94. 二叉树的中序遍历

题目：[LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/description/)

源码：[94.二叉树的中序遍历.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/94.二叉树的中序遍历.cpp)

## 题面

返回二叉树的中序遍历结果。中序顺序为：**左子树 → 当前节点 → 右子树**。

## 核心思路：用栈模拟递归

递归中序会先不断进入左子树。迭代写法用栈保存沿途暂时不能访问的节点：

1. 当前节点不为空时，不断入栈并向左走。
2. 走到空节点后，弹出栈顶并访问。
3. 转向它的右子树，重复以上过程。

栈顶始终是“左子树已经处理完，下一个应该访问”的节点。

## C++ 题解

```cpp
#include <stack>
#include <vector>

class Solution {
public:
    std::vector<int> inorderTraversal(TreeNode* root) {
        std::vector<int> answer;
        std::stack<TreeNode*> pending;

        while (root != nullptr || !pending.empty()) {
            // 左子树优先：沿途节点先保存起来
            while (root != nullptr) {
                pending.push(root);
                root = root->left;
            }

            root = pending.top();
            pending.pop();
            answer.push_back(root->val);

            // 当前节点访问完，再处理右子树
            root = root->right;
        }
        return answer;
    }
};
```

`stack.top()` 只读取栈顶，`stack.pop()` 才会删除栈顶，两者通常连续使用。

**时间复杂度 $O(n)$，额外空间 $O(h)$；`h` 为树高。**
