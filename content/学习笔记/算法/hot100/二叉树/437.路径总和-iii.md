# 437. 路径总和 III

题目：[LeetCode 437](https://leetcode.cn/problems/path-sum-iii/description/)

源码：[437.路径总和-iii.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/437.路径总和-iii.cpp)

## 题面

统计二叉树中路径和等于 `targetSum` 的路径数量。路径必须从父节点走向子节点，但可以从任意节点开始和结束。

## 核心思路：树上的前缀和

从根到当前节点的路径可以看成一条数组路径。若当前前缀和为 `prefix`，想让某段路径和为 `target`，需要之前出现过：

```text
prefix - target
```

用哈希表记录当前递归路径上每种前缀和出现的次数。进入节点时加入当前前缀，离开节点时撤销，避免左子树的前缀错误地参与右子树计算。

初始放入 `count[0] = 1`，用于统计从根节点开始、路径和正好等于目标的情况。

## C++ 题解

```cpp
#include <unordered_map>

class Solution {
private:
    std::unordered_map<long long, int> count;

    int dfs(TreeNode* node, long long prefix, int target) {
        if (node == nullptr) return 0;

        prefix += node->val;
        int answer = count[prefix - target];

        ++count[prefix];
        answer += dfs(node->left, prefix, target);
        answer += dfs(node->right, prefix, target);
        --count[prefix];  // 回溯：只保留当前祖先链上的前缀和

        return answer;
    }

public:
    int pathSum(TreeNode* root, int targetSum) {
        count.clear();
        count[0] = 1;
        return dfs(root, 0, targetSum);
    }
};
```

这里用 `long long` 保存前缀和，避免多节点累加时溢出 `int`。

**平均时间复杂度 $O(n)$，额外空间 $O(n)$。**
