# 98. 验证二叉搜索树

题目：[LeetCode 98](https://leetcode.cn/problems/validate-binary-search-tree/description/)

源码：[98.验证二叉搜索树.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二叉树/98.验证二叉搜索树.cpp)

## 题面

判断一棵二叉树是否为有效二叉搜索树：左子树所有节点严格小于当前节点，右子树所有节点严格大于当前节点。

## 核心思路：向下传递整个合法范围

只比较节点和直接孩子不够，因为右子树深处的节点也必须大于所有祖先给出的下界。

递归时维护当前节点允许的开区间 `(lower, upper)`：

- 进入左子树，上界改为当前值。
- 进入右子树，下界改为当前值。
- 当前值不在开区间内，立即返回 `false`。

## C++ 题解

```cpp
#include <climits>

class Solution {
private:
    bool valid(TreeNode* node, long long lower, long long upper) {
        if (node == nullptr) return true;
        if (node->val <= lower || node->val >= upper) return false;

        return valid(node->left, lower, node->val) &&
               valid(node->right, node->val, upper);
    }

public:
    bool isValidBST(TreeNode* root) {
        return valid(root, LLONG_MIN, LLONG_MAX);
    }
};
```

使用 `long long` 边界，是因为节点值本身可能等于 `INT_MIN` 或 `INT_MAX`。

**时间复杂度 $O(n)$，递归栈空间 $O(h)$。**
