# 416. 分割等和子集

题目：[LeetCode 416](https://leetcode.cn/problems/partition-equal-subset-sum/description/)

源码：[416.分割等和子集.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/416.分割等和子集.cpp)

## 题面

给定只包含正整数的非空数组 `nums`，判断能否把所有元素分成两个子集，使两边的元素和相等。每个元素只能分配一次，不要求子集在原数组中连续。

- `[1,5,11,5]` → `true`，分成 `[1,5,5]` 和 `[11]`。
- `[1,2,3,5]` → `false`。

范围：`1 <= nums.length <= 200`，`1 <= nums[i] <= 100`。

## 核心思路

设数组总和为 `sum`：

- `sum` 为奇数，直接返回 `false`。
- 否则，只要选出一部分元素，和恰好为 `target = sum / 2`，剩下的元素之和也必然是 `target`。

问题转化为：**每个元素最多选一次，能否凑出指定的和？** 这是 0/1 背包问题。

定义 `dp[j]`：使用目前考虑过的元素，能否凑出和 `j`。初始只有 `dp[0] = true`，表示一个数也不选。

处理当前数字 `x` 时：不选它，保留原来的 `dp[j]`；选它，需要之前能凑出 `j - x`。两种情况任意一种成立即可：

```text
dp[j] = dp[j] || dp[j - x]
```

### 为什么必须倒序遍历

这两个状态在逻辑上都应来自“还没处理当前数字”的上一轮。

**从大到小更新 `j`，较小的 `dp[j - x]` 在本轮尚未被更新，因此不会重复使用当前数字。**

如果正序更新，`dp[j - x]` 可能已经使用了当前的 `x`，再加一个 `x` 就变成重复使用。

例如 `[1,2,5]`，目标是 4，正确答案为 `false`。但如果正序处理第一个数字 1，就会连续得到：

```text
dp[1] = dp[0] = true
dp[2] = dp[1] = true
dp[3] = dp[2] = true
dp[4] = dp[3] = true
```

这相当于把同一个 1 用了四次。倒序处理时，第一轮只会新增 `dp[1] = true`。

与「零钱兑换」区别就在这里：零钱兑换允许重复使用，本题每个数组元素只能使用一次；值相同但下标不同的元素，仍可以分别选取。

## C++ 题解

```cpp
#include <numeric>
#include <vector>

class Solution {
public:
    bool canPartition(std::vector<int>& nums) {
        int sum = std::accumulate(nums.begin(), nums.end(), 0);
        if (sum % 2 == 1) return false;

        int target = sum / 2;
        std::vector<bool> dp(target + 1, false);
        dp[0] = true;

        int n = nums.size();
        for (int k = 0; k < n; ++k) {
            int x = nums[k];
            // 倒序更新，确保当前元素最多使用一次。
            for (int j = target; j >= x; --j) {
                dp[j] = dp[j] || dp[j - x];
            }
        }
        return dp[target];
    }
};
```

## STL：accumulate 求和

`std::accumulate(nums.begin(), nums.end(), 0)` 对区间 `[begin, end)` 中的元素累加，需要头文件 `<numeric>`。

最后的 `0` 是初始值，也决定累加结果的类型为 `int`。如果总和可能很大，可以用 `0LL` 让它按 `long long` 累加，并用 `long long` 接收结果；本题总和最多 20000，`int` 足够。

**复杂度：时间 `O(n × target)`，额外空间 `O(target)`。** `n` 为数组长度。
