# 152. 乘积最大子数组

题目：[LeetCode 152](https://leetcode.cn/problems/maximum-product-subarray/description/)

源码：[152.乘积最大子数组.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/152.乘积最大子数组.cpp)

## 题面

给定整数数组 `nums`，返回**非空连续子数组**的最大乘积。

- `[2,3,-2,4]` → `6`，对应 `[2,3]`。
- `[-2,0,-1]` → `0`，不能跳过 0 把 `-2` 和 `-1` 相乘。

范围：`1 <= nums.length <= 20000`，`-10 <= nums[i] <= 10`；任意子数组的乘积保证在 32 位整数范围内。

## 核心思路

与最大子数组和类似，先固定子数组的右端点。但**负数会把最小乘积变成最大乘积**，所以只记录最大值不够，需要同时保存：

- `curMax`：以当前位置结尾的最大乘积。
- `curMin`：以当前位置结尾的最小乘积。

设当前数是 `x`，上一位置的两个状态是 `oldMax`、`oldMin`。当前子数组要么从 `x` 重新开始，要么接在前一段后面：

```text
curMax = max(x, x * oldMax, x * oldMin)
curMin = min(x, x * oldMax, x * oldMin)
```

例如 `[-2,3,-4]`：

| 当前数 | `curMax` | `curMin` |
| --- | --- | --- |
| -2 | -2 | -2 |
| 3 | 3 | -6 |
| -4 | 24 | -12 |

到 `-4` 时，正是前面的最小乘积 `-6` 带来了最大值 `24`。

**更新前要保存旧的最大、最小值**，两条转移都必须使用上一轮的状态，不能拿刚更新的 `curMax` 去算 `curMin`。

初始状态和答案都设为 `nums[0]`，不能设为 0，因为子数组不能为空。用 `res` 记录所有 `curMax` 的最大值；遇到 0 时两个状态自然归零，不需要额外分支。

## C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int maxProduct(std::vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;

        int curMax = nums[0];
        int curMin = nums[0];
        int res = nums[0];

        for (int i = 1; i < n; ++i) {
            // 两个新状态都从上一轮的状态计算。
            int oldMax = curMax;
            int oldMin = curMin;
            int x = nums[i];

            curMax = std::max({x, x * oldMax, x * oldMin});
            curMin = std::min({x, x * oldMax, x * oldMin});
            res = std::max(res, curMax);  // 最优子数组未必在最后结尾。
        }
        return res;
    }
};
```

## STL：max / min 比较多个值

`std::max({a, b, c})` 使用 C++11 的初始化列表重载，返回三个值中最大的；`std::min` 同理，需要头文件 `<algorithm>`。

注意花括号不能省略成 `std::max(a, b, c)`：三个普通参数的重载中，第三个参数是比较规则，不是第三个待比较的数。本题三个表达式都是 `int`，类型一致。

**复杂度：时间 `O(n)`，额外空间 `O(1)`。**
