# 279. 完全平方数

题目：[LeetCode 279](https://leetcode.cn/problems/perfect-squares/description/)

源码：[279.完全平方数.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/279.完全平方数.cpp)

## 题面

给定正整数 `n`，求和为 `n` 的完全平方数的最少数量。可选的数为 `1、4、9、16……`，同一个数可以重复使用。

- `n = 12` → `3`，因为 `12 = 4 + 4 + 4`。
- `n = 13` → `2`，因为 `13 = 4 + 9`。

范围：`1 <= n <= 10000`。

## 核心思路

**`dp[i]`：凑出总和 `i`，最少需要多少个完全平方数。**

枚举最后选的数 `j²`：去掉它后，还需要凑出 `i - j²`，所需数量就是 `dp[i - j²]`，再加上当前这一个。

```text
dp[i] = min(dp[i], dp[i - j*j] + 1)
枚举 j = 1, 2, ...，直到 j*j > i
```

- **初始化**：`dp[0] = 0`，凑出 0 不需要选数。其余状态先设为 `n`，因为全部使用 1 时，任意 `i <= n` 最多也只需要 `n` 个数。
- **顺序**：总和 `i` 从小到大，保证 `dp[i - j*j]` 已经算好。
- **答案**：`dp[n]`。前面的状态可以已经使用过 `j²`，因此自然允许重复选取。

例如计算 `dp[12]`，最后一个数可以选 `1、4、9`：

```text
dp[12] = min(dp[11] + 1, dp[8] + 1, dp[3] + 1)
       = min(4, 3, 4)
       = 3
```

**不能贪心地每次选最大的平方数**：12 先选 9，会得到 `9+1+1+1`，需要 4 个；选 `4+4+4` 只需要 3 个。

这与「零钱兑换」是同一种思路：把完全平方数看成可重复使用的硬币面额，求凑出目标金额的最少硬币数。

## C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int numSquares(int n) {
        std::vector<int> dp(n + 1, n);  // 用全是 1 的方案作为数量上界。
        dp[0] = 0;

        for (int i = 1; i <= n; ++i) {
            // j 是底数，真正选取的平方数是 j*j。
            for (int j = 1; j * j <= i; ++j) {
                dp[i] = std::min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
};
```

**复杂度：时间 `O(n√n)`，额外空间 `O(n)`。** 每个总和最多枚举 `√n` 个平方数。
