# 32. 最长有效括号

题目：[LeetCode 32](https://leetcode.cn/problems/longest-valid-parentheses/description/)

源码：[32.最长有效括号.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/32.最长有效括号.cpp)

## 题面

给定只包含 `'('` 和 `')'` 的字符串 `s`，返回最长有效括号**连续子串的长度**。

- `s = "(()"` → `2`
- `s = ")()())"` → `4`
- `s = ""` → `0`

范围：`0 <= s.length <= 30000`。

## 核心思路

**`dp[i]`：以 `s[i]` 结尾的最长有效括号子串长度。** 初始化为 0，从左到右计算，答案取所有 `dp[i]` 的最大值。

`s[i] == '('` 时，`dp[i] = 0`。当前是 `')'` 时，分两种情况：

### 1. 末尾是 ()：接上前一段

最后两个字符直接配对，再接上以 `i - 2` 结尾的有效段：

```text
dp[i] = dp[i - 2] + 2
```

`i < 2` 时，前一段按 0 处理。例如 `()()` 最后一个位置的结果是 `2 + 2 = 4`。

### 2. 末尾是 ))：跨过已配好的段，向外配对

以 `i - 1` 结尾的有效段长度为 `dp[i - 1]`，它的起点是 `i - dp[i - 1]`。当前右括号需要找的左括号，就在这段的前一格：

```text
j = i - dp[i - 1] - 1
```

只有 `j >= 0` 且 `s[j] == '('`，才能配成新的一段；否则 `dp[i] = 0`。

配对成功后，**还要接上 `j` 左侧紧挨着的有效段**：

```text
[前段] ( [中间有效段] )
        j             i

dp[i] = dp[j - 1] + 2 + dp[i - 1]
         前段     新配对   中间段
```

`j == 0` 时没有前段，`dp[j - 1]` 按 0 处理。

例如 `()(())`，计算最后一个位置 `i = 5`：

```text
下标：0 1 2 3 4 5
字符：( ) ( ( ) )

dp[4] = 2             // 中间的 ()
j = 5 - 2 - 1 = 2     // 找到外层左括号
dp[5] = dp[1] + 2 + dp[4] = 6
```

本题关键就是：**用前一段的长度跳到候选左括号，再把“前段 + 新配对 + 中间段”连起来。**

## C++ 题解

```cpp
#include <algorithm>
#include <string>
#include <vector>

class Solution {
public:
    int longestValidParentheses(std::string s) {
        int n = s.size();
        if (n < 2) {
            return 0;
        }

        // dp[i]：以 i 结尾的最长有效括号长度。
        std::vector<int> dp(n, 0);
        int ans = 0;

        for (int i = 1; i < n; ++i) {
            if (s[i] == '(') {
                continue;
            }

            if (s[i - 1] == '(') {
                // 末尾是 ()，接上前面的有效段。
                dp[i] = 2;
                if (i >= 2) {
                    dp[i] += dp[i - 2];
                }
            } else {
                // 跨过前一个有效段，找到候选左括号。
                int j = i - dp[i - 1] - 1;
                if (j >= 0 && s[j] == '(') {
                    dp[i] = dp[i - 1] + 2;
                    // 新配成的一段，可能还能接上更前面的有效段。
                    if (j >= 1) {
                        dp[i] += dp[j - 1];
                    }
                }
            }

            ans = std::max(ans, dp[i]);
        }
        return ans;
    }
};
```

注意先检查下标再访问数组；返回 `ans`，不能返回 `dp[n - 1]`，因为最长有效串未必在最后结束。

**复杂度：时间 `O(n)`，额外空间 `O(n)`。**
