# 70. 爬楼梯

题目：[LeetCode 70](https://leetcode.cn/problems/climbing-stairs/description/)

源码：[70.爬楼梯.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/70.爬楼梯.cpp)

## 题面

爬到第 `n` 阶楼梯，每次可以走 1 阶或 2 阶，求不同走法的数量。顺序不同算不同走法。

- `n = 2` → `2`：`1+1`、`2`。
- `n = 3` → `3`：`1+1+1`、`1+2`、`2+1`。

范围：`1 <= n <= 45`。

## 核心思路

**`dp[i]`：到达第 `i` 阶的方法数。** 最后一步只能是：从第 `i - 1` 阶走 1 阶，或从第 `i - 2` 阶走 2 阶。两类走法互不重复，直接相加：

```text
dp[i] = dp[i - 1] + dp[i - 2]
dp[0] = 1，dp[1] = 1
```

`dp[0] = 1` 表示“不走任何一步”这一种方案，使得直接走 2 阶也能被计入。

每次只依赖前两项，所以用 `prev`、`curr` 滚动保存即可。初始对应 `dp[0]`、`dp[1]`，再计算 `n - 1` 次，得到 `dp[n]`。

## C++ 题解

```cpp
class Solution {
public:
    int climbStairs(int n) {
        int prev = 1;  // dp[0]
        int curr = 1;  // dp[1]

        // 依次计算 dp[2] 到 dp[n]。
        for (int i = 0; i < n - 1; ++i) {
            int next = prev + curr;
            // 先算出新值，再把前两项向后移动。
            prev = curr;
            curr = next;
        }
        return curr;
    }
};
```

**复杂度：时间 `O(n)`，额外空间 `O(1)`。**
