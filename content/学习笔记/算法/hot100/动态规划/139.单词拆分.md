# 139. 单词拆分

题目：[LeetCode 139](https://leetcode.cn/problems/word-break/description/)

源码：[139.单词拆分.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/139.单词拆分.cpp)

## 题面

判断字符串 `s` 能否由字典 `wordDict` 中的单词拼接而成。单词可以重复使用，也不要求用完字典中的所有单词。

- `s = "leetcode"`，`wordDict = ["leet", "code"]` → `true`。
- `s = "applepenapple"`，`wordDict = ["apple", "pen"]` → `true`。
- `s = "catsandog"`，`wordDict = ["cats", "dog", "sand", "and", "cat"]` → `false`。

范围：`1 <= s.length <= 300`，字典有 `1~1000` 个互不相同的单词，每个单词长度为 `1~20`；字符串和单词只含小写英文字母。

## 核心思路

**`dp[i]`：`s` 的前 `i` 个字符能否被拆分。** 注意 `i` 是前缀长度，对应区间 `[0, i)`，不是最后一个字符的下标。

沿用源码的做法：枚举前缀长度 `i`，再枚举字典中的单词，尝试把它作为**最后一段**。设单词长度为 `len`：

```text
s 的前 i 个字符 = [前 i-len 个字符] + [最后 len 个字符]
                   已经可以拆分       恰好等于当前单词
```

只要 `i >= len`，并且下面两个条件同时成立，就能令 `dp[i] = true`：

1. `dp[i - len] == true`：前面那段能够拆分。
2. `s.substr(i - len, len) == word`：末尾恰好是当前单词。

对应转移：

```text
dp[i] = dp[i] || (dp[i - len] && 末尾等于当前单词)
```

初始化 `dp[0] = true`：空前缀可以作为起点，否则第一个单词也接不上。按 `i` 从小到大计算，最终返回 `dp[n]`。

例如 `leetcode`：`dp[0] + "leet"` 使 `dp[4]` 成立，再由 `dp[4] + "code"` 使 `dp[8]` 成立。

### 为什么要保留原来的 dp[i]

**这是“存在一种拆法即可”，不能让后面失败的候选覆盖之前的成功。**

例如 `s = "abcd"`，字典为 `["abc", "d", "bcd"]`。计算 `dp[4]` 时，`"abc" + "d"` 已使它为 `true`；随后虽然末尾匹配 `"bcd"`，但前面的 `"a"` 不可拆，不能因此把 `dp[4]` 改回 `false`。

源码用 `|| dp[i]` 保留成功结果；也可以在找到有效拆分后立即 `break`。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
public:
    bool wordBreak(std::string s, std::vector<std::string>& wordDict) {
        int n = s.size();
        std::vector<bool> dp(n + 1, false);
        dp[0] = true;  // 空前缀可拆，作为第一个单词的起点。

        for (int i = 1; i <= n; ++i) {
            for (int j = 0; j < wordDict.size(); ++j) {
                int len = wordDict[j].size();
                if (i < len) {
                    continue;
                }

                // 取前 i 个字符中，末尾长度为 len 的那一段。
                std::string sub = s.substr(i - len, len);
                if (sub == wordDict[j]) {
                    // 前段可拆即可成功，同时保留其他单词带来的成功结果。
                    dp[i] = dp[i - len] || dp[i];
                }
            }
        }
        return dp[n];
    }
};
```

## STL：substr 的第二个参数是长度

```cpp
s.substr(pos, len);  // 从下标 pos 开始，取 len 个字符，返回新字符串。
// s = "leetcode" 时，s.substr(4, 4) 得到 "code"。
```

这里写 `s.substr(i - len, len)`，取的是 `[i - len, i)`。第二个参数不是结束下标；先判断 `i >= len`，确保起点不会为负数。

**复杂度：时间 `O(n × m × L)`，额外空间 `O(n)`。** `m` 为单词数，`L` 为最长单词长度；截取和比较字符串都需要最多 `O(L)`，不能把它们算成常数时间。
