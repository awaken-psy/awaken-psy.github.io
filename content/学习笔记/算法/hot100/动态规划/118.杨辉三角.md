# 118. 杨辉三角

题目：[LeetCode 118](https://leetcode.cn/problems/pascals-triangle/description/)

源码：[118.杨辉三角.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/118.杨辉三角.cpp)

## 题面

生成杨辉三角的前 `numRows` 行：每行两端都是 1，内部每个数等于它左上方和右上方的数之和。

```text
输入：numRows = 5
输出：[[1], [1,1], [1,2,1], [1,3,3,1], [1,4,6,4,1]]

输入：numRows = 1
输出：[[1]]
```

范围：`1 <= numRows <= 30`。

## 核心思路

**`dp[i][j]`：第 `i` 行、第 `j` 列的数，下标从 0 开始。** 第 `i` 行有 `i + 1` 个数：

```text
边界：j == 0 或 j == i，dp[i][j] = 1
内部：dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
```

按行生成即可，计算当前行时上一行已经完整。例如上一行是 `[1,3,3,1]`，下一行就是 `[1,1+3,3+3,3+1,1]`。

**先处理两端的 1，再处理内部元素**，这样第一行也不需要特殊分支，而且不会访问不存在的上一行。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> generate(int numRows) {
        std::vector<std::vector<int>> dp;

        for (int i = 0; i < numRows; ++i) {
            dp.push_back(std::vector<int>{});  // 先添加空的第 i 行。
            for (int j = 0; j <= i; ++j) {
                if (j == 0 || j == i) {
                    dp[i].push_back(1);  // 两端固定为 1。
                } else {
                    dp[i].push_back(dp[i - 1][j - 1] + dp[i - 1][j]);
                }
            }
        }
        return dp;
    }
};
```

## STL：区分“添加一行”和“添加一个数”

- `dp.push_back(std::vector<int>{})`：向外层数组添加一个空数组，即新的一行。
- `dp[i].push_back(x)`：向第 `i` 行末尾添加一个数。

必须先添加这一行，才能访问 `dp[i]`。

**复杂度：时间 `O(numRows²)`；结果数组占 `O(numRows²)` 空间，除结果外额外空间为 `O(1)`。** 本题要返回所有行，因此不能像爬楼梯一样只留下最近的状态。
