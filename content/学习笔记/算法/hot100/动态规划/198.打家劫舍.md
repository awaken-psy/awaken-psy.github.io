# 198. 打家劫舍

题目：[LeetCode 198](https://leetcode.cn/problems/house-robber/description/)

源码：[198.打家劫舍.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/198.打家劫舍.cpp)

## 题面

数组 `nums` 表示沿街各房屋的金额。不能偷相邻的两间房，求最多能偷到多少钱。

- `[1,2,3,1]` → `4`，选择金额为 1、3 的房屋。
- `[2,7,9,3,1]` → `12`，选择金额为 2、9、1 的房屋。

范围：`1 <= nums.length <= 100`，`0 <= nums[i] <= 400`。

## 核心思路

**`dp[i]`：考虑前 `i` 间房，最多能偷到的金额。** 不要求一定偷第 `i` 间。

针对第 `i` 间房（数组下标为 `i - 1`），只有两种选择：

- **不偷**：沿用前 `i - 1` 间的最优结果，即 `dp[i - 1]`。
- **偷**：不能偷第 `i - 1` 间，因此用前 `i - 2` 间的最优结果，加上当前金额，即 `dp[i - 2] + nums[i - 1]`。

两种选择取最大值：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])
dp[0] = 0，dp[1] = nums[0]
```

从 `i = 2` 开始计算，返回 `dp[n]`。例如 `[2,7,9,3,1]` 对应的 `dp` 为 `[0,2,7,11,11,12]`。

这里的 `dp[i]` 已经是前 `i` 间房的最优答案，不像「乘积最大子数组」那样要求以当前元素结尾，所以不需要另设全局最大值。

**也不是固定偷奇数间或偶数间。** 例如 `[2,1,1,2]`，选第一间和第四间得到 4，比两种固定间隔方案都好。

## C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int rob(std::vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        if (n == 1) return nums[0];

        std::vector<int> dp(n + 1, 0);
        dp[1] = nums[0];

        for (int i = 2; i <= n; ++i) {
            // 不偷当前房屋，或跳过相邻房屋后偷当前房屋。
            dp[i] = std::max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[n];
    }
};
```

**复杂度：时间 `O(n)`，额外空间 `O(n)`。** 只依赖前两项，也可以像「爬楼梯」一样用两个滚动变量，把空间降到 `O(1)`。
