# 300. 最长递增子序列

题目：[LeetCode 300](https://leetcode.cn/problems/longest-increasing-subsequence/description/)

源码：[300.最长递增子序列.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/动态规划/300.最长递增子序列.cpp)

## 题面

给定整数数组 `nums`，求最长**严格递增子序列**的长度。可以跳过元素，但必须保持原有顺序。

- `[10,9,2,5,3,7,101,18]` → `4`，例如 `[2,3,7,101]`。
- `[0,1,0,3,2,3]` → `4`。
- `[7,7,7,7,7,7,7]` → `1`，相等的元素不能接在一起。

范围：`1 <= nums.length <= 2500`，`-10000 <= nums[i] <= 10000`。

## 核心思路

**`dp[i]`：以 `nums[i]` 结尾的最长递增子序列长度。** 每个元素自己就能构成长度为 1 的子序列，因此全部初始化为 1。

枚举它前面的所有位置 `j < i`：如果 `nums[j] < nums[i]`，就能把当前元素接在以 `j` 结尾的子序列后面：

```text
dp[i] = max(dp[i], dp[j] + 1)
条件：j < i 且 nums[j] < nums[i]
```

**固定结尾，才能判断能不能接。** 因为 `dp[j]` 的最后一个数确定是 `nums[j]`，只需比较这个数与 `nums[i]`。

子序列可以跳过元素，所以要枚举所有 `j < i`，不能只看 `i - 1`。严格递增则要求用 `<`，不能用 `<=`。

答案取所有 `dp[i]` 的最大值，不能直接返回最后一项。例如 `[1,2,3,0]` 的 `dp` 为 `[1,2,3,1]`，答案是 3。

## C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int lengthOfLIS(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> dp(n, 1);
        int ans = 1;  // 题目保证数组非空。

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (nums[j] < nums[i]) {
                    // 尝试把 nums[i] 接在以 j 结尾的子序列后面。
                    dp[i] = std::max(dp[i], dp[j] + 1);
                }
            }
            ans = std::max(ans, dp[i]);
        }
        return ans;
    }
};
```

**复杂度：时间 `O(n²)`，额外空间 `O(n)`。**

## 进阶：贪心 + 二分，O(n log n)

### 核心思路：相同长度，结尾越小越好

两条长度相同的递增子序列，结尾较小的那条更容易接上后面的数。因此，不必保留所有方案，只需要记录每种长度对应的最小结尾：

> **`tails[k]`：在已扫描的元素中，长度为 `k + 1` 的严格递增子序列，能够拥有的最小结尾值。**

注意，这里下标表示**长度减一**，存的是**元素值**，与前面 `dp[i]` 的含义不同。

`tails` 始终严格递增。遍历当前数 `x` 时，二分找到第一个 **大于等于 `x`** 的位置 `p`：

- **找不到**：`x` 比所有结尾都大，可以接在当前最长子序列后面，执行 `push_back(x)`。
- **找到了**：用 `x` 替换 `tails[p]`，让长度为 `p + 1` 的子序列拥有更小或相同的结尾，长度不变。

为什么替换是合法的？如果 `p > 0`，就有 `tails[p - 1] < x`，所以 `x` 能接在某条长度为 `p` 的子序列后面；如果 `p == 0`，`x` 自己就能构成长度为 1 的子序列。

例如处理 `[3,5,6,2,4]`：

| 当前数 | 更新后的 `tails` | 操作 |
| --- | --- | --- |
| 3 | `[3]` | 新增长度 1 |
| 5 | `[3,5]` | 新增长度 2 |
| 6 | `[3,5,6]` | 新增长度 3 |
| 2 | `[2,5,6]` | 降低长度 1 的结尾 |
| 4 | `[2,4,6]` | 降低长度 2 的结尾 |

**答案是 `tails.size()`，但 `tails` 本身不一定是原数组中的一条子序列。** 上例的 `[2,4,6]` 不符合原数组顺序，真实的最长递增子序列是 `[3,5,6]`，长度同样为 3。

### C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int lengthOfLIS(std::vector<int>& nums) {
        std::vector<int> tails;
        int n = nums.size();

        for (int i = 0; i < n; ++i) {
            int x = nums[i];
            // 找到第一个 >= x 的结尾。
            auto it = std::lower_bound(tails.begin(), tails.end(), x);

            if (it == tails.end()) {
                tails.push_back(x);  // 可以构成更长的递增子序列。
            } else {
                *it = x;  // 长度不变，更新该长度的最小结尾。
            }
        }
        return tails.size();
    }
};
```

### STL：lower_bound 和迭代器

`std::lower_bound(begin, end, x)` 在这里的有序区间 `[begin, end)` 中，返回第一个 **`>= x`** 的元素的迭代器；不存在则返回 `end`。需要头文件 `<algorithm>`。[标准说明](https://eel.is/c++draft/lower.bound)

- `auto it`：由编译器推导类型，这里是 `std::vector<int>::iterator`。可以把迭代器理解为指向容器中某个位置的对象，不是数组下标。
- `*it = x`：修改迭代器所指向的元素。必须先排除 `it == tails.end()`，因为 `end()` 不指向有效元素。

**为什么找 `>= x`，而不是 `> x`？** 严格递增不能接上相等的数。例如 `[2,2,2]`，后两个 2 都应替换已有的 2，长度始终为 1。若改用寻找第一个 `> x` 的 `upper_bound`，就会把相等元素接到后面，求成最长非递减子序列。

**复杂度：时间 `O(n log n)`，额外空间 `O(n)`。** 每个元素在 `vector` 上进行一次二分查找。
