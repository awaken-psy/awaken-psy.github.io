# 84. 柱状图中最大的矩形

题目：[LeetCode 84](https://leetcode.cn/problems/largest-rectangle-in-histogram/description/)

源码：[84.柱状图中最大的矩形.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/栈/84.柱状图中最大的矩形.cpp)

## 题面

给定柱状图中每根柱子的高度，柱子相邻且宽度都为 1，求能容纳在柱状图内的最大矩形面积。

- `[2,1,5,6,2,3]` → `10`，取高度为 5、宽度为 2 的矩形。
- `[2,4]` → `4`。

范围：`1 <= n <= 100000`，`0 <= heights[i] <= 10000`。

## 核心思路：固定高度，找能向两侧延伸的边界

把每根柱子看作矩形的最低高度。如果选 `heights[i]` 作为高度，就可以向两边扩展，直到遇到**严格更矮**的柱子。

定义：

- `left[i]`：左边最近的、更矮柱子的下标；不存在则为 `-1`。
- `right[i]`：右边最近的、更矮柱子的下标；不存在则为 `n`。

两根边界柱子本身都不能包含在矩形里，因此：

```text
宽度 = right[i] - left[i] - 1
面积 = heights[i] * 宽度
```

任何最优矩形都有一根最低的柱子，因此枚举这些高度，就能覆盖最优答案。

例如 `[2,1,5,6,2,3]` 中，下标 2 的高度为 5：左边界是下标 1，右边界是下标 4，宽度为 `4-1-1=2`，面积为 10。

### 用两趟单调栈找边界

栈中存的是**柱子的下标**，并且这些下标对应的高度从栈底到栈顶严格递增：

```text
heights[栈底] < ... < heights[栈顶]
```

#### 从左往右找 `left[i]`

处理下标 `i` 时：

1. 如果栈顶高度 `>= heights[i]`，就不断弹出。
2. 弹出结束后：
   - 栈为空：左边不存在更矮的柱子，`left[i] = -1`。
   - 栈不为空：栈顶就是左边最近的更矮柱子，`left[i] = stack.top()`。
3. 把当前下标 `i` 入栈，供后面的柱子使用。

为什么剩下的栈顶一定是**最近**的？因为下标按从左到右的顺序入栈。弹掉所有不够矮的柱子后，栈顶既满足高度更矮，又是剩余下标中最靠右的一个。

为什么弹出的柱子以后也没用了？假设下标 `j` 被当前下标 `i` 弹出，那么：

```text
j < i，并且 heights[i] <= heights[j]
```

对于之后的柱子 `k`，如果 `j` 能作为它左边更矮的柱子，那么 `i` 也一定足够矮，而且 `i` 离 `k` 更近。因此 `j` 不可能再成为“左边最近的更矮柱子”。

以 `heights = [2,1,5,6,2,3]` 为例，栈中写成 `下标(高度)`：

| `i` | 当前高度 | 弹栈过程 | `left[i]` | 入栈后的栈 |
| --- | ---: | --- | ---: | --- |
| 0 | 2 | 无 | -1 | `[0(2)]` |
| 1 | 1 | 弹出 `0(2)` | -1 | `[1(1)]` |
| 2 | 5 | 无 | 1 | `[1(1), 2(5)]` |
| 3 | 6 | 无 | 2 | `[1(1), 2(5), 3(6)]` |
| 4 | 2 | 弹出 `3(6)`、`2(5)` | 1 | `[1(1), 4(2)]` |
| 5 | 3 | 无 | 4 | `[1(1), 4(2), 5(3)]` |

所以：

```text
left = [-1, -1, 1, 2, 1, 4]
```

例如处理高度 2 的下标 4 时，高度 6 和 5 都不能作为它的更矮边界，所以连续弹出；最后栈顶是高度 1 的下标 1，它就是最近的更矮柱子。

#### 从右往左找 `right[i]`

先清空栈，再从右往左扫描，规则完全相同：弹出高度 `>= heights[i]` 的栈顶。弹出后，栈顶就是右边最近的更矮柱子；栈为空则记为 `n`。

同一个例子得到：

```text
right = [1, 6, 4, 4, 6, 6]
```

虽然扫描方向反了，但原理没有变化：当前栈顶是已经扫描过的右侧柱子中，离 `i` 最近且高度严格更矮的一个。

#### 为什么判断条件是 `>=`

边界要求的是**严格更矮**，相等高度的柱子不能阻止矩形继续延伸，所以相等时也必须弹出。

例如 `[2,2]`，两个高度 2 可以共同组成宽度为 2、面积为 4 的矩形。如果只弹出 `>`，另一个高度 2 会被错误地当成边界，矩形宽度就会被截断。

最后根据左右边界计算面积：

| `i` | 高度 | `left[i]` | `right[i]` | 宽度 | 面积 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 | 2 | -1 | 1 | 1 | 2 |
| 1 | 1 | -1 | 6 | 6 | 6 |
| 2 | 5 | 1 | 4 | 2 | **10** |
| 3 | 6 | 2 | 4 | 1 | 6 |
| 4 | 2 | 1 | 6 | 4 | 8 |
| 5 | 3 | 4 | 6 | 1 | 3 |

两趟扫描中，每个下标都只会入栈一次、出栈一次，所以虽然有嵌套的 `while`，总时间复杂度仍然是 $O(n)$。

## C++ 题解

```cpp
#include <algorithm>
#include <stack>
#include <vector>

class Solution {
public:
    int largestRectangleArea(std::vector<int>& heights) {
        int n = heights.size();
        std::vector<int> left(n), right(n);
        std::stack<int> indices;

        // 左边最近的严格更矮柱子。
        for (int i = 0; i < n; ++i) {
            while (!indices.empty() && heights[indices.top()] >= heights[i]) {
                indices.pop();
            }
            left[i] = indices.empty() ? -1 : indices.top();
            indices.push(i);
        }

        while (!indices.empty()) indices.pop();

        // 右边最近的严格更矮柱子。
        for (int i = n - 1; i >= 0; --i) {
            while (!indices.empty() && heights[indices.top()] >= heights[i]) {
                indices.pop();
            }
            right[i] = indices.empty() ? n : indices.top();
            indices.push(i);
        }

        int answer = 0;
        for (int i = 0; i < n; ++i) {
            int width = right[i] - left[i] - 1;
            answer = std::max(answer, heights[i] * width);
        }
        return answer;
    }
};
```

**时间 `O(n)`，额外空间 `O(n)`。** 每趟扫描中，每个下标都只入栈一次、出栈至多一次。最大面积不超过 `100000 × 10000 = 10^9`，本题用 `int` 足够。

与「每日温度」的共同点是：用单调栈寻找某个方向上最近的、更大或更小的元素。本题把左右边界分开计算，重点记住**严格更矮**和**宽度减一**。
