# 155. 最小栈

题目：[LeetCode 155](https://leetcode.cn/problems/min-stack/description/)

源码：[155.最小栈.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/栈/155.最小栈.cpp)

## 题面

实现 `MinStack`，支持压入、弹出、读取栈顶，以及在常数时间内取得栈中最小值。

```text
push(-2), push(0), push(-3)
getMin() → -3
pop()
top()    → 0
getMin() → -2
```

元素可以是任意 32 位有符号整数。`pop`、`top`、`getMin` 保证只在非空栈上调用，操作总数不超过 30000。

## 核心思路：用辅助栈保存最小值的历史

只记一个 `minValue` 不够：当前最小值被弹出后，还需要知道之前的最小值。

沿用源码的两个栈：

- `values` 保存所有元素。
- `minimums` 只记录新出现的最小值，**与当前最小值相等时也要记录**。

压入时，如果辅助栈为空，或 `val <= minimums.top()`，就把 `val` 同时压入辅助栈。弹出时，如果主栈栈顶等于当前最小值，辅助栈也同步弹出。

例如依次压入 `-2、0、-3`，辅助栈为 `[-2,-3]`；弹出 `-3` 后，栈顶自然恢复为 `-2`。

**相等值不能省略。** 连续压入两次 2 时，辅助栈也应有两个 2。否则只弹出一个 2，就可能把唯一的最小值记录删掉。

## C++ 题解

```cpp
#include <stack>

class MinStack {
private:
    std::stack<int> values;
    std::stack<int> minimums;

public:
    MinStack() {}

    void push(int val) {
        if (minimums.empty() || val <= minimums.top()) {
            minimums.push(val);
        }
        values.push(val);
    }

    void pop() {
        // 先比较旧栈顶，再删除，不能颠倒顺序。
        if (values.top() == minimums.top()) {
            minimums.pop();
        }
        values.pop();
    }

    int top() {
        return values.top();
    }

    int getMin() {
        return minimums.top();
    }
};
```

**每次操作时间 `O(1)`，空间 `O(n)`。** `n` 为当前栈中元素个数；最坏情况下，每个元素都要同时进入辅助栈。
