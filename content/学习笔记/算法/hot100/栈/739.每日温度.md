# 739. 每日温度

题目：[LeetCode 739](https://leetcode.cn/problems/daily-temperatures/description/)

源码：[739.每日温度.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/栈/739.每日温度.cpp)

## 题面

给定每天的温度，求每一天还要等几天才能遇到更高温度。之后没有更高温度则填 0。

- `[73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`。
- `[30,40,50,60]` → `[1,1,1,0]`。
- `[30,60,90]` → `[1,1,0]`。

数组长度为 `1~100000`，温度为 `30~100`。

## 核心思路：栈里放还没等到升温的日期

从左到右扫描，用栈保存尚未找到答案的日期下标，对应温度从栈底到栈顶保持**非递增**。

遇到第 `i` 天时，如果它比栈顶那天更暖，就为栈顶日期 `j` 找到了答案：

```text
answer[j] = i - j
```

弹出 `j`，继续检查新的栈顶，直到当前温度不再更高；最后把今天的下标压栈。

为什么当前这天就是第一次升温？如果更早已经出现了更暖的一天，旧日期就会在当时被弹出，不会继续留在栈里。

**这里必须用 `while`，不能只用一次 `if`**：一个暖日可能同时解决多个旧日期。例如 `[70,69,68,72]` 中，最后的 72 会依次解决下标 2、1、0。

相同温度不算升温，因此比较条件必须是 `>`。栈里只存下标即可，温度可以通过原数组查到，也方便计算相隔天数。

## C++ 题解

```cpp
#include <stack>
#include <vector>

class Solution {
public:
    std::vector<int> dailyTemperatures(std::vector<int>& temperatures) {
        int n = temperatures.size();
        std::vector<int> answer(n, 0);
        std::stack<int> pending;

        for (int i = 0; i < n; ++i) {
            while (!pending.empty() && temperatures[i] > temperatures[pending.top()]) {
                int j = pending.top();
                pending.pop();
                answer[j] = i - j;
            }
            pending.push(i);
        }
        return answer;
    }
};
```

最后留在栈里的日期没有等到更高温，答案保留初始值 0。

**时间 `O(n)`，额外空间 `O(n)`。** 虽然有嵌套循环，但每个下标只入栈一次、出栈至多一次，所有出栈操作加起来仍是线性的。
