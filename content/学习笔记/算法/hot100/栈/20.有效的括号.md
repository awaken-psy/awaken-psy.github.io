# 20. 有效的括号

题目：[LeetCode 20](https://leetcode.cn/problems/valid-parentheses/description/)

源码：[20.有效的括号.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/栈/20.有效的括号.cpp)

## 题面

字符串只包含 `()[]{}`，判断括号能否按正确的类型和顺序全部配对。

- `"()"`、`"()[]{}"`、`"([])"` → `true`。
- `"(]"`、`"([)]"` → `false`。

范围：`1 <= s.length <= 10000`。

## 核心思路：最后打开的括号，最先闭合

嵌套括号满足“后进先出”，因此用栈记录尚未闭合的括号。

这里让栈直接保存**接下来期待的右括号**：遇到 `(` 就压入 `)`，遇到 `[` 就压入 `]`，遇到 `{` 就压入 `}`。

遇到右括号时，必须与栈顶相同，才能弹出；栈为空或类型不匹配，立即返回 `false`。

例如 `([)]`，读完 `([` 后，栈顶期待的是 `]`，实际却读到了 `)`，因此无效。仅统计各种括号数量是否相等是不够的。

**扫描完字符串后，还要检查栈是否为空**，否则仍有左括号没有闭合。

## C++ 题解

```cpp
#include <stack>
#include <string>

class Solution {
public:
    bool isValid(std::string s) {
        std::stack<char> expected;
        for (char ch : s) {
            if (ch == '(') {
                expected.push(')');
            } else if (ch == '[') {
                expected.push(']');
            } else if (ch == '{') {
                expected.push('}');
            } else {
                // 先判空，避免访问不存在的栈顶。
                if (expected.empty() || expected.top() != ch) return false;
                expected.pop();
            }
        }
        return expected.empty();
    }
};
```

## STL：stack 的几个操作

- `push(x)`：把元素压到栈顶。
- `top()`：读取栈顶，不删除它。
- `pop()`：删除栈顶，**不会返回被删除的元素**。
- `empty()`：判断栈是否为空。

`top()`、`pop()` 前必须保证栈非空。代码中的 `||` 会短路：左边已经为真时，不再执行右边的 `top()`。[标准库说明](https://eel.is/c++draft/stack.defn)

`for (char ch : s)` 是范围 `for`，依次取出字符串中的每个字符，不会额外读取字符串末尾之后的位置。

**时间 `O(n)`，额外空间 `O(n)`。**
