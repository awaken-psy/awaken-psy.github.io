# 394. 字符串解码

题目：[LeetCode 394](https://leetcode.cn/problems/decode-string/description/)

源码：[394.字符串解码.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/栈/394.字符串解码.cpp)

## 题面

编码规则为 `k[内容]`，表示将括号内解码后的内容重复 `k` 次，允许嵌套。输入保证有效，数字只表示重复次数。

- `"3[a]2[bc]"` → `"aaabcbc"`。
- `"3[2[a]2[c]]"` → `"aaccaaccaacc"`。
- `"2[abc]3[cd]ef"` → `"abcabccdcdcdef"`。
- `"abc3[cd]xyz"` → `"abccdcdcdxyz"`。

编码长度为 `1~30`，只含小写字母、数字和方括号；重复次数为 `1~300`，解码后长度不超过 100000。

## 核心思路：进入括号保存外层，退出括号恢复外层

维护 `current` 表示当前这一层已解码的字符串，`number` 表示正在读取的重复次数。

| 读到的字符 | 操作 |
| --- | --- |
| 数字 | `number = number * 10 + 当前数字`，处理多位数 |
| `[` | 把 `{重复次数, 外层前缀}` 压栈，再清空当前层和次数 |
| 字母 | 追加到 `current` |
| `]` | 弹出外层状态，得到 `外层前缀 + current 重复 k 次` |

例如 `3[a2[c]]`：进入 `2[` 时，必须保存前面的 `a`。内层结束得到 `a + cc = acc`，再关闭外层，得到 `accaccacc`。

**每层的次数和前缀必须一起保存**；仅保存次数，会丢失进入括号前已经读过的内容。每次遇到 `[` 后，也要把 `number` 重置为 0。

## C++ 题解

```cpp
#include <stack>
#include <string>
#include <utility>

class Solution {
public:
    std::string decodeString(std::string s) {
        std::stack<std::pair<int, std::string>> states;
        std::string current;
        int number = 0;

        for (char ch : s) {
            if (ch >= '0' && ch <= '9') {
                number = number * 10 + (ch - '0');
            } else if (ch == '[') {
                states.push({number, current});
                current.clear();
                number = 0;
            } else if (ch == ']') {
                // 先复制出这一层的外部状态，再弹栈。
                auto [count, prefix] = states.top();
                states.pop();
                for (int i = 0; i < count; ++i) {
                    prefix += current;
                }
                current = prefix;
            } else {
                current += ch;
            }
        }
        return current;
    }
};
```

## C++：pair 和结构化绑定

`pair<int, string>` 把次数和前缀合成一份记录，`.first` 是次数，`.second` 是前缀。

```cpp
auto [count, prefix] = states.top();  // C++17 结构化绑定。
```

这行把栈顶记录复制出来，并给两个成员分别命名。随后 `pop()` 删除原记录，不影响这份副本。不要改成 `auto& [count, prefix]` 后又立即弹栈，否则引用会指向已经被删除的对象。

**时间保守上界 `O(N(L+1))`，空间 `O(N+L)`。** `N` 是编码长度，`L` 是输出长度。保存前缀和拼接字符串可能反复复制已有字符，不能只按输入长度认作线性时间。
