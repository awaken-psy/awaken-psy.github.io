# 78. 子集

题目：[LeetCode 78](https://leetcode.cn/problems/subsets/description/)

源码：[78.子集.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/78.子集.cpp)

## 题面

给定一个不含重复元素的数组，返回它的所有子集，答案不能包含重复子集。

## 核心思路：每个搜索节点都是一个子集

当前 `path` 本身就是一个合法子集，所以每次进入递归都先记录它。

参数 `start` 表示后续只能选择该位置及其右边的元素。选择一个元素后传入 `i + 1`，保证每个元素最多使用一次，也避免顺序不同造成重复。

## C++ 题解

```cpp
#include <vector>

class Solution {
private:
    void dfs(const std::vector<int>& nums, int start,
             std::vector<int>& path,
             std::vector<std::vector<int>>& answer) {
        answer.push_back(path);

        for (int i = start; i < static_cast<int>(nums.size()); ++i) {
            path.push_back(nums[i]);
            dfs(nums, i + 1, path, answer);
            path.pop_back();
        }
    }

public:
    std::vector<std::vector<int>> subsets(std::vector<int>& nums) {
        std::vector<std::vector<int>> answer;
        std::vector<int> path;
        dfs(nums, 0, path, answer);
        return answer;
    }
};
```

共有 $2^n$ 个子集，复制每个子集还需要线性时间，因此**时间复杂度 $O(n2^n)$，递归栈与路径占 $O(n)$。**
