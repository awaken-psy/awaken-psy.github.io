# 46. 全排列

题目：[LeetCode 46](https://leetcode.cn/problems/permutations/description/)

源码：[46.全排列.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/46.全排列.cpp)

## 题面

给定一个不含重复数字的数组，返回它的所有全排列。

## 核心思路：固定当前位置，交换所有候选数

递归参数 `fixed` 表示 `[0,fixed)` 已经确定。依次把区间 `[fixed,n)` 中的每个数字交换到 `fixed`：

1. 交换，做出本层选择。
2. 递归固定下一个位置。
3. 再交换回来，恢复现场。

当 `fixed == n` 时，整个数组就是一个排列。

## C++ 题解

```cpp
#include <utility>
#include <vector>

class Solution {
private:
    void dfs(std::vector<int>& nums, int fixed,
             std::vector<std::vector<int>>& answer) {
        if (fixed == static_cast<int>(nums.size())) {
            answer.push_back(nums);
            return;
        }

        for (int i = fixed; i < static_cast<int>(nums.size()); ++i) {
            std::swap(nums[fixed], nums[i]);
            dfs(nums, fixed + 1, answer);
            std::swap(nums[fixed], nums[i]);
        }
    }

public:
    std::vector<std::vector<int>> permute(std::vector<int>& nums) {
        std::vector<std::vector<int>> answer;
        dfs(nums, 0, answer);
        return answer;
    }
};
```

必须交换回来，否则下一条分支看到的数组已经被上一条分支修改。

**时间复杂度 $O(n\cdot n!)$，递归栈空间 $O(n)$。**
