# 51. N 皇后

题目：[LeetCode 51](https://leetcode.cn/problems/n-queens/description/)

源码：[51.n-皇后.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/51.n-皇后.cpp)

## 题面

在 `n × n` 棋盘上放置 `n` 个皇后，使任意两个皇后不在同一行、同一列或同一条对角线上，返回所有棋盘方案。

## 核心思路：每一层放置一行

递归到第 `row` 层时，只决定这一行的皇后放在哪一列，因此同行冲突天然避免。

另外维护三组占用状态：

```text
列：col
左上到右下对角线：row - col + n - 1
右上到左下对角线：row + col
```

同一条对角线上的格子具有相同的下标表达式。选择位置时标记三组状态，递归返回后撤销。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
private:
    void dfs(int row, int n, std::vector<std::string>& board,
             std::vector<bool>& columns,
             std::vector<bool>& diagonal1,
             std::vector<bool>& diagonal2,
             std::vector<std::vector<std::string>>& answer) {
        if (row == n) {
            answer.push_back(board);
            return;
        }

        for (int col = 0; col < n; ++col) {
            int d1 = row - col + n - 1;
            int d2 = row + col;
            if (columns[col] || diagonal1[d1] || diagonal2[d2]) continue;

            board[row][col] = 'Q';
            columns[col] = diagonal1[d1] = diagonal2[d2] = true;

            dfs(row + 1, n, board, columns, diagonal1, diagonal2, answer);

            board[row][col] = '.';
            columns[col] = diagonal1[d1] = diagonal2[d2] = false;
        }
    }

public:
    std::vector<std::vector<std::string>> solveNQueens(int n) {
        std::vector<std::vector<std::string>> answer;
        std::vector<std::string> board(n, std::string(n, '.'));
        std::vector<bool> columns(n, false);
        std::vector<bool> diagonal1(2 * n - 1, false);
        std::vector<bool> diagonal2(2 * n - 1, false);

        dfs(0, n, board, columns, diagonal1, diagonal2, answer);
        return answer;
    }
};
```

状态数组把“当前位置是否安全”的检查从扫描棋盘降为 $O(1)$。

**最坏时间复杂度约为 $O(n!)$，状态与递归栈占 $O(n)$，输出空间不计。**
