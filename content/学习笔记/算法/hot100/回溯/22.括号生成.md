# 22. 括号生成

题目：[LeetCode 22](https://leetcode.cn/problems/generate-parentheses/description/)

源码：[22.括号生成.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/22.括号生成.cpp)

## 题面

给定括号对数 `n`，返回所有有效的括号组合。

## 核心思路：只生成合法前缀

用 `leftUsed`、`rightUsed` 记录已经使用的左右括号数量：

- `leftUsed < n` 时可以加入左括号。
- `rightUsed < leftUsed` 时才能加入右括号，保证任何前缀中右括号都不会多于左括号。

这样在搜索过程中就剪掉非法分支，不需要生成后再验证。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
private:
    void dfs(int n, int leftUsed, int rightUsed,
             std::string& path, std::vector<std::string>& answer) {
        if (static_cast<int>(path.size()) == 2 * n) {
            answer.push_back(path);
            return;
        }

        if (leftUsed < n) {
            path.push_back('(');
            dfs(n, leftUsed + 1, rightUsed, path, answer);
            path.pop_back();
        }

        if (rightUsed < leftUsed) {
            path.push_back(')');
            dfs(n, leftUsed, rightUsed + 1, path, answer);
            path.pop_back();
        }
    }

public:
    std::vector<std::string> generateParenthesis(int n) {
        std::vector<std::string> answer;
        std::string path;
        dfs(n, 0, 0, path, answer);
        return answer;
    }
};
```

**搜索规模与有效答案数量有关，递归深度为 $2n$。**
