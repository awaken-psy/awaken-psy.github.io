# 17. 电话号码的字母组合

题目：[LeetCode 17](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/)

源码：[17.电话号码的字母组合.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/17.电话号码的字母组合.cpp)

## 题面

数字 `2~9` 各自对应若干字母。给定一串数字，返回所有可能的字母组合；空字符串返回空结果。

## 核心思路：每一层决定一个数字选哪个字母

递归参数 `index` 表示正在处理第几个数字。遍历该数字对应的所有字母：选择一个字母、处理下一位、撤销选择。

当 `index == digits.size()` 时，每一位都已经选择完，记录当前字符串。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
private:
    const std::vector<std::string> mapping = {
        "", "", "abc", "def", "ghi",
        "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    void dfs(const std::string& digits, int index,
             std::string& path, std::vector<std::string>& answer) {
        if (index == static_cast<int>(digits.size())) {
            answer.push_back(path);
            return;
        }

        const std::string& letters = mapping[digits[index] - '0'];
        for (char letter : letters) {
            path.push_back(letter);       // 选择
            dfs(digits, index + 1, path, answer);
            path.pop_back();             // 撤销
        }
    }

public:
    std::vector<std::string> letterCombinations(std::string digits) {
        if (digits.empty()) return {};

        std::vector<std::string> answer;
        std::string path;
        dfs(digits, 0, path, answer);
        return answer;
    }
};
```

`digits[index] - '0'` 把数字字符转换成对应整数下标。

**时间复杂度与输出数量成正比，递归深度为数字个数。**
