# 131. 分割回文串

题目：[LeetCode 131](https://leetcode.cn/problems/palindrome-partitioning/description/)

源码：[131.分割回文串.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/131.分割回文串.cpp)

## 题面

把字符串分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。

## 核心思路：枚举下一段在哪里结束

`start` 表示还没有分割的字符串起点。枚举结束位置 `end`：

- `s[start...end]` 是回文串时，把它加入当前方案，并从 `end + 1` 继续分割。
- 不是回文串时，这一段不能选择。

当 `start == s.size()` 时，整个字符串已经分割完，记录当前方案。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
private:
    bool isPalindrome(const std::string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) return false;
            ++left;
            --right;
        }
        return true;
    }

    void dfs(const std::string& s, int start,
             std::vector<std::string>& path,
             std::vector<std::vector<std::string>>& answer) {
        if (start == static_cast<int>(s.size())) {
            answer.push_back(path);
            return;
        }

        for (int end = start; end < static_cast<int>(s.size()); ++end) {
            if (!isPalindrome(s, start, end)) continue;

            path.push_back(s.substr(start, end - start + 1));
            dfs(s, end + 1, path, answer);
            path.pop_back();
        }
    }

public:
    std::vector<std::vector<std::string>> partition(std::string s) {
        std::vector<std::vector<std::string>> answer;
        std::vector<std::string> path;
        dfs(s, 0, path, answer);
        return answer;
    }
};
```

`substr(pos, count)` 从 `pos` 开始复制 `count` 个字符，因此长度是 `end - start + 1`。

**搜索规模为指数级，递归深度最多为字符串长度。**
