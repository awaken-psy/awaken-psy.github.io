# 79. 单词搜索

题目：[LeetCode 79](https://leetcode.cn/problems/word-search/description/)

源码：[79.单词搜索.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/79.单词搜索.cpp)

## 题面

判断给定单词能否由字符矩阵中相邻格子的字母依次组成。只能上下左右移动，同一个格子不能重复使用。

## 核心思路：从每个格子尝试 DFS

`index` 表示当前要匹配单词的第几个字符。位置越界、字符不同或格子已使用时，当前分支失败。

匹配成功后，临时把当前字符改成特殊标记，再搜索四个方向；返回前恢复原字符。这样直接使用棋盘记录访问状态，不需要额外 `visited` 数组。

## C++ 题解

```cpp
#include <string>
#include <vector>

class Solution {
private:
    bool dfs(std::vector<std::vector<char>>& board,
             const std::string& word, int row, int col, int index) {
        int rows = static_cast<int>(board.size());
        int cols = static_cast<int>(board[0].size());

        if (row < 0 || row >= rows || col < 0 || col >= cols) return false;
        if (board[row][col] != word[index]) return false;
        if (index == static_cast<int>(word.size()) - 1) return true;

        char saved = board[row][col];
        board[row][col] = '#';  // 当前路径中禁止再次使用

        bool found = dfs(board, word, row - 1, col, index + 1) ||
                     dfs(board, word, row + 1, col, index + 1) ||
                     dfs(board, word, row, col - 1, index + 1) ||
                     dfs(board, word, row, col + 1, index + 1);

        board[row][col] = saved;  // 恢复现场
        return found;
    }

public:
    bool exist(std::vector<std::vector<char>>& board, std::string word) {
        for (int row = 0; row < static_cast<int>(board.size()); ++row) {
            for (int col = 0; col < static_cast<int>(board[0].size()); ++col) {
                if (dfs(board, word, row, col, 0)) return true;
            }
        }
        return false;
    }
};
```

短路运算 `||` 会在某个方向成功后停止检查后续方向，但恢复棋盘的语句仍会执行。

设单词长度为 $L$，**最坏时间复杂度 $O(mn\cdot3^L)$，递归栈空间 $O(L)$。**
