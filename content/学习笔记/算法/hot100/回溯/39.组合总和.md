# 39. 组合总和

题目：[LeetCode 39](https://leetcode.cn/problems/combination-sum/description/)

源码：[39.组合总和.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/回溯/39.组合总和.cpp)

## 题面

给定互不相同的正整数数组 `candidates` 和目标值，找出所有和等于目标值的组合。每个数字可以重复使用，组合顺序不同不算新答案。

## 核心思路：用起点限制选择顺序

递归参数 `start` 表示本层只能从 `start` 及其后面选择，保证组合中的下标顺序不下降，避免同时产生 `[a,b]` 和 `[b,a]`。

选择 `candidates[i]` 后，下一层仍从 `i` 开始，因为当前数字允许重复使用。用剩余目标 `remain` 代替每次重新求和。

排序后，如果当前数字已经大于 `remain`，后面的数字也不可能选择，可以直接结束循环。

## C++ 题解

```cpp
#include <algorithm>
#include <vector>

class Solution {
private:
    void dfs(const std::vector<int>& candidates, int start, int remain,
             std::vector<int>& path,
             std::vector<std::vector<int>>& answer) {
        if (remain == 0) {
            answer.push_back(path);
            return;
        }

        for (int i = start; i < static_cast<int>(candidates.size()); ++i) {
            if (candidates[i] > remain) break;

            path.push_back(candidates[i]);
            // 仍传 i：同一个数字可以继续使用
            dfs(candidates, i, remain - candidates[i], path, answer);
            path.pop_back();
        }
    }

public:
    std::vector<std::vector<int>> combinationSum(
        std::vector<int>& candidates, int target) {
        std::sort(candidates.begin(), candidates.end());

        std::vector<std::vector<int>> answer;
        std::vector<int> path;
        dfs(candidates, 0, target, path, answer);
        return answer;
    }
};
```

`std::sort(begin, end)` 将 `[begin,end)` 中的元素升序排列。

**时间复杂度取决于搜索树和答案数量，递归深度最多约为 `target / 最小候选数`。**
