# 153. 寻找旋转排序数组中的最小值

题目：[LeetCode 153](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/description/)

源码：[153.寻找旋转排序数组中的最小值.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/153.寻找旋转排序数组中的最小值.cpp)

## 题面

一个元素互不相同的升序数组经过若干次旋转，返回其中的最小元素，要求时间复杂度为 $O(\log n)$。

- `[3,4,5,1,2]` 返回 `1`。
- `[4,5,6,7,0,1,2]` 返回 `0`。
- `[11,13,15,17]` 返回 `11`。

## 核心思路：用 `nums[right]` 判断最小值在哪边

始终保证最小值位于闭区间 `[left, right]` 中，比较 `nums[mid]` 和 `nums[right]`。

### `nums[mid] > nums[right]`

例如：

```text
[4,5,6,7,0,1,2]
       mid     right
```

`mid` 还在旋转点左边的较大部分，最小值一定在 `mid` 右侧：

```cpp
left = mid + 1;
```

### `nums[mid] < nums[right]`

`mid` 到 `right` 这一段已经有序，最小值不可能出现在 `mid` 右侧，但 `mid` 自己可能就是最小值：

```cpp
right = mid;
```

注意这里不能写 `right = mid - 1`，否则可能把真正的最小值 `mid` 排除。

由于题目保证元素互不相同，不会出现 `nums[mid] == nums[right]`，除非区间只剩一个元素；而循环条件 `left < right` 会在此之前结束。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    int findMin(std::vector<int>& nums) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;

        // 区间缩小到一个位置时结束
        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > nums[right]) {
                // 最小值严格位于 mid 右边
                left = mid + 1;
            } else {
                // 最小值位于 [left, mid]，mid 不能排除
                right = mid;
            }
        }

        return nums[left];
    }
};
```

这道题二分的不是某个目标值，而是最小值所在的区间。每次比较后都能排除一半位置。

**时间复杂度 $O(\log n)$，额外空间 $O(1)$。**
