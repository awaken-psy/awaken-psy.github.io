# 74. 搜索二维矩阵

题目：[LeetCode 74](https://leetcode.cn/problems/search-a-2d-matrix/description/)

源码：[74.搜索二维矩阵.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/74.搜索二维矩阵.cpp)

## 题面

给定一个 `m × n` 矩阵：

- 每一行从左到右非递减。
- 每一行的第一个数大于上一行的最后一个数。

判断 `target` 是否在矩阵中。

例如：

```text
matrix = [[1,3,5,7],
          [10,11,16,20],
          [23,30,34,60]]
```

`target = 3` 返回 `true`，`target = 13` 返回 `false`。

## 核心思路：把矩阵看成一维有序数组

由于下一行的第一个数大于上一行的最后一个数，按行连接整个矩阵后，仍然是有序数组：

```text
[1,3,5,7,10,11,16,20,23,30,34,60]
```

不需要真的创建这个数组。假设矩阵每行有 `n` 列，一维下标 `index` 对应：

```text
行号 = index / n
列号 = index % n
```

因此可以直接在虚拟区间 `[0, m * n - 1]` 上进行普通二分查找。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    bool searchMatrix(std::vector<std::vector<int>>& matrix, int target) {
        int rows = static_cast<int>(matrix.size());
        int cols = static_cast<int>(matrix[0].size());

        int left = 0;
        int right = rows * cols - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            // 把一维下标 mid 映射回矩阵坐标
            int row = mid / cols;
            int col = mid % cols;
            int value = matrix[row][col];

            if (value < target) {
                left = mid + 1;
            } else if (value > target) {
                right = mid - 1;
            } else {
                return true;
            }
        }

        return false;
    }
};
```

`/` 和 `%` 只是完成下标映射，并没有复制矩阵。

**时间复杂度 $O(\log(mn))$，额外空间 $O(1)$。**
