# 4. 寻找两个正序数组的中位数

题目：[LeetCode 4](https://leetcode.cn/problems/median-of-two-sorted-arrays/description/)

源码：[4.寻找两个正序数组的中位数.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/4.寻找两个正序数组的中位数.cpp)

## 题面

给定两个正序数组 `nums1` 和 `nums2`，返回两个数组合并后的中位数，要求时间复杂度为 $O(\log(m+n))$。

- `[1,3]` 和 `[2]` 的中位数是 `2`。
- `[1,2]` 和 `[3,4]` 的中位数是 `(2+3)/2 = 2.5`。

两个数组可以有一个为空，但总长度至少为 1。

## 核心思路：二分寻找正确的分割线

真正合并数组需要 $O(m+n)$。这道题要在两个数组中各画一条分割线，使左半部分正好包含合并数组中较小的一半。

设较短数组为 `A`，长度为 `m`；较长数组为 `B`，长度为 `n`。分割线左边分别取 `i` 个和 `j` 个元素：

```text
A: [A 的左半部分 | A 的右半部分]
	  i 
B: [B 的左半部分 | B 的右半部分]
      j
```

左半部分需要包含：

```text
half = (m + n + 1) / 2
```

个元素，所以选择 `i` 后，`j` 随之确定：

```text
j = half - i
```

多出来的 `+1` 会让总长度为奇数时，左半部分比右半部分多一个元素，中位数就直接是左半部分最大值。

### 怎样判断分割线正确

记分割线两侧的四个数为：

```text
Aleft  = A[i - 1]    Aright = A[i]
Bleft  = B[j - 1]    Bright = B[j]
```

正确分割需要满足：

```text
Aleft <= Bright
Bleft <= Aright
```

也就是左半部分的所有数都不大于右半部分的所有数。

- `Aleft > Bright`：A 的分割线太靠右，需要减小 `i`。
- `Bleft > Aright`：A 的分割线太靠左，需要增大 `i`。
- 两个条件都满足：找到正确分割。

只在较短数组上二分，可以保证 `j` 不会越出较长数组，复杂度也是最小的。

### 如何得到中位数

- 总长度为奇数：左半部分比右半部分多一个，中位数是 `max(Aleft, Bleft)`。
- 总长度为偶数：中位数是 `(max(Aleft, Bleft) + min(Aright, Bright)) / 2`。

当分割线位于数组最左或最右时，缺少的边界分别用负无穷和正无穷代替。

## C++ 题解

```cpp
#include <algorithm>
#include <climits>
#include <vector>

class Solution {
public:
    double findMedianSortedArrays(std::vector<int>& nums1,
                                  std::vector<int>& nums2) {
        // 始终在较短数组上二分
        if (nums1.size() > nums2.size()) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = static_cast<int>(nums1.size());
        int n = static_cast<int>(nums2.size());
        int half = (m + n + 1) / 2;

        int left = 0;
        int right = m;

        while (left <= right) {
            int i = left + (right - left) / 2;
            int j = half - i;

            // 分割线位于数组边缘时，用无穷值补齐边界
            int Aleft = (i == 0) ? INT_MIN : nums1[i - 1];
            int Aright = (i == m) ? INT_MAX : nums1[i];
            int Bleft = (j == 0) ? INT_MIN : nums2[j - 1];
            int Bright = (j == n) ? INT_MAX : nums2[j];

            if (Aleft > Bright) {
                // nums1 左边取多了，分割线左移
                right = i - 1;
            } else if (Bleft > Aright) {
                // nums1 左边取少了，分割线右移
                left = i + 1;
            } else {
                // 左半部分的所有数都不大于右半部分的所有数
                int leftMax = std::max(Aleft, Bleft);

                if ((m + n) % 2 == 1) {
                    return leftMax;
                }

                int rightMin = std::min(Aright, Bright);
                return (static_cast<double>(leftMax) + rightMin) / 2.0;
            }
        }

        // 输入数组有序时一定能找到合法分割
        return 0.0;
    }
};
```

这道题最难的地方不是二分代码，而是把搜索对象从“某个值”改成“两数组的分割位置”。

**时间复杂度 $O(\log\min(m,n))$，额外空间 $O(1)$。**
