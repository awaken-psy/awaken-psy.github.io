# 35. 搜索插入位置

题目：[LeetCode 35](https://leetcode.cn/problems/search-insert-position/description/)

源码：[35.搜索插入位置.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/35.搜索插入位置.cpp)

## 题面

给定一个无重复元素的升序数组 `nums` 和目标值 `target`：

- 如果 `target` 存在，返回它的下标。
- 如果不存在，返回它按顺序插入的位置。

要求时间复杂度为 $O(\log n)$。

例如：

- `nums = [1,3,5,6], target = 5`，返回 `2`。
- `nums = [1,3,5,6], target = 2`，返回 `1`。
- `nums = [1,3,5,6], target = 7`，返回 `4`。

## 核心思路：找第一个大于等于 `target` 的位置

无论 `target` 是否存在，答案都是：

```text
数组中第一个满足 nums[i] >= target 的位置
```

如果所有数都小于 `target`，答案就是数组末尾的后一位 `n`。

采用左闭右开的搜索区间 `[left, right)`，初始为 `[0, n)`：

- `nums[mid] < target`：`mid` 不可能是答案，令 `left = mid + 1`。
- `nums[mid] >= target`：`mid` 可能是答案，但左边可能还有更早的位置，令 `right = mid`。

循环结束时 `left == right`，这个位置就是答案。这也是 C++ `std::lower_bound` 的含义。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    int searchInsert(std::vector<int>& nums, int target) {
        // 在左闭右开区间 [left, right) 中寻找答案
        int left = 0;
        int right = static_cast<int>(nums.size());

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                // mid 以及 mid 左边都不可能是答案
                left = mid + 1;
            } else {
                // mid 可能是第一个 >= target 的位置
                right = mid;
            }
        }

        return left;
    }
};
```

这里不用单独判断是否找到了 `target`：找到时返回它的下标，找不到时 `left` 自然停在插入位置。

**时间复杂度 $O(\log n)$，额外空间 $O(1)$。**
