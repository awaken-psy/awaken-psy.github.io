# 34. 在排序数组中查找元素的第一个和最后一个位置

题目：[LeetCode 34](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/)

源码：[34.在排序数组中查找元素的第一个和最后一个位置.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/34.在排序数组中查找元素的第一个和最后一个位置.cpp)

## 题面

给定一个非递减数组 `nums` 和目标值 `target`，返回 `target` 第一次和最后一次出现的位置。不存在则返回 `[-1,-1]`，要求时间复杂度为 $O(\log n)$。

例如：

- `[5,7,7,8,8,10]`，`target = 8`，返回 `[3,4]`。
- `[5,7,7,8,8,10]`，`target = 6`，返回 `[-1,-1]`。

## 核心思路：分别找两条分界线

普通二分找到任意一个 `target` 后，再向两边遍历可能退化成 $O(n)$。应该直接进行两次二分：

1. 找第一个 `>= target` 的位置，记为 `first`。
2. 找第一个 `> target` 的位置，记为 `afterLast`。

如果 `first` 越界或 `nums[first] != target`，说明目标不存在；否则最后一个位置就是 `afterLast - 1`。

例如 `[5,7,7,8,8,10]` 中：

```text
第一个 >= 8 的位置：3
第一个 > 8  的位置：5
答案：[3, 5 - 1] = [3, 4]
```

两次二分只差一个等号：

- 找第一个 `>= target`：遇到 `nums[mid] >= target` 时收缩右边界。
- 找第一个 `> target`：遇到 `nums[mid] > target` 时收缩右边界。

## C++ 题解

```cpp
#include <vector>

class Solution {
private:
    // 返回第一个 >= target 的位置
    int lowerBound(const std::vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size());

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }

    // 返回第一个 > target 的位置
    int upperBound(const std::vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size());

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] <= target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }

public:
    std::vector<int> searchRange(std::vector<int>& nums, int target) {
        int first = lowerBound(nums, target);

        // lowerBound 也可能停在数组末尾，必须先检查越界
        if (first == static_cast<int>(nums.size()) || nums[first] != target) {
            return {-1, -1};
        }

        int afterLast = upperBound(nums, target);
        return {first, afterLast - 1};
    }
};
```

C++ 标准库中的 `std::lower_bound` 和 `std::upper_bound` 分别对应上面的两个函数。

**时间复杂度 $O(\log n)$，额外空间 $O(1)$。**
