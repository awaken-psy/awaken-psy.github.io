# 33. 搜索旋转排序数组

题目：[LeetCode 33](https://leetcode.cn/problems/search-in-rotated-sorted-array/description/)

源码：[33.搜索旋转排序数组.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/二分查找/33.搜索旋转排序数组.cpp)

## 题面

一个元素互不相同的升序数组经过旋转，例如：

```text
[0,1,2,4,5,6,7] -> [4,5,6,7,0,1,2]
```

给定旋转后的数组和 `target`，返回目标下标；不存在则返回 `-1`。要求时间复杂度为 $O(\log n)$。

## 核心思路：每次判断哪一半有序

旋转数组整体可能无序，但以 `mid` 分开后，**至少有一半一定有序**。

### 左半部分有序

```cpp
nums[left] <= nums[mid]
```

如果目标位于有序范围 `[nums[left], nums[mid])` 中，就去左半部分；否则去右半部分。

### 右半部分有序

否则右半部分 `[mid, right]` 有序。如果目标位于 `(nums[mid], nums[right]]` 中，就去右半部分；否则去左半部分。

判断左半部分有序时必须写 `<=`。当区间只剩一个元素时 `left == mid`，这个单元素区间也应该被视为有序。

以 `[4,5,6,7,0,1,2]`、`target = 0` 为例：

1. `mid` 指向 7，左半部分 `[4,5,6,7]` 有序，但 0 不在其中，搜索右半部分。
2. 新的 `mid` 指向 1，右侧 `[1,2]` 有序，但 0 不在其中，搜索左半部分。
3. 找到 0。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    int search(std::vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            if (nums[left] <= nums[mid]) {
                // 左半部分 [left, mid] 有序
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 右半部分 [mid, right] 有序
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return -1;
    }
};
```

这道题不需要先找旋转点。每次确定有序的一半，再判断目标是否在这个有序范围内即可。

**时间复杂度 $O(\log n)$，额外空间 $O(1)$。**
