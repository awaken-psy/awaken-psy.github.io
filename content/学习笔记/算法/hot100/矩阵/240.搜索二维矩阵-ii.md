# 240. 搜索二维矩阵 II

题目：[LeetCode 240](https://leetcode.cn/problems/search-a-2d-matrix-ii/description/)

源码：[240.搜索二维矩阵-ii.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/矩阵/240.搜索二维矩阵-ii.cpp)

## 题面

矩阵每行从左到右有序，每列从上到下有序，判断是否存在目标值 `target`。

```text
matrix =
 1  4  7 11 15
 2  5  8 12 19
 3  6  9 16 22
10 13 14 17 24
18 21 23 26 30

target = 5  → true
target = 20 → false
```

范围：`1 <= m, n <= 300`，元素值和目标值均在 `[-10^9, 10^9]` 内。

## 核心思路：从右上角出发，每次排除一行或一列

从 `(row = 0, col = n - 1)` 开始。当前未排除的区域是第 `row` 行及以下、第 `col` 列及左侧。

- **当前值等于目标**：找到，返回 `true`。
- **当前值大于目标**：这一列下面的元素也都大于目标，整列排除，`col--`。
- **当前值小于目标**：这一行左边的元素也都小于目标，整行排除，`row++`。

右上角同时是“当前行的最大值”和“当前列的最小值”，因此一次比较就能决定排除哪一边。

例如查找 5，访问路径为 `15 → 11 → 7 → 4 → 5`。行越过底部或列越过左边界，就说明不存在目标。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    bool searchMatrix(std::vector<std::vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();
        int row = 0;
        int col = n - 1;

        while (row < m && col >= 0) {
            if (matrix[row][col] == target) return true;

            if (matrix[row][col] > target) {
                --col;  // 排除当前列。
            } else {
                ++row;  // 排除当前行。
            }
        }
        return false;
    }
};
```

**时间 `O(m+n)`，额外空间 `O(1)`。** 指针只向左或向下移动，不修改输入矩阵。

注意：本题只保证每行、每列各自有序，**不保证下一行第一个数大于上一行最后一个数**，因此不能直接把矩阵拉平成一个整体有序数组做二分。
