# 73. 矩阵置零

题目：[LeetCode 73](https://leetcode.cn/problems/set-matrix-zeroes/description/)

源码：[73.矩阵置零.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/矩阵/73.矩阵置零.cpp)

## 题面

如果矩阵中某个元素原本为 0，就把它所在的整行、整列都设为 0，直接修改输入矩阵。

```text
输入：[[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]

输入：[[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

范围：`1 <= m, n <= 200`，元素可以是任意 32 位有符号整数。题面进阶要求把额外空间降到 `O(1)`。

## 核心思路：先记录，再修改

**不能一遇到 0 就立即清空它所在的行和列**，否则后面可能把刚生成的 0 也当成原始的 0，导致清零范围继续扩散。

沿用源码的两趟扫描：

1. 第一趟只记录：`zeroRow[i]` 表示第 `i` 行原本有 0，`zeroCol[j]` 表示第 `j` 列原本有 0。
2. 第二趟再修改：只要 `zeroRow[i] || zeroCol[j]` 成立，就把 `matrix[i][j]` 置零。

这里用逻辑或，因为行、列中**任意一个**需要清零，这个位置就必须变成 0。

## C++ 题解

```cpp
#include <vector>

class Solution {
public:
    void setZeroes(std::vector<std::vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        std::vector<bool> zeroRow(m, false);
        std::vector<bool> zeroCol(n, false);

        // 第一趟不修改原矩阵，只记录原始的 0。
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (matrix[i][j] == 0) {
                    zeroRow[i] = true;
                    zeroCol[j] = true;
                }
            }
        }

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (zeroRow[i] || zeroCol[j]) {
                    matrix[i][j] = 0;
                }
            }
        }
    }
};
```

**时间 `O(mn)`，额外空间 `O(m+n)`。** 正文修改的是输入矩阵，但仍使用了辅助标记数组；常数空间版本见末尾。

> [!example]- 进阶写法（后续复习）：用第一行、第一列保存标记
> 把两个标记数组借放在原矩阵里：`matrix[i][0] == 0` 表示第 `i` 行要清零，`matrix[0][j] == 0` 表示第 `j` 列要清零。
>
> 第一行、第一列还需要保存自身原本是否含 0。它们共用 `matrix[0][0]`，不能靠这个位置同时表达两件事，所以提前用两个布尔变量分别记录。
>
> 顺序是：**记录首行首列 → 用内部元素设置标记 → 根据标记清零内部 → 最后处理首行首列。** 不能提前清空作为标记的首行首列。
>
> ```cpp
> #include <vector>
>
> class Solution {
> public:
>     void setZeroes(std::vector<std::vector<int>>& matrix) {
>         int m = matrix.size();
>         int n = matrix[0].size();
>         bool firstRowZero = false;
>         bool firstColZero = false;
>
>         for (int j = 0; j < n; ++j) {
>             if (matrix[0][j] == 0) firstRowZero = true;
>         }
>         for (int i = 0; i < m; ++i) {
>             if (matrix[i][0] == 0) firstColZero = true;
>         }
>
>         for (int i = 1; i < m; ++i) {
>             for (int j = 1; j < n; ++j) {
>                 if (matrix[i][j] == 0) {
>                     matrix[i][0] = 0;
>                     matrix[0][j] = 0;
>                 }
>             }
>         }
>
>         // 标记区保持不动，先处理内部。
>         for (int i = 1; i < m; ++i) {
>             for (int j = 1; j < n; ++j) {
>                 if (matrix[i][0] == 0 || matrix[0][j] == 0) {
>                     matrix[i][j] = 0;
>                 }
>             }
>         }
>
>         if (firstRowZero) {
>             for (int j = 0; j < n; ++j) matrix[0][j] = 0;
>         }
>         if (firstColZero) {
>             for (int i = 0; i < m; ++i) matrix[i][0] = 0;
>         }
>     }
> };
> ```
>
> **时间 `O(mn)`，额外空间 `O(1)`。** 只用两个额外布尔变量，满足题目进阶要求。
