# 48. 旋转图像

题目：[LeetCode 48](https://leetcode.cn/problems/rotate-image/description/)

源码：[48.旋转图像.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/矩阵/48.旋转图像.cpp)

## 题面

把 `n × n` 方阵顺时针旋转 90°。必须直接修改原矩阵，不能另外创建一个矩阵来保存旋转结果。

```text
输入：             输出：
1 2 3              7 4 1
4 5 6              8 5 2
7 8 9              9 6 3
```

范围：`1 <= n <= 20`，元素值为 `-1000~1000`。

## 核心思路：转置，再反转每一行

顺时针旋转后，原来的位置 `(i, j)` 应该变成 `(j, n - 1 - i)`。把这个变化拆成两步：

```text
沿主对角线转置：(i, j) → (j, i)
每一行左右反转：(j, i) → (j, n - 1 - i)
```

例如：

```text
原矩阵       转置后       每行反转后
1 2 3        1 4 7        7 4 1
4 5 6   →    2 5 8   →    8 5 2
7 8 9        3 6 9        9 6 3
```

**转置时只遍历主对角线的一侧**，每对元素交换一次。若整个矩阵都遍历，交换 `(i,j)` 和 `(j,i)` 后，又会在另一位置把它们换回来。对角线元素不用动。

## C++ 题解

```cpp
#include <algorithm>
#include <utility>
#include <vector>

class Solution {
public:
    void rotate(std::vector<std::vector<int>>& matrix) {
        int n = matrix.size();

        // 只遍历严格上三角，完成转置。
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                std::swap(matrix[i][j], matrix[j][i]);
            }
        }

        // 转置后，每一行再左右反转。
        for (int i = 0; i < n; ++i) {
            std::reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
```

## STL：reverse 操作的是哪个范围

`std::reverse(first, last)` 原地反转区间 `[first, last)`，需要 `<algorithm>`，不会返回一个新数组。[标准库说明](https://eel.is/c++draft/alg.reverse)

这里的 `matrix[i].begin()`、`matrix[i].end()` 指定**第 `i` 行内部的元素**。如果写成 `reverse(matrix.begin(), matrix.end())`，反转的是各行的排列顺序，效果是上下翻转。

**时间 `O(n²)`，额外空间 `O(1)`。**
