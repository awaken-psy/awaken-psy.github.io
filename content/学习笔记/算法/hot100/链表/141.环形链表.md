# 141. 环形链表

题目：[LeetCode 141](https://leetcode.cn/problems/linked-list-cycle/description/)

源码：[141.环形链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/141.环形链表.cpp)

## 题面

判断沿着 `next` 是否会再次到达已经经过的节点：有环返回 `true`，否则返回 `false`。

- `[3,2,0,-4]`，尾节点接到索引 1 → `true`。
- `[1,2]`，尾节点接到索引 0 → `true`。
- `[1]`，尾节点指向空 → `false`。

题面中的 `pos` 仅用来描述尾节点连接的位置，不会作为函数参数。节点数为 `0~10000`，节点值为 `-100000~100000`；题面进阶要求 `O(1)` 空间。

## 核心思路：快慢指针追及

两个指针都从 `head` 出发：`slow` 每次走一步，`fast` 每次走两步。

- **无环**：`fast` 最终会走到空节点，结束循环。
- **有环**：两个指针进入环后，`fast` 每轮相对 `slow` 多走一步，因此会在环内相遇。

判断相遇比较的是**节点地址**，不是节点值。要先移动再比较，不能把初始时两个指针都在 `head` 当成有环。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    bool hasCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // fast 要走两步，先保证能访问 fast->next。
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        return false;
    }
};
```

空链表和无环的单节点链表会直接返回 `false`；节点指向自身时，移动后两个指针仍指向它，返回 `true`。

**时间 `O(n)`，额外空间 `O(1)`。** 这份主解法已满足题目进阶要求，且不会修改链表。
