# 24. 两两交换链表中的节点

题目：[LeetCode 24](https://leetcode.cn/problems/swap-nodes-in-pairs/description/)

源码：[24.两两交换链表中的节点.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/24.两两交换链表中的节点.cpp)

## 题面

两两交换链表中相邻的节点，返回新头节点。**只能改连接，不能交换节点里的值。** 最后剩下单个节点时保持不动。

- `[1,2,3,4]` → `[2,1,4,3]`。
- `[]` → `[]`。
- `[1]` → `[1]`。

链表长度为 `0~100`，节点值为 `0~100`。

## 核心思路

`prev` 始终指向当前这一对节点的前驱。记这一对为 `first`、`second`，需要把：

```text
prev → first → second → rest
```

改为：

```text
prev → second → first → rest
```

对应三次改线：

```cpp
first->next = second->next;  // first 接上后面的 rest。
second->next = first;
prev->next = second;
```

**先接好 `rest`，再改变 `second->next`**，否则可能丢失后半段入口。交换完成后，`first` 变成这对节点的尾部，让 `prev = first`，继续处理下一对。

头部放 `dummy`，第一对也能统一处理。循环条件检查剩下至少两个节点，空链表和奇数长度自然被覆盖。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode dummy(0, head);
        ListNode* prev = &dummy;

        while (prev->next && prev->next->next) {
            ListNode* first = prev->next;
            ListNode* second = first->next;

            first->next = second->next;
            second->next = first;
            prev->next = second;

            prev = first;  // 交换后的尾节点，也是下一对的前驱。
        }
        return dummy.next;
    }
};
```

**时间 `O(n)`，额外空间 `O(1)`。**
