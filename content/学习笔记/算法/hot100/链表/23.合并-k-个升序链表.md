# 23. 合并 K 个升序链表

题目：[LeetCode 23](https://leetcode.cn/problems/merge-k-sorted-lists/description/)

源码：[23.合并-k-个升序链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/23.合并-k-个升序链表.cpp)

## 题面

给定 `k` 条已经按非递减顺序排列的链表，将它们合并成一条有序链表。

- `[[1,4,5],[1,3,4],[2,6]]` → `[1,1,2,3,4,4,5,6]`。
- `[]` → `[]`。
- `[[]]` → `[]`。

`0 <= k <= 10000`，每条链表长度不超过 500，总节点数不超过 10000，节点值为 `-10000~10000`。

## 核心思路：把两条链表的合并重复使用

先复用「21. 合并两个有序链表」的函数。若总是把下一条链表合并到越来越长的结果中，已有节点会被反复扫描，最坏需要 `O(kN)` 时间，`N` 为总节点数。

改成**每一轮两两合并，下一轮再合并这些结果**：

```text
初始：L0        L1        L2        L3
第1轮：   L01                 L23
第2轮：            L0123
```

用 `step` 表示当前每组包含多少条原始链表，从 1 开始，每轮翻倍：

- `step = 1`：合并 `lists[0]` 与 `lists[1]`，`lists[2]` 与 `lists[3]`……
- `step = 2`：合并 `lists[0]` 与 `lists[2]`……
- `step = 4`：合并 `lists[0]` 与 `lists[4]`……

每组的合并结果放回该组第一个位置。没有配对对象的组保留到下一轮，最后答案就在 `lists[0]`。

## C++ 题解

代码使用题目提供的 `ListNode` 定义，直接重连原节点。

```cpp
#include <vector>

class Solution {
private:
    ListNode* mergeTwo(ListNode* a, ListNode* b) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        while (a && b) {
            if (a->val <= b->val) {
                tail->next = a;
                a = a->next;
            } else {
                tail->next = b;
                b = b->next;
            }
            tail = tail->next;
        }
        tail->next = a ? a : b;
        return dummy.next;
    }

public:
    ListNode* mergeKLists(std::vector<ListNode*>& lists) {
        int k = lists.size();
        if (k == 0) return nullptr;

        for (int step = 1; step < k; step *= 2) {
            for (int i = 0; i + step < k; i += 2 * step) {
                // 只在右侧还有一组时合并。
                lists[i] = mergeTwo(lists[i], lists[i + step]);
            }
        }
        return lists[0];
    }
};
```

每轮处理至多 `N` 个节点，轮数为 `O(log k)`。**时间 `O(k + N log(k+1))`，额外空间 `O(1)`**；写上 `k` 和 `log(k+1)` 也涵盖空链表和 `k <= 1` 的情况，通常简写为 `O(N log k)`。

这里利用输入数组存放每轮结果，会修改 `lists` 中的头指针以及原节点的连接关系。

> [!example]- 进阶写法（后续复习）：最小堆 + 自定义比较器
> 每条链表当前的头节点都是该链表剩余部分的最小值。把这些头节点放进最小堆，每次取出全局最小的一个，再把它的后继放进去。
>
> 堆中每条链表最多保留一个候选节点，大小不超过 `k`。不需要一次把所有节点都放入堆。
>
> ```cpp
> #include <queue>
> #include <vector>
>
> class Solution {
> private:
>     struct Compare {
>         bool operator()(ListNode* a, ListNode* b) const {
>             return a->val > b->val;  // 值越大，优先级越低。
>         }
>     };
>
> public:
>     ListNode* mergeKLists(std::vector<ListNode*>& lists) {
>         std::priority_queue<ListNode*, std::vector<ListNode*>, Compare> heap;
>         int k = lists.size();
>         for (int i = 0; i < k; ++i) {
>             if (lists[i]) heap.push(lists[i]);
>         }
>
>         ListNode dummy(0);
>         ListNode* tail = &dummy;
>         while (!heap.empty()) {
>             ListNode* node = heap.top();
>             heap.pop();
>             if (node->next) heap.push(node->next);
>
>             tail->next = node;
>             tail = node;
>         }
>         tail->next = nullptr;
>         return dummy.next;
>     }
> };
> ```
>
> **STL 用法：**
>
> - `priority_queue<元素类型, 底层容器, 比较器>`：这里存节点指针，用 `vector` 存储，并按节点值比较。
> - `Compare::operator()` 让比较器对象可以像函数一样被调用。返回 `a->val > b->val`，表示值较大的 `a` 优先级较低，因此较小的值在堆顶。不能直接使用指针的默认比较来比较节点值。
> - `top()` 读取堆顶；`pop()` 只移除、不返回堆顶，所以要先 `top()` 再 `pop()`；移除指针不会删除它指向的节点。
> - `push()`、`pop()` 为对数复杂度，`top()` 为常数复杂度。[标准库说明](https://eel.is/c++draft/priority.queue)
>
> **时间 `O(k + N log(k+1))`，额外空间 `O(k)`。** 与正文同一时间复杂度量级，但需要维护堆，并不比正文更省空间。
