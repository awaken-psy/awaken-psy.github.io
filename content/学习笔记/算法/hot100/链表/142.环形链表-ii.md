# 142. 环形链表 II

题目：[LeetCode 142](https://leetcode.cn/problems/linked-list-cycle-ii/description/)

源码：[142.环形链表-ii.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/142.环形链表-ii.cpp)

## 题面

返回链表的入环节点；无环返回 `nullptr`。不能修改链表。

- `[3,2,0,-4]`，尾节点接索引 1 → 返回索引 1 的节点。
- `[1,2]`，尾节点接索引 0 → 返回头节点。
- `[1]`，无环 → `nullptr`。

`pos` 只用于展示，不是函数参数。节点数为 `0~10000`，节点值为 `-100000~100000`；题面进阶要求 `O(1)` 空间。

## 核心思路：先相遇，再找入口

先按「141. 环形链表」的方法，让 `slow` 一次走一步、`fast` 一次走两步。

**相遇点不一定是入口。** 相遇后，让一个指针回到 `head`，另一个留在相遇点，随后都一次走一步；再次相遇的位置就是入口。

为什么成立？设：

- `a`：从头节点到入口的距离。
- `b`：沿环从入口到相遇点的距离。
- `r`：环长。

相遇时，快指针比慢指针多走了整数圈，而快指针的路程又是慢指针的两倍。因此慢指针走过的总路程是 `r` 的整数倍，去掉它可能走过的整圈，就有：

```text
(a + b) % r == 0
```

所以从相遇点再走 `a` 步，正好回到入口；从头节点走 `a` 步也到入口。在到达入口之前，头部出发的指针还在环外，不可能与另一个指针相遇，因此再次相遇的位置就是入口。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                ListNode* p = head;
                // 两个指针现在都一次走一步。
                while (p != slow) {
                    p = p->next;
                    slow = slow->next;
                }
                return p;
            }
        }
        return nullptr;  // 快指针到达链表末尾，说明无环。
    }
};
```

把找入口的逻辑放在确认相遇的分支中，可以避免把“遍历结束”误判为“已经相遇”。若入口就是头节点，第二阶段不需要再移动。

**时间 `O(n)`，额外空间 `O(1)`。** 主解法已满足进阶要求，不修改节点值或连接。
