# 138. 随机链表的复制

题目：[LeetCode 138](https://leetcode.cn/problems/copy-list-with-random-pointer/description/)

源码：[138.随机链表的复制.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/138.随机链表的复制.cpp)

## 题面

每个节点除了 `val`、`next`，还有一个可以指向链表中任意节点或空节点的 `random`。返回整条链表的**深拷贝**：所有节点都要新建，复制后的 `next`、`random` 不能指回原链表。

输入示例用 `[val, random_index]` 表示节点；索引只是展示方式，函数实际收到的是头指针。

- `[[7,null],[13,0],[11,4],[10,2],[1,0]]` → 结构相同的一条新链表。
- `[[1,1],[2,1]]` → 两个新节点的 `random` 都指向新的第二个节点。
- `[[3,null],[3,0],[3,null]]` → 即使值相同，也必须复制成三个不同的节点。

节点数为 `0~1000`，节点值为 `-10000~10000`。

## 核心思路：先建节点，再连指针

难点是复制 `random` 时，它的目标节点可能还没遍历到。用哈希表保存对应关系：

```text
原节点地址 → 对应的新节点地址
```

分两趟处理：

1. 遍历原链表，为每个原节点创建新节点，记录到 `copies`。
2. 再遍历一次，用映射连接新节点的 `next` 和 `random`。

例如原来 `A.random = B`，复制后就应该是 `copies[A]->random = copies[B]`。

**哈希表的键必须是节点地址，不能用节点值**，因为不同节点可能存着相同的值。提前记录 `nullptr → nullptr`，可以统一处理空指针和空链表。

## C++ 题解

代码使用题目提供的 `Node` 定义，包含 `val`、`next`、`random` 三个成员。

```cpp
#include <unordered_map>

class Solution {
public:
    Node* copyRandomList(Node* head) {
        std::unordered_map<Node*, Node*> copies;
        copies[nullptr] = nullptr;

        // 第一趟：只创建节点，保证之后每个目标都能查到。
        for (Node* p = head; p; p = p->next) {
            copies[p] = new Node(p->val);
        }

        // 第二趟：所有连接都指向新节点。
        for (Node* p = head; p; p = p->next) {
            copies[p]->next = copies[p->next];
            copies[p]->random = copies[p->random];
        }
        return copies[head];
    }
};
```

## STL：unordered_map 的键可以是指针

`unordered_map<Node*, Node*>` 的键和值都是指针，`copies[p]` 取的是原节点 `p` 对应的新节点地址，不是复制 `p` 本身。

`operator[]` 遇到不存在的键会插入默认值；对这里的指针类型，默认值是空指针。本解法先建齐节点并显式记录空指针映射，再读取连接关系，避免把“尚未创建目标节点”误当成正常结果。[标准库说明](https://eel.is/c++draft/unord.map.elem)

**平均时间 `O(n)`，辅助哈希表占 `O(n)` 空间；输出还需新建 `n` 个节点。** 原链表保持不变。
