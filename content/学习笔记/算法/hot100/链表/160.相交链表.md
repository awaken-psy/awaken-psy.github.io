# 160. 相交链表

题目：[LeetCode 160](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/)

源码：[160.相交链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/160.相交链表.cpp)

## 题面

返回两个无环单链表相交的第一个节点；不相交则返回 `nullptr`。不能改变原链表结构。

**相交指的是同一个节点地址，不是两个节点的值相同。** 相交之后，后续节点都会是共同的一段。

- A 的独占部分为 `[4,1]`，B 为 `[5,6,1]`，共同接到同一段 `[8,4,5]` → 返回共同的节点 8。
- A 的独占部分为 `[1,9,1]`，B 为 `[3]`，共同接到同一段 `[2,4]` → 返回共同的节点 2。
- A 为 `[2,6,4]`，B 为 `[1,5]`，节点全部独立 → 返回 `nullptr`。

两条链表长度为 `1~30000`，节点值为 `1~100000`。进阶要求 `O(m+n)` 时间和 `O(1)` 空间。

## 核心思路：交换起点，抵消长度差

两个指针分别从 A、B 出发：

- `p` 走完 A 后，改从 B 的头继续走。
- `q` 走完 B 后，改从 A 的头继续走。

设 A、B 的独占部分长度为 `a、b`，公共部分长度为 `c`。如果没有提前相遇，换表后到达交点前，它们经过的节点段分别为：

```text
p：A 独占 a + 公共 c + B 独占 b
q：B 独占 b + 公共 c + A 独占 a
```

总长度相同，因此消除了最初的长度差，会在公共部分入口相遇。若没有公共部分，则两者走完 A、B 后同时到达 `nullptr`。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        ListNode* p = headA;
        ListNode* q = headB;
        while (p != q) {
            p = p ? p->next : headB;
            q = q ? q->next : headA;
        }
        return p;
    }
};
```

**只改变指针变量的指向，不要把尾节点的 `next` 真的接到另一条链表上。** 后者会修改结构，甚至制造环。这也正是你源码注释中错误写法的问题。

`p == q` 可能表示遇到了相交节点，也可能表示两者都为空；直接返回 `p` 即可。

**时间 `O(m+n)`，额外空间 `O(1)`。** 主解法已满足题目进阶要求。
