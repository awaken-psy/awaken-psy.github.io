# 148. 排序链表

题目：[LeetCode 148](https://leetcode.cn/problems/sort-list/description/)

源码：[148.排序链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/148.排序链表.cpp)

## 题面

将链表按非递减顺序排序，返回排序后的头节点。

- `[4,2,1,3]` → `[1,2,3,4]`。
- `[-1,5,3,4,0]` → `[-1,0,3,4,5]`。
- `[]` → `[]`。

节点数为 `0~50000`，节点值为 `-100000~100000`。进阶要求 `O(n log n)` 时间和 `O(1)` 额外空间。

## 核心思路：归并排序

链表不支持按下标快速访问，但很适合拆分、拼接。因此用归并排序：

1. 快慢指针找到前半段的尾节点，把链表断成两半。
2. 递归排序左右两半。
3. 用「21. 合并两个有序链表」的方法合并。

空链表或只有一个节点时，直接返回。

```text
[4,2,1,3]
    ↓ 拆分并分别排序
[2,4] + [1,3]
    ↓ 合并
[1,2,3,4]
```

**切分后必须执行 `slow->next = nullptr`。** 只保存右半段入口而不断链，左半段仍包含后半段，递归规模就可能不缩小。

代码让 `fast` 从 `head->next` 出发，保证 `slow` 停在前半段末尾；尤其是两个节点时，可以正确拆成两个单节点。

## C++ 题解

代码使用题目提供的 `ListNode` 定义，复用原节点。

```cpp
class Solution {
private:
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        while (a && b) {
            if (a->val <= b->val) {
                tail->next = a;
                a = a->next;
            } else {
                tail->next = b;
                b = b->next;
            }
            tail = tail->next;
        }
        tail->next = a ? a : b;
        return dummy.next;
    }

public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;

        ListNode* slow = head;
        ListNode* fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }

        ListNode* right = slow->next;
        slow->next = nullptr;  // 必须先断开，再分别递归。
        ListNode* left = sortList(head);
        right = sortList(right);
        return merge(left, right);
    }
};
```

**时间 `O(n log n)`，额外空间 `O(log n)`。** 归并本身只需要常数空间，但递归调用栈不能忽略。

> [!example]- 进阶写法（后续复习）：自底向上归并，O(1) 空间
> 不再递归拆分，而是先合并长度为 1 的相邻段，再合并长度为 2、4、8……的相邻段。与「23. 合并 K 个升序链表」的逐轮合并类似。
>
> `cut(head, size)` 负责截取一段并返回剩余部分；每次先保存后续入口，再合并当前两段。`mergeAfter` 把结果接在已有尾部后面，并返回新的尾节点。
>
> ```cpp
> class Solution {
> private:
>     ListNode* cut(ListNode* head, int size) {
>         for (int i = 1; head && i < size; ++i) {
>             head = head->next;
>         }
>         if (!head) return nullptr;
>         ListNode* rest = head->next;
>         head->next = nullptr;
>         return rest;
>     }
>
>     ListNode* mergeAfter(ListNode* a, ListNode* b, ListNode* tail) {
>         while (a && b) {
>             if (a->val <= b->val) {
>                 tail->next = a;
>                 a = a->next;
>             } else {
>                 tail->next = b;
>                 b = b->next;
>             }
>             tail = tail->next;
>         }
>         tail->next = a ? a : b;
>         while (tail->next) tail = tail->next;
>         return tail;
>     }
>
> public:
>     ListNode* sortList(ListNode* head) {
>         int n = 0;
>         for (ListNode* p = head; p; p = p->next) ++n;
>         ListNode dummy(0, head);
>
>         for (int size = 1; size < n; size *= 2) {
>             ListNode* curr = dummy.next;
>             ListNode* tail = &dummy;
>             while (curr) {
>                 ListNode* left = curr;
>                 ListNode* right = cut(left, size);
>                 curr = cut(right, size);  // 保存下一对链表的入口。
>                 tail = mergeAfter(left, right, tail);
>             }
>         }
>         return dummy.next;
>     }
> };
> ```
>
> **时间 `O(n log n)`，额外空间 `O(1)`。** 消除了递归栈，满足题目进阶要求。每轮虽然包含切段和寻找合并后的尾部，但各节点只被访问常数次，仍为 `O(n)`。
