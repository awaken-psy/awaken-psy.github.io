# 146. LRU 缓存

题目：[LeetCode 146](https://leetcode.cn/problems/lru-cache/description/)

源码：[146.lru-缓存.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/146.lru-缓存.cpp)

## 题面

实现固定容量的最近最少使用缓存：

- `get(key)`：存在则返回值，并将它标记为最近使用；不存在则返回 `-1`。
- `put(key, value)`：存在则更新值并标记为最近使用；不存在则插入，容量不足时淘汰最久未使用的键。
- 两个操作都要求**平均 `O(1)` 时间**。

例如容量为 2：依次写入 `(1,1)`、`(2,2)`，再读取 1，随后写入 `(3,3)`，应淘汰 2；此时读取 2 返回 `-1`。

`1 <= capacity <= 3000`，键为 `0~10000`，值为 `0~100000`，最多调用 `200000` 次 `get`、`put`。

## 核心思路：哈希表定位，双向链表维护顺序

需要同时完成两件事：按键快速查找，以及快速把某个元素移到最前、删除最末元素。

- **双向链表 `order`**：保存 `{key, value}`，头部最近使用，尾部最久未使用。
- **哈希表 `pos`**：保存 `key → 链表迭代器`，直接找到该键对应的链表节点。

链表中也要保存 `key`，因为淘汰尾部节点时，需要用它同步删除哈希表记录。

```text
操作             从最近到最久的 key 顺序
put(1,1)         1
put(2,2)         2 → 1
get(1)           1 → 2
put(3,3)         3 → 1    淘汰 2
```

单靠时间戳再遍历找最老的键，会让淘汰操作变成线性时间。这里用 `list::splice` 直接移动已有节点，避免查找和复制。

## C++ 题解

```cpp
#include <list>
#include <unordered_map>
#include <utility>

class LRUCache {
private:
    int capacity;
    std::list<std::pair<int, int>> order;
    std::unordered_map<int, std::list<std::pair<int, int>>::iterator> pos;

public:
    LRUCache(int cap) {
        capacity = cap;
    }

    int get(int key) {
        auto it = pos.find(key);
        if (it == pos.end()) return -1;

        auto node = it->second;  // 取出保存的链表迭代器。
        order.splice(order.begin(), order, node);
        return node->second;
    }

    void put(int key, int value) {
        auto it = pos.find(key);
        if (it != pos.end()) {
            auto node = it->second;
            node->second = value;
            order.splice(order.begin(), order, node);
            return;
        }

        int count = order.size();
        if (count == capacity) {
            int oldKey = order.back().first;
            pos.erase(oldKey);  // 两个容器的记录必须同步删除。
            order.pop_back();
        }

        order.push_front({key, value});
        pos[key] = order.begin();
    }
};
```

## STL：这几个操作需要会用

`std::list` 是双向链表；`pair<int,int>` 保存一对数，`.first` 是键，`.second` 是值。

`pos.find(key)` 返回的是**哈希表迭代器**，它的 `it->second` 才是保存在表里的**链表迭代器**。代码用 `auto node = it->second` 拆开这两层，随后 `node->second` 就是缓存值。`auto` 让编译器推导迭代器类型。

```cpp
order.splice(order.begin(), order, node);
//           插入位置       源链表  要移动的节点
```

这个重载把已有节点移到目标位置之前，在同一条链表里也能使用。**单节点移动是 `O(1)`，移动后原迭代器仍有效**，所以不需要重写 `pos[key]`。删除节点后，对应迭代器才不能再使用。[标准库说明](https://eel.is/c++draft/list.ops)

`find()` 用于查询是否存在，不会插入记录；`pos[key] = order.begin()` 则用于登记新节点的位置。不要用 `pos[key]` 直接判断是否存在，否则可能插入无效的迭代器记录。

**`get`、`put` 平均时间均为 `O(1)`，空间 `O(capacity)`。** 访问失败不改变顺序；更新已有键也算一次使用。
