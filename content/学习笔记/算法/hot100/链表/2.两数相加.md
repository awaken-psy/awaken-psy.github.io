# 2. 两数相加

题目：[LeetCode 2](https://leetcode.cn/problems/add-two-numbers/description/)

源码：[2.两数相加.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/2.两数相加.cpp)

## 题面

两个非空链表分别表示两个非负整数，数字按**低位在前**的顺序存储，每个节点保存一位。返回两数之和，仍按相同顺序存储。

- `[2,4,3] + [5,6,4]` → `[7,0,8]`，即 `342 + 465 = 807`。
- `[0] + [0]` → `[0]`。
- `[9,9,9,9,9,9,9] + [9,9,9,9]` → `[8,9,9,9,0,0,0,1]`。

每条链表有 `1~100` 个节点，节点值为 `0~9`，表示的整数除 0 外没有前导零。

## 核心思路

低位在前，正好可以从头开始模拟竖式加法。每轮取两条链表的当前位，再加上上一位的进位：

```text
sum = 当前位1 + 当前位2 + carry
当前结果位 = sum % 10
下一位进位 = sum / 10
```

较短的链表走完后，它提供的数字按 0 处理。**循环条件必须包含进位**，否则 `[9] + [1]` 会漏掉最后的 1。

用 `dummy` 保存结果链表的入口，`tail` 始终指向结果末尾，每算出一位就接一个新节点。不要先转成整数相加，100 位数字会超出普通整数类型的范围。

正文采用新建结果链表的写法，不修改输入；你源码中的复用节点写法放在末尾。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        int carry = 0;

        while (l1 || l2 || carry) {
            int sum = carry;
            if (l1) {
                sum += l1->val;
                l1 = l1->next;
            }
            if (l2) {
                sum += l2->val;
                l2 = l2->next;
            }

            tail->next = new ListNode(sum % 10);
            tail = tail->next;
            carry = sum / 10;
        }
        return dummy.next;
    }
};
```

设两条链表长度为 `m、n`。**时间 `O(max(m,n))`；结果链表占 `O(max(m,n))` 空间，除结果外额外空间为 `O(1)`。**

> [!example]- 进阶写法（后续复习）：复用输入节点
> 沿用你源码的思路：把和直接写进 `l1`。如果 `l1` 提前走完，就把 `l2` 剩余部分接到结果后面，继续处理进位；最后有进位时才新建一个节点。
>
> 接上 `l2` 剩余段后，将 `l2` 置空，避免同一段既作为 `l1` 又作为 `l2` 被加两遍。
>
