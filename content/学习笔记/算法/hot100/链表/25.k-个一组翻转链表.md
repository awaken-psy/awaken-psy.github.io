# 25. K 个一组翻转链表

题目：[LeetCode 25](https://leetcode.cn/problems/reverse-nodes-in-k-group/description/)

源码：[25.k-个一组翻转链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/25.k-个一组翻转链表.cpp)

## 题面

每 `k` 个节点为一组翻转链表，最后不足 `k` 个节点时保持原顺序。**必须实际改变节点连接，不能只交换节点值。**

- `[1,2,3,4,5]`，`k = 2` → `[2,1,4,3,5]`。
- `[1,2,3,4,5]`，`k = 3` → `[3,2,1,4,5]`。

链表长度为 `n`，`1 <= k <= n <= 5000`，节点值为 `0~1000`。进阶要求只用 `O(1)` 额外空间。

## 核心思路：暂存一组指针，倒着接回去

正文先用一个数组暂存当前组的节点指针：

1. 从 `curr` 开始，尝试收集 `k` 个节点，并保存下一组入口 `nextGroup`。
2. 不足 `k` 个就停止，剩余链表保持不动。
3. 收集满了，就按 `group[k-1]` 到 `group[0]` 的顺序，把这些节点接到结果末尾。
4. 组内新尾节点接上 `nextGroup`，再处理下一组。

例如 `k = 3`：

```text
收集：[节点1, 节点2, 节点3]，nextGroup 指向节点4
重连：dummy → 3 → 2 → 1 → 4 → ...
```

`vector<ListNode*>` 保存的是指针，不是复制节点。数组只帮助我们倒序访问，实际操作仍然是改 `next`。

**必须先确认满一组，再开始翻转**，否则最后不足 `k` 个节点也会被翻转。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
#include <vector>

class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode dummy(0, head);
        ListNode* tail = &dummy;
        ListNode* curr = head;

        while (curr) {
            std::vector<ListNode*> group;
            ListNode* nextGroup = curr;
            int count = 0;
            while (count < k && nextGroup) {
                group.push_back(nextGroup);
                nextGroup = nextGroup->next;
                ++count;
            }

            if (count < k) {
                tail->next = curr;  // 不满一组，保留原顺序。
                break;
            }
            for (int i = k - 1; i >= 0; --i) {
                tail->next = group[i];
                tail = group[i];
            }
            tail->next = nextGroup;  // 修正新尾节点的旧连接，避免成环。
            curr = nextGroup;
        }
        return dummy.next;
    }
};
```

**时间 `O(n)`，额外空间 `O(k)`。** 每个节点只被收集、重连常数次。`k = 1` 时结果不变；`k = 2` 时就是「两两交换链表中的节点」。

> [!example]- 进阶写法（后续复习）：O(1) 空间，原地翻转整组
> 不再保存一组指针。用 `groupPrev` 指向当前组的前驱，向后找第 `k` 个节点 `kth`，确认这一组完整，再保存下一组入口 `groupNext = kth->next`。
>
> 对当前组使用普通链表翻转的三指针操作。把 `prev` 初始设为 `groupNext`，这样原来的组头在翻转后成为组尾，并且已经接好下一组。
>
> ```text
> 翻转前：groupPrev → a → b → c → groupNext
> 翻转后：groupPrev → c → b → a → groupNext
>                   新组头    新组尾
> ```
>
> 翻转后让 `groupPrev->next = kth` 接上新组头，再把 `groupPrev` 移到原组头 `first`，为下一组做准备。
>
> ```cpp
> class Solution {
> public:
>     ListNode* reverseKGroup(ListNode* head, int k) {
>         ListNode dummy(0, head);
>         ListNode* groupPrev = &dummy;
>
>         while (true) {
>             ListNode* kth = groupPrev;
>             for (int i = 0; i < k && kth; ++i) {
>                 kth = kth->next;
>             }
>             if (!kth) break;  // 剩余不足 k 个，完全不动这一段。
>
>             ListNode* groupNext = kth->next;
>             ListNode* first = groupPrev->next;
>             ListNode* prev = groupNext;
>             ListNode* curr = first;
>
>             while (curr != groupNext) {
>                 ListNode* next = curr->next;  // 改线前保存后继。
>                 curr->next = prev;
>                 prev = curr;
>                 curr = next;
>             }
>
>             groupPrev->next = kth;  // 原组尾成为新组头。
>             groupPrev = first;     // 原组头成为新组尾。
>         }
>         return dummy.next;
>     }
> };
> ```
>
> **时间 `O(n)`，额外空间 `O(1)`，满足题目进阶要求。** 找组尾与翻转各扫描一遍当前组，总工作量仍然是线性的。
