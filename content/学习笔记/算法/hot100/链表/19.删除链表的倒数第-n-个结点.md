# 19. 删除链表的倒数第 N 个结点

题目：[LeetCode 19](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/)

源码：[19.删除链表的倒数第-n-个结点.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/19.删除链表的倒数第-n-个结点.cpp)

## 题面

删除链表倒数第 `n` 个节点，返回新的头节点。

- `[1,2,3,4,5]`，`n = 2` → `[1,2,3,5]`。
- `[1]`，`n = 1` → `[]`。
- `[1,2]`，`n = 1` → `[1]`。

链表长度为 `L`，`1 <= n <= L <= 30`，节点值为 `0~100`。进阶要求只扫描一趟。

## 核心思路

**让快慢指针保持相隔 `n` 条边，直接定位待删除节点的前驱。**

1. `fast`、`slow` 都从头节点前的 `dummy` 出发。
2. `fast` 先走 `n` 步，然后两个指针一起移动。
3. 当 `fast` 到达最后一个节点时，`slow` 正好停在待删除节点的前一个位置。

为什么是前驱？把 `dummy` 看作第 0 个节点：`fast` 停在第 `L` 个，`slow` 就在第 `L - n` 个，而倒数第 `n` 个节点的位置是 `L - n + 1`。

例如 `[1,2,3,4,5]`、`n = 2`：先让 `fast` 到 2、`slow` 留在 `dummy`；随后一起走，最终 `fast` 在 5、`slow` 在 3，再跳过节点 4。

```text
删除前：slow(3) → 4 → 5
删除后：slow(3) ───→ 5
```

`dummy` 统一处理删除头节点和唯一节点的情况，不需要额外分支。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;

        for (int i = 0; i < n; ++i) {
            fast = fast->next;
        }
        while (fast->next) {  // fast 停在最后一个节点。
            fast = fast->next;
            slow = slow->next;
        }
        slow->next = slow->next->next;
        return dummy.next;
    }
};
```

注意配套关系：`fast` 先走 **`n` 步**，循环判断 **`fast->next`**，保证 `slow` 停在前驱，而不是待删除节点本身。

**一趟扫描，时间 `O(L)`，额外空间 `O(1)`。** 这里按题目惯例摘除节点；工程中是否还要 `delete`，取决于节点的内存所有权。
