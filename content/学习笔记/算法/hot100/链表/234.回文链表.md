# 234. 回文链表

题目：[LeetCode 234](https://leetcode.cn/problems/palindrome-linked-list/description/)

源码：[234.回文链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/234.回文链表.cpp)

## 题面

判断链表的节点值从前往后、从后往前读是否相同。

- `[1,2,2,1]` → `true`。
- `[1,2]` → `false`。

节点数为 `1~100000`，节点值为 `0~9`。进阶要求 `O(n)` 时间和 `O(1)` 空间。

## 核心思路：存进数组，从两端比较

单链表无法直接从尾部往前走，因此先把节点值存进数组，再用左右指针向中间比较。

任意一对不同就返回 `false`，全部相同则返回 `true`。这个版本不修改链表，面试时也容易写清楚。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
#include <vector>

class Solution {
public:
    bool isPalindrome(ListNode* head) {
        std::vector<int> values;
        for (ListNode* p = head; p; p = p->next) {
            values.push_back(p->val);
        }

        int n = values.size();
        for (int left = 0, right = n - 1; left < right; ++left, --right) {
            if (values[left] != values[right]) return false;
        }
        return true;
    }
};
```

**时间 `O(n)`，额外空间 `O(n)`。**

> [!example]- 进阶写法（后续复习）：反转后半段，O(1) 空间
> 结合快慢指针与「206. 反转链表」：
>
> 1. 找到前半段末尾；奇数长度时，`slow` 停在中间节点。
> 2. 反转 `slow->next` 开始的后半段。
> 3. 从原头节点和反转后的后半段头节点开始比较，直到后半段走完。
> 4. 再反转一次后半段，恢复原链表。
>
> 例如 `[1,2,3,2,1]`，中间的 3 不参与比较；后半段反转后为 `[1,2]`，与前面的 `[1,2]` 比较即可。
>
> ```cpp
> class Solution {
> private:
>     ListNode* reverseList(ListNode* head) {
>         ListNode* prev = nullptr;
>         while (head) {
>             ListNode* next = head->next;
>             head->next = prev;
>             prev = head;
>             head = next;
>         }
>         return prev;
>     }
>
> public:
>     bool isPalindrome(ListNode* head) {
>         if (!head || !head->next) return true;
>
>         ListNode* slow = head;
>         ListNode* fast = head;
>         while (fast->next && fast->next->next) {
>             slow = slow->next;
>             fast = fast->next->next;
>         }
>
>         ListNode* second = reverseList(slow->next);
>         ListNode* p1 = head;
>         ListNode* p2 = second;
>         bool same = true;
>         while (p2) {
>             if (p1->val != p2->val) {
>                 same = false;
>                 break;  // 先退出比较，恢复链表后再返回。
>             }
>             p1 = p1->next;
>             p2 = p2->next;
>         }
>
>         slow->next = reverseList(second);
>         return same;
>     }
> };
> ```
>
> `second` 要保留为后半段入口，比较时另用 `p2` 移动，这样最后才能恢复。即使发现不相等，也不能直接返回而跳过恢复步骤。
>
> **时间 `O(n)`，额外空间 `O(1)`**，满足题目进阶要求，返回时原链表结构也已恢复。
