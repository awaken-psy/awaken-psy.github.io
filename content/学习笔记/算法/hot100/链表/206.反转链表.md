# 206. 反转链表

题目：[LeetCode 206](https://leetcode.cn/problems/reverse-linked-list/description/)

源码：[206.反转链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/206.反转链表.cpp)

## 题面

反转单链表，返回反转后的头节点。

- `[1,2,3,4,5]` → `[5,4,3,2,1]`。
- `[1,2]` → `[2,1]`。
- `[]` → `[]`。

节点数为 `0~5000`，节点值为 `-5000~5000`。

## 核心思路：保存后继，再反转当前连接

维护两个指针：

- `prev`：已经反转部分的头节点，初始为空。
- `curr`：还没处理部分的头节点，初始为 `head`。

每轮把 `curr` 从未处理部分拿下来，接到已反转部分的最前面：

```cpp
ListNode* next = curr->next;  // 先保存原来的后继。
curr->next = prev;           // 当前节点转而指向前一个节点。
prev = curr;                // 更新已反转部分的头。
curr = next;                // 继续处理原来的后继。
```

**保存 `next` 必须发生在改写 `curr->next` 之前**，否则后面的链表入口会丢失。第一次把原头节点指向空，也保证它最终成为正确的尾节点。

循环结束时 `curr` 为空，`prev` 指向新头，所以返回 `prev`。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;

        while (curr) {
            ListNode* next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }
};
```

**时间 `O(n)`，额外空间 `O(1)`。** 不创建新节点、不改节点值，空链表也无需特殊分支。这个反转过程可以直接用于「回文链表」和「K 个一组翻转链表」。
