# 21. 合并两个有序链表

题目：[LeetCode 21](https://leetcode.cn/problems/merge-two-sorted-lists/description/)

源码：[21.合并两个有序链表.cpp](https://github.com/awaken-psy/leetcode/blob/main/hot100/链表/21.合并两个有序链表.cpp)

## 题面

把两个非递减链表合并成一个非递减链表，要求**拼接原来的节点**。

- `[1,2,4]` 与 `[1,3,4]` → `[1,1,2,3,4,4]`。
- `[]` 与 `[]` → `[]`。
- `[]` 与 `[0]` → `[0]`。

每条链表长度为 `0~50`，节点值为 `-100~100`，允许重复值。

## 核心思路

两条链表都已排序，所以它们各自的头节点就是各自剩余部分的最小值。**比较两个头，把较小的节点接到结果末尾，再推进对应链表。**

用 `dummy` 记住结果入口，`tail` 维护结果末尾。一条链表走完后，另一条剩余部分已经有序，可以整段接上，不必逐个处理。

只修改 `next`，不复制节点值、不新建结果节点。这段合并逻辑也能直接用于「23. 合并 K 个升序链表」。

## C++ 题解

代码使用题目提供的 `ListNode` 定义。

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy(0);
        ListNode* tail = &dummy;

        while (list1 && list2) {
            if (list1->val <= list2->val) {
                tail->next = list1;
                list1 = list1->next;
            } else {
                tail->next = list2;
                list2 = list2->next;
            }
            tail = tail->next;
        }

        tail->next = list1 ? list1 : list2;  // 接上剩余部分。
        return dummy.next;
    }
};
```

**时间 `O(m + n)`，额外空间 `O(1)`。** 合并会改变输入节点的连接关系。

你源码里的提醒很重要：`ListNode* tail;` 只声明了指针，并没有创建节点，不能直接写 `tail->next`。这里先创建真实的 `dummy`，再让 `tail` 指向它。
