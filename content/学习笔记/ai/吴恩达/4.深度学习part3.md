## 1.决策树
### 1.1 什么是决策树
![](<Attachments/Pasted image 20261108045900.png>)

构建决策树的关键：
1. 在每个节点上如何选择特征
	- 最大化纯度（purity），最小化熵
2. 何时停止划分
	- 限制树深度
	- 节点上所有元素为一类
	- 纯度分数的改进低于阈值
	- 节点中的元素过少
### 1.2 熵
![](<Attachments/Pasted image 20261108050842.png>)

**熵（entropy）用来衡量一个节点内类别的混杂程度。熵越小，节点越纯。**

假设问题为二分类，$p_1$ = 当前节点中标签为 1 的样本数 / 当前节点的样本总数
$$H(p_1) = -p_1\log_2 p_1 - (1-p_1)\log_2(1-p_1)$$
- 当 $p_1=0$ 或 $p_1=1$ 时，节点中只有一种类别，规定 $H(p_1)=0$。
- 当 $p_1=0.5$  时，两类各占一半。熵达到最大值 $1$，纯度最低。


#### 1.2.1 加权平均熵与信息增益

假设父节点有 $n$ 个样本，划分后左、右子节点分别有 $n_L$、$n_R$ 个样本，标签为 1 的样本比例分别为 $p_1^L$、$p_1^R$，则

划分后的加权平均熵为$$H_{\text{after}}=w_LH(p_1^L)+w_RH(p_1^R)$$
信息增益（一次划分带来的熵的减少量）为$$IG=H(p_1)-\left[w_LH(p_1^L)+w_RH(p_1^R)\right]$$
- 信息增益越大，说明这次划分使整体混杂程度下降得越多。
- 最大化信息增益等价于最小化划分后的加权平均熵，所以优先选择信息增益最大的划分

### 1.3 何时停止划分

- 停止条件：
	1. 节点的熵为 $0$ 
	2. 达到最大深度
	3. 节点样本过少
	4. 最佳候选划分的信息增益低于设定阈值
- 停止时如果节点仍包含多个类别，输出该节点样本中的多数类。

### 1.4 使用独热编码的分类特征

- 独热编码（one-hot encoding）将一个有 $k$ 种可能取值的分类特征，转换为 $k$ 个取值为 0 或 1 的特征。

| 原始毛色 | 是否黑色 | 是否白色 | 是否棕色 |
| --- | --- | --- | --- |
| 黑色 | 1 | 0 | 0 |
| 白色 | 0 | 1 | 0 |
| 棕色 | 0 | 0 | 1 |

### 1.5 连续值特征

对于连续值特征，决策树通过选择一个**阈值 $t$**，将当前节点的样本分为两组。

**如何选择阈值**
1. 将当前节点中的该特征排序，记为 $v_1<v_2<\cdots<v_m$。取相邻取值的中点作为候选阈值，共 $m-1$ 个。
2. 对每个候选阈值划分样本，计算左右子节点的加权平均熵和信息增益。
3. 选择信息增益最大的阈值

## 2 决策树集成

### 2.1 使用多棵树预测

单棵决策树对训练数据的变化比较敏感。少量样本变化，就可能改变根节点选择的特征，进而影响整棵树的结构和预测。

**决策树集成（tree ensemble）通过组合多棵树的预测，提高预测的稳定性。** 

- 分类任务通常采用多数投票。
- 回归任务通常取各棵树预测值的平均。

### 2.2 有放回抽样构建数据集

**有放回抽样（sampling with replacement）允许同一个样本被多次抽中。** 从训练集进行这种重采样，得到的数据集称为 bootstrap 样本集。

假设原训练集有 $m$ 个样本，要训练 $B$ 棵树。

1. 从原训练集中随机抽取一个样本，将样本记录到新数据集中，并放回原训练集。
2. 重复抽取 $m$ 次，得到一个含 $m$ 条记录的新训练集，其中可能包含重复样本，也可能遗漏。
3. 为每棵树分别重新抽样，得到 $B$ 个训练集，并各自训练一棵树。

用 bootstrap 样本集分别训练模型，再通过投票或平均组合预测，称为 Bagging（bootstrap aggregating）。

### 2.3 随机森林算法

随机森林（random forest）在有放回抽样的基础上，进一步随机选择每个节点参与比较的候选特征。

假设共有 $n$ 个输入特征，每次从中抽取 $k$ 个候选特征。

1. 为当前树有放回抽样，构建训练集。
2. 在当前节点随机抽取 $k$ 个候选特征。
3. 按信息增益选择最优特征及划分方式。
4. 到下一节点，重复2和3。
5. 重复训练多棵树。

分类问题常使用 $k\approx\sqrt{n}$，这样可以让不同的树探索不同特征，降低各棵树预测错误的相关性。

### 2.4 XGBoost

XGBoost（eXtreme Gradient Boosting）是一种高效的梯度提升树实现，通过逐轮加入新树来改进当前集成模型的预测。

1. 从一个初始预测 $F_0(\mathbf{x})$ 开始。
2. 根据当前预测与真实标签计算损失及其梯度信息，训练一棵新树 $f_b$，使加入它后目标函数下降。
3. 将新树的输出乘以学习率 $\eta$，加入已有模型，得到新的预测。
4. 重复上述过程。

每轮更新可以写为
$$F_b(\mathbf{x})=F_{b-1}(\mathbf{x})+\eta f_b(\mathbf{x})$$
其中 $f_b$ 的叶节点输出一个数值修正量，$\eta$ 控制每轮更新的幅度。回归可直接使用最终预测值，二分类任务则可应用 Sigmoid，得到类别概率。

常调节的参数包括树数量、树深、学习率，以及样本和特征的采样比例。

| 比较内容   | 随机森林              | XGBoost 梯度提升树         |
| ------ | ----------------- | --------------------- |
| 树之间的关系 | 各棵树独立训练           | 后续树依赖当前集成模型的预测        |
| 主要训练思路 | 通过样本和特征的随机性构建不同的树 | 逐轮优化损失，改进当前预测         |
| 组合预测   | 分类投票或平均概率，回归取平均   | 累加各棵树的数值输出，并按目标函数转换结果 |
| 并行方式   | 不同树可并行训练          | 按轮次依次加入树，单轮内部可并行计算    |

### 2.5 何时使用决策树

输入是结构化表格数据时，决策树及其集成通常值得优先尝试。

| 场景或需求             | 可以优先尝试的模型      |
| ----------------- | -------------- |
| 表格数据，希望获得稳定的预测结果  | 随机森林           |
| 表格数据，愿意通过调参优化预测性能 | XGBoost 等梯度提升树 |
| 直接处理图像、语音、文本等原始数据 | 通常优先考虑神经网络     |

## 3.回归树

回归树（regression tree）用于预测连续数值。

### 3.1 叶节点如何给出预测

设叶节点包含的训练样本集合为 $S$，共有 $n$ 个样本，新样本沿树中的条件到达某个叶节点，就使用这个叶节点的均值作为预测值。
$$\hat y_S=\bar y_S=\frac{1}{n}\sum_{i\in S}y^{(i)}$$
### 3.2 如何选择划分

使用当前节点内目标值 $y$ 的方差，衡量这些数值的离散程度。$$V(S)=\frac{1}{n}\sum_{i\in S}\left(y^{(i)}-\bar y_S\right)^2$$
设划分后的左右子节点为 $S_L$、$S_R$，分别包含 $n_L$、$n_R$ 个样本，则划分带来的方差减少量为$$\Delta V=V(S)-\left[\frac{n_L}{n}V(S_L)+\frac{n_R}{n}V(S_R)\right]$$
1. 在当前节点枚举候选特征及其划分方式。连续值特征可以尝试相邻不同取值的中点。
2. 对每个候选划分，计算子节点的加权平均方差。
3. **选择方差减少量最大的划分**，然后在子节点上递归重复。

### 3.3 何时停止划分

- 节点内所有目标值相同，方差为 0。
- 达到最大树深度。
- 当前节点样本过少。
- 最佳候选划分带来的方差减少量低于设定阈值。
