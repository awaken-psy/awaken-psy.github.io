## 1.模型评估

### 1.1 训练与评估的基本流程

1. 将数据分为训练集和测试集，例如 100 个样本中，80 个用于训练，20 个用于测试。
2. 只使用训练集，最小化训练目标。
3. 固定学到的参数，分别计算训练误差和测试误差。
4. 比较模型对见过的数据和未见过的数据的表现。

### 1.2 如何评估

训练时优化的目标：
$$
J(\mathbf{w}, b)
= \frac{1}{2m_{\text{train}}}
\sum_{i=1}^{m_{\text{train}}}
\left(f_{\mathbf{w},b}(\mathbf{x}_{\text{train}}^{(i)}) - y_{\text{train}}^{(i)}\right)^2
+ \frac{\lambda}{2m_{\text{train}}}\sum_{j=1}^{n} w_j^2
$$
训练误差：评价对训练数据的预测效果
$$
J_{\text{train}}(\mathbf{w}, b)
= \frac{1}{2m_{\text{train}}}
\sum_{i=1}^{m_{\text{train}}}
\left(f_{\mathbf{w},b}(\mathbf{x}_{\text{train}}^{(i)}) - y_{\text{train}}^{(i)}\right)^2
$$
测试误差：评价对未见过数据的预测效果
$$
J_{\text{test}}(\mathbf{w}, b)
= \frac{1}{2m_{\text{test}}}
\sum_{i=1}^{m_{\text{test}}}
\left(f_{\mathbf{w},b}(\mathbf{x}_{\text{test}}^{(i)}) - y_{\text{test}}^{(i)}\right)^2
$$
### 1.3 如何解读

| 观察到的现象        | 可能的解释                  |
| ------------- | ---------------------- |
| 训练误差小，测试误差明显大 | 可能过拟合：对训练数据表现好，对新数据表现差 |
| 训练误差和测试误差都大   | 可能欠拟合：对训练数据也没有学好       |
| 两者都小，且差距较小    | 通常说明泛化表现较好             |
### 1.4 分类问题：另一种评估方法

分类预测的是类别。可直接使用统计分错的样本比例$$ \text{分类错误率} = \frac{\text{分错的样本数量}}{\text{样本总数}} $$

## 2.模型选择

### 2.1 为什么不能用测试集选模型

模型选择是决定使用哪一种模型，例如多项式回归应该使用几次多项式。

有问题的流程：

1. 在训练集上，分别训练 $d=1,2,\ldots,10$ 的模型。
2. 在测试集上比较误差，选择测试误差最小的模型。
3. 用这个最小测试误差，报告模型对未来新数据的表现。

问题在于：测试集既参与了选择模型，又被用来给选中的模型做最终评分。选出的最低测试误差容易成为对泛化误差的乐观估计

### 2.2 正确流程：训练集、验证集、测试集

| 数据集                             | 作用                 |
| ------------------------------- | ------------------ |
| 训练集（training set）               | 学习参数               |
| 验证集（cross validation set，简称 CV） | 比较候选模型，选择 $d$ 等超参数 |
| 测试集（test set）                   | 模型选定后，独立评估最终的泛化表现  |

1. **训练**：只用训练集，分别训练不同的模型，得到各自的参数。
2. **选择**：固定各模型参数，在验证集上计算 $J_{\text{cv}}$，选择验证误差最低的模型。
3. **确定模型**：确定采用的次数 $d$，保留该候选模型训练得到的参数。
4. **最终评估**：在测试集上计算选定模型的 $J_{\text{test}}$，用它估计对未来新数据的预测误差。

正则化强度 $\lambda$ 也可以用验证集的方法来选择

### 2.3 验证集也用于诊断模型（在最终评估之前）

$J_{\text{cv}}$ 本质上是模型在验证集上的误差。比较不同模型的 $J_{\text{cv}}$ 可以选择模型；对同一个模型，结合 $J_{\text{train}}$ 和 $J_{\text{cv}}$ 则可以诊断问题：
- 两者都高，可能欠拟合；
- 训练误差低、验证误差明显高，可能过拟合；
- 两者都低且差距较小，通常表现较好。
开发阶段可以据此改进模型，再用验证集比较效果；模型确定后，才使用测试集做独立的最终评估。

## 4.增加数据

### 4.1 错误分析 + 增加特定子集的数据

**先找出模型经常在哪类样本上出错，再有针对性地增加这类训练数据。**

1. **查看错误样本**：从验证集中抽取模型预测错误的样本，逐个查看。
2. **归类并统计**：按主要错误类型分组。
3. **确定优先级**：结合各类错误的数量、影响和改善成本，选择值得优先解决的问题。
4. **补充训练数据**：收集并标注更多对应场景的数据，加入训练集；重新训练后，用验证集检查是否改善。

### 4.2 数据增强

**数据增强（data augmentation）是在已有训练样本上施加合理变换，生成更多训练变体。** 

| 任务   | 常见增强方式            | 标签保持不变的条件       |
| ---- | ----------------- | --------------- |
| 图像分类 | 小幅平移、旋转、适度裁剪、左右翻转 | 变换后仍能识别出原来的类别   |
| 图像分类 | 调整亮度、对比度、加入适量噪声   | 模拟合理成像变化，保留类别信息 |
| 语音识别 | 加入背景噪声、适度调整音量或语速  | 说话内容仍然相同且可辨认    |
## 5.迁移学习

### 5.1 基本思路

**迁移学习（transfer learning）：复用在源任务上训练好的模型参数，作为新任务训练的起点。**

预训练网络可以学到边缘、线条、纹理、形状等视觉特征，新任务可以利用这些已有能力，通常能够减少所需的标注数据和训练成本。

### 5.2 例子：从 1000 类物体识别迁移到数字识别

1. **获得预训练模型**：原网络在约 100 万张图片上训练，识别猫、狗、汽车等 1000 个类别，输出层有 1000 个单元。
2. **复用隐藏层**：复制第 1～4 层训练好的权重和偏置，作为新网络相应层的初始参数。
3. **替换输出层**：移除原来的第 5 层，新建并初始化含 10 个输出单元的输出层，分别对应数字 0～9。
4. **训练新任务**：使用自己的数字图片和标签，训练新输出层，并决定是否继续调整前面的隐藏层。

迁移的是训练好的参数；目标任务仍需要自己的训练数据。原输出层与新输出层的类别数不同，因此新的输出层需要重新学习。

### 5.3 两种训练方式

| 方式 | 第 1～4 层隐藏层 | 新的第 5 层输出层 |
| --- | --- | --- |
| 只训练输出层 | 冻结预训练参数，不更新 | 学习如何利用已有特征识别数字 |
| 训练全部参数 | 从预训练参数出发，继续更新 | 同时训练 |

- **冻结（freeze）**：训练时保持指定层的参数不变，把这些层当作固定的特征提取器。
- **微调（fine-tuning）**：以预训练参数为起点，用目标任务的数据继续调整部分或全部隐藏层，使特征更适合新任务。
- 微调预训练层时，通常使用较小的学习率。也可以先训练新输出层，再逐步解冻部分层进行微调。

### 5.4 什么时候适合使用

- **源任务与目标任务有可复用的特征**：例如都处理图片，即使类别不同，也可能共享边缘和形状等特征。
- **源任务数据充足、目标任务标注数据较少**：可以利用预训练阶段学到的能力，降低从少量目标数据学习的难度。

## 6.精确率、召回率与 F1 分数

### 6.1 类别不平衡与混淆矩阵

在关注稀有类别的任务中，单看准确率可能掩盖问题。例如 1000 个样本中只有 10 个正类，全部预测为负类，准确率仍有 $99\%$，但一个正类也没有检出。

| 预测／真实         | 实际 $y=1$       | 实际 $y=0$       |
| ------------- | -------------- | -------------- |
| 预测 $\hat y=1$ | **TP：15**，正确检出 | **FP：5**，误报    |
| 预测 $\hat y=0$ | **FN：10**，漏报   | **TN：70**，正确排除 |

### 6.2 精确率、召回率与准确率

**精确率（Precision）**：在模型预测为正类的样本中，实际为正类的比例。回答“报出来的正类，有多少是真的”。

$$
P = \text{Precision}
= \frac{TP}{TP+FP}
= \frac{15}{15+5}
= 75\%
$$

**召回率（Recall）**：在实际为正类的样本中，被模型正确检出的比例。回答“真正的正类，有多少被找到了”。

$$
R = \text{Recall}
= \frac{TP}{TP+FN}
= \frac{15}{15+10}
= 60\%
$$
**准确率（Accuracy）**：全部样本中预测正确的比例。

$$
\text{Accuracy}
= \frac{TP+TN}{TP+FP+FN+TN}
= \frac{15+70}{100}
= 85\%
$$
### 6.3 调整阈值：权衡精确率与召回率

逻辑回归输出属于正类的概率 $p=f_{\mathbf{w},b}(\mathbf{x})$。调整阈值 $t$：
$$
\hat y =
\begin{cases}
1, & p \ge t, \\
0, & p < t.
\end{cases}
$$

| 调整方式 | 预测正类 | 常见影响             | 更关注的目标           |
| ---- | ---- | ---------------- | ---------------- |
| 提高阈值 | 更少   | 精确率通常提高，召回率降低或不变 | 减少误报，希望报出来的结果更可靠 |
| 降低阈值 | 更多   | 召回率提高或不变，精确率通常降低 | 减少漏报，希望尽量找全正类    |

- 对同一个模型逐渐降低分类阈值，召回率越来越高，但精确率通常会下降。

### 6.5 F1 分数：综合精确率与召回率

F1 是精确率与召回率的**调和平均**：
$$
F_1
= \frac{1}{\frac{1}{2}\left(\frac{1}{P}+\frac{1}{R}\right)}
= \frac{2PR}{P+R}
= \frac{2TP}{2TP+FP+FN}
$$
它对较小的那项更敏感：**一项很高、另一项很低时，F1 仍然较低；两项都较高，F1 才能较高。** 当精确率或召回率为 0 时，通常将 F1 记为 0。
