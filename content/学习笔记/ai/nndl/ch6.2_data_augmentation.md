# 为什么数据增强 + 卷积网络效果更好

> 出自《神经网络与深度学习》第 6.2 节

---

## 原题

![题目](学习笔记/ai/nndl/image/ch06_data_augmentation_exercise.png)

**题目：** 卷积层的设计已经具备平移不变性（对图像中物体的位置不敏感）。但当我们做了数据增强（平移训练图像）后，网络反而学得更多。这为什么合理？

---

## 矛盾点

卷积层的两大特性让人以为不需要数据增强：

1. **局部连接**：卷积核只看局部，不关心物体在图像哪个位置
2. **权重共享**：同一个核在整张图上滑动，在左上角学到的模式在右下角也能用

既然卷积已经"平移不变"了，为什么把图像平移 ±1 像素做数据增强，还能让网络学得更多？

---

## 解答

### 1. 卷积层本身是"平移等变"，不是"平移不变"

```
平移等变 (equvariant):     平移不变 (invariant):
  输入平移 → 输出也平移      输入平移 → 输出不变

  卷积层是等变的             全连接层和 softmax 才需要不变性
  (不是不变的!)
```

卷积核在左上角检测到边缘，滑动到右下角也能检测到边缘。但如果边缘从位置 (5,5) 移到 (6,6)，卷积输出中检测到的位置也跟着移动了——**特征图变了**。

```
原始图像:              平移后:

  ┌────────┐            ┌────────┐
  │  ●     │            │        │
  │ │      │            │  ●     │  ← 边缘下移了 1 像素
  │ │      │            │ │      │
  │        │            │ │      │
  └────────┘            └────────┘

卷积输出 (特征图):      卷积输出:

  ┌────┐                 ┌────┐
  │ ●  │                 │    │
  │ │  │                 │ ●  │  ← 特征也跟着移了!
  └────┘                 └────┘

  特征图发生了变化 → 后面的全连接层看到不同的输入
```

### 2. 全连接层和 softmax 不是平移不变的

卷积层之后是全连接层 + softmax。全连接层对输入位置**非常敏感**：

```
全连接层的输入是展平的特征图:

  原始特征图 (展平):    平移后特征图 (展平):
  [1, 0, 0, 0, ...]    [0, 1, 0, 0, ...]
   ↑ 位置 0 有特征       ↑ 位置 1 有特征

  对全连接层来说这是完全不同的输入！
  权重 w[0] 和 w[1] 是不同的参数
```

所以即使卷积层是等变的，整个网络（卷积+全连接+softmax）**不是**完全平移不变的。

### 3. 数据增强帮助网络学到"位置无关"的判断

```
没有数据增强:
  网络只见过数字在正中间的图
  → 全连接层学到"位置 (5,5) 有竖线 → 数字 1"
  → 如果数字稍微偏了，全连接层就不认了

有数据增强 (平移 ±1):
  网络见过同一数字在不同位置的图
  → 全连接层被迫学到"不管竖线在 (5,5) 还是 (6,6)，都是数字 1"
  → 泛化到没见过的位置
```

### 4. 额外好处：防止过拟合

```
原始数据: 50000 张
  → 网络可能死记硬背每张图

扩展数据: 250000 张 (5倍)
  → 同一张图出现在 5 个位置
  → 网络无法死记硬背，被迫学习"真正有用的模式"
  → 起到正则化作用
```

### 5. 更直观的比喻

```
卷积核 = "放大镜"，可以到处移动看东西

但如果只有一张照片:
  你只在一个位置看过这个字
  → 换个位置你就不确定了

数据增强 = "同一个字写在不同位置"
  → 你见过各种位置
  → 不管字在哪都能认出来
```

---

## 总结

| | 卷积层 | 全连接层 | 整个网络 |
|---|---|---|---|
| 平移等变？ | ✅ 是 | ❌ 否 | 部分 |
| 平移不变？ | ❌ 否 | ❌ 否 | ❌ 不是完全不变 |

**数据增强弥补了全连接层缺乏平移不变性的缺陷，让网络见过各种位置的同一数字，被迫学到位置无关的判断能力。卷积层的等变性帮了一部分忙，但不够——数据增强补上了剩下的部分。**
