# S 型神经元模拟感知机

> 出自《神经网络与深度学习》第一章练习

---

## 第一部分

**题目：** 假设我们把一个感知机网络中的所有权重和偏置乘以一个正的常数 c > 0。证明网络的行为并没有改变。

**证明：**

感知机的输出规则为：

- 当 w·x + b > 0 时，输出 1
- 当 w·x + b ≤ 0 时，输出 0

将所有权重和偏置乘以 c > 0 后，新的判断条件变为：

```
cw·x + cb = c(w·x + b)
```

因为 c > 0，不等号方向不变：

- w·x + b > 0  ⟺  c(w·x + b) > 0  → 输出仍为 1
- w·x + b ≤ 0  ⟺  c(w·x + b) ≤ 0  → 输出仍为 0

因此网络行为完全不变。 ∎

---

## 第二部分

**题目：** 假设有上题中相同的感知机网络，输入固定，且对任意感知机都有 w·x + b ≠ 0。现在用 S 型神经元替换所有感知机，并把权重和偏置乘以 c > 0。证明在 c → ∞ 时，S 型神经元网络的行为与感知机网络完全一致。当 w·x + b = 0 时为什么会不同？

**证明：**

S 型神经元的输出为 σ(c(w·x + b))，其中：

```
σ(z) = 1 / (1 + e^(-z))
```

**情况 1：w·x + b > 0**

当 c → ∞ 时，c(w·x + b) → +∞，因此：

```
σ(c(w·x + b)) = 1 / (1 + e^(-c(w·x + b)))
             → 1 / (1 + 0)
             = 1
```

与感知机输出一致。

**情况 2：w·x + b < 0**

当 c → ∞ 时，c(w·x + b) → -∞，因此：

```
σ(c(w·x + b)) = 1 / (1 + e^(-c(w·x + b)))
             → 1 / (1 + ∞)
             = 0
```

与感知机输出一致。

**当 w·x + b = 0 时：**

```
σ(c · 0) = σ(0) = 1 / (1 + e^0) = 1 / 2 = 0.5
```

无论 c 多大，输出始终为 0.5。而感知机在 w·x + b ≤ 0 时输出 0。因此两者在边界点 w·x + b = 0 处行为不同。 ∎
