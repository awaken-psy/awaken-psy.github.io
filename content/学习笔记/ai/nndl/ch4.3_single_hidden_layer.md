# 单隐藏层通用性证明

> 出自《神经网络与深度学习》第 4.3 节末尾练习

---

## 原题

![题目](学习笔记/ai/nndl/image/ch04_single_hidden_layer_exercise.png)

**题意：** 4.3 节用了两个隐藏层（第一层造塔+高原，第二层 if-then-else 削平高原）。能否只用一个隐藏层？提示分三步。

---

## (a) 任意方向的阶跃函数

### 问题

4.3 节中的阶跃函数只能沿 $x$ 或 $y$ 轴方向。能否让阶跃沿**任意方向**？

### 证明

考虑一个两输入神经元，$w_1$ 和 $w_2$ 都不为零：

$$z = w_1 x + w_2 y + b$$

阶跃发生在 $z = 0$ 处：

$$w_1 x + w_2 y + b = 0$$

这是一条**直线方程**，斜率为 $-w_1/w_2$，截距为 $-b/w_2$。

- 4.3 节：$w_2 = 0$，退化为 $x = -b/w_1$，即垂直于 $x$ 轴的阶跃线
- 一般情况：$w_1, w_2$ 都不为零，阶跃线可以是**任意角度的直线**

```
w2=0 (4.3节):          w1, w2 都≠0 (任意方向):

  y                       y
  │  │                    │    ╲
  │  │                    │      ╲
  │  │                    │        ╲
  └──┴── x                └─────────╲ x
     ↑                       任意角度
   x方向阶跃
```

增大 $w_1, w_2$（同时缩放，保持方向不变），sigmoid 越来越陡，近似阶跃函数。 $\blacksquare$

## (b) 圆形塔型函数

### 问题

用 (a) 中的任意方向阶跃，能否构造**圆形**塔型函数？

### 思路

4.3 节用 4 个阶跃（上下左右）拼出方形塔。如果用**很多个不同方向的阶跃**，就能拼出近似圆形的塔。

### 构造方法

取 $N$ 个方向，均匀分布在 $360°$：

$$\theta_k = \frac{2\pi k}{N}, \quad k = 0, 1, \dots, N-1$$

每个方向的阶跃线切掉圆外的一半：

- 方向 $\theta_k$ 的阶跃：$w_1 = \cos\theta_k$, $w_2 = \sin\theta_k$
- 阶跃位置 $s$：阶跃线距离圆心的距离
- 偏置 $b = -s$（圆半径方向截断）

$N$ 个方向的阶跃叠加后：

```
N=4 (方形):              N=8 (八边形):           N→∞ (圆形)

  ┌──┐                    ╱  ╲                   ╱    ╲
  │  │                   ╱    ╲                │      │
  └──┘                  │      │               │      │
                        ╲    ╱                 ╲    ╱
                         ╲  ╱                   ╲  ╱

  4 个方向阶跃              8 个方向阶跃             无穷多方向 → 圆
```

每个阶跃函数用一对神经元（上跳 + 下跳）控制高度，$N$ 对构造一个圆形塔。

### 消除高原

和 4.3 节一样，叠加多个方向阶跃后会产生高原。但如果我们把所有阶跃线设在同一个半径 $r$ 处，并且所有权重方向一致（都指向圆内），则：

- 圆内：所有阶跃都"开启" → 输出 $N \cdot h$（最大）
- 圆外至少有一个阶跃"关闭" → 输出降低

用 if-then-else 思路或直接选择合适的 $h$ 和 $b$，可以削平高原只留圆塔。 $\blacksquare$

## (c) 用圆形塔近似任意函数

### 问题

用 (b) 中的圆形塔，近似任意二元函数 $f(x, y)$。

### 证明

和方形塔完全一样：

1. 在 $(x, y)$ 平面上不同位置 $(x_i, y_i)$ 放置圆形塔
2. 每个塔的高度 $h_i = \sigma^{-1}(f(x_i, y_i))$
3. 塔的半径 $r$ 越小 → 近似越精确
4. 塔的数量越多 → 覆盖越完整

$$f(x, y) \approx \sum_i h_i \cdot \text{circle\_tower}_i(x, y)$$

当塔数量 → ∞，半径 → 0 时，近似误差 → 0。 $\blacksquare$

## 关键区别：一个隐藏层 vs 两个隐藏层

| | 两个隐藏层（4.3 节方法） | 一个隐藏层（本证明） |
|---|---|---|
| 阶跃方向 | 只能沿 $x$ 或 $y$ 轴 | 任意方向 |
| 塔的形状 | 方形 | 圆形 |
| 削高原 | 需要第二隐藏层做 if-then-else | 不需要（方向足够多时自然逼近圆形） |
| 神经元数量 | 4 个/塔 + 1 个削平 | $2N$ 个/塔（$N$ 个方向，每方向 2 个） |
| 精度 | 台阶越细越好 | 塔越细、方向越多越好 |

### 为什么一个隐藏层就够

关键在于 4.3 节的方法受限于"只能沿 $x/y$ 方向阶跃"，所以方形塔有高原问题，需要第二层削平。

而任意方向阶跃可以直接构造圆形塔，**不需要第二层 if-then-else 削平**——圆塔本身就是干净的（圆内为 1，圆外为 0），直接在输出层叠加即可。

**一句话：放宽阶跃方向到任意角度后，一个隐藏层就能构造干净的圆形塔，直接叠加近似任意函数，不需要第二隐藏层。**
