# 为何正则化可以帮助减轻过拟合，提升泛化能力

> 出自《神经网络与深度学习》第三章，结合多方资料整理

---

## 1. 什么是过拟合

### 现象

网络在训练数据上表现极好，但在未见过的测试数据上表现很差。

```
训练准确率: 99.99%  ← 几乎完美
测试准确率: 82.00%  ← 大幅下降
```

### 本质

网络不是在学习"规律"，而是在"死记硬背"训练数据中的噪声和细节。

### 经典例子

```
欠拟合:        恰好:          过拟合:
                                    
  数据点           数据点           数据点
  散乱分布         散乱分布         散乱分布
    ·   ·           ·   ·           ·   ·
  ·       ·       ·       ·       ·       ·
      ·               ·               ·
  ─────────     ╱─────────╲     ╱╲╱╲╱╲╱╲╱╲
  直线穿过         平滑曲线         疯狂扭曲穿过每个点

训练误差: 大     训练误差: 小      训练误差: ≈0
测试误差: 大     测试误差: 小      测试误差: 大
```

### 过拟合的常见原因

| 原因 | 说明 |
|---|---|
| 参数太多 | 网络太大，记住所有细节 |
| 训练数据太少 | 没见过足够的变化 |
| 训练太久 | epoch 太多，过度优化 |
| 缺乏正则化 | 没有任何约束 |

## 2. 正则化的直觉

### 核心思想

**在代价函数中加一个惩罚项，阻止权重变得太大。**

### 公式

原始代价（以二次代价为例）：

$$C_0 = \frac{1}{2n}\sum_x \|a^L - y\|^2$$

加入 L2 正则化后：

$$C = C_0 + \frac{\lambda}{2n}\sum_w w^2$$

- $C_0$：原始代价（网络对训练数据的拟合程度）
- $\frac{\lambda}{2n}\sum_w w^2$：正则化项（惩罚大权重）
- $\lambda$：正则化系数（控制惩罚力度）
- $n$：训练样本数

### 比喻

```
没有正则化:
  学生考试复习，把每道练习题的答案死记硬背
  → 练习题满分，考试题不会做

有正则化:
  老师要求"答案不能太极端"（限制权重大小）
  → 学生被迫总结规律，而非死记硬背
  → 练习题略低分，但考试题也能做好
```

---

## 3. 为什么惩罚大权重有效

### 奥卡姆剃刀原则

**最简单的解释往往是最可能的。** 在神经网络中，"简单"意味着权重小。

### 大权重 = 复杂模型

```
权重很小（正则化强）:
  z = 0.01×x1 + 0.02×x2 + 0.01×x3 + ...
  → 输出对所有输入都"温和"响应
  → 模型简单，只抓住主要趋势

权重很大（无正则化）:
  z = 847.3×x1 + (-523.1)×x2 + 291.7×x3 + ...
  → 输出对某些输入极度敏感
  → 模型复杂，能记住每个细节
```

### 扰动敏感性

大权重意味着网络对输入的微小变化极度敏感：

```
输入 x = [0.5, 0.3]
权重 w = [1000, 800]
  z = 1000×0.5 + 800×0.3 = 740

输入稍微变化 x' = [0.501, 0.3]
  z' = 1000×0.501 + 800×0.3 = 741
  → Δz = 1（变化大！）

权重 w = [0.1, 0.08]
  z = 0.1×0.5 + 0.08×0.3 = 0.074
  z' = 0.1×0.501 + 0.08×0.3 = 0.0741
  → Δz = 0.0001（变化小）
```

**小权重 → 对噪声不敏感 → 泛化能力强。** 真实数据中的噪声不影响整体趋势，但大权重会把噪声放大。

## 4. L2 正则化的数学解释

### 更新规则的变化

原始梯度下降：

$$w \to w - \eta \frac{\partial C_0}{\partial w}$$

正则化后：

$$w \to w - \eta \left(\frac{\partial C_0}{\partial w} + \frac{\lambda}{n}w\right)$$

展开：

$$w \to \left(1 - \frac{\eta\lambda}{n}\right)w - \eta\frac{\partial C_0}{\partial w}$$

### 权重衰减

每次更新时，权重先乘以 $(1 - \frac{\eta\lambda}{n})$，这是一个小于 1 的因子：

```
w_new = (1 - ηλ/n) × w_old - η × ∇C_0
         ──────────────
         权重衰减因子（< 1）
```

这就是为什么 L2 正则化也叫**权重衰减（weight decay）**——每一步都先把权重缩小一点点，再根据梯度调整。

### 对应到代码

```python
# network2.py 中的 update_mini_batch:
self.weights = [(1-eta*(lmbda/n))*w-(eta/len(mini_batch))*nw
                for w, nw in zip(self.weights, nabla_w)]
#              ─────────────────      ────────────────────
#              权重衰减项              原始梯度项
```

## 5. 贝叶斯视角的解释

### 先验概率

L2 正则化等价于假设权重服从**均值为 0 的高斯先验分布**：

$$w \sim N(0, \sigma^2)$$

意思是：在看到数据之前，我们倾向于认为权重应该接近 0。

### 最大后验估计（MAP）

- 没有正则化：最大似然估计（MLE），只管拟合数据
- 有 L2 正则化：最大后验估计（MAP），拟合数据 + 尊重先验

$$\text{后验} \propto \text{似然} \times \text{先验}$$

正则化项 $\frac{\lambda}{2n}\sum w^2$ 就是先验 $-\log P(w)$ 的体现。$\lambda$ 越大，先验越强（越倾向于小权重）。

## 6. 双下降现象

### 传统观点的挑战

传统认为：模型越大越容易过拟合。但现代深度学习发现了一个反直觉现象——**双下降（Double Descent）**：

```
测试误差
  │
  ●                              ← 第二次下降
  │ ↘                        ╱
  │   ↘                    ╱
  │     ↘                ╱
  │       ●            ╱
  │         ↘        ╱
  │           ↘    ╱
  │             ↘╱     ← 过拟合峰值（临界点）
  │           
  │           ╱
  │         ╱
  │       ╱
  │     ●  ← 传统最优点
  │   ╱
  │ ╱
  └────────────────────────── 模型复杂度
  欠拟合  传统最优点  过拟合峰值  现代大模型
```

- 模型从简单到复杂：测试误差先降（欠拟合→刚好）→ 再升（过拟合峰值）→ **又降**（大模型+正则化）
- 超过临界点后，更大的模型反而泛化更好

### 正则化的角色

正则化在双下降中起到**压低过拟合峰值**的作用：

```
无正则化:  峰值很高
有正则化:  峰值被压平，过渡更平滑
```

这说明正则化不仅仅是"限制模型复杂度"，在大模型场景下它帮助模型更好地利用额外的参数。

## 7. 其他正则化方法

### 7.1 L1 正则化

$$C = C_0 + \frac{\lambda}{n}\sum_w |w|$$

与 L2 的区别：

| | L2 正则化 | L1 正则化 |
|---|---|---|
| 惩罚项 | $w^2$ | $\|w\|$ |
| 效果 | 权重变小但不为 0 | 权重变稀疏（很多变 0） |
| 梯度 | $\frac{\lambda}{n}w$（与 $w$ 成正比） | $\frac{\lambda}{n}\text{sign}(w)$（常数，与 $w$ 大小无关） |
| 适用 | 一般场景 | 特征选择 |

L1 的稀疏性来自梯度是常数：无论 $w$ 多小，每步都减固定值 $\eta\lambda/n$，最终很多 $w$ 被减到恰好 0。而 L2 的梯度 $\propto w$，$w$ 越小衰减越慢，趋近 0 但不到 0。

### 7.2 Dropout（随机失活）

训练时随机"关闭"一部分神经元：

```
训练时（每次随机选择不同的神经元关闭）:

  完整网络:      Dropout 后:
  
  ○ ─ ○         ○ ─ ○  (关闭)
  │ ╲ │         │   │
  ○ ─ ○    →    ○ ─ ○  (保留)
  │ ╲ │         │   │
  ○ ─ ○         ○ ─ ○  (保留)
                 (关闭)

  每次用不同子网络训练，测试时用全部神经元（权重缩放）
```

**为什么有效？**

1. **防止共适应**：神经元不能依赖某个特定连接，必须独立学到有用特征
2. **隐式集成**：每次用不同子网络 = 训练了多个不同模型，测试时取平均
3. **类似于 L2**：Dropout 会自动缩放权重，效果接近 L2 正则化

### 7.3 早停法（Early Stopping）

不一直训练到收敛，而是在验证集准确率不再提升时停止：

```
准确率
  │
  │              训练准确率
  │            ╱─────────────
  │          ╱
  │        ╱
  │      ╱     ← 训练还在涨
  │    ╱    
  │  ╱          验证准确率
  │╱          ╱────●  ← 早停点
  │         ╱    │
  │       ╱      │ 过了这里验证开始下降 = 过拟合
  │     ╱        ↓
  │   ╱          
  └────────────────────── epoch
```

### 7.4 数据增强

不改变模型，通过人为扩充训练数据来减轻过拟合：

```
原始图像:       增强:
┌───────┐      ┌───────┐  ┌───────┐  ┌───────┐
│  3    │  →   │  3    │  │   3   │  │  3    │
│       │      │ (平移) │  │(旋转) │  │(缩放) │
└───────┘      └───────┘  └───────┘  └───────┘

MNIST: 每张图平移±1像素 → 50000 张变 250000 张
```

数据越多，网络越难死记硬背，被迫学习通用规律。

## 8. 正则化参数 λ 的选择

### λ 太大

```
权重被压到几乎为 0 → 网络变成线性模型 → 欠拟合
训练误差: 高
测试误差: 高
```

### λ 太小

```
权重不受约束 → 过拟合
训练误差: ≈0
测试误差: 高
```

### λ 合适

```
权重适度减小 → 拟合 + 泛化平衡
训练误差: 较低
测试误差: 较低
```

### 实验方法

用验证集调参：尝试 $\lambda = 0.001, 0.01, 0.1, 1.0, 10.0, 100.0$，选验证集准确率最高的。

---

## 9. 总结

### 为什么正则化有效？

| 视角 | 解释 |
|---|---|
| **直觉** | 惩罚大权重 → 阻止死记硬背 → 被迫学规律 |
| **数学** | 权重衰减因子 → 每步缩小权重 → 降低噪声敏感性 |
| **贝叶斯** | 高斯先验 → 倾向小权重 → MAP 估计 |
| **信息论** | 限制模型复杂度 → 降低有效VC维 → 提高泛化界 |

### 一句话

**正则化通过限制权重大小，迫使网络学习简洁的规律而非死记硬背训练数据，从而在新数据上泛化得更好。**
