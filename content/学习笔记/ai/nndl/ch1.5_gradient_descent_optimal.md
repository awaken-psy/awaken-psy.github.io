# 梯度下降是最优下降方向的证明

> 出自《神经网络与深度学习》第一章练习

---

## 原题

![题目](学习笔记/ai/nndl/image/ch01_gradient_descent_exercise.png)

**题意：**

我们要找一个 Δv，使得 C 的变化量 ΔC ≈ ∇C · Δv 尽可能小（即 C 下降最多），同时限制步长 ||Δv|| = ε（固定值，不能走太远）。证明最优解是 Δv = -η∇C，其中 η = ε / ||∇C||。

另外，解释一元函数时梯度下降的几何意义。

---

## 第一题：证明 Δv = -η∇C 是最优下降方向

### 什么是柯西-施瓦茨不等式？

对任意两个向量 a 和 b：

```
|a · b| ≤ ||a|| × ||b||
```

等号成立（即 a · b 取到极值）当且仅当 **a 和 b 方向相同或相反**（即 a = λb，λ 为实数）。

- 方向相同（λ > 0）：a · b = +||a|| × ||b||（取最大值）
- 方向相反（λ < 0）：a · b = -||a|| × ||b||（取最小值）

### 要最小化什么？

我们要最小化：

```
∇C · Δv
```

这代表 C 的变化量。越小（越负），C 下降越多。

### 约束条件是什么？

```
||Δv|| = ε    （步长固定）
```

### 证明过程

**第一步：用柯西-施瓦茨不等式给出下界**

设 a = ∇C，b = Δv，根据柯西-施瓦茨不等式：

```
∇C · Δv ≥ -||∇C|| × ||Δv||
```

即 ∇C · Δv 最小只能到 -||∇C|| × ||Δv||，不可能更小。

**第二步：代入约束 ||Δv|| = ε**

```
∇C · Δv ≥ -||∇C|| × ε
```

所以 ∇C · Δv 的最小可能值是 **-||∇C|| × ε**。

**第三步：什么时候取到这个最小值？**

柯西-施瓦茨不等式等号成立（取到最小值）的条件是：**Δv 和 ∇C 方向相反**，即：

```
Δv = -η∇C    （η > 0，某个正常数）
```

**第四步：用约束确定 η 的值**

||Δv|| = ε 代入：

```
||-η∇C|| = ε
η × ||∇C|| = ε
η = ε / ||∇C||
```

**结论：**

```
Δv = -η∇C,  其中 η = ε / ||∇C||
```

此时 ∇C · Δv = -||∇C|| × ε，是所有步长为 ε 的方向中让 C 下降最多的。 ∎

---

## 直觉理解

想象你站在山坡上，蒙着眼睛，想往下走一步（步长固定为 ε）。

- ∇C 是梯度，指向**最陡上坡**方向
- -∇C 指向**最陡下坡**方向
- 柯西-施瓦茨不等式告诉我们：在所有固定长度的方向中，**沿着 -∇C 方向走，高度下降最多**

所以梯度下降法 = "每一步都沿着最陡的下坡方向走"，这就是为什么它是最优的下降策略。

## 第二题：一元函数的几何解释

### 一元函数的情况

当 C 只是一个变量的函数 C(v) 时：

- 梯度 ∇C 就退化为导数 C'(v)（一个标量，不是向量）
- Δv 就是一个标量（正的或负的，表示往左走还是往右走）

### 几何意义

想象一条曲线 y = C(v)：

```
C
|        ╱
|       ╱
|      ╱        ← 曲线
|     ╱
|    ●           ← 你在这里 (当前 v)
|   
+---------------- v
```

- **C'(v) > 0**（曲线在上升）：梯度下降取 Δv = -ηC'(v) < 0，即**向左走**（走向更低处）
- **C'(v) < 0**（曲线在下降）：梯度下降取 Δv = -ηC'(v) > 0，即**向右走**（走向更低处）

### 一句话总结

一元函数的梯度下降，就是：**斜率为正就往左走，斜率为负就往右走**——始终沿着曲线下降的方向移动。

```
C
|         ╲
|          ╲     斜率 < 0 → 向右走 ↓
|           ╲
|            ●→
|       
|     ←●           斜率 > 0 → 向左走 ↓
|    ╱
|   ╱
|  ╱
+---------------- v
```

无论斜率正负，-C'(v) 的符号都会让 v 朝曲线更低的方向移动。这就是一元函数下梯度下降的几何意义。
