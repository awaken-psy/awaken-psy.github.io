# 卷积神经网络中的反向传播

> 出自《神经网络与深度学习》第 6.1 节

---

## 原题

![题目](学习笔记/ai/nndl/image/ch06_conv_backprop_exercise.png)

**题目：** 全连接层的反向传播方程是 BP1–BP4。假设网络包含卷积层、最大值池化层和全连接输出层，反向传播方程如何修改？

---

## 0. 先搞清楚：全连接反向传播回顾

在看卷积之前，先回忆全连接层的 BP2-BP4 到底在做什么：

```
前向:  z_j = Σ_k w_jk × a_k + b_j      （第 j 个输出神经元）
       a_j = σ(z_j)

反向:
  BP4:  ∂C/∂w_jk = a_k × δ_j           （权重梯度 = 输入 × 误差）
  BP3:  ∂C/∂b_j  = δ_j                  （偏置梯度 = 误差）
  BP2:  δ_j = (Σ_m w_mj × δ_m) × σ'(z_j) （误差 = 后层误差按权重传回来）
```

**核心逻辑：**
- BP4：这个权重连接了输入 $a_k$ 和输出 $j$，梯度就是两者的乘积
- BP3：偏置对输出的影响是 1:1，所以梯度 = 误差
- BP2：把后一层的误差按权重"反向分配"回当前层

**卷积层的反向传播，本质上也是这三件事，只是"连接方式"变了。**

---

## 1. 卷积层的前向传播：到底在算什么

### 全连接 vs 卷积

```
全连接层:
  每个输出神经元连接所有输入
  每条连接有独立的权重 w_jk
  z_j = Σ_k w_jk × a_k + b_j

  [a1] ──w11──→ [z1]
  [a2] ──w12──→ [z1]      每条线一个独立权重
  [a3] ──w13──→ [z1]
  [a1] ──w21──→ [z2]
  ...
```

```
卷积层:
  一个小核（如 3×3）在输入上滑动
  所有位置共享同一组权重（核的 9 个数）
  z[i,j] = Σ_{u,v} w[u,v] × a[i+u, j+v] + b

  输入:           卷积核 w (3×3):     输出:

  a b c d         w0 w1 w2           z[0,0] = w0·a + w1·b + w3·e + w4·f
  e f g h   ×     w3 w4 w5    =      z[0,1] = w0·b + w1·c + w3·f + w4·g
  i j k l         w6 w7 w8           （核滑到每个位置，逐元素相乘再求和）
  m n o p
                  ↑ 同一个核在所有位置复用
```

**关键区别：权重共享。** 全连接层每个连接有独立权重，卷积层同一个核在所有位置共用。

---

## 2. 卷积层的 BP4（权重梯度）

### 回到 BP4 的本质

全连接的 BP4：$\frac{\partial C}{\partial w_{jk}} = a_k \times \delta_j$

意思是：权重 $w_{jk}$ 连接了输入 $a_k$ 和输出 $j$，它的梯度 = 这个输入 × 这个输出的误差。

### 卷积层的权重梯度

卷积核的某个权重 $w[u,v]$ 在前向传播中被**多次使用**——核在每个滑动位置都用到它。

以 3×3 核的 $w_0$（左上角）为例：

```
前向传播时 w_0 被用在了:

  位置 (0,0): z[0,0] += w_0 × a[0,0]
  位置 (0,1): z[0,1] += w_0 × a[0,1]
  位置 (0,2): z[0,2] += w_0 × a[0,2]
  位置 (1,0): z[1,0] += w_0 × a[1,0]
  ...
  每个输出位置都用到了 w_0！

所以 w_0 的梯度 = 所有使用它的地方的 (输入 × 误差) 之和:

  ∂C/∂w_0 = a[0,0]×δ[0,0] + a[0,1]×δ[0,1] + a[0,2]×δ[0,2] + ...
          = Σ_{i,j} a[i,j] × δ[i,j]
```

**这就是一个卷积运算！**

$$\boxed{\frac{\partial C}{\partial w} = a^{l-1} * \delta^l}$$

### 具体数字例子

```
输入 a (3×3):         误差 δ (2×2):        权重梯度 ∂C/∂w_0:

  1 2 3                 0.1 0.2            w_0 用在:
  4 5 6                 0.3 0.4              a[0,0]×δ[0,0] = 1×0.1 = 0.1
  7 8 9                                      a[0,1]×δ[0,1] = 2×0.2 = 0.2
                                             a[1,0]×δ[1,0] = 4×0.3 = 0.3
  卷积核 (2×2):                              a[1,1]×δ[1,1] = 5×0.4 = 0.4
  w0 w1                                    ∂C/∂w_0 = 0.1+0.2+0.3+0.4 = 1.0
  w2 w3
                                         同理:
                                         ∂C/∂w_1 = 2×0.1 + 3×0.2 + 5×0.3 + 6×0.4 = 4.1
                                         ∂C/∂w_2 = 4×0.1 + 5×0.2 + 7×0.3 + 8×0.4 = 6.5
                                         ∂C/∂w_3 = 5×0.1 + 6×0.2 + 8×0.3 + 9×0.4 = 7.7
```

**每个核权重的梯度 = 输入和误差在对应位置的卷积（逐元素相乘再求和）。**

---

## 3. 卷积层的 BP3（偏置梯度）

### 全连接的 BP3

$\frac{\partial C}{\partial b} = \delta$

偏置加到一个输出神经元上，梯度 = 那个神经元的误差。

### 卷积层的偏置梯度

卷积层的偏置 $b$ 是一个标量（每个卷积核一个偏置），它被加到**输出特征图的每个位置**：

```
前向: z[i,j] = (卷积结果) + b

  z[0,0] += b
  z[0,1] += b
  z[1,0] += b
  z[1,1] += b
  ...每个位置都加了同一个 b

所以 b 的梯度 = 所有位置的误差之和:

  ∂C/∂b = δ[0,0] + δ[0,1] + δ[1,0] + δ[1,1] + ...
        = Σ_{i,j} δ[i,j]
```

$$\boxed{\frac{\partial C}{\partial b} = \sum_{i,j} \delta^l_{i,j}}$$

**因为偏置被所有位置共享，所以梯度是所有位置误差的求和。**

---

## 4. 卷积层的 BP2（误差传播）

### 全连接的 BP2

$\delta^l = (w^{l+1})^T \delta^{l+1} \odot \sigma'(z^l)$

把后一层的误差按权重的转置"反向分配"回当前层。

### 卷积层的误差传播

前向卷积时，卷积核在输入上滑动产生输出。反向传播时要反过来：把输出层的误差"展开"回输入层的尺寸。

**核心思路：前向时核怎么"扫描"输入，反向时就怎么把误差"撒回"输入。**

```
前向卷积 (核从左上滑到右下):

  输入 (4×4):          核 (2×2):         输出 (3×3):
  a b c d              w0 w1             z00 z01 z02
  e f g h      ×       w2 w3      =      z10 z11 z12
  i j k l                                 z20 z21 z22
  m n o p

  z00 = w0·a + w1·b + w2·e + w3·f    ← 输入 a 参与了 z00 的计算
  z01 = w0·b + w1·c + w2·f + w3·g    ← 输入 a 没参与
  ...
```

反向传播时，输入位置 $a[0,0]$ 的误差 = 它参与过的所有输出的误差之和：

```
a[0,0] 只参与了 z[0,0] 的计算 (通过 w0):
  δ_a[0,0] = w0 × δ[0,0]

b[0,1] 参与了 z[0,0] (通过 w1) 和 z[0,1] (通过 w0):
  δ_b[0,1] = w1 × δ[0,0] + w0 × δ[0,1]

f[1,1] 参与了 z[0,0](w3), z[0,1](w2), z[1,0](w1), z[1,1](w0):
  δ_f[1,1] = w3 × δ[0,0] + w2 × δ[0,1] + w1 × δ[1,0] + w0 × δ[1,1]
```

**这个"把误差撒回去"的操作，正好是翻转 180° 的核与误差做 full convolution：**

$$\boxed{\delta^l = (w^{l+1}_{\text{flip}} \star \delta^{l+1}) \odot \sigma'(z^l)}$$

- $w_{\text{flip}}$：卷积核翻转 180°（上下翻转 + 左右翻转）
- $\star$：full convolution（在边缘补零，输出比输入大）
- $\odot \sigma'(z^l)$：和全连接一样，乘激活函数导数

### 为什么是翻转 180°？

因为前向卷积时核从左上往右下滑动，反向传播要"原路返回"，核的运动方向反过来。翻转核就是让误差沿着和前向相同的方向"撤回"。

### 为什么是 full convolution？

前向卷积使输出变小（valid convolution，不补零）。反向传播要把小尺寸的误差恢复成大尺寸的输入，所以用 full convolution（补零扩大）。

## 5. 最大值池化层的反向传播

### 前向传播

池化层没有权重和偏置，只是下采样。对每个窗口取最大值：

```
前向: 2×2 窗口 → 取 max

  [1  3]     →   max = 7
  [5  7]          ↑ 只有 7 的位置"贡献"了输出
```

### 反向传播

梯度只回传给**前向传播时被选中的那个最大值位置**，其他位置梯度为 0：

$$\delta^{l-1}_{i,j} = \begin{cases} \delta^l_{i',j'} & \text{如果 } (i,j) \text{ 是窗口内最大值的位置} \\ 0 & \text{其他} \end{cases}$$

```
前向:  [1  3]  →  max=7         反向:
       [5  7]                      [0  0]
              ↑ 7 被选中            [0  δ]
                                        ↑ 只有 7 的位置收到梯度
```

### 直觉

池化层是个"路由器"：
- 前向时：从 $2\times2$ 中选最大的传出去，其他三个直接丢弃
- 反向时：把梯度原路退回给被选中的那个位置，没被选中的梯度为 0

**为什么其他位置是 0？** 因为它们对输出没有任何贡献（$\frac{\partial \text{output}}{\partial \text{其他位置}} = 0$），所以梯度也是 0。

### 没有参数

池化层没有 $w$ 和 $b$，所以没有 BP3/BP4，只需要把误差 $\delta$ 路由回去。

## 6. 完整数据流

```
输入 a^0 (28×28)
    ↓  前向: z^1 = w^1 * a^0 + b^1,  a^1 = σ(z^1)
卷积层 1
    ↓  前向: max pooling, a^2 = pool(a^1)
池化层 1
    ↓  前向: z^3 = w^3 * a^2 + b^3,  a^3 = σ(z^3)
卷积层 2
    ↓  前向: max pooling, a^4 = pool(a^3)
池化层 2
    ↓  前向: z^5 = w^5 · a^4 + b^5 (展平后矩阵乘法)
全连接层
    ↓
输出

反向传播:
    全连接层:  δ^5 = (a^5 - y) ⊙ σ'(z^5)              ← BP1
              ∇w^5 = a^4 · δ^5                          ← BP4
              ∇b^5 = δ^5                                ← BP3

    池化层 2:  δ^4 = route(δ^5 reshape)                 ← 路由梯度

    卷积层 2:  δ^3 = (w^4_flip ⋆ δ^4) ⊙ σ'(z^3)       ← 卷积版 BP2
              ∇w^3 = a^2 * δ^3                          ← 卷积版 BP4
              ∇b^3 = Σ δ^3                              ← 卷积版 BP3

    池化层 1:  δ^2 = route(δ^3)                          ← 路由梯度

    卷积层 1:  δ^1 = (w^2_flip ⋆ δ^2) ⊙ σ'(z^1)       ← 卷积版 BP2
              ∇w^1 = a^0 * δ^1                          ← 卷积版 BP4
              ∇b^1 = Σ δ^1                              ← 卷积版 BP3
```

## 7. 三种层的 BP 对照表

| | 全连接层 | 卷积层 | 最大值池化层 |
|---|---|---|---|
| 前向 | $z = w \cdot a + b$ | $z = w * a + b$ | $a_{\text{out}} = \max(\text{window})$ |
| 有参数？ | ✅ $w, b$ | ✅ $w, b$ | ❌ 无 |
| BP1 (输出层误差) | $\delta^L = \nabla_a C \odot \sigma'$ | 同左 | 不适用 |
| BP2 (误差传播) | $(w^{l+1})^T \delta^{l+1} \odot \sigma'$ | $w_{\text{flip}} \star \delta^{l+1} \odot \sigma'$ | 路由到最大值位置 |
| BP3 (偏置梯度) | $\nabla b = \delta$ | $\nabla b = \sum_{i,j} \delta_{i,j}$ | 无偏置 |
| BP4 (权重梯度) | $a_{\text{in}} \cdot \delta_{\text{out}}$ | $a_{\text{in}} * \delta_{\text{out}}$ | 无权重 |

---

## 8. 一句话总结

| 层类型 | 反向传播在做什么 |
|---|---|
| **全连接层** | 矩阵乘法 → 反向是转置矩阵乘法 |
| **卷积层** | 卷积 → 反向还是卷积（权重梯度是输入卷误差，误差传播是翻转核做 full conv） |
| **池化层** | 取最大值 → 反向只把梯度传给最大值位置 |

**卷积反向传播的本质：前向卷积怎么"扫描"输入，反向就怎么"撒回"误差。权重共享导致梯度需要累加，偏置共享导致梯度需要求和。池化层没有参数，只是个梯度路由器。**
