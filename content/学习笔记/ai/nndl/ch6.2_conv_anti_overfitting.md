# 为什么卷积层天然抗过拟合

> 出自《神经网络与深度学习》第 6.2 节

---

## 核心原因：参数少

卷积层通过两个机制大幅减少参数量，而参数越少越不容易过拟合。

### 机制 1：局部连接

**全连接层**：每个输出神经元连接**所有**输入

```
输入: 784 个像素    输出: 30 个神经元

  全连接: 784 × 30 = 23,520 个权重
  每个输出神经元连 784 个输入

  [a1] ──→ [z1]
  [a2] ──→ [z1]
  [a3] ──→ [z1]
  ...      (全部连接)
  [a784] ─→ [z1]
```

**卷积层**：每个输出神经元只连接**局部**输入（核大小，如 5×5=25）

```
输入: 28×28 = 784 像素    卷积核: 5×5

  卷积: 5×5 = 25 个权重
  每个输出位置只看 25 个输入像素

  [a1..a5]     ──→ [z1]    ← 只连 5×5 邻域
  [a6..a10]    ──→ [z2]    ← 滑动到下个位置
  ...
```

**参数对比：**

| | 全连接 | 卷积 (5×5 核) |
|---|---|---|
| 一个输出神经元的权重 | 784 | 25 |
| 30 个输出神经元的权重 | 23,520 | **25**（共享） |

### 机制 2：权重共享

**全连接层**：每条连接有独立权重

```
全连接: 每个位置都是不同的权重
  w[1,1], w[1,2], ..., w[1,784]   ← z1 的 784 个权重
  w[2,1], w[2,2], ..., w[2,784]   ← z2 的 784 个权重
  ...
  共 30 × 784 = 23,520 个独立权重
```

**卷积层**：同一个核在所有位置复用

```
卷积: 所有位置共用同一组 25 个权重
  w[0,0], w[0,1], ..., w[4,4]  ← 就这 25 个，到处复用

  位置 (0,0): z = w·a[0:5, 0:5]
  位置 (0,1): z = w·a[0:5, 1:6]   ← 同一个 w！
  位置 (1,0): z = w·a[1:6, 0:5]   ← 还是同一个 w！
  ...
```

**结果：** 不管特征图多大，卷积核的参数始终只有核大小（如 5×5=25）。

### 实际参数对比

以 MNIST 的网络为例：

| 层 | 参数量 |
|---|---|
| 全连接 784→30 | 23,520 |
| 全连接 784→100 | 78,400 |
| 卷积 1→20, 5×5 核 | **500** |
| 卷积 20→40, 5×5 核 | **20,000** |

卷积层的参数量**不依赖图像大小**，只取决于核大小和核数量。

## 参数少为什么抗过拟合

### 过拟合的本质

过拟合 = 网络有太多参数 → 有能力"死记硬背"每个训练样本

```
参数多:                          参数少:
  78400 个权重                    500 个权重
  → 有足够容量记住每张图            → 容量不够记住每张图
  → 新图不认 (过拟合)              → 被迫学习通用规律 (泛化)
```

### 比喻

```
考试复习:

  参数多 (全连接):
    有 78400 个笔记本格子
    → 每道题单独记录答案
    → 换一道题就不会了

  参数少 (卷积):
    只有 500 个笔记本格子
    → 记不下每道题
    → 被迫总结通用规律 ("边缘长这样"、"圆圈长这样")
    → 新题也能做
```

## 卷积层的"先天先验"

卷积层编码了两个关于图像的"先验知识"：

### 先验 1：局部性

**图像中的重要模式是局部的。** 一个边缘、一个角、一个纹理，只需要看局部区域就能识别，不需要看整张图。

```
"这里有一条竖线"     ← 只需要看 5×5 邻域
"这是一个数字 7"      ← 才需要看整张图（全连接层的工作）
```

### 先验 2：平移等变性

**同一个模式可能出现在图像的任何位置。** 左上角的边缘和右下角的边缘是同一种特征，应该用同一组权重检测。

```
不管竖线在左上角还是右下角:
  卷积核都能检测到 (因为核会滑动到所有位置)
  用的是同一组权重 (权重共享)
```

### 先验 = 正则化

这两个先验相当于一种**结构性正则化**：

```
全连接层:
  没有任何先验 → 什么都可以学 → 容易过拟合

卷积层:
  先验1: "只看局部"     → 限制连接范围
  先验2: "位置不变"     → 共享权重
  → 搜索空间大大缩小 → 不容易过拟合
```

相当于在**网络结构设计阶段**就内置了正则化，不需要靠 L2 或 Dropout 来事后补救。

## 实验对比

书中提到，在基本的卷积网络（不加正则化）上实验：

```
无正则化 (lmbda=0):
  全连接网络: 过拟合严重 (训练 100%, 测试 82%)
  卷积网络:   轻微过拟合 (训练 99%, 测试 98%)

加正则化 (lmbda=0.1):
  全连接网络: 改善 (训练 98%, 测试 97%)
  卷积网络:   改善不大 (训练 99%, 测试 98.5%)
```

卷积网络即使不加正则化也已经不错，加正则化后改善没有全连接那么明显——因为**卷积结构本身已经提供了正则化效果**。

---

## 总结

| 机制 | 全连接层 | 卷积层 |
|---|---|---|
| 连接方式 | 全局连接 | **局部连接** |
| 权重 | 每个独立 | **共享** |
| 参数量 | 多 (随输入尺寸增长) | **少** (只取决于核大小) |
| 先验知识 | 无 | 局部性 + 平移等变性 |
| 抗过拟合 | ❌ 弱 | ✅ **天然抗** |

**一句话：卷积层通过局部连接和权重共享大幅减少参数量，相当于内置了"图像模式是局部的且位置无关的"先验知识。参数越少 + 先验越强 → 搜索空间越小 → 越不容易过拟合。**
