# ReLU 函数

> 出自《神经网络与深度学习》第三章

---

## 什么是 ReLU

ReLU = Rectified Linear Unit = 修正线性单元

公式极其简单：

$$\text{ReLU}(z) = \max(0, z)$$

就是：**负数变 0，正数不变。**

```
ReLU(z)
  │      ╱
  │     ╱
  │    ╱
  │   ╱
───●──────── z
  │
  │
  0

z < 0 → 输出 0
z > 0 → 输出 z（原样输出）
```

---

## 为什么 ReLU 不映射到 [0, 1]

### Sigmoid

$$\sigma(z) = \frac{1}{1+e^{-z}} \in (0, 1)$$

sigmoid 把任何输入压缩到 (0, 1) 之间，有上限 1。

```
sigmoid:
  │        ━━━━━━━  ← 最大 1
  │      ╱
  │    ╱
───╳──────── z
  │
  │  ━━━━━━━    ← 最小 0
```

### ReLU

$$\text{ReLU}(z) = \max(0, z) \in [0, +\infty)$$

ReLU **没有上限**，输入多大输出就多大。

```
ReLU:
  │        ╱       ← 一直涨，没有上限
  │       ╱
  │      ╱
  │     ╱
───●──────── z
  │
  0
```

### 为什么这样设计？

因为 ReLU 通常用在**隐藏层**，不需要输出概率。隐藏层的任务是提取特征，特征值的大小可以代表"这个特征有多强"：

```
sigmoid 神经元:  输出 0.8  → "这个特征比较强"（但不知道绝对大小）
ReLU 神经元:    输出 8.3  → "这个特征很强"（数值本身就是强度）
```

**输出层**才需要 [0, 1]（用 sigmoid 表示概率）或 softmax（表示概率分布）。

## ReLU 的导数

$$\text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

```
ReLU'(z)
 1 │──────────────
   │
   │
 0 ━━━━━●────────
         z=0

 z > 0: 导数 = 1（永远不衰减！）
 z ≤ 0: 导数 = 0（神经元"死了"）
```

### 和 sigmoid 导数对比

| | sigmoid' | ReLU' |
|---|---|---|
| 最大值 | 0.25 | 1 |
| z 很大时 | → 0（饱和） | = 1（不衰减） |
| z 很小时 | → 0（饱和） | = 0 |

---

## ReLU 的优缺点

### 优点

**1. 不饱和（z > 0 时）**

sigmoid 的导数最大才 0.25，且很容易趋近 0。ReLU 在正区间导数恒为 1，**梯度不会消失**：

```
sigmoid 反向传播 4 层:
  δ¹ ≈ δ⁴ × 0.25 × 0.25 × 0.25 × 0.25 = δ⁴ × 0.004  ← 梯度消失

ReLU 反向传播 4 层（全在正区间）:
  δ¹ ≈ δ⁴ × 1 × 1 × 1 × 1 = δ⁴  ← 梯度无损传播
```

**2. 计算极快**

```
sigmoid:  1/(1+e^(-z))  → 涉及指数运算
ReLU:     max(0, z)     → 只需一次比较
```

**3. 产生稀疏激活**

```
sigmoid:  几乎所有神经元都输出非零值 → 密集表示
ReLU:     负输入的神经元输出 0 → 自然稀疏 → 类似正则化效果
```

### 缺点

**死亡 ReLU（Dying ReLU）**

当 $z < 0$ 时，导数为 0。如果某个神经元的权重更新后 $z$ 永远 < 0，那它**永远不会被激活**，也不再更新：

```
神经元一开始 z = -0.1 → ReLU 输出 0
  → 梯度 = 0 → 权重不更新
  → 下次 z 还是 ≤ 0 → 还是输出 0
  → 永久死亡，再也活不过来
```

**解决方案：Leaky ReLU**

$$\text{LeakyReLU}(z) = \begin{cases} z & z > 0 \\ 0.01z & z \leq 0 \end{cases}$$

负区间给一个很小的斜率（如 0.01），保证导数不为 0：

```
LeakyReLU:
  │      ╱
  │     ╱
  │    ╱
  │   ╱
  │ ╱ ← 很小的斜率，不会死
──●──────── z
```

## 总结

| | Sigmoid | ReLU |
|---|---|---|
| 输出范围 | (0, 1) | [0, +∞) |
| 有上限 | ✅ | ❌ |
| 最大导数 | 0.25 | 1 |
| 正区间饱和 | ✅ 会 | ❌ 不会 |
| 负区间 | 输出接近 0 | 输出精确 0 |
| 梯度消失 | ✅ 严重 | ❌ 正区间不会 |
| 稀疏性 | ❌ | ✅ |
| 计算速度 | 慢（指数） | 快（比较） |

**一句话：ReLU 不映射到 [0,1] 是因为它用在隐藏层提取特征，特征值不需要有上限；而 [0,1] 是输出层表示概率才需要的。ReLU 的核心优势是正区间导数恒为 1，彻底解决了 sigmoid 的梯度消失问题。**
