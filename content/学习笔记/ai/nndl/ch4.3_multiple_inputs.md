# 多个输入变量

> 出自《神经网络与深度学习》第 4.3 节

---

## 1. 从一维到二维

4.2 节证明了神经网络可以近似任意一元函数 $f(x)$。本节将这个结论推广到多元函数 $f(x_1, x_2, \dots, x_n)$。

为方便理解，书里以两个输入 $x, y$ 为例。所有核心思路在二维情况中都能体现，更多维度只是重复。

---

## 2. 二维阶跃函数

### 令一个权重为 0

考虑一个两输入神经元，输入 $x$ 和 $y$，权重 $w_1$ 和 $w_2$：

$$z = w_1 x + w_2 y + b$$

如果设 $w_2 = 0$，则 $z = w_1 x + b$，输入 $y$ 完全不起作用。此时神经元的行为和一维情况一模一样，只是一个关于 $x$ 的阶跃函数。

### 增大 $w_1$ → 二维阶跃

和一维情况一样，把 $w_1$ 增大到很大（比如 1000），神经元输出接近阶跃函数。但现在是三维的（$x, y$ 两个输入 + 一个输出），阶跃面是一条平行于 $y$ 轴的直线：

```
      y
      │
      │   阶跃面（垂直于 x 轴的平面）
      │  │
      │  │
      │  │
      └──┴──── x
         ↑
    阶跃位置 sx = -b/w1
```

- 神经元上标记 $s_x$ 和小 $x$，表示阶跃发生在 $x$ 方向的位置 $s_x = -b/w_1$
- 小 $x$ 隐含了 $w_1$ 很大、$w_2 = 0$

### y 方向的阶跃

同理，设 $w_1 = 0$，$w_2$ 很大，就能得到 $y$ 方向的阶跃函数。神经元标记 $s_y$ 和小 $y$。

---

## 3. 二维凸起（塔型函数）

### 用两个 x 方向阶跃构造 x 方向凸起

和一维完全一样，用两个 $x$ 方向阶跃（位置 $s_1$ 和 $s_2$）+ 输出权重 $\pm h$，构造一个在 $[s_1, s_2]$ 之间的凸起：

```
2 个隐藏神经元:

  (sx=0.30, x) ──(w=+h)──→ 输出
  (sx=0.70, x) ──(w=-h)──→ 输出

→ 在 x 方向 [0.30, 0.70] 之间形成一个高度 h 的凸起
  但这个凸起在 y 方向上是均匀延伸的（像一个长条）
```

### 叠加 x 方向和 y 方向凸起

关键思路：**把一个 x 方向凸起和一个 y 方向凸起叠加**。

```
4 个隐藏神经元:

  (sx=0.40, x) ──(+0.30)──→
  (sx=0.60, x) ──(-0.30)──→     ← x 方向凸起，高度 h
  (sy=0.30, y) ──(+0.30)──→
  (sy=0.70, y) ──(-0.30)──→     ← y 方向凸起，高度 h

→ 叠加结果：中心区域高度 = 2h，周围环带高度 = h
```

### 问题：不是纯塔，有"高原"

叠加后不是干净的塔型，而是"中心塔 + 周围高原"：

```
俯视图:              侧视图:

  y                    ┌──┐ 2h  ← 中心塔
  │ ┌────┐             │  │
  │ │ 塔 │ h           │  └──┐
  │ └────┘             │     │ h  ← 高原
  └────── x            └─────┘
    高原=1层, 塔=2层
```

---

## 4. 用 if-then-else 提取纯塔

### 思路

把"中心塔 + 高原"通过一个阈值判断变成纯塔：

```
if 隐藏层输出 >= 阈值:
    输出 1（塔保留）
else:
    输出 0（高原削平）
```

### 实现

在输出层设置偏置 $b$，作为阈值：

- 高原高度 = $h$
- 中心塔高度 = $2h$
- 阈值设在两者中间：$b \approx -3h/2$

当 $h$ 足够大时，sigmoid 近似阶跃函数：

- 高原区域 $h$：$h + b = h - 3h/2 = -h/2 < 0$ → $\sigma \approx 0$（削平）
- 塔顶区域 $2h$：$2h + b = 2h - 3h/2 = h/2 > 0$ → $\sigma \approx 1$（保留）

### 具体参数

```
h = 10, b = -15 (= -3h/2)

高原区域: 加权输出 = 10, + b = 10 - 15 = -5 → σ(-5) ≈ 0.007 ≈ 0 ✓
塔顶区域: 加权输出 = 20, + b = 20 - 15 = 5  → σ(5) ≈ 0.993 ≈ 1 ✓
```

→ 干净的塔型函数！

---

## 5. 用塔型函数近似任意二元函数

### 叠加多个塔

和一维用台阶叠加一样，用多个不同位置、不同高度的塔叠加来近似任意二元函数 $f(x, y)$：

```
                    × 不同位置
多个塔 (不同 x,y) →
                    × 不同高度 h

→ 叠加结果近似 f(x, y)
```

### 提高精度

- 塔越细（$s$ 间距越小）→ 近似越精确
- 塔越多 → 覆盖越完整
- 极限情况下（无穷多塔）→ 精确近似任意连续函数

### $\sigma^{-1}$ 技巧

如果 $f(x, y)$ 不在 $(0, 1)$ 范围内，用 4.2 节的 $\sigma^{-1}$ 技巧：

$$\text{第二隐藏层加权输出} \approx \sigma^{-1} \circ f(x, y)$$

然后输出层 sigmoid 还原：

$$\sigma(\sigma^{-1}(f(x,y))) = f(x,y)$$

## 6. 推广到更多变量

### 三维输入 $f(x_1, x_2, x_3)$

完全相同的思路：

1. 用 3 对阶跃函数（分别在 $x_1, x_2, x_3$ 方向）构造三维"塔"
2. 用 if-then-else 阈值削平高原
3. 叠加多个三维塔近似 $f(x_1, x_2, x_3)$

### 任意 $n$ 维

$$f(x_1, x_2, \dots, x_n)$$

- 每个维度用一对阶跃函数
- $n$ 对构造一个 $n$ 维塔
- 叠加足够多的塔 → 近似任意 $n$ 元函数

---

## 7. 网络架构总结

### 二维情况需要的架构

```
输入层:     x, y          （2 个神经元）
第一隐藏层: 阶跃函数        （每个方向需要 2 个，2 方向共 4 个/塔）
第二隐藏层: if-then-else   （1 个/塔，用于削平高原）
输出层:     σ (求和 + 还原)  （1 个）
```

### 一维 vs 多维对比

| | 一维 | 二维 |
|---|---|---|
| 输入 | $x$ | $x, y$ |
| 阶跃方向 | x 方向 | x 方向 + y 方向 |
| 凸起形状 | 台阶（1D） | 塔（2D） |
| 构造一个凸起所需神经元 | 2 | 4（+1 削平） |
| 近似方法 | 叠加台阶 | 叠加塔 |

---

## 8. 核心要点

| 要点 | 说明 |
|---|---|
| 权重设为 0 | 忽略某个输入维度，降维成一维问题 |
| 增大权重 | 让 sigmoid 变成阶跃函数 |
| 叠加两个方向凸起 | 得到"中心塔 + 高原" |
| if-then-else 阈值 | 削平高原，只留纯塔 |
| 叠加多个塔 | 近似任意多元函数 |
| $\sigma^{-1}$ 技巧 | 处理 $f$ 不在 $(0,1)$ 的情况 |

**一句话：多维情况的核心思路和一维一样——用阶跃函数构造凸起，叠加凸起来近似目标函数。区别只是每个维度都需要一对阶跃，再用 if-then-else 阈值把"塔+高原"变成纯塔。**

---

## 9. $\sigma^{-1}$ 在哪里做

### 完整数据流

```
第一隐藏层:  阶跃函数 → 产生"塔+高原"
                ↓
第二隐藏层:  if-then-else (sigmoid + 大权重) → 干净的 0/1 塔
                ↓
输出层:      σ( Σ h_i × 塔_i )  → f(x,y)
                ↑         ↑
            sigmoid    权重 = 塔的高度
```

### $\sigma^{-1}$ 不是单独的步骤

输出层有 sigmoid，所以最终输出是：

$$\text{output} = \sigma\Big(\sum_i h_i \cdot \text{tower}_i(x,y)\Big)$$

要让它等于 $f(x,y)$：

$$\sigma\Big(\sum_i h_i \cdot \text{tower}_i\Big) = f(x,y)$$

两边套 $\sigma^{-1}$：

$$\sum_i h_i \cdot \text{tower}_i = \sigma^{-1}(f(x,y))$$

**所以塔的高度不设为 $f$ 的值，而是设为 $\sigma^{-1}(f)$ 的值：**

| 目标值 $f$ | 塔的高度 $h_i$ |
|---|---|
| 0.8 | $\sigma^{-1}(0.8) = \ln(4) \approx 1.386$ |
| 0.5 | $\sigma^{-1}(0.5) = \ln(1) = 0$ |
| 0.3 | $\sigma^{-1}(0.3) = \ln(3/7) \approx -0.847$ |

### $\sigma^{-1}$ 被吸收进输出层权重

$\sigma^{-1}$ 不是一个单独的网络层，而是被"烤进"输出层的权重 $h_i$ 里了。不把塔的高度设为目标值 $f$，而是设为 $\sigma^{-1}(f)$，这样输出层 sigmoid 一套就还原成 $f$。
