# 修补阶跃函数

> 出自《神经网络与深度学习》第 4.5 节

---

## 1. 问题：sigmoid 不是真正的阶跃函数

前面的通用性证明假设神经元能精确产生阶跃函数（0→1 的瞬间跳变）。但 sigmoid 是平滑的 S 形，在阶跃点附近有一个**过渡区**（故障窗口），函数行为和理想阶跃函数不一样：

```
理想阶跃:              sigmoid 近似:

  1 ━━━━━━━              1 ━━━━━━━
           │                       │╲
           │                        ╲
  0 ━━━━━━┷━━━            0 ━━━━━━╲━━━━
                x                     x
           ↑                  ↑
      瞬间跳变              故障窗口（过渡区）
```

在这些故障窗口内，通用性证明会失败。

### 严重吗？

不算严重。通过增大权重，可以把故障窗口缩到任意窄。但书中给出了一个更彻底的修补方案。

---

## 2. 解决方案：偏移叠加

**用多组近似，每组偏移半个台阶宽度，故障窗口互相错开，叠加后抵消。**

### 步骤

#### 第 1 步：第一组近似

用隐藏神经元产生一系列凸起，近似目标函数的一半，即 $\sigma^{-1} \circ f(x) / 2$：

```
第一组近似 (σ⁻¹∘f / 2):

  ┌──╲──┐  ┌──╲──┐  ┌──╲──┐
  │     ╲│  │     ╲│  │     ╲
──┘      └──┘      └──┘      └──
  ↑      ↑  ↑      ↑
  故障窗口  故障窗口
```

#### 第 2 步：第二组近似（偏移半个台阶）

用另一组隐藏神经元，同样近似 $\sigma^{-1} \circ f(x) / 2$，但凸起**整体偏移半个台阶宽度**：

```
第二组近似 (σ⁻¹∘f / 2, 偏移半步):

     ┌──╲──┐  ┌──╲──┐  ┌──╲──┐
     │     ╲│  │     ╲│  │     ╲
  ───┘      └──┘      └──┘      └──
     ↑      ↑  ↑      ↑
     故障窗口  故障窗口（和第一组错开）
```

#### 第 3 步：叠加

两组相加 = $\sigma^{-1} \circ f(x)$ 的完整近似：

```
叠加结果:

  ┌───────┐┌───────┐┌───────┐
  │       ││       ││       │
──┘       └┘       └┘       └──
  ↑       ↑
  故障被互相修补！
```

### 为什么有效

第一组的故障窗口在台阶正中间，第二组的故障窗口在台阶边界，两者**不重叠**：

```
第一组故障:    ┌──╲──┐     ╲ 在中间
第二组故障:       ┌──╲──┐   ╲ 在中间（但偏移了半步）

叠加后:        ┌───────┐    某一组故障时另一组是好的
```

- 在第一组故障窗口中 → 第二组是好的 → 用第二组补
- 在第二组故障窗口中 → 第一组是好的 → 用第一组补

### 推广到 M 组

用 $M$ 组不同的偏移叠加，每组近似 $\sigma^{-1} \circ f(x) / M$：

- 假设故障窗口足够窄，每个点最多在一个故障窗口中
- $M$ 组偏移使故障窗口互相错开
- 叠加后故障的影响缩小 $M$ 倍
- $M \to \infty$ 时，近似误差 $\to 0$

$$\text{最终近似} = \sum_{i=1}^{M} \frac{\sigma^{-1} \circ f(x)}{M} \Big|_{\text{偏移 } i/M} \approx \sigma^{-1} \circ f(x)$$

## 3. 激活函数的通用性条件

4.4 节指出，不只是 sigmoid，任何满足以下条件的激活函数 $s(z)$ 都能用于通用性证明：

1. **$z \to -\infty$ 和 $z \to +\infty$ 时有明确极限**（阶跃的两个值）
2. **两个极限值不同**（否则没有阶跃，只是平坦直线）

### 不满足条件的例子

| 激活函数 | 极限 | 满足？ |
|---|---|---|
| sigmoid | $\to 0$ 和 $\to 1$ | ✅ |
| tanh | $\to -1$ 和 $\to 1$ | ✅ |
| ReLU | $\to 0$ 和 $\to +\infty$ | ❌ 无上限 |
| 线性 $s(z)=z$ | $\to \pm\infty$ | ❌ 无有限极限 |

ReLU 和线性神经元不满足通用性证明的条件，但它们在实践中仍然有用（通用性定理只是理论保证，不代表实际中不能用）。

---

## 4. 总结

| 要点 | 说明 |
|---|---|
| 问题 | sigmoid 过渡区不是完美阶跃，有故障窗口 |
| 修补方法 | 多组偏移叠加，故障窗口互相错开 |
| 效果 | $M$ 组叠加后误差缩小 $M$ 倍 |
| 激活函数条件 | 需要有有限且不同的上下极限 |

**一句话：sigmoid 的过渡区不是完美的阶跃，但通过多组偏移叠加，让故障窗口互相错开、互相修补，就能消除误差。**
