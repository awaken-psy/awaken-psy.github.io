# 为什么 ReLU 优于 Sigmoid/Tanh

> 出自《神经网络与深度学习》第 6.2 节

---

## 核心原因：梯度不衰减

### 深层网络中的梯度连乘

反向传播中，误差每往前传一层就乘一次激活函数的导数：

```
δ^1 = δ^L × σ'(z^L) × σ'(z^{L-1}) × ... × σ'(z^2)
```

| 激活函数 | 导数 | 连乘效果 |
|---|---|---|
| Sigmoid | $\sigma'(z) = \sigma(1-\sigma) \leq 0.25$ | 10 层 → $0.25^{10} \approx 10^{-6}$，梯度消失 |
| Tanh | $\tanh'(z) = 1-\tanh^2 \leq 1$ | 比 sigmoid 好但仍 < 1，深层仍会衰减 |
| **ReLU** | $\text{ReLU}'(z) = 1$（当 $z>0$） | 10 层 → $1^{10} = 1$，**梯度不衰减** |

```
Sigmoid 10层网络:
  δ^10 = 1.0
  δ^9  = 1.0 × 0.25 = 0.25
  δ^8  = 0.25 × 0.25 = 0.0625
  ...
  δ^1  = 0.25^10 ≈ 0.0000001  ← 梯度消失，前面层学不动

ReLU 10层网络（全在正区间）:
  δ^10 = 1.0
  δ^9  = 1.0 × 1 = 1.0
  δ^8  = 1.0 × 1 = 1.0
  ...
  δ^1  = 1^10 = 1.0  ← 梯度无损传播，前面层照常学习
```

---

## ReLU 的三个优势

### 1. 解决梯度消失

如上所示，ReLU 正区间导数恒为 1，梯度可以无损穿越任意多层。这是 ReLU 最大的优势，也是深度网络能训练的关键。

### 2. 计算极快

```
Sigmoid:  σ(z) = 1/(1+e^(-z))     → 指数运算，慢
Tanh:     tanh(z) = (e^z-e^(-z))/(e^z+e^(-z))  → 更复杂
ReLU:     ReLU(z) = max(0, z)      → 一次比较，极快
```

在卷积网络中，卷积层有大量神经元，激活函数被调用数百万次。ReLU 的速度优势在这里非常显著。

### 3. 稀疏激活

```
Sigmoid:  几乎所有神经元输出非零 → 密集表示
ReLU:     负输入的神经元输出 0 → 大量神经元"沉默"

  Sigmoid 层 (100个神经元):     ReLU 层 (100个神经元):
  [0.5 0.3 0.7 0.2 0.8 ...]     [0.0 0.3 0.0 0.0 0.8 ...]
   全都有值，密集                  大量为 0，稀疏

  → 稀疏激活类似生物神经元 (大部分时间不放电)
  → 起到隐式正则化作用
  → 减少计算量 (0 × w = 0，可以跳过)
```

## Sigmoid/Tanh 的问题

### Sigmoid 的两个问题

**1. 梯度消失**（已讨论）

**2. 输出非零均值**

```
Sigmoid 输出范围 (0, 1)，均值 ≈ 0.5（恒为正）

  → 后一层神经元收到的输入全是正的
  → 权重更新方向全同号（全正或全负）
  → Z 字形更新路径，收敛慢

  δ = (a - y) × σ'(z)
  ∇w = δ × a    ← a 恒为正，所以所有 ∇w 同号
```

### Tanh 改善了但不够

```
Tanh 输出范围 (-1, 1)，均值为 0

  → 解决了非零均值问题
  → 但导数最大才 1（在 z=0 处），很快衰减
  → 深层网络仍然会梯度消失
```

---

## ReLU 的问题：死亡 ReLU

### 现象

当 $z < 0$ 时，$\text{ReLU}(z) = 0$，$\text{ReLU}'(z) = 0$。如果某次更新后某神经元的 $z$ 永远 ≤ 0：

```
z = -0.1 → ReLU 输出 0
  → δ = 0（梯度为 0）
  → 权重不更新
  → z 还是 ≤ 0
  → 永远死亡，再也活不过来
```

### 解决方案

| 变体 | 公式 | 特点 |
|---|---|---|
| **Leaky ReLU** | $\max(0.01z, z)$ | 负区间给 0.01 斜率，不死 |
| **PReLU** | $\max(\alpha z, z)$ | 斜率 $\alpha$ 可学习 |
| **ELU** | $z$ if $z>0$; $\alpha(e^z-1)$ if $z\leq0$ | 负区间平滑，均值更接近 0 |

```
ReLU:        Leaky ReLU:       ELU:
  │    ╱          │    ╱           │    ╱
  │   ╱           │   ╱            │   ╱
  │  ╱            │ ╱              │ ╱
───●────     ────●────        ────●────
  │              │ ╲              │  ╲╱  ← 平滑
  │              │  (0.01斜率)    │
```

## 总结对比

| | Sigmoid | Tanh | ReLU |
|---|---|---|---|
| 输出范围 | (0, 1) | (-1, 1) | [0, +∞) |
| 最大导数 | 0.25 | 1.0 | 1.0 |
| 正区间导数 | 衰减 | 衰减 | **恒为 1** |
| 梯度消失 | ✅ 严重 | ✅ 较轻 | ❌ 不会 |
| 零均值 | ❌ | ✅ | 部分（取决于输入） |
| 计算速度 | 慢 | 慢 | **极快** |
| 稀疏性 | ❌ | ❌ | ✅ |
| 死亡问题 | ❌ | ❌ | ✅ 可能 |

**一句话：ReLU 好于 Sigmoid/Tanh 的核心原因是正区间导数恒为 1，梯度可以无损穿越任意多层，让深度网络能训练。额外优势是计算快和稀疏激活。代价是负区间可能"死亡"，用 Leaky ReLU 等变体解决。**
