# Hessian 技术与基于 Momentum 的梯度下降

> 出自《神经网络与深度学习》第三章

---

## 1. 问题背景：梯度下降的"病态"问题

普通梯度下降只看一阶导数（梯度），不考虑代价函数曲面的"形状"。这会导致一个问题——**病态（ill-conditioning）**：在某些方向上走得太快，另一些方向走得太慢。

```
代价函数的等高线是椭圆形（不是圆形）:

  C
  │
  │     ╱─╲      等高线又窄又长
  │   ╱─╲─╱─╲
  │  ╱   ●   ╲    ← 当前位置
  │   ╲─╱─╲─╱
  │     ╲─╱
  └────────────

梯度方向（垂直于等高线）几乎垂直于最小值方向！
→ 梯度下降在窄方向上来回震荡，在长方向上爬行极慢
```

---

## 2. Hessian 矩阵

### 二阶导数

- 一阶导数（梯度）告诉你**方向**：往哪走
- 二阶导数（Hessian）告诉你**曲率**：走多快、方向对不对

### 定义

Hessian 是代价函数 $C$ 对所有参数的**二阶偏导数矩阵**：

$$H_{jk} = \frac{\partial^2 C}{\partial w_j \partial w_k}$$

如果网络有 $n$ 个参数（权重+偏置），Hessian 是 $n \times n$ 矩阵。

### 直觉

```
梯度 ∇C = 一阶导数 = 坡度
         → "哪边下坡"
Hessian H = 二阶导数 = 曲率
         → "坡度变化多快"
```

### 牛顿法

用 Hessian 可以一步走到最小值（近似）：

$$w \to w - H^{-1} \nabla C$$

对比普通梯度下降：

$$w \to w - \eta \nabla C$$

牛顿法用 $H^{-1}$ 修正了方向和步长，理论上比梯度下降高效得多。

### 为什么神经网络不用 Hessian？

**计算量太大。** 如果网络有 100 万个参数：

| | 普通梯度下降 | 牛顿法 |
|---|---|---|
| 存储量 | $O(n)$（存梯度） | $O(n^2)$（存 Hessian） |
| 计算量 | $O(n)$ | $O(n^3)$（求逆） |

$n = 10^6$ 时：
- 存 Hessian：$10^6 \times 10^6 \times 4$ 字节 $\approx 4000$ GB
- 求逆：$O(10^{18})$ 次运算

**完全不现实。** 所以需要 Momentum 等近似方法。

## 3. 基于 Momentum 的梯度下降

### 核心思想

既然 Hessian 太贵用不起，Momentum 用一个**便宜的近似**来解决病态问题：引入"速度"累积梯度方向。

### 更新公式

$$v \to \mu v - \eta \nabla C$$

$$w \to w + v$$

- $v$：速度（累积的历史梯度）
- $\mu$：摩擦系数/动量系数（通常 0.5~0.9）
- $\eta$：学习率

### 直觉：球滚下山

```
普通 SGD:
  像一个没有惯性的球，每步只看当前坡度
  → 在窄谷中来回弹跳，在平坦区停停走走

Momentum SGD:
  像一个有惯性的球，累积速度
  → 窄谷中震荡被惯性抵消（正反方向互相抵消）
  → 平坦区持续加速（速度累积）
```

### 具体例子：震荡消除

假设代价函数是一个窄谷，梯度在窄方向交替正负：

```
普通 SGD:
  坡度: [+1, -1, +1, -1, +1, -1, ...]  ← 窄方向来回弹
  位移: +1, 0, +1, 0, +1, 0, ...      ← 原地踏步！

Momentum (μ=0.9):
  v = 0.9×0 + 1 = 1
  v = 0.9×1 - 1 = -0.1
  v = 0.9×(-0.1) + 1 = 0.91
  v = 0.9×0.91 - 1 = -0.181
  → 正负梯度的效应被惯性平均掉了，不再来回弹
  → 球贴着谷底往长方向滑
```

### 展开看动量项

$$v_t = \mu v_{t-1} - \eta \nabla C_t$$

递推展开：

$$v_t = -\eta \nabla C_t - \eta\mu \nabla C_{t-1} - \eta\mu^2 \nabla C_{t-2} - \dots$$

当前速度 = 当前梯度 + 历史梯度的**指数衰减加权和**：

```
v = -η×∇C(现在) - η×μ×∇C(上一步) - η×μ²×∇C(上上步) - ...
     ─────────    ────────────     ──────────────
     权重 1        权重 μ           权重 μ²
```

$\mu = 0.9$ 时，10 步前的梯度还有 $0.9^{10} \approx 0.35$ 的权重。**历史梯度在缓慢衰减，不是全记也不是全忘。**

---

## 4. Momentum 与 Hessian 的关系

### Momentum 是 Hessian 的廉价近似

Hessian 修正的目的是：**在不同方向上用不同步长**。曲率大的方向（窄方向）走小步，曲率小的方向（长方向）走大步。

Momentum 通过惯性累积，天然实现了类似效果：

| 方向 | 梯度特征 | Momentum 效果 | 等价于 Hessian |
|---|---|---|---|
| 窄方向 | 梯度正负交替 | 互相抵消，步长小 | $H$ 大 → 步长小 |
| 长方向 | 梯度持续同号 | 速度累积，步长大 | $H$ 小 → 步长大 |

**Momentum 自适应地在大曲率方向减步、小曲率方向加步，和 Hessian 的效果一致，但只需 $O(n)$ 成本。**

---

## 5. 对比总结

| | 普通 SGD | Momentum SGD | 牛顿法 (Hessian) |
|---|---|---|---|
| 更新公式 | $w \to w - \eta\nabla C$ | $v \to \mu v - \eta\nabla C$，$w \to w + v$ | $w \to w - H^{-1}\nabla C$ |
| 利用信息 | 一阶导数 | 一阶导数 + 历史 | 二阶导数 |
| 存储成本 | $O(n)$ | $O(n)$ | $O(n^2)$ |
| 计算成本 | $O(n)$ | $O(n)$ | $O(n^3)$ |
| 病态问题 | ❌ 严重 | ✅ 缓解 | ✅ 完美解决 |
| 收敛速度 | 慢 | 中 | 快 |
| 实际可用 | ✅ | ✅ | ❌（参数太多） |

---

## 6. 一句话

**Hessian 用二阶导数完美修正方向，但计算量太大用不起；Momentum 用历史梯度的指数加权平均做廉价近似，以 $O(n)$ 成本缓解病态问题——窄方向震荡被抵消，长方向速度被累积。**
