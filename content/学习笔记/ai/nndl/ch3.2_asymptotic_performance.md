# 研究问题：机器学习算法在大数据集上的渐近性能

> 出自《神经网络与深度学习》第三章

---

## 问题

能否从理论上预测算法在数据量趋于无穷时的性能上限？并用此比较不同算法？

---

## 1. 为什么不能简单外推

直接把学习曲线画到无穷大不可靠，因为**不同数据规模下曲线形状不同**：

```
误差
  │
  │ ●●
  │   ●●___         观测范围内的拟合
  │        ────____
  │              ────____
  │                    ────____  ← 真实趋势可能完全不同
  └─────────────────────────────── 训练数据量 n
```

- 100~1000 样本时可能像 $1/n$（快速下降）
- 到了 10000~100000 可能变缓为 $1/\ln n$
- 不同尺度拟合出来的曲线推到无穷大，结果完全不同

---

## 2. 理论框架

### 偏差-方差分解

$$\text{误差} = \underbrace{\text{偏差}^2}_{\text{模型能力限制}} + \underbrace{\text{方差}}_{\text{对数据的敏感度}} + \underbrace{\text{噪声}}_{\text{不可消除}}$$

当 $n \to \infty$：

- **方差 → 0**：数据够多，不再对特定训练集敏感
- **偏差不变**：模型假设空间的固有限制
- **噪声不变**：数据本身的随机性

所以：

$$\lim_{n \to \infty} \text{误差} = \text{偏差}^2 + \text{噪声}$$

**不同算法的渐近线高度不同，因为偏差不同：**

```
误差
  │
  │ ╲    线性模型（高偏差）
  │  ╲___────────────  ← 高渐近线
  │
  │  ╲    深度网络（低偏差）
  │   ╲     ╱
  │    ╲   ╱___
  │     ╲╱        ───  ← 低渐近线
  └────────────────────── n
```

### PAC 学习框架

给出了达到目标误差 $\epsilon$ 所需的样本数：

$$m \geq \frac{1}{\epsilon}\left(d_{VC} + \log\frac{1}{\delta}\right)$$

反推误差上界 $\epsilon \propto d_{VC}/n$，其中 $d_{VC}$ 是 VC 维（模型容量）。

---

## 3. 不同算法的收敛速率

学习理论给出了各算法的理论渐近速率：

| 算法 | 收敛速率 | 特点 |
|---|---|---|
| K-NN | $O(n^{-2/d})$ | 受维度灾难影响严重 |
| 核方法 | $O(n^{-1/2})$ | 不依赖维度 |
| 深度网络 | $O(n^{-1/2})$ ~ $O(n^{-1})$ | 高维数据上优势大 |

### K-NN 的维度灾难

K-NN 的速率 $O(n^{-2/d})$ 依赖维度 $d$：

| 维度 $d$ | 速率 | 含义 |
|---|---|---|
| 2 | $n^{-1}$ | 收敛快 |
| 10 | $n^{-0.2}$ | 慢 |
| 784 (MNIST) | $n^{-0.0026}$ | 几乎不降！ |

在 784 维的 MNIST 上，K-NN 需要天文数字的样本才能收敛，而神经网络不受维度限制。

---

## 4. 深度学习的特殊情况

### 幂律经验

实验发现深度学习误差遵循幂律：

$$E(n) = \alpha \cdot n^{-\beta} + E_\infty$$

- $\beta$：幂指数，经验值约 0.05~0.5
- $E_\infty$：无穷数据下的渐近误差

### 双下降

超过插值阈值后，更大模型误差反而持续下降，打破了"模型太复杂必然过拟合"的传统认知。

---

## 5. 总结

| 问题 | 回答 |
|---|---|
| 简单外推可靠吗？ | ❌ 不可靠，不同尺度拟合曲线不同 |
| 有理论方法吗？ | ✅ 偏差-方差分解 + PAC 框架 |
| 能比较不同算法吗？ | ✅ 不同算法有不同渐近速率和渐近线 |
| 深度学习特殊吗？ | 幂律经验 + 双下降，理论仍在完善 |

**一句话：不同算法在无限数据下的性能天花板由偏差决定，收敛速度由算法本身决定。简单外推不可靠，需要结合偏差-方差分解和学习理论来分析。**
