# 只用卷积-池化层，去掉全连接层

> 出自《神经网络与深度学习》第 6.2 节

---

## 原题

![题目](学习笔记/ai/nndl/image/ch06_conv_only_exercise.png)

**题目：** 如果删除全连接层，只使用卷积-池化层和 softmax 层，分类准确率如何？全连接层的加入有帮助吗？

---

## 解答

### 网络结构对比

**原网络（有全连接层）：**

```
输入 (1, 28, 28)
    ↓
ConvPoolLayer: 20 个 5×5 卷积核 + 2×2 池化
    → 输出: (20, 12, 12)
    ↓
FullyConnectedLayer: 12*12*20=2880 → 100
    → 输出: (100,)
    ↓
SoftmaxLayer: 100 → 10
    → 输出: 10 类概率
```

**去掉全连接层后：**

```
输入 (1, 28, 28)
    ↓
ConvPoolLayer: 20 个 5×5 卷积核 + 2×2 池化
    → 输出: (20, 12, 12) = 2880 维
    ↓
SoftmaxLayer: 2880 → 10    ← 直接从卷积特征接到 softmax
    → 输出: 10 类概率
```

### 实验结果

书中的实验结果（`conv.py` 中的 `omit_FC()` 函数）：

| 网络结构 | 测试准确率 |
|---|---|
| 卷积+池化+全连接+softmax | ~98.9% |
| 卷积+池化+softmax（无全连接） | ~97.8% |

### 为什么准确率下降了？

#### 1. 全连接层起到"特征整合"作用

卷积层提取的是**局部特征**（边缘、纹理、局部形状），全连接层将这些局部特征**整合为全局理解**：

```
卷积层输出:                    全连接层做了什么:

  ●  ●  ●  ●                   把分散的局部特征
  ●  ●  ●  ●     ──────→       组合成"这是一个数字 7"的全局判断
  ●  ●  ●  ●                   (哪些局部特征同时出现 → 哪个数字)
  ●  ●  ●  ●

  20 张 12×12 的特征图           100 个"数字概念"神经元
  (局部模式)                     (全局判断)
```

去掉全连接层后，softmax 直接面对 2880 维的局部特征，缺乏整合过程，判别能力变弱。

#### 2. 参数量大幅减少

| 结构 | softmax 输入维度 | softmax 权重参数 |
|---|---|---|
| 有全连接层 | 100 | 100×10 = 1,000 |
| 无全连接层 | 2,880 | 2,880×10 = 28,800 |

虽然无全连接层参数更多，但这些参数全在 softmax 上，**缺乏中间的非线性变换**。全连接层的价值不在于参数多少，而在于多了一层非线性激活（sigmoid/ReLU），让网络有更强的表达能力。

#### 3. 缺少非线性变换

```
有全连接层:
  卷积(线性) → 池化 → 全连接(线性) → sigmoid(非线性) → softmax
                          ↑ 多了一层非线性变换

无全连接层:
  卷积(线性) → 池化 → softmax
                      ↑ 缺少非线性变换，表达力弱
```

### 结论

**全连接层的加入有帮助。** 它的作用是：
1. 将卷积层提取的局部特征整合为全局判断
2. 增加一层非线性变换，提升表达能力
3. 起到"瓶颈"作用，从 2880 维压缩到 100 维，迫使网络学到更紧凑的表示

去掉全连接层后准确率下降约 1%，说明局部特征直接做分类不如先整合再分类。

---

## 补充：现代 CNN 的做法

在现代 CNN 中（如 ResNet、MobileNet），全连接层逐渐被**全局平均池化（GAP）**替代：

```
传统做法:  卷积 → 展平 → 全连接 → softmax
现代做法:  卷积 → 全局平均池化 → softmax
```

GAP 直接对每张特征图取平均，把 (channels, h, w) 变成 (channels,)，不需要展平，参数量更少且不容易过拟合。这是去掉全连接层的一种更好的替代方案。
