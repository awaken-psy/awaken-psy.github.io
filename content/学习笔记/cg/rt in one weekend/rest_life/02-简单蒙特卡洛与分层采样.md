# 第 2 章：简单蒙特卡洛与分层采样

## 本章解决什么问题

蒙特卡洛方法用随机样本估计一个难以精确计算的结果。它不保证有限样本下完全准确，但样本越多，平均结果通常越接近真实值。

一句话理解：

> 把“对所有可能情况求和”改成“随机观察一部分情况，再求平均”。

这正适合光线追踪：一个像素可能接收到无数条路径的贡献，我们无法全部枚举，只能随机抽取一部分路径。

## Monte Carlo 与 Las Vegas 算法

- **Monte Carlo**：运行时间可以预先控制，但结果带有随机误差；运行越久通常越准确。
- **Las Vegas**：最终结果一定正确，但运行时间是随机的。

例如，在单位圆盘中反复随机生成点，直到落进圆内：

```cpp
inline vec3 random_in_unit_disk() {
    while (true) {
        auto p = vec3(random_double(-1,1),
                      random_double(-1,1), 0);
        if (p.length_squared() < 1)
            return p;
    }
}
```

返回的点一定合法，但不知道要循环多少次，所以它属于 Las Vegas 算法。

## 用随机点估计圆周率

在边长为 2 的正方形中放一个半径为 1 的圆：

$$
\frac{\text{圆面积}}{\text{正方形面积}}
=
\frac{\pi}{4}
$$

均匀生成很多点，统计有多少点落在圆内：

```cpp
int inside_circle = 0;
int N = 100000;

for (int i = 0; i < N; ++i) {
    auto x = random_double(-1, 1);
    auto y = random_double(-1, 1);

    if (x*x + y*y < 1)
        ++inside_circle;
}

double pi_estimate = 4.0 * inside_circle / N;
```

因为：

$$
\frac{\text{圆内样本数}}{N}
\approx
\frac{\pi}{4}
$$

所以：

$$
\pi\approx4\frac{N_{\text{inside}}}{N}
$$

## 收敛与边际收益递减

普通蒙特卡洛误差通常按下面的量级下降：

$$
\text{error}=O\left(\frac{1}{\sqrt N}\right)
$$

这意味着如果想把误差缩小到原来的一半，样本数大约要增加到 4 倍。前几个样本带来的改善很明显，后面每增加一个样本，改善越来越小，这就是书中所说的边际收益递减。

## 分层采样（Stratified Sampling / Jittering）

普通随机采样可能出现：

- 某些区域挤了很多点；
- 某些区域完全没有点；
- 样本覆盖不均匀。

分层采样先把区域切成规则小格，再在每一格中随机取一个点。

假设每个方向切成 `sqrt_N` 份：

```cpp
for (int i = 0; i < sqrt_N; ++i) {
    for (int j = 0; j < sqrt_N; ++j) {
        auto x = 2 * ((i + random_double()) / sqrt_N) - 1;
        auto y = 2 * ((j + random_double()) / sqrt_N) - 1;

        if (x*x + y*y < 1)
            ++inside_circle_stratified;
    }
}
```

其中：

$$
\frac{i+\operatorname{random}()} {\sqrt N}
$$

表示在第 $i$ 个小格内部随机抖动，而不是固定取格子中心。

## 为什么分层采样通常更好

它不是让每个样本更准确，而是减少了样本之间无意义的聚集和空洞。

特别是在函数变化剧烈的位置，例如：

- 物体轮廓；
- 阴影边缘；
- 高频纹理；
- 反射或折射边缘；

普通随机采样可能恰好漏掉变化区域，分层采样则强制整个像素都有覆盖，因此方差通常更低。

在相机中，每个像素可以分成二维小格：

```cpp
for (int s_j = 0; s_j < sqrt_spp; ++s_j) {
    for (int s_i = 0; s_i < sqrt_spp; ++s_i) {
        ray r = get_ray(i, j, s_i, s_j);
        pixel_color += ray_color(r, max_depth, world);
    }
}
```

## 维度诅咒

如果每一维分成 $m$ 层，$d$ 维空间一共需要：

$$
m^d
$$

个格子。

例如每维只分 10 份：

| 维度 | 格子数 |
|---:|---:|
| 2 | $10^2=100$ |
| 4 | $10^4=10000$ |
| 8 | $10^8$ |

路径追踪维度很高：像素位置有 2 维，每次反弹方向又增加 $\theta,\phi$ 两维，景深和时间采样还会继续增加维度。因此完整路径空间很难直接做规则分层。

实践中的分工通常是：

- 像素位置等低维问题：适合分层采样；
- 光照和反射方向：更适合重要性采样。

## 本章结论

> 蒙特卡洛用随机平均逼近真实结果；分层采样通过改善样本覆盖来降低方差，但它在高维空间中的成本会指数增长。
