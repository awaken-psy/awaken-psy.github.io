# 第 9 章：直接采样光源

## 本章核心

不再等待随机散射方向碰巧撞到小光源，而是：

1. 在光源表面随机选择点 $q$；
2. 从当前表面点 $p$ 朝 $q$ 发射光线；
3. 计算这种方向选择方法的正确 PDF；
4. 用 $f/p$ 对采样偏向进行补偿。

这样能把样本集中到真正有光的区域，显著降低小光源场景中的方差。

## 为什么普通材质采样容易产生噪声

Lambertian 采样只知道表面法线：

$$
p_{surface}(\omega)=\frac{\cos\theta_S}{\pi}
$$

它不知道灯的位置。小光源只占据很小的立体角，因此：

- 大量样本没有命中灯，贡献接近 0；
- 少量样本命中灯，贡献非常大；
- 样本差异巨大，形成噪点。

直接光源采样让每次选择的方向都指向灯面上的某一点；遮挡仍然由后续射线求交自然判断。

## 灯面上的面积 PDF

设矩形灯面积为 $A_L$。在灯面上均匀选点：

$$
\boxed{p_A(q)=\frac{1}{A_L}}
$$

它是相对于面积 $dA$ 的概率密度，单位可以理解为 $1/m^2$。

但渲染方程对方向立体角 $d\omega$ 积分，所以分母需要方向 PDF $p_\omega(\omega)$，不能直接使用 $1/A_L$。

> 这里的 $A_L$ 表示光源面积，不是第五章中表示 albedo 的 $A$。

## 面积到立体角的几何关系

设：

- $r=\|q-p\|$：着色点到灯面点的距离；
- $\theta_L$：灯面法线与观察方向的夹角；
- $dA$：灯面小块；
- $d\omega$：它从点 $p$ 看来占据的立体角。

灯面小块的垂直投影面积为：

$$
dA_\perp=dA\cos\theta_L
$$

投影到单位方向球面后还要除以距离平方：

$$
\boxed{
d\omega
=
\frac{dA\cos\theta_L}{r^2}
}
$$

## 推导方向 PDF

选择 $dA$ 和选择它对应的 $d\omega$ 是同一个随机事件，因此概率相同：

$$
p_\omega(\omega)d\omega
=
p_A(q)dA
$$

代入：

$$
p_A(q)=\frac{1}{A_L}
$$

以及：

$$
d\omega=\frac{dA\cos\theta_L}{r^2}
$$

得到：

$$
p_\omega(\omega)
\frac{dA\cos\theta_L}{r^2}
=
\frac{dA}{A_L}
$$

约掉 $dA$：

$$
\boxed{
p_{light}(\omega)
=
\frac{r^2}{A_L\cos\theta_L}
}
$$

## 如何理解这个 PDF

### 距离越远，方向 PDF 越大

远处灯光占据的方向范围更小，但选灯面点的总概率仍为 1，所以概率被压缩到更小的立体角中，局部密度变大。

估计器会除以 PDF，因此最终贡献中出现：

$$
\frac{1}{r^2}
$$

即平方反比衰减。

### 光源越倾斜，方向 PDF 越大

$\cos\theta_L$ 越小，灯的投影面积越小，概率越集中，方向密度越大。

### 光源面积越大，方向 PDF 越小

灯越大，对应的方向范围越宽，所以每个方向附近的密度越低。

PDF 可以大于 1；它是密度，不是某个单一方向的概率。

## 原书的 Cornell Box 硬编码

在顶部矩形灯上均匀选点：

```cpp
auto on_light = point3(
    random_double(213,343),
    554,
    random_double(227,332)
);
```

计算方向和距离：

```cpp
auto to_light = on_light - rec.p;
auto distance_squared = to_light.length_squared();
to_light = unit_vector(to_light);
```

检查灯是否位于接收表面的上半球：

```cpp
if (dot(to_light, rec.normal) < 0)
    return color_from_emission;
```

灯面积：

```cpp
double light_area = (343-213) * (332-227);
```

灯是水平的，法线沿 $y$ 轴，所以灯光侧余弦为：

```cpp
auto light_cosine = std::fabs(to_light.y());
```

避免接近切线时除零：

```cpp
if (light_cosine < 0.000001)
    return color_from_emission;
```

最终方向 PDF：

```cpp
pdf_value = distance_squared
          / (light_cosine * light_area);
```

然后生成指向灯的光线：

```cpp
scattered = ray(rec.p, to_light, r.time());
```

## 两个余弦不能混淆

### 接收表面的余弦

$$
\cos\theta_S=\mathbf n_S\cdot\omega
$$

它属于 Lambertian 物理散射项：

$$
p_{scatter}=\frac{\cos\theta_S}{\pi}
$$

位于蒙特卡洛分子。

### 光源表面的余弦

$$
\cos\theta_L
=
|\mathbf n_L\cdot(-\omega)|
$$

它用于面积到立体角的转换：

$$
p_{light}=\frac{r^2}{A_L\cos\theta_L}
$$

位于蒙特卡洛分母。

对于 albedo 为 $\rho$ 的 Lambertian 表面，单样本贡献可以展开成：

$$
\frac{
\rho(\cos\theta_S/\pi)L_i
}{r^2/(A_L\cos\theta_L)}
=
\boxed{
\frac{
\rho L_iA_L
\cos\theta_S\cos\theta_L
}{\pi r^2}
}
$$

这里自然出现了接收面余弦、光源面余弦、光源面积和距离平方衰减。

## 单面发光

为了防止灯背面通过灯与天花板之间的小缝产生异常亮点，光源只在正面命中时发光：

```cpp
color emitted(
    const ray& r_in,
    const hit_record& rec,
    double u,
    double v,
    const point3& p
) const override {
    if (!rec.front_face)
        return color(0,0,0);

    return tex->value(u, v, p);
}
```

Cornell Box 顶灯的正面朝向房间内部，所以只向房间内部发光。

## 当前 `quad` 中的通用封装

后续代码把第九章硬编码的计算放进矩形几何体。

面积：

```cpp
auto n = cross(u, v);
area = n.length();
```

均匀选择矩形点：

```cpp
vec3 random(const point3& origin) const override {
    auto p = Q
           + random_double() * u
           + random_double() * v;

    return p - origin;
}
```

评估方向 PDF：

```cpp
double pdf_value(
    const point3& origin,
    const vec3& direction
) const override {
    hit_record rec;

    if (!hit(ray(origin, direction),
             interval(0.001, infinity), rec))
        return 0;

    auto distance_squared =
        rec.t * rec.t * direction.length_squared();

    auto cosine = std::fabs(
        dot(direction, rec.normal)
        / direction.length()
    );

    return distance_squared / (cosine * area);
}
```

其中：

$$
r^2=t^2\|\mathbf d\|^2
$$

因为射线方向未必是单位向量，不能简单把 $t^2$ 当作真实距离平方。

## 直接光源采样的局限

直接朝灯采样非常适合漫反射直接光，但不一定适合：

- 理想镜面反射；
- 折射；
- 强烈的材质方向峰值；
- 重要的间接光方向。

所以后续会把光源 PDF 与材质 PDF 混合，而不是永远只朝灯采样。

## 本章结论

$$
\boxed{
\text{灯面均匀选点}
\Longrightarrow
p_A=\frac1{A_L}
\Longrightarrow
d\omega=\frac{\cos\theta_L}{r^2}dA
\Longrightarrow
p_\omega=\frac{r^2}{A_L\cos\theta_L}
}
$$

> 直接光源采样让样本更频繁地落在有贡献的方向，再通过除以正确的方向 PDF，保证图像不会因为“故意多采灯光”而产生偏差。
