# 第 4 章：球面方向积分与均匀采样

## 方向为什么可以看作单位球面上的点

三维方向只表示朝向，不需要长度。把方向单位化后：

$$
\|\omega\|=1
$$

所有可能方向正好对应单位球面 $S^2$ 上的所有点。因此：

- 一个方向：球面上的一个点；
- 一小片方向范围：球面上的一小块面积；
- 对所有方向积分：对单位球面面积积分。

这个方向面积叫作**立体角**，记作 $d\omega$，单位是球面度（steradian，sr）。

## 球面面积元

球坐标中的单位方向：

$$
\omega(\theta,\phi)
=
(\sin\theta\cos\phi,
 \sin\theta\sin\phi,
 \cos\theta)
$$

球面上的面积元为：

$$
\boxed{d\omega=\sin\theta\,d\theta\,d\phi}
$$

$\sin\theta$ 来自纬线长度：靠近极点时圆周短，靠近赤道时圆周长，所以相同的 $d\theta,d\phi$ 对应的实际面积不同。

整个单位球面的面积：

$$
\int_0^{2\pi}\int_0^\pi
\sin\theta\,d\theta\,d\phi
=4\pi
$$

上半球面积为 $2\pi$。

## 球面上的蒙特卡洛估计

目标积分：

$$
I=\int_{S^2}f(\omega)d\omega
$$

如果方向由 $p(\omega)$ 生成：

$$
\boxed{
I\approx
\frac1N\sum_{i=1}^N
\frac{f(\omega_i)}{p(\omega_i)},\qquad
\omega_i\sim p
}
$$

它与一维公式完全相同，只是：

| 一维积分 | 方向积分 |
|---|---|
| $x$ | $\omega$ |
| $dx$ | $d\omega$ |
| 区间长度 $b-a$ | 球面面积 $4\pi$ |
| $p(x)$ | $p(\omega)$ |

## 什么叫球面均匀采样

均匀不是指 $\theta$ 和 $\phi$ 都均匀，而是：

> 任意两块面积相等的球面区域，被采到的概率相同。

整个球面积为 $4\pi$，所以均匀方向 PDF 是常数：

$$
\boxed{p(\omega)=\frac{1}{4\pi}}
$$

等价的球坐标采样规则是：

$$
\phi\sim U(0,2\pi),\qquad
z=\cos\theta\sim U(-1,1)
$$

不能直接令 $\theta\sim U(0,\pi)$，否则样本会在南北极附近堆积。

## 拒绝采样生成均匀方向

项目中的 `random_unit_vector()` 使用：

1. 在立方体 $[-1,1]^3$ 内均匀选点；
2. 拒绝单位球外的点；
3. 拒绝接近零向量的点；
4. 把球内点单位化。

```cpp
inline vec3 random_unit_vector() {
    while (true) {
        auto p = vec3::random(-1, 1);
        auto lensq = p.length_squared();

        if (1e-160 < lensq && lensq <= 1.0)
            return p / std::sqrt(lensq);
    }
}
```

单位球具有旋转对称性，球内均匀分布在单位化后不会偏爱任何方向，因此得到球面均匀方向。

错误做法是直接对立方体中的点单位化而不拒绝球外点，因为立方体在对角线方向拥有更多体积，结果会偏向立方体角落。

## 示例：积分 $\cos^2\theta$

设 $\theta$ 是方向与 $z$ 轴的夹角。对于单位向量 $d$：

$$
d_z=\cos\theta
$$

所以：

$$
f(d)=d_z^2
$$

使用均匀球面 PDF：

```cpp
double f(const vec3& d) {
    return d.z() * d.z();
}

double pdf(const vec3&) {
    return 1.0 / (4.0 * pi);
}

for (int i = 0; i < N; ++i) {
    vec3 d = random_unit_vector();
    sum += f(d) / pdf(d);
}

double I = sum / N;
```

解析结果：

$$
\int_{S^2}\cos^2\theta\,d\omega
=
\frac{4\pi}{3}
$$

所以程序应收敛到：

$$
\frac{4\pi}{3}\approx4.18879
$$

## 怎么判断采样是否均匀

只看散点图不够可靠，可以做以下检查。

### 检查平均方向

$$
\mathbb E[x]\approx
\mathbb E[y]\approx
\mathbb E[z]\approx0
$$

### 检查二阶矩

由于三个轴完全对称，而且 $x^2+y^2+z^2=1$：

$$
\mathbb E[x^2]
\approx
\mathbb E[y^2]
\approx
\mathbb E[z^2]
\approx\frac13
$$

### 检查 $z$ 的直方图

球面均匀时：

$$
z\sim U(-1,1)
$$

所以把 $z$ 等宽分桶，每桶数量应大致相同。

### 检查等面积区域

把球面切成面积相等的区域，各区域样本数应接近，而不是简单按等宽 $\theta$ 分区。

## 本章结论

> 三维方向积分就是单位球面上的面积积分。判断方向是否均匀，要看单位球面的等面积区域，而不是看球坐标参数是否均匀。
