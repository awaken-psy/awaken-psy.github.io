## 1. 从球面到八面体到平面

**八面体映射（octahedral mapping）**：把每个方向向量交到正八面体表面，再把八面体沿棱线展开成正方形。这是球面方向与正方形之间的连续双射。

![808](<Attachments/Pasted image 20260918130634.png>)

三个性质决定了它是标准选择：

1. **双射**——每个格子和方向一一对应；
2. **近似等面积**——每格在球面上的立体角几乎一样大，所以每条打出的射线的权重相同；
3. **半球版**——先把方向转到"法线朝上"的局部坐标系，只展开上半球，格子全部落在有用的方向上。

经纬度在两极挤成一团，近极格子的权重高；八面体的均衡性最好，逆运算也精确。
``` cpp
vec2 signNotZero(vec2 v) {
    return vec2((v.x >= 0.0) ? +1.0 : -1.0, (v.y >= 0.0) ? +1.0 : -1.0);
}

// Assume normalized input. Output is on [-1, 1] for each component.
vec2 float32x3_to_oct(in vec3 v) {
    // Project the sphere onto the octahedron, and then onto the xy plane
    vec2 p = v.xy * (1.0 / (abs(v.x) + abs(v.y) + abs(v.z)));
    // Reflect the folds of the lower hemisphere over the diagonals
    return (v.z <= 0.0) ? ((1.0 - abs(p.yx)) * signNotZero(p)) : p;
}

vec3 oct_to_float32x3(vec2 e) {
    vec3 v = vec3(e.xy, 1.0 - abs(e.x) - abs(e.y));
//    if (v.z < 0) v.xy = (1.0 - abs(v.yx)) * signNotZero(v.xy);
    v.xy = (v.z < 0) ? (1.0 - abs(v.yx)) * signNotZero(v.xy) : v.xy;
    return normalize(v);
}
```

## 2. 抖动：把规律误差打散成均匀噪声

8×8 方向格、16×16 屏幕格都是固定网格。固定网格的问题是**周期性误差**：误差呈现规律排列，而人眼对规律排列的误差极其敏感（波纹、格子印）。

解法是给每个采样块、每个方向格加一点每帧不同的微小偏移，即**抖动（jitter）**，再被邻域滤波和多帧累积一平均，趋近于零。这和 TAA 的亚像素抖动是同一个思路：**牺牲瞬时的严格正确，换统计上的长期正确**。

偏移用蓝噪声（blue noise）而不是白噪声，关键在误差的分布：白噪声的误差分布不均匀，有的地方成堆、有的地方空缺；蓝噪声的误差在相邻位置均匀交错。**人眼对低频的误差团敏感，对高频的细噪宽容**——蓝噪声把误差全部推到高频段，恰好避开人眼最敏感的频段。

## 3. 重要性采样：按上一帧的亮度分配射线

**重要性采样**：如果知道哪些方向可能有光，就把采样配额优先分给它们。TuanjieGI 的做法是——**用上一帧的结果指导这一帧的采样**。上一帧这 9 个系数能重建出"哪个方向亮"，这一帧就按亮度比例分配 64 条射线。

代价与限制：求和时要按实际立体角加权，否则统计上偏色。另外上一帧的结果只用于引导方向、不直接作为结果，避免光照剧变时出现滞后。


八面体映射给方向编号，抖动和蓝噪声打散误差，重要性采样按亮度分配射线——合起来，每个采样块得到一套均匀、无纹、集中在有效方向上的 64 条射线。
