## 1. 它解决什么问题

屏幕空间查询要沿画面推进一条射线，找到"射线走到哪里、进入了已画表面的背后"。最直接的做法是逐像素比较：射线深度 vs 深度图。但一条射线在 1080p 上可能横跨上千个像素——上千次采样，乘以每帧几十万条射线，完全不可行。

性质和[球体步进](学习笔记/cg/tuanjie引擎/GI原理/01-数学基础/03-SDF与球体步进.md)完全一样：**空旷处大步跳过、接近表面自动减速**。球体步进的安全步长来自 3D 距离场；Hi-Z 是同一套行为在 2D 屏幕深度场上的版本。

## 2. 构造：深度图的 mip 链，取"最近"而不是平均

把深度图当作纹理逐级缩半：

- 第 0 层 = 原始深度图（例如 1920×1080）；
- 第 k+1 层每格**取 2×2 子块中离相机最近的表面深度**（正 Z 约定下取 min；用倒序 Z 的引擎取 max，方向相反、本质相同）；
- 缩到 1×1 为止，1080p 大约 11 层。

```
第0层 4×4（像素深度）           第1层 2×2（每格=子块内最近表面）
┌────┬────┬────┬────┐          ┌─────┬─────┐
│ 5  │ 5  │ 8  │ 8  │          │ 5   │ 6   │     第2层 1×1
├────┼────┼────┼────┤    →     ├─────┼─────┤           ┌────┐
│ 5  │ 5  │ 6  │ 7  │          │ 4   │ 10  │     →    │ 4  │
├────┼────┼────┼────┤          └─────┴─────┘           └────┘
│ 4  │ 9  │ 10 │ 10 │
├────┼────┼────┼────┤
│ 4  │ 11 │ 12 │ 12 │
└────┴────┴────┴────┘
```

粗格子的语义：**这块 2^k × 2^k 像素区域内，最近的表面有多近**——一个保守下界。

## 3. 步进规则

1. 射线投到屏幕坐标，进入金字塔；
2. 在当前层的格子上比较：若射线**在这格覆盖的整个区间内**都离相机比"格内最近表面"更近——它在这块里不可能穿过任何东西——整格一步跳过，继续用同样的粗细；
3. 跳不过就降一级细层，在原位置重试；
4. 细到单像素还跳不过：射线在这一像素进入了表面的背后——**命中候选**；
5. 候选不直接采信：按运动矢量带回上一帧核对深度，通过后取上一帧最终画面的颜色——这两步属于[六级查询](学习笔记/cg/tuanjie引擎/GI原理/03-核心算法/02-射线的六级查询.md) ① 级本身的流程。

两条判定式：

$$
\text{整格跳过}：\ z_{\text{射线}}(\text{整段区间}) < \min z(\text{块})
\qquad
\text{命中}：\ z_{\text{射线}} \geq z(\text{像素})
$$

粗层跳不过只说明"这格里可能有东西"，不代表命中；命中只在最细层判定。

## 4. 与球体步进的对照

|        | SDF 球体步进       | Hi-Z 屏幕步进           |
| ------ | -------------- | ------------------- |
| 存的东西   | 3D 空间"离最近表面多远" | 2D 屏幕区域"离相机最近的表面多近" |
| 保守下界   | 读数 ≤ 真实距离      | 粗格值 = 块内最近表面        |
| 安全跳过   | 半径 d 的球内没有表面   | 整格区间内射线都在所有表面之前     |
| 步长     | = 读数，空旷处大步     | = 格子尺寸，空旷处用粗层       |
| 接近表面   | 读数变小、自动减速      | 层级变细、自动减速           |
| 不漏过的保证 | 读数是真实距离的下界     | 粗格取的是"最近"表面         |
| 作用域    | 任意 3D 射线       | 只能回答"沿屏幕投影方向"的射线    |

## 5. 成本

- **构建**：每层一次减半下采样，1080p 约 10 次极快的 pass——每层就是全图几千次 2×2 取小，GPU 上天然并行；
- **显存**：各级面积 1/4 + 1/16 + 1/64 + … ≈ 额外 1/3；
- **步数**：逐像素是千级；金字塔下通常几十步——空旷区域几大步跨过整个画面，几何附近自动细化到像素。

## 6. 局限

- **只记第一层**：深度图只保存每条相机射线最先撞到的表面，被它挡住的几何完全不可见。射线一旦进入可见表面背后，后续查询没有可信答案。
- **只在画面内**：屏幕外的方向、这一帧没画进画面的东西，一律答不了。
- **深度非线性**：深度通常按 1/z 存储，远处精度低，比较时要用阈值吸收误差（或先线性化再比）。

## 7. 谁在用它

所有"沿屏幕深度场做保守步进"的系统共用这一个加速结构：**SSR**、**SSAO/HBAO**（遮蔽判定的射线）、以及 TuanjieGI 的 ① 屏幕空间查询。在 TuanjieGI 里它位于[六级查询](学习笔记/cg/tuanjie引擎/GI原理/03-核心算法/02-射线的六级查询.md)的第一级：命中后读上一帧最终画面——等于不额外计算地多拿到一反弹的信息。
