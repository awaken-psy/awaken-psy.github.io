# 调试可视化与调优

GI 是一条多层流水线（射线 → 结果 → 滤波 → 九个数 → 像素），出了问题时"调参数看画面"是最低效的做法——你不知道问题出在哪一层。正确做法是逐层检查。

## 1. 先看见，再动手

系统自带一整套分层视图，每层中间数据都能单独显示：

- 采样块分布——屏幕上的网格与加密点；
- 各级射线命中——屏幕/局部/粗场/光追各自"找到"了什么，横向对比找遗漏；
- bent normal 图——角落的弯法线对不对；
- 面片图集各层——颜色、自发光、间接光照、出射光、累积帧数，每项数据都能查；
- 距离场切片——粗场精场的距离与法线；
- 最终三张输出图——间接漫反射、粗糙镜面、bent normal。

用法：按数据流顺序从上游往下游检查——射线都找到了吗？结果合理吗？滤波把不同表面混到一起了吗？图集数据对吗？一层层排除，问题逐层定位。**每层可独立检查，把 N 维参数空间拆成 N 个一维问题**——这是调优效率的分水岭。

还有一个强工具是**分量检查**：间接光里的各成分可以单独置零——直接光置零看纯反弹的收敛质量；自发光置零排查霓虹串色；间接置零看图集里的直接光投影；甚至有"第 1 反弹置黑 / 第 2 反弹置黑"的开关，逐反弹检查。任何"说不清哪里怪"的问题，基本十分钟能定位到某一层。

## 2. 症状速查

| 观感 | 机理 | 对策方向 |
|---|---|---|
| 间接光块状/糊 | 块间滤波半径不足 | 加大滤波半径；开自适应加密 |
| 噪点闪烁 | 单帧射线太少、时间混合被频繁清零 | 查帧数是否在积累；重要性采样是否开 |
| 拖影/幽灵反弹 | 屏幕空间查询采信了不该信的旧画面；像素层校验太松 | 关屏幕查询对比确认；查深度校验 |
| 漏光（薄墙透亮） | 粗场分辨率把薄墙存得太薄 | 调大粗场"截短"的保守量；资产侧加撑厚偏置 |
| 角落太亮、缺凹感 | bent normal 没启用/尺度不对 | 确认开启；调大采样距离 |
| 转身后反弹光消失再慢慢回来 | 屏幕外无信息，世界层下帧才跟上 | 属正常现象；查局部+粗场两级是否正常工作 |
| 动态物体处涟漪/拖尾 | 面片迁移、旧数据重采样 | 减少"会动的 GI 物体"；反弹由屏幕层处理 |
| 灯光变化响应有延迟 | 交错更新的固有延迟 | 取舍已定；不能接受则关分批 |
| 远处细节反弹光偏少 | 级联粗场半径外图集没更新 | 扩大 GI 影响距离（注意显存） |

## 3. 性能调优顺序

帧率不够时按性价比从高到低动手：

1. 确认交错更新开着（射线 ÷16，收益最大的一步）；
2. 快速积分（摊回从邻域加权降为就近取，质量略降速度明显）；
3. 采样块变粗（16 → 32 像素一块）；
4. 追踪链缩减（关掉某一级查询，牺牲对应范围的信息）；
5. 资产侧减负（降面片分辨率档、缩粗场距离——动手前先看显存统计）；
6. 最后才轮到滤波半径等细节参数（对速度影响小，别在这层浪费时间）。

先测量再动手的原则在这里同样成立：分析工具能分层显示 GPU 耗时，动手之前先看耗时分布。

## 4. 收官

全册压缩成九行，能默写下来这套系统就真正属于你了：

```
目标:   间接光提供真实感，多级反弹让光在场景中充分传播
结构:   世界层=面片出射光图集(每帧推一反弹)；屏幕层=采样块查询(64射线→九个数→摊回)
数学:   球谐：方向压成系数，余弦瓣预制系数，锥形瓣=粗糙镜面
几何:   SDF：安全步长推进，梯度顺便得法线；粗场+索引表两级结构
复用:   空间复用(256像素/块)+方向复用(64格)+时间复用(16组分批)
查询:   屏幕空间(读上帧≈两反弹)→局部→粗场→[光追]→天空
时间:   块层帧数混合(质量)+像素层重投影(运动)+曝光预乘(衔接)
原则:   静止即零成本；构造即接线；输入七样、输出三张
调优:   先逐层检查，再分量检查，最后才动参数
```
