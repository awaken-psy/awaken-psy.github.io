# TuanjieGI 学习笔记

关于团结引擎实时全局光照 TuanjieGI 的一组学习笔记，基于源码阅读整理。假设你读过《总览》篇的第 06 章和第 10 章——知道直接光和间接光的区别、知道为什么烘焙 GI 不支持动态灯，就够了。

这组笔记刻意不贴代码、不出现内部类名——先把原理讲透，将来读源码时自然会认出每一部分。

## 1. 核心思路（30 秒版）

TuanjieGI 是一个**双层**的实时 GI：

- **世界层**：给每个静态物体的表面铺一层小面片，每片面片记录"我向外发多少光"。面片之间每帧互相照射，间接光逐帧累积，多级反弹逐帧收敛。
- **屏幕层**：把屏幕切成 16×16 像素的采样块，每块朝半球发射 64 条射线，查询各方向的反弹光，命中后读面片上存的出射光，汇总成球谐系数再摊回像素。

两层每帧互相读取对方的"上一帧结果"，松弛地耦合——这是它能实时跑起来的根本原因。
