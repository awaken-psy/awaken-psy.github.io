# 分层距离场

每个模型都有一张自己的距离场（[SDF 篇](学习笔记/cg/tuanjie引擎/GI原理/01-数学基础/03-SDF与球体步进.md)）。问题在射线出发那一刻：当前这段路径，应该查哪张距离场？

最直接的办法是逐个模型查询——几千次查询 × 每条射线 × 几十万条射线，开销不可接受。就算给模型建包围盒树，也比一张覆盖全区域的连贯距离场慢得多。理想是一张覆盖全场景的连贯场，但全场景统一高分辨率，内存不可承受。

## 1. 粗场：以相机为中心的分层结构

解法是把级联阴影（CSM）的思想搬过来——**结构跟着相机走，近细远粗**：

```
┌────────────────────────────┐
│ 第3层：覆盖最远，格子最粗      │
│  ┌──────────────────────┐  │
│  │ 第2层：中等            │  │
│  │  ┌────────────┐       │  │
│  │  │ 第1层：较细  │       │  │
│  │  │ ┌──────┐    │       │  │
│  │  │ │第0层  │    │       │  │
│  │  │ │[相机] │    │       │  │
│  │  │ └──────┘    │       │  │
│  │  └────────────┘       │  │
│  └──────────────────────┘  │
└────────────────────────────┘
```

每层是一张 3D 距离场，由它覆盖的所有模型的精场**重新体素化合成**而来；内层格子小（半米级），外层格子大。相机移动时整个结构跟随移动（格子对齐到网格，避免每帧重建）。

射线的查询分两级：**在粗场里大步推进**接近目标；粗场读数变小、接近命中时，**查当前格的模型索引表**——转入登记的模型精场做精确判定，得到精确命中点和法线，再到对应面片取色。粗场负责"快速接近"，索引表负责"找到候选模型"，精场负责"精确判定"，面片负责"提供光照"。

## 2. 模型索引表

粗场的每个格子除了记"离最近表面多远"，还附带一张小索引表：**与本格相交的模型，最多记录 4 个**。射线在粗场命中后取出名单，逐个到它们的精场精查、逐个取面片的光、按可信度加权平均，足够可信就提前结束。

查询复杂度收缩到本格最多 4 个，**与场景总规模脱钩**。索引表在构建粗场时生成，运行时只读。

## 3. 防漏光：保守

粗场格子粗，外层可能一米多一格。**薄墙**比格子还薄，可能一步跨过薄墙，落地后读数变回正的，全程没有触发"接近表面"——漏光，这是 GI 最常见的错误。

对策：**把命中判定的门槛放大**。粗场步进判定命中不看"读数归零"，而是"读数小于半个体素"（同时不超过沿途见过的最大读数——贴近表面时门槛自动收紧）。效果上等于把每个表面向外膨胀半个体素。射线想一步跨过这条带，步长必须大于带宽；但步长就是读数本身，带附近的读数只有半个体素量级——跨不过去，命中在带上被拦下。

引擎里另有一个注释为"防漏光"、默认 0.5 的可调参数，但当前版本它没有接在任何生效的步进路径上——生效路径里的半体素是写死在代码里的（见 [GI代码/01-级联距离场](学习笔记/cg/tuanjie引擎/GI代码/01-级联距离场.md)）。

代价：命中点落在真实表面外半个体素以内，但粗场本来只负责导航，精确判定永远由精场和面片完成。
