**面片(facet)**：把模型表面切成 8×8 的像素方格，平铺贴满表面。每片方格记录"每块表面向外发多少光"，是光照存储的基本单元。

## 1. 只有六个朝向

关键设计：**每片面片只朝六个方向之一**（±X、±Y、±Z 共六种）。

- 不需要精确贴合每个法线，只需要把表面覆盖住：每个表面点找一片朝向大致匹配的面片盖住它，贴合误差由下面的"深度层"修正。
- 换来的是查询速度的飞跃。可以**按命中处法线方向直接筛选**：法线朝 +X 就只查"+X 朝向"的面片名单，名单里逐个判断"点在你覆盖的范围内吗"。没有空间树、没有排序、没有哈希，一次方向判断锁定候选名单。六个朝向，把空间查找压缩成六选一加名单遍历。

## 2. facet的存储

facet是 8×8 的像素块，每像素存这几层：

| 层       | 存什么                    | 谁用               |
| ------- | ---------------------- | ---------------- |
| 颜色      | 固有色                    | 合成出射光            |
| 法线      | 朝哪                     | 光照计算、取色校验        |
| 自发光     | 自己发多少光（霓虹、岩浆）          | 合成出射光            |
| 深度      | 这个像素对应的真实表面**离面片平面多深** | 取色校验             |
| 间接光照    | 被别的面片弹了多少光（多帧累积）       | 合成出射光            |
| 累积帧数    | 这份间接光照累积了多少帧           | 历史加权             |
| **出射光** | **最终结果：我向外发多少光**       | **一切 GI 射线的取色源** |

出射光是整个系统的核心数据——屏幕层射线、面片互相照射、调试视图，全读它。具体见[核心算法](学习笔记/cg/tuanjie引擎/GI原理/03-核心算法/03-面片光照与多级反弹.md)。

## 3. 图集与暂存纹理

所有物体的面片的像素平铺进一张 4096×4096 的大图集统一管理。另外备一张 512×512 的暂存纹理：每帧只把"本批待处理"的面片搬进去——重新从原模型采样基本数据、做本帧的光照计算，算完把结果按各自区域写回大图集。

配套的管理规则：面片有**优先级**（视野内、离相机近、数据更新距今久的优先处理）和**有效期**（过期就重新处理）。物体移动时，旧数据按新位置**重采样**迁移——模糊但连续，之后逐帧重新变清晰。

## 4. 取色的校验

GI 射线命中后，找到覆盖命中点的面片、读它的出射光——这里有个坑：面片是平的，表面是曲的，面片边缘可能悬空（盖着空气）也可能穿进另一面墙。直接读数，会把隔壁墙面的光错误混进来。

校验靠深度层。命中点换算到面片平面内找到最近的 2×2 像素（准备双线性混合），每个候选像素取出自己的深度记录："我这里，真实表面离面片平面 0.05 米"。与命中点的实际深度对比，**对不上的像素权重清零**——它对应的不是命中点所在的那块表面。只有深度匹配的像素参与最终取色。

两层各管一件事：深度校验判断"你是不是这块表面的"，双线性决定"这块表面内部怎么平滑混合"。
