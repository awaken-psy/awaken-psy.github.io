## Math/（自研数学库，18 文件 1MB）逐件职责

| 文件 | 职责（关键事实） |
|---|---|
| `SphericalHarmonics.h/.cpp` | SH 9 阶/16 阶（4 阶）双特化：`project`、`integrateDiffuse`（固定 9，ClampedCosine 系数 CosineA0=π…）、`integrateRoughSpecular`（模板 num 阶锥角瓣）；`SphericalHarmonicsInt` 定点编码 `SHEncodingScale=2^20`；窗口化锥角系数 `_Window` 变体 |
| `SphereMapping.h/.cpp` | 八面体全家：`mapToSphere(Hemi)Octahedron(Inverse)`（半球版注释引 Clarberg 快速等面积映射）、`GetOrthoVectors`、`CreateTBN`（**转置**，配 `mul(tbn,v)` 风格）、mapToDisk/CosineHemisphere/Gaussian/UniformHemisphere、`MapToTriangleLowDistortion`；⚠️ `mapToCosineHemisphereInverse` 疑似拷贝自 disk 版（与 encode 不互逆） |
| `BlueNoise.h/.cpp` + `BlueNoiseSamples.h` | Heitz 低差异蓝噪声采样器：Sobol 256×256 + ranking/scrambling tiles 128×128（966KB 常量表）；`Sample1D/2D/3D` 时间动画用黄金比例 `frac(s+(idx&255)φ)`；`HammerSley(i,total[,scramble])` |
| `BilateralFilter.h` | **"三判据"的实现文件**：`GetWeight` = 屏幕/深度/法线三个高斯乘积，`GetSigmaRsqr = −0.5/σ²`，`WeightMesure(coord,viewDepth,normal)`——历史混合与摊回共用的权重核（[../04-屏幕层/06](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/06-历史混合与重投影.md) 的公式出处） |
| `TextureCodec.h` | **RGBE 编码**（源自 Microsoft Minigraph/James Stanard）：`Pack/UnpackRGBE[_sqrt]`——共享指数压缩，`_sqrt` 变体尾数开方换小值精度；命中载荷（PackRGBE_sqrt）与重要性采样历史读取（UnpackRGBE_sqrt）共用 |
| `OrthoNormalBasis.h` | `ConstructOrthoNormalBasis`——Duff 等 2017 无分支正交基；半球方向采样旋回世界系时用（[../04-屏幕层/08](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/08-方向采样与重要性采样.md) §1） |
| `InterlockedFloat.h` | 浮点原子：`interlocked_add/min/max_float`——CAS 循环 + 位重解释；直接光逐 texel 累加的基础 |
| `Interpolation.h/.cpp` | `BiLinearInterpolation`、`TriLinearInterpolationAndGradEvaluation`（输出 float4 = 梯度 xyz + 值 w；用 `$outline` DSL 生成）——3D 纹理带梯度求值 |
| `GPUCone.h` / `GPUCylinder.h` | 光源剔除几何：锥体（底球/顶点/锥面三段 `overlapsSphere`）与无限圆柱——面片直接光的灯-块相交测试可用 |
| `GPUMinMaxAABB.h` | CPU+GPU 双版 AABB（overlaps/intersection/sqrDistanceTo）——级联/精场的范围判定到处用 |
| `Matrix3x4f.h` + `Matrix3x4fTests.cpp` | 3×4 变换（轴+位置+内部缩放），序列化字段 p_x1..p_w3——面片 `facetToWorld`/GIFacetInfo 的存储类型 |
