# 04 未解之处与存疑项（诚实清单）

> 本文记录三类信息：**①失效/短路/禁用的路径 ②无注释的设计决定 ③疑似 bug**，以及**超出本档范围**的内容。全部条目均为本档核实记录（Tuanjie 1.11.0 / 内部版本 2022.3.62t17）。
> **本套文档自包含**：引用本文声明的内容时如实转述；本档范围之外的问题回答"超出本档范围"或"本档未覆盖"，**不以源码为退路**（读者环境没有源码）。

## A. 被禁用/短路的路径（引用时先声明"当前禁用"）

1. **GICascadeMipSpreading 整体被短路**：`LoadSrcDFValue` 直接 `return 0.0f`，真实 atlas 读取代码整块被注释（含 `$permutation_if("READ_ATLAS")`）。mip 的 Eikonal 扩散在常量 0 上做，无注释说明。→ 不要当成生效的 mip 机制。
2. **GIDataBuilder 的 SDF LOD 只生成 level 0**：`for (level=0; level>=0; --level)` 实际只跑一轮，注释 "TODO: match shader"。`sdfLODCount=3` 的 2、3 级资产当前不会生成。
3. **GIHWRTScene 的自建 native TLAS**：整块 `#if 0 // TODO: build native tlasBuffer`（含 UpdateMeshesAndRenderers、顶点/三角形分配器）。实际加速结构 = 引擎 `RayTracingAccelerationStructure`。
4. **DFAOPipeline 未接线**：工厂宏里对应行被注释（ITuanjieGIPipeline.h）。属旧实验。
5. **URP 的可视化颜色映射被注释**：`GetComputeVizColorRangeShader/GetVizColorMappingShader/ExecVizColorMapping` 整段注释（HDRP 版启用）。
6. **BlendHistoryQuads 旧版**：QuadTraceSH.h L1480–1522 整段 `#if 0` 保留（现行是 BlendHistoryQuads2）。
7. **CompositeRadiosity 的旧 lambda**：`lightingComposite` 注释版（h:1646–1714），公式与现行一致但多一个 `1/256` 缩放——历史对照用。
8. **URP 的 ReadTransparencyMaterial**：函数体全注释，返回全 0（透明材质读取未实现于 URP；HDRP 已实现）。
9. **URP 的 ReflectionHistoryColorAndCount**：函数体全注释返回 0——屏幕镜面的"命中深度历史源"在 URP 是死路（HDRP 已实现，见 [../05-集成与工程/02-管线接入URP与HDRP](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/05-集成与工程/02-管线接入URP与HDRP.md) §5）。
10. **URP 的 `GetHistoryClipPosByDeviceZ`、`PlaceQuadInViewport`、`WorldPositionToViewportCoord`、`ViewPixelOffsetToUV`**：全部未实现/返回占位值（HDRP 有真实现，同上 §5）。
11. **`RenderGI()` 函数体为空**（TuanjieGIManager.cpp:313）：真正入口是 ExecuteGIPipeline。
12. **`TuanjieGIConfig::Transfer` 为空**：序列化配置当前没有任何字段。
13. **HDRP 的块内抖动蓝噪声版被注释**：HDRP 的 `GetJitter` 当前走 8 周期确定序列（`GetQuadJitter×quadSize`）；URP 以蓝噪声为主路径（备用 `GetQuadJitter`）——两平台抖动实现相反，见 [../04-屏幕层/02 §2](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/02-采样块与射线发射.md)。
14. **`LightingQuadID` 的 12/10/10 位打包是 TODO 未实现**：注释描述了 12 位请求 ID + 10/10 位抖动中心的打包设计，但现行结构是三个独立字段（`rasterRequestID`/`facetID`/`jitteredPixelOffset`，[../03-世界层/02-面片系统GIFacet](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/03-世界层/02-面片系统GIFacet.md) §9.5）。

## B. 无注释的设计决定（事实已核实，动机无说明）

1. **面片出射光里 baseColor 取平方**（`out *= baseColor*baseColor`，DoCompositeRadiosity）——无注释解释设计意图。
2. **ScreenTracer 的 `hitDistance × 0.5f`**——无注释。
3. **ScreenTracer 命中把 `(uv.x, uv.y, bufferZ)` 写进 hitNormal**——本意取世界法线的行被注释掉；下游若把 hitNormal 当法线用会拿到非法线数据。
4. **SeperableFilter kernelRadius=14 硬编码**、边缘吸附 `2e-4`（注释 "TODO: magic number"）。
5. **URP/HDRP 的 `fLightRangeCompressFactor` 差 10⁴ 倍**（1.6384 vs 16384.0）——数值如核实，差异原因无注释。
6. **URP 的曝光乘子硬编码 1**——曝光校正在 URP 路径不生效。
7. **URP `GetLightPositionWSAndRange` 硬编码 range=1000**。
8. **`GIRadianceCacheSH` 每块 48 个 float**（`shCoord = quadCoord×(8,6)+idx`）——与 4 阶 SH×3 通道=48 吻合，但源码未显式写阶数（有据推断，非确认）。
9. **三处"quad"尺寸的选值**（屏幕块 16 / 射线格与光照块 8）：值已核实，动机无注释。

## C. 疑似 bug / 错位

1. **`writeBlackToIndIrradiance1/2` 注册同名**：两个选项都注册成 `FacetScene.finalLighting.zeroOutIndirect1`（第二个应为 …Indirect2）——调第二个开关实际动的是同一个 id。
2. **`GIClusterTracer.traceMaxDistance`**：GIOption 默认 1，注释写 "Tracer cluster count."——名字/注释/语义三错位，实际按 cluster 数预算理解。
3. **`resolvedRadianceTexture` 类型/格式不一致**：声明 `GITexture2D<float>` 却用 B10G11R11 格式创建（ScreenTraceSpecular）。
4. **`mapToCosineHemisphereInverse` 疑似拷贝错误**：实现体是 `mapToDisk` 的逆，与 `mapToCosineHemisphere` 不互逆（Math/SphereMapping.cpp）——未找到调用方依赖。
5. **`belowMip0` 写后未读**（ScreenTracer）。
6. **Emit 期间增删监听器无保护**（TuanjieGIEvent.h）——现有代码未触发问题，但扩展时注意。
7. **`GIGBufferVisualize` 里 `depthBufferBind.load(...)` 结果未使用**。
8. **`GIRadianceCacheSH` 单面片版深度权重是正号**：`exp(+d²/depthAttenuation)`（GIFacetScene.h:1195）——与其他三处取色校验的负号相反，且正号下"深度差越大权重越大"，设计意图未理解。
9. **`GIFacetSceneDSL` 的面片几何访问器是空占位**：`GetFacetWorldCenter/AxisX/AxisY/Extent` 全返回空 `Float3()`，注释 `//todo : wait fentyuan 's edit`（L591–L608）；实际坐标换算由 QuadGPU 方法群承担（[../03-世界层/02 §9.5](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/03-世界层/02-面片系统GIFacet.md)）。
10. **`GetHistoryQuadByCoord` 读取偏移未定案**：L1972 有 `// todo get the read offset.`
11. **`WorldSpaceToFacetNDC` 双减 center**：实现写作 `WorldSpaceToFacetSpace(p − center)`，叠加定义后 center 被减两次——是否有意未说明（[../03-世界层/02 §9.6](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/03-世界层/02-面片系统GIFacet.md)）。
12. **`traceHit` 的 `testRun` permutation 声明但未用**：ScreenTraceSpecular.h L105–109 声明了四个 permutation，函数体内未见 `testRun` 的使用点——作用未体现（可能在上游 dispatch/生成层）。
13. **拼写**（检索时按源码拼写）：`GIGBufferVisuzlize`、`intergrateSize`、`reasterizeRequrest`、`GetNeighorQuad`、`sdfMeshRenderesRenderingDataBuffer`、`2st pass`、`se to 1`、`aded automaticaly`（图集名注释）。

### D.2 超出本档范围（模块外的内容——回答"超出本档范围"，不臆测）

1. **HDRP 公共包的衰减函数体**：`PunctualLightAttenuation / EllipsoidalDistanceAttenuation / BoxDistanceAttenuation / GetPunctualLightVectors`——TuanjieGI 只经 `call<>()` 调用，函数体在 HDRP 包 include 内（各光型调用签名与传参见 [../05-集成与工程/02 §5.3](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/05-集成与工程/02-管线接入URP与HDRP.md)）。
2. **URP/HDRP C# 侧调用 `Execute` 的具体 RenderPass/CustomPass 类**：在 C# 包代码内；本档只确认"静态入口 `Execute` + 数据流向"。
3. **VG culling 的 HLSL kernel 本体与 `GPUCuller` 的剔除算法**：在引擎 GPUDriven 管线内；模块侧只做装配（四个 kernel 名 `InitPersistentState / InstanceCullFacetRasterize / ClusterCullPersistent / DegenerateCullFacetRasterize`，由引擎 `GPUCuller` 调度；投影矩阵 Y 分量取反——"Non vg projMatrix set invertY true, but Vg requires false"）。
4. **RadeonRays 库内部**（HlbvhBuilder/RadixSort/Scan 等）：第三方 BVH 构建库。
5. **`BlueNoiseSamples.h` 的逐值内容**：966KB 常量表（Sobol 256×256 + ranking/scrambling tiles 128×128），只确认结构与采样算法。
6. **HDRP 侧曝光的完整链路**：由 HDRP ShaderLibrary 内部处理，集成层无显式字段（URP 侧已核实为恒 1）。
7. **引擎级 GPU 设施的内部实现**：`GraphicsTexturesPool` 的池化/生命周期策略、`RayTracingAccelerationStructure` 的内部构建、**oceanus DSL 生成器**的编译细节——本档只记录这些设施的**用法**（按名取纹理、创建/释放时机、DSL 写法约定），其内部机制属引擎侧。
8. **Unity/Tuanjie 引擎本体**（渲染循环、Job 系统、TransformChangeDispatch 等）：本档假设读者从各篇的接口描述获得所需上下文；引擎级问题超出范围。
