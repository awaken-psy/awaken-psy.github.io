# 06 调试可视化指南

> 编辑器里看 TuanjieGI 中间结果的全部入口（开关名、看什么、注意事项）。全部经源码核实。

## 1. 取图通道：C# 管理器 API

`TuanjieGIManager.bindings.cs` 暴露（C# 侧 `TuanjieGI.Manager`）：

| API | 用途 |
|---|---|
| `GetTextureByName(name)` / `GetTextureByIndex(i)` / `GetBufferByIndex(i)` | **按名取池内任何中间纹理/缓冲**——GI 全部 GPU 资源走 `GraphicsTexturesPool/GraphicsBufferPool`（名字即池键，清单见 [05-GPU资源与数据布局总表](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/06-参考/05-GPU资源与数据布局总表.md)） |
| `SetTestTexture(name)` + `debugTextureIndex` | 把某张池内纹理设为"当前调试纹理" |
| `fullscreenDebugMinRange / MaxRange / fullscreenDebugComputeRangeTag` | 全屏调试的颜色映射范围（自动计算或手填） |
| `pooledTextureNames / pooledBufferNames` | 枚举池内全部资源名——找图先列这个 |
| `pipelineType` / `enabled` | 切换 URP/HDRP 管线、总开关 |

## 2. 可视化开关（GIOption，前缀即子系统）

所有 `AddVisualize` 开关默认 false，注释统一为 "When enable, this will slow down the framerate, since it cost GPU time to render the TuanjieGI XXX."（开可视化会占 GPU 时间降帧）。

| 开关 | 看什么 |
|---|---|
| `GILightDataVisualize.enable` | **全部光照的裸和**（方向光色 + 点光/聚光 color×intensity × 曝光）——**不做阴影**，用来验证光照数据本身 |
| `GISDFVisualize.enable`（+SDFNormalVisualizer） | 模型精场：从相机打射线多次 trace 取最近命中，输出法线着色 |
| `GICascadedSDFVisualize.enable` | 级联粗场：**四种盒线框**（draw-from-CPU / dirty node / dirty brick / allocator 使用情况，`VisualizeBox::GetWorldMatrix`）+ 全屏 trace 视图（`TraceCascadeSDF`、tMax=1000000，8×8 线程）——看级联结构、脏区域、砖分配的首选 |
| `GITraceVisualize.enable` | tracer 结果：默认输出 `hitRadiance×压缩因子`（miss 白色）；`useNormal` 模板参数改看 `hitNormal`。另有 `VisualizeBentNormal`（弯法线 `×0.5+0.5`）、`VisualizeDepth`、`VisualizeColorBuffer` 变体 |
| `GIDirSampleVisualize.enableTraceDir` / `enableDotSign` | 射线方向可视化：`traceDir`（R8G8B8A8_SNorm，尺寸=块数×8）与"方向是否朝表面"的正负号（R16_SFloat） |
| `GIGBufferVisualize.enable` | GBuffer 三视图：WorldPosition / WorldNormal / ViewDepth（注意源码类名拼写 `GIGBufferVisuzlize`） |
| `InlineRaytracingVisualize.enable`（HWRT） | ray query 全屏打射线：primitive index 灰度 / SDF 法线 / 面片色 |
| `RaytracingVisualize.enable`（HWRT） | 完整光追版，靠全局关键字切换输出：`TJGI_RT_PRIMITIVE_INDEX / TJGI_RT_BASE_COLOR / TJGI_RT_NORMAL / TJGI_RT_EMISSIVE / TJGI_RT_DIRECT_LIGHTING`（dispatch 前开、后关） |
| `FacetScene.DirectLighting.visualizeIrradiance` | 额外输出直接辐照度缓冲（`directLightingDebug`） |
| `FacetScene.finalLighting.zeroOutIndirect1/2` | **对照实验开关**：把 finalLighting 第 1/2 pass 的间接结果强制写黑——用来分离"直接/间接"贡献（注意：两个选项注册名相同，第二个实际改的是同一个 id，见 [04-未解之处](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/06-参考/04-未解之处.md) C.1） |

## 3. 逐中间纹理调试（最常用手法）

不需要开关——GI 的输出与状态纹理全在池里，用 `GetTextureByName` 直接看：

| 想看 | 取什么 |
|---|---|
| 间接漫反射结果 | `outputDiffuse`（B10G11R11，**已乘压缩因子与曝光**，看值时注意量程） |
| 粗糙镜面 / 反射 | `outputRoughSpecular` / `outputReflectionSpecular` / 合成后 `outputCompositeSpecular` |
| 弯法线 | `bentNormalBuffer`（0.5+0.5 编码，中性灰=无遮挡） |
| 历史可靠度 | `outputNumFrames`（R8 归一化 0..1，全白=累积到上限） |
| 射线命中结果 | hit/hitDistance/radiance（QuadTraceSH 的帧内缓冲） |
| 面片出射光 | persistent atlas 的 `Radiosity` 图层（4096²，可看到面片矩形排布） |
| 级联几何 | 级联 atlas 的 3D 距离纹理（`sdfMeshBricksData`） |
| 屏幕镜面中间量 | `directionTexture`（含 pdf）/ `resolvedRadiance` / `reprojectedReflection` |

## 4. 面片 gizmo

`renderGizmos`（默认 false，"this will slow down the framerate"）：编辑器 Scene 视图画面片 OBB 线框（`RenderGIFacetMeshGizmos`，cpp:225–241）——直观确认哪些物体登记了面片。

## 5. 注意事项

1. **URP 的可视化颜色映射未实现**：`ExecVizColorMapping` 整段被注释（HDRP 版启用）——URP 下某些调试输出量程可能偏暗/偏亮，属已知状态。
2. 可视化 kernel 与正式 GI kernel **共用池与命令流**：开关全开会显著降帧（注释明说）。
3. 三种 debug 因子在 `ExecutionContextURP` 可调（direct/sky/emissive/indirect 各 float4，默认全 1）——想把某类光隔离出来看，把其他因子置 0。
4. 调参入口本身也是调试面板：`TuanjieGIOptions.bindings.cs` 的 `MarshalOptions()` 拉全表构 UI，按 id 写回（`SetBoolOption` 等）。
