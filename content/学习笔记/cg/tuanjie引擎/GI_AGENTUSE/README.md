## 2. 30 秒版

TuanjieGI 是团结引擎的**实时全局光照（Real-time Global Illumination）模块**：实时计算间接光的多次反弹。它由两层组成：

- **世界层**：给静态物体表面铺小**面片**，每个面片记录自己的**出射光**（存在一张大图集里）；面片之间每帧互相照射，逐帧迭代收敛出多级反弹。
- **屏幕层**：把屏幕切成 16×16 像素的**采样块**，每块朝半球发 64 条射线，查询命中处的面片出射光，汇总成 9 个**球谐系数**，再摊回 256 个像素。

射线的命中查询按成本分六级：屏幕空间 → 局部精场 → 级联粗场步进 →（有硬件时）内联光追 / 完整光追 → 天空回退。

## 4. 术语表

模块内固定使用的译名与术语（非比喻，是约定）。**先看三义警告**——"quad"在模块里有三个不同含义，最容易踩坑：

| 术语 | 含义 |
|---|---|
| **采样块**（screen quad） | 屏幕上 16×16 像素的方块，屏幕层间接光的最小查询单位，256 像素共享一套 SH 结果 |
| **射线格**（ray grid） | 采样块内的 8×8=64 个方向编号格（`kLightingQuadSize`），每格一条射线——"64 条射线"的来源 |
| **面片光照块**（facet lighting quad） | 面片图集上 8×8 texel 的处理块（直接光/复合的粒度，GILighting/ 用） |
| ⚠️ **三义辨析** | 三者都叫 quad：**像素**（16×16）→ 采样块；**方向**（8×8）→ 射线格；**图集 texel**（8×8）→ 面片光照块。`kLightingQuadSize=8` 服务后两者，`quadInterval=16` 服务第一个 |

其余术语：

| 术语 | 含义 |
|---|---|
| **面片**（facet） | 静态物体表面切出的小块矩形，世界层的最小光照单位；记录颜色、法线、自发光与出射光 |
| **出射光**（outgoing radiance） | 表面向各方向发出的辐射亮度；面片的核心存储量 |
| **出射光图集**（facet radiance atlas） | 4096×4096 大图集，所有面片的出射光（及基础属性）纹理页 |
| **工作台** | 512×512 暂存纹理，本批待更新面片先在这里重录基础属性，再写回图集 |
| **反弹**（bounce） | 光在表面间的一次反射；"多级反弹"= 光多次弹射后的间接光 |
| **直接光** | 从光源直射到达表面的一次光照 |
| **间接光** | 经至少一次反弹到达表面的光 |
| **SH / 球谐**（Spherical Harmonics） | 方向函数的低频压缩表示；本模块用三阶 9 系数（RGB 各 9，共 27 数） |
| **SDF / 有向距离场**（Signed Distance Field） | 空间每点存"到最近表面的有符号距离"，存于 3D 纹理；球体步进的基础 |
| **UDF / 无符号距离场** | 不分内外只有绝对距离的版本；树叶、栅栏等开放表面用它 |
| **级联**（cascade） | 距离场按离相机远近分的多级分辨率层，TuanjieGI 用 4 级 |
| **cluster / 模型索引表** | 粗场每个格子登记其中模型的表格；每格最多登记 4 个模型 |
| **球体步进**（sphere tracing / ray marching） | 按 SDF 读数安全前进的射线求交算法 |
| **命中阈值** | 步进中读数小于它判定命中；"半体素"=当前级联体素尺寸的一半（`worldVoxelSize×0.5`，逐级随体素变粗而放大）；源码事实：阈值 = min(半体素, 沿途最大读数)，受 0.5 硬编码钳制 |
| **Hi-Z** | 深度金字塔（逐级 2×2 取最远），屏幕空间射线步进的安全步长来源 |
| **弯法线**（bent normal） | 逐像素算的"实际可见方向平均"，长度携带可见度；漫反射求值方向 |
| **八面体映射**（octahedral mapping） | 球面方向 ↔ 正方形格子的双射；方向采样与纹理化的标准方案 |
| **重要性采样** | 按上一帧 SH 重建的亮度分布分配本帧射线方向 |
| **流压缩**（stream compaction） | 六级查询中"未命中的射线紧密排队交给下一级"的实现方式 |
| **交错更新**（interleaved update） | 采样块分 16 组每帧只更新一组的节流机制 |
| **历史混合** | 本帧结果与历史按帧数加权的滚动平均；模块共有**三套独立累积**（块级 2–16 / 面片 8 / 像素 8×updateSpeed），对照表见 [01-背景知识/06-时域累积 §7](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/01-背景知识/06-时域累积与重投影.md) |
| **重投影**（reprojection） | 上帧结果按运动矢量搬到本帧位置继续使用 |
| **摊回**（resolve/splat） | 把采样块的 9 个 SH 系数经邻域插值与按瓣求值还原为每个像素的光照 |
| **三判据** | 屏幕距离 / 深度差 / 法线夹角三个高斯权重，滤波与历史匹配共用 |
| **GIOption** | 模块可调参数的类型，`GIOption<T>::Add(默认值, 名字, 注释)`；注释即官方文档 |
| **Oceanus DSL** | 本模块 GPU 程序的写法：C++ 模板元编程生成着色器，见方言册 |
