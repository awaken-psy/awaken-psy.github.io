# 06 历史混合与重投影

> 源文件：`RenderPipeline/ReprojectHistory.h`（像素层）、`GITracing/QuadTraceSH.h`（采样块层：BlendHistoryQuads / SeperableFilter / borrowRadiance）
> 作用：把"多帧平均"从数学变成工程——两个独立的累积系统，一个在采样块级混合 SH 数据，一个在像素级混合最终输出图。
> 前置阅读：[../01-背景知识/06-时域累积与重投影](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/01-背景知识/06-时域累积与重投影.md)（数学基础）

## 1. 两套累积系统总览

| | 采样块级（QuadTraceSH） | 像素级（ReprojectHistory） |
|---|---|---|
| 累积对象 | 每块的射线结果（8×8 方向格亮度） | 最终输出图（diffuse/粗糙镜面/bent normal/帧数） |
| 帧数上限 | 2（下限）～ **16**（上限） | `reprojectionMaxFrames`（默认 8）× updateSpeed，clamp **[1,20]** |
| 相机运动处理 | 采样点每帧块内抖动 → 邻域匹配；`GetQuadFromHistory` 取历史 | 运动矢量重投影（UV 搬移） |
| 触发者 | QuadTraceSH 后处理链 | GIForURP/HDRP `updateView` 第 8 步 |

两者共享同一个数学骨架：**滚动平均**。旧值代表前 n−1 帧的均值，按 $\text{新} = \text{lerp}(\text{旧}, \text{本帧}, 1/\min(n, N_{max}))$ 混入第 n 帧后恰为 n 帧均值——只需存"上一帧结果 + 帧数"两样，不用存帧序列。

## 2. 采样块级：QuadTraceSH 的历史机制

### 2.1 选项（QuadTraceSH.h L166–236，默认值均为源码事实）

| 选项 | 默认 | 含义 |
|---|---|---|
| `blendHistoryQuadsMinFrameCount` | 2.f | 历史混合权重下限（注释 "for fast moving object"） |
| `MaxFrameCount` | 16.f | 累积上限（注释 "for static object"） |
| `historyDist` | 0.01 | 历史可信距离 |
| `borrowFalloff` | 100 | 借用辐射度的衰减率 |
| `enableBlendHistoryQuads` | true | 开关 |
| `enableSeperableFilter` | true | 可分离滤波开关 |
| `intergrateSize`（Integrate 邻域） | 5 | 摊回邻域 5×5 |
| `boxFilterKernelSize` | 5 | 盒滤波核 |
| `integrateDistanceReject` | 100 | 摊回深度拒绝阈值 |

### 2.2 执行顺序（DoExecute 后处理链，L522–549）

```
alignRay → borrowRadiance → SeperableFilter → BoxFilter → BlendHistoryQuads → convertSH(9×3) → IntegrateScreenSpace/Integrate
```

1. **alignRay**（L885–951）：重要性采样后射线方向与 8×8 规整格错位，把每条射线结果按真实方向重新归位：`targetProjection = clamp(floor(mapToSphereOctahedronInverse(dir)×8), 0, 7)`。编码有量化上限 `0xffffffff/(quadSize²)/1000`。
2. **borrowRadiance**（L953–1021）：历史可信度 `historyConfidence = exp(-len/max(historyDist,1e-6))`（历史离本帧采样点越远越不可信）；同平面邻块（`dPlane<0.1 && normalDot>0.95`）可"借"辐射度，空间借用权重 `spatialBorrowWeight = exp(-dLength×borrowFalloff)`；最终 `borrowWeight = (1−historyConfidence)×spatialBorrowWeight`——历史越差、邻块越近，借得越多。
3. **SeperableFilter**（L1317–1408）：可分离两趟滤波；**kernelRadius=14 硬编码**（L1323）；`realSigma = lerp(sigmaRsqr, sigmaRsqrMin, historyFrames)`——**历史越长（越干净）滤波越弱**，新块的噪声靠宽 sigma 压住，干净块不糊；权重定点化 `×65536`。
4. **BoxFilter**：5 核盒滤波。
5. **BlendHistoryQuads2**（L1524–1636；旧版 BlendHistoryQuads 整段 `#if 0` 保留对照）：块级历史混合，`historyBlendFactor = currentFrames/frameCount`，帧数受 §2.1 的 2～16 钳制，`lerp` 混合（L1581–1622）。
6. **convertSH**（L1023–1067）：投影成 9×3 系数——`shInt->project(dir, radiance×importance)`，importance 来自 `GetImportance`（IndirectLightingScene.h：`4π/kLightingQuadSize²`）。
7. **Integrate / IntegrateScreenSpace**：摊回（见 [04-QuadTraceSH主流程](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/04-QuadTraceSH主流程.md)）。

失效条件：物体移动、表面变化 → 帧数清零，从下限 2 重新累积。

## 3. 像素级：ReprojectHistory 完整算法

Dispatch：8×8 组；permutation `enableAccurateHistory`（默认 false，URP/HDRP 接入层显式设 true）、`enableBentNormal`（默认 true，URP 设 false）。

### 3.1 常量（L23–26）

- `depthRejectionThreshold = 0.005f`（快速路径 0.001f）
- `normalRejectionThreshold = 0.5f`
- `framesLimit = maxAccumulatedFrames`（外部传入 = `clamp(round(reprojectionMaxFrames × updateSpeed), 1, 20)`，URP/HDRP .cpp）

### 3.2 流程（行号为 ReprojectHistory.h）

1. **坐标换算**（L34–38）：`BufferCoord = viewportCoord + viewMin`；当前深度/法线读入。
2. **写回下一帧状态**（L40–42）：`nextStates` 写当前 depth 与法线（法线 `0.5n+0.5` 编码）——**这两样只存 1 帧做校验用，不参与累积**。
3. **历史坐标**（L44–51）：`DecodeMotionVector3D` 解出运动矢量；`prevClipPos = (currClipPos, deviceZ) − motionVector×2`；换算 `prevUV` 与预估历史深度 `prevCalculatedEyeDepth`。
4. **离屏拒绝**（L53–56）：历史位置超出视口 → `offScreen`。
5. **准确分支**（`enableAccurateHistory`，L77–149）：
   - 深度阈值按掠射角放大：`threshold /= clamp(dot(V, N), 0.1, 1)`（L79）——掠射时深度差天然大，放宽容忍度；
   - **2×2 gather 双线性**：取 prevUV 四邻（TL/TR/BL/BR），各自算双线性权重 `wX×wY`；
   - **深度校验**（L106）：`|prevEyeDepth − prevCalculatedEyeDepth| ≥ |prevCalculatedEyeDepth| × depthRejectionThreshold` → 拒绝；
   - **法线校验**（L109）：`dot(prevNormal, currNormal) < 0.5` → 拒绝；
   - **置信度**（L112–115）：`prevConfidence = offScreen ? 0 : 1 − max(depthFail, normalFail)`；权重归一化后使用；
   - **帧数更新**（L118–119）：`numFrames = gather_red(prevUV).wzxy() × framesLimit`（注意通道重排对应 gather 象限），`outputNumFrames = dot(min(numFrames, framesLimit), weights) + 1`。
6. **快速分支**（L150–183）：单点采样 + 手动双线性深度，只用深度校验，`framesLimit` 强制 2——速度优先的粗模式。
7. **曝光校正**（L74）：`prev ×= GetInversePreviousExposureMultiplier() / fLightRangeCompressFactor`（URP 下曝光恒 1、压缩因子 1.6384，见 [../05-集成与工程/02-管线接入URP与HDRP](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/05-集成与工程/02-管线接入URP与HDRP.md)）。
8. **混合**（L185–194）：`blendFactor = 1/outputNumFrames`；diffuse/roughSpecular/bentNormal 各自 `lerp(prev, curr, blendFactor)`；负值清零。
9. **写回**（L200–211）：diffuse/specular 乘回压缩因子与当前曝光；**`outputNumFrames 存储时除以 framesLimit`（归一化 0..1，读时乘回）**；bentNormal 直接写。

### 3.3 被累积的量

`outputDiffuse`、`outputRoughSpecular`、`bentNormalBuffer`（仅 `enableBentNormal` 下）、`outputNumFrames`。深度与法线**不累积**（只做 1 帧写回供下帧校验）。

## 4. "三判据"的求值端：WeightMesure 与双边滤波（完整公式）

三判据（屏幕距离/深度/法线）的两半：**数据封装**（QuadGPU 各 `GetWeightMesure*` 方法构造）与**权重合成**（`Math/BilateralFilter.h`）。

### 4.1 数据结构（BilateralFilter.h L16–21）

```cpp
template<typename posVector> struct WeightMesure {
    posVector coord;      // 位置：float2=图集/屏幕像素坐标，或 float3=世界坐标（模板定）
    float viewDepth;      // 视空间深度
    float3 normal;        // 法线
};
```

块中心版的构造（URP/HDRP 一致）：

```cpp
coord     = ScreenJitteredCenter();          // 抖动后的块中心坐标
normal    = GetJitteredCenterWorldNormal();   // 法线（"use world space instead"——URP 注释明确弃用视空间法线）
viewDepth = min(GetJitteredCenterViewSpaceDepth(), referenceFar);   // 被远参考(128)截断的视深
```

### 4.2 权重合成（GetWeight，L31–43——逐行抄录）

```cpp
Float GetWeight(Var<WeightMesure<posVector>> target, Float3 sigmaRsqr)
{
    auto distCenter = target.coord - this->coord;
    auto spatialWeight = exp(dot(distCenter, distCenter) * sigmaRsqr.x);
    auto distDepth = this->viewDepth - target.viewDepth;
    auto depthWeight = exp(distDepth * distDepth * sigmaRsqr.y);
    auto distNormal = 1.0f - dot(this->normal, target.normal);
    auto normalWeight = exp(distNormal * distNormal * sigmaRsqr.z);
    return spatialWeight * depthWeight * normalWeight;
}
```

**三个判据的距离定义与权重**（`this`=中心/历史中心，`target`=邻域）：

| 判据 | 距离定义 | 权重 |
|---|---|---|
| 空间 | `d²=dot(Δcoord,Δcoord)` | `exp(d² × (−0.5/σ_s²))` |
| 深度 | `d=ΔviewDepth` | `exp(d² × (−0.5/σ_d²))` |
| 法线 | `d = 1 − dot(N, N_target)`（即 1−cosθ） | `exp(d² × (−0.5/σ_n²))` |

- `GetSigmaRsqr(s, d, n)` 返回 `(−0.5/σ²)×3`（L10–14）——负号内置于此，`GetWeight` 里直接乘。
- 最终权重 = **三高斯乘积，无归一化除法**（归一化由调用方做）。
- σ 由调用方传入；QuadTraceSH 侧此前核实的默认值：空间 ≈1.5×块尺寸、深度 0.3、法线 1.0。文件内另有一组被注释的参考默认（`kSigmaPixels=4px / kSigmaDepth=0.5m / kSIgmaNormal=0.1`，未启用）；还有 `GetWeightSpatial`（只算空间项的单 σ 版，供预筛用）。
- 旧版世界坐标实现（含 `kDepthThreshold=1` 硬阈值）整段被注释，非现行。

### 4.3 历史匹配与平台差异

- `referenceFar`（128）参与深度判据（视深截断）；`referenceNear`（2）只存在于被注释的旧公式 `min(referenceNear/viewDepth,1)` 中。
- **URP**：`GetWeightMesureHistoryCenter` **normal 置 0**——历史匹配实际只有屏幕距离+深度两判据；`GetWeightMesureCenterWithoutNormal` 同为单/双判据模式；`SubPixelGetViewSpaceNormal` 返回空 + todo。
- **HDRP**：历史中心用**历史世界法线**（三判据齐全）；`GetVirtualWeightMesureHistoryCenter` 保留当前帧法线。
- 面片侧同构版在 `ViewContextFacetLighting` 的 QuadGPU 上（coord 为图集像素坐标，`WeightMesure<float2>`；世界坐标版 `WeightMesure<float3>` 被注释 + todo），见 [../03-世界层/02-面片系统GIFacet](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/03-世界层/02-面片系统GIFacet.md) §9.5。

## 5. 设计要点

- **帧数即可靠度**：所有累积系统共用"帧数越多 → 新帧权重越小（1/n）→ 越平滑但响应越慢"的谱系；失效时清零重来。
- **上限防惯性**：16（块级）/8×updateSpeed（像素级）封顶防止静止场景永远不响应光照变化（拖影、冻结）。
- **下限防噪声**：2 的下限保证清零后新帧至多占 50%，单帧噪声不进画面。
- **校验防错采**：像素级用深度+法线双校验；块级用"历史距离可信度 + 同平面借用"补偿抖动错位。

## 6. 快速问答

**Q：屏幕上看到的 GI 输出经历了几层平均？**
A：至少三层——块内空间滤波（Seperable/Box）、块间历史混合（2–16 帧）、像素级重投影（上限 8×updateSpeed，clamp 20）。噪声按各层帧数/核宽乘性衰减。

**Q：为什么 ReprojectHistory 里 NumFrames 存的是 0..1？**
A：存储带宽考虑：R8_UNorm 单通道存归一化值（`outputNumFrames/framesLimit`），读时 `×framesLimit` 还原——上限会随 updateSpeed 变，归一化存储避免上限变化时数据失配。

**Q："三判据"在哪些地方出现？**
A：块级邻域匹配与摊回权重（屏幕距离/深度/法线三个高斯 σ，见 [04-QuadTraceSH主流程](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/04-QuadTraceSH主流程.md)）；像素级重投影是它的简化版（深度阈值 + 法线点积两个布尔判定）。
