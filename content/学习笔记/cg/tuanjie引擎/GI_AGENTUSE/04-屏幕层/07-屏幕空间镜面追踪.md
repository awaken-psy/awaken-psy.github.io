# 07 屏幕空间镜面追踪（ScreenTraceSpecular）

> 源文件：`GITracing/ScreenTraceSpecular.h/.cpp`、`GITracing/ScreenTracer.h`（步进实现见 [03-六级查询与流压缩](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/03-六级查询与流压缩.md) §3）、`GITracing/SpecularCommon.h/.cpp`（GGX VNDF 采样）
> 作用：给"粗糙镜面"补屏幕空间分量——基于 GGX的重要性采样反射射线 + VNDF 重加权解析 + 时间/空间去噪。它是 SWRTPipeline 里独立于间接光之外的第二条 `IndirectLightingScene`（`specularLightingScene`），复用同一批 tracer。

## 1. 启用与范围

GIOption（默认值全部源码事实）：

- `enableReflection=true`（"Enable TuanjieGI Reflection."）
- tracer 选择：`enableReflectionSDFTrace=false`、`enableReflectionClusterTrace=false`、`enableReflectionCDFTrace=true`；HWRT 平台 `enableReflectionInlineRayTrace=false`、`enableReflectionRayTrace=true`——**反射默认走"屏幕 ① + 级联 ③ + 光追 ⑤"的组合**
- `maxRoughnessToTrace=0.4`（"Max Roughness of pixel reflection."）——粗糙度超过 0.4 的像素不做屏幕镜面追踪（它们的反射交给 QuadTraceSH 的锥角瓣）
- `maxRoughnessToTraceBackfaceDiffuse=0.2`；`enableHitLight/enableSkyLight=true`

## 2. 执行链

```
CountTiles → [tracers 按级 dispatch] → Resolve → TemporalDenoise → SpatialDenoise（非透明通道）
```

- 追踪前 `screenTracer.bSkipFirstTexel2D = 0`、之后复位 1（跳过首 texel 的开关）。
- `spatialFilterNeighborSampleNum ×= reflectionQuality`；`spatialFilterKernelScale ×= (reflectionQuality+1)/2`——`reflectionQuality`（FrameContext，默认 1）直接缩放飞控成本。
- 纹理：`hitRadiance`(B10G11R11)、`hitDistance`(R32_SFloat)、`direction`(R16G16B16A16_SFloat)、`hitDeviceZ`(R32_SFloat)、`resolvedRadiance`/`reprojectedReflection`(B10G11R11)。
- TracerType 同 QuadTraceSH 的 kScreen/kSDF/kCDF/kInlineRay/kRay，`LowestBit/HighestBit` 选首尾级。

## 3. CountTiles：生成反射方向（8×8 tile）

- 粗糙度 < **0.02** → 纯镜面反射 `reflect(cameraVector, worldNormal)`（注释：保证 GGX 的 `a²−1` 数学有效）；
- 否则**蓝噪声 + `SampleGGXVNDF`** 采样 GGX 半向量再反射，pdf clamp `[1e-4, maxPDF=1e5]`；
- 组内 `interlocked_or` 归约 tile 有效性 → 有效 tile 记入 `validTileBuffer`（`interlocked_add` 领号）；
- 输出 `directionTexture`：xyz = 方向，w = pdf。

`SampleGGXVNDF`（SpecularCommon.cpp，注释引 Heitz 2018 JCGT 论文）：半球化视向量→椭球采样→重投影的标准 VNDF 实现；`PDFofGGXVNDF` 用 Smith G1 与 GGX D 项。

### 3.1 traceHit：每 tile 每像素的追踪 kernel（L102–207 逐行核实）

模板 `traceHit<isFirst, isLast, Tracer>`，四个 permutation：`enableHitLight/enableSkyLight/transparencySurface/testRun`（**testRun 已声明但函数体内无使用点——作用未体现，如实记录**）。流程：

1. `tileId = validTileBuffer.read(coord.z)` → `screenCoord = tileId×8 + coord.xy`；
2. 材质读取按 `transparencySurface` permutation 分支（`ReadTransparencyMaterial` / `ReadMaterial`）；
3. `NeedReflection` 门控为真才追踪：射线 `start = worldPos + worldNormal×kRayStartBias`、`maxIteration=50`、`maxDistance = tracer->DefaultTraceMaxDistance()`；
4. **两趟衔接**（宿主 C++ 模板 if，非 DSL）：`!isFirst` 时 `rayStart.start += 方向 × hitDistanceTexture.read(screenCoord)`——第二趟从上一趟命中点续追；
5. 命中：`$permutation_if("enableHitLight")` → `radiance = hitRadiance`（否则置 0）；**未命中**：`bTerminate=false`，且**仅 `isLast` 趟**补天光（`enableSkyLight` → `GetSkyLightReflection(dir, 0)×skylightingFactor`）——**中间趟 miss 只标记继续，不补天**；
6. `hitRadianceTexture.write` 恒写；`hitDistanceTexture` **仅 isFirst 趟写**（注释 "hack: works only for 1/2 tracing pass"）；
7. `NeedReflection` 为假：仅 isFirst 趟写 `(0,0,0)` 与 `hitDistance=-1`（第二趟不碰，防误用）。

**tracer 链的连接**（L418–450）：`lowestBit/highestBit` 决定首尾；**只有链上第一个 tracer 的趟 isFirst=true（写 hitDistance）、最后一个 isLast=true（miss 补天）**。执行序：kScreen 先跑（前后置 `bSkipFirstTexel2D` 0→1）→ SDF/cluster 二选一（`enableReflectionClusterTrace`）→ kCDF →（HWRT）kInlineRay/kRay。

## 4. Resolve：VNDF 重加权解析（16 邻域）

屏幕上相邻像素的反射射线命中点，其实都是"这个像素的反射瓣"的合法样本——把邻域命中**重新按本像素的 GGX PDF 加权**，等于免费多变体采样：

1. `alpha = roughness²`；核直径 `kernelScale × lerp(minRadius, maxRadius, saturate(roughness×8))`；
2. 16 个邻域偏移 = `HammerSley(i, 16, GenerateHashedRandomFloat(...)) − 0.5`，乘核直径；
3. 邻域命中点重建：`neighborHitPos = neighborWorldPos + neighborDir × min(neighborDistance, centerHitDistance)`；
4. **重加权**：`tangentH = mul(TBN, normalize(V + dirToNeighborHit))`；`newPDF = min(PDFofGGXVNDF(tangentV, tangentH, alpha), pdf)`；`cosine = dot(dirToNeighborHit, N)`；只有 `newPDF>0 && cosine>0` 计入；
5. `resolved = Σ neighborRadiance×max(newPDF,1e-6)`，归一化除 `max(totalWeight, minResolveClampedWeight=1e3)`；
6. 输出 `hitDeviceZ`（命中深度转 DeviceZ）。

二次追踪：非首 pass 的起点沿上次 `hitDistance` 偏移再追一次（源码注释 "hack: this works only for 1/2 tracing pass"）。

## 5. TemporalDenoise：时间去噪

1. 读 Resolve 结果，乘回压缩因子与当前曝光；
2. **双源历史**：(a) 用**命中深度**投影的历史位置取色；(b) 用**当前像素深度**投影的历史位置取色——两条历史路径各取一份。
   **历史取色经 `ReflectionHistoryColorAndCount`**（ViewContext 提供）：HDRP 版已实现——**dissoclusion 权重 = `exp(−|1−max(0,dot(N, 历史N))|×1.4) × exp(−|历史深度−当前深度|/当前深度)`**，全部四邻 >0.9 取均值、部分 >0.9 取最大池坐标；**URP 版函数体被注释、恒返回 0**——即**命中深度历史源在 URP 上是死路**，双源混合实际只剩像素深度一路（[../05-集成与工程/02-管线接入URP与HDRP](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/05-集成与工程/02-管线接入URP与HDRP.md) §5）；
3. **8 邻域方差裁剪**（硬编码 8 偏移，Welford 增量法算均值/方差，只计 `hitDistance≥0` 的有效邻居）→ neighborhoodMin/Max；
4. **双源混合**：每条历史的权重 = `saturate(exp2(−exposure×luminance(历史−邻域均值)))`——亮度离群的历史被压权；两源加权平均并 clamp 到邻域 min/max；
5. **累积上限随位置变化**：`vignette = pow(15×|uv.x×uv.y|, 0.25)`，`maxSampleCount = max(reprojectMaxFrame(16)×vignette, 1)`——**屏幕中心累积多、边缘累积少**（边缘历史不可靠）；
6. **颜色压缩**：累加后做 reinhard 风格压/解变换（`c/(1+c)` 存、读回 `c/max(1−c,1e-4)`），稳住 HDR 亮度。

## 6. SpatialDenoise：空间去噪

- 核直径同 Resolve 的粗糙度缩放；
- 邻域权重 = **平面权重**（`1−saturate(|dot(N, Δpos)|/depth−near−far)`）× **高斯权重**（`exp(−offset²)`，注释 "TODO: parameter"）；
- 输出写 `GetReflectionSpecularRT()`（`outputReflectionSpecular`），随后由接入层的 `CompositeSpecularTextures` 按 `blendFactor = saturate((maxRoughnessToTrace−roughness)×10)` 与 GI 粗糙镜面合成（见 [../05-集成与工程/02-管线接入URP与HDRP](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/05-集成与工程/02-管线接入URP与HDRP.md) §2.2）。

## 7. 与 QuadTraceSH 粗糙镜面的分工

| | QuadTraceSH 的锥角瓣 | ScreenTraceSpecular |
|---|---|---|
| 光源 | SH 系数（块级，含间接反弹） | 屏幕命中处上一帧颜色（全光照） |
| 适用 | 全部粗糙度（`maxRoughnessToTrace` 之上也兜底） | 粗糙度 ≤ 0.4 的较光滑表面 |
| 成本 | 极低（9 系数求值） | 一次射线 + 三步去噪 |
| 互补 | 提供反弹光 | 提供屏幕内清晰反射细节 |

`NeedReflection` 为假的像素两条链都直写 0；合成时按粗糙度在两者间过渡。

## 8. 快速问答

**Q：为什么反射默认不走 ②级（SDF/cluster）？**
A：`enableReflectionSDFTrace/ClusterTrace` 默认 false——反射射线是长程的，短程级贡献小还多一级压缩开销；默认组合"屏幕→级联→光追"覆盖远距离命中。

**Q：VNDF 重加权为什么有效？**
A：邻域像素的反射瓣在本像素的 GGX 分布下有非零概率——把它们当作本像素的额外采样并按"本像素 PDF/邻域 PDF"重加权，是无偏的重要性重采样；16 邻域等价 16× 样本量。

**Q：时间累积上限为什么中心高边缘低？**
A：屏幕边缘的像素更容易"移出画面"导致历史失配——vignette（`pow(15|xy|,0.25)`）压低边缘的 maxSampleCount，让边缘历史快速过期，代价是边缘稍噪。
