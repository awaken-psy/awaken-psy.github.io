# 07 实时 GI 技术谱系（TuanjieGI 的定位）

> 背景册。回答"TuanjieGI 和 XX 方案什么关系"这类问题时的事实与对照基础。

## 1. 方案谱系

| 方案 | 原理 | 优点 | 硬伤 |
|---|---|---|---|
| **离线路径追踪** | 对渲染方程蒙特卡洛积分，每像素几十~上千样本 | 物理正确，任意反弹 | 分钟~小时级，非实时 |
| **烘焙 GI（Lightmap）** | 离线算好每 texel 的入射光，存纹理 | 质量高、运行时几乎零成本 | 灯光/几何一动全部作废；内存大；动态物体不受光 |
| **Light Probe 网格** | 空间撒探针，每探针存 SH 辐照度；物体在探针间插值 | 支持移动物体；更新可以增量 | 分辨率粗（墙角级）；连一反弹都难支持；探针摆放是人工活 |
| **SSGI（屏幕空间）** | 从当前画面深度/颜色推断反弹 | 全自动、无资产、动态 | 屏幕外全瞎；漏光/糊边；离屏物体不受间接光 |
| **DDGI / 探针类实时 GI** | 探针每帧发射线重建 SH，加可见性深度缓冲防漏光 | 支持动态几何与灯光 | 探针密度与成本挂钩；漏光处理复杂 |
| **表面缓存 + 屏幕采集**（本世代主流实时 GI 的共同形态） | 世界层缓存一份表面光照场，屏幕层在画面上采集合成 | 静态世界下多反弹收敛、动态灯光即时响应 | 静态假设；低频 SH 的清晰度上限 |

## 2. TuanjieGI 在谱系上的位置

TuanjieGI 是最后一行的形态，两个成分各有出处：

- **世界层 = 逐帧迭代的辐射度法**。面片即辐射度方程的面元；每帧每面片算 $L_o = \rho \times (E_{直接} + E_{间接}) + L_{自发光}$，间接读别的面片**上一帧**的出射光——这是把大型线性方程组的求解拆成逐帧的 Jacobi 式迭代（数学见 [01-全局光照基础](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/01-背景知识/01-全局光照基础.md) §4）。以"面片纹理"存表面光场、射线查形状因子的做法，与烘焙管线里的 radiosity/最终采集同宗，但把"离线解一次"变成"在线每帧推进"。
- **屏幕层 = 表面光场上的实时采集**。采样块 64 射线读命中面片的出射光、SH 压缩、邻域/历史滤波——把世界层缓存"用进画面"的最后一步。屏幕空间查询①级用上一帧颜色近似"多一反弹"，是屏幕空间方案的借用。

与"两个传统方案"的互补关系（源码级证据）：

- 烘焙 GI 不能动态 → TuanjieGI 的直接光每帧入账、间接逐帧推进（`GILighting/`、finalLighting 两 pass）；
- Light Probe 粗 → 面片是"贴在表面上的探针"，密度跟表面走（8²~64² texel/面片），墙角分辨率由面片密度保证；
- SSGI 屏幕外全瞎 → 射线主要答案来自世界层（③级级联/⑤级光追 + 面片取色），①级只是最便宜的近似层。

## 3. 它不做什么（读代码前先校准预期）

1. **不做锐利镜面反射**：粗糙镜面走 SH 锥角瓣（锥角 = π/2×粗糙度），清晰反射交给 `ScreenTraceSpecular`（≤0.4 粗糙度）与 SSR 类系统。
2. **不做动态几何的完整反弹**：面片与距离场是资产（离线生成）；动态物体的间接光只被屏幕层部分处理（动态物体本身不被面片覆盖，只作为遮挡/贡献出现在屏幕空间与 Hi-Z 数据里）。静态物体被移动时由 TransformTracker 触发重算（正确性兜底，非实时增量）。
3. **不做路径级噪声参考解**：多反弹靠逐帧收敛，单帧是近似——移动/剧变场景有明确的响应延迟（交错更新最坏 16 帧）。
4. **平台边界**：`TuanjieGISupportedRHI = d3d11|vulkan|metal`（GlobalConfig.h）——需要 3D 纹理与通用计算；GLES/WebGL 不在范围（微信小游戏 `GetEnabled()` 直接 false）。

## 4. 概念对照表（跨方案术语）

| 通用概念 | TuanjieGI 内部名 |
|---|---|
| 探针 / irradiance sample | **面片**（facet）与它的 texel |
| 探针的 SH 辐照度 | 面片 `IndIrradiance`（texel 级）与 `GIRadianceCacheSH`（块级 48 float） |
| 表面缓存 | **persistent atlas**（4096²）各图层 |
| 采集/最终聚集 | 屏幕层采样块 64 射线 + SH 投影 + 摊回 |
| 可见性缓冲防漏光 | cluster 索引表 + 命中阈值 + bent normal（像素级） |
| 时域累积 | 三套帧数加权（块 2–16 / 面片 8 / 像素 8×speed） |
| 距离场追踪 | 精场/级联两级 SDF + 球体步进 |
| 硬件回退/升级 | ④⑤ 级替换 ②③（换几何不换光照数据） |

## 5. 快速自检

- "TuanjieGI 是探针方案吗？" —— 是面片方案：探针贴在表面上（密度随表面走），不是空间网格。
- "和 DDGI 最大的区别？" —— DDGI 探针发真射线（通常光追）每帧全量重建；TuanjieGI 面片每帧只动"轮到的少数"（优先级调度）+ 历史混合渐进收敛——成本模型不同（增量 vs 全量）。
- "为什么说它是'辐射度法'？" —— 面片两两间的能量传输用射线查询近似形状因子、逐帧 Jacobi 迭代，数学结构同辐射度方程组。
