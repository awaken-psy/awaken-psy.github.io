# 03 八面体映射与方向采样

> TuanjieGI 里"方向"怎么被编号、射线方向怎么均匀铺开、误差怎么打散。读射线发射/重要性采样相关代码前必读。

## 1. 为什么需要方向 ↔ 平面的映射

GPU 纹理是 2D 的，很多任务需要把**球面方向**存进方格：方向函数的采样格、按方向查环境光、把 64 条射线的结果按方向归档。经纬度映射（lat/long）在两极把格子挤成一团、近极格子立体角远大于赤道格子——不均匀。**八面体映射（octahedral mapping）**是标准替代方案。

## 2. 原理与代码

把每个单位方向向量先"交"到正八面体表面（各分量绝对值归一），再沿棱线把八面体展开成一个正方形。球面方向 ↔ 方形格子构成**连续双射**：

```hlsl
vec2 float32x3_to_oct(in vec3 v) {
    // 投影到八面体，再压到 xy 平面
    vec2 p = v.xy * (1.0 / (abs(v.x) + abs(v.y) + abs(v.z)));
    // 下半球的褶皱沿对角线翻折过来
    return (v.z <= 0.0) ? ((1.0 - abs(p.yx)) * signNotZero(p)) : p;
}

vec3 oct_to_float32x3(vec2 e) {
    vec3 v = vec3(e.xy, 1.0 - abs(e.x) - abs(e.y));
    v.xy = (v.z < 0) ? (1.0 - abs(v.yx)) * signNotZero(v.xy) : v.xy;
    return normalize(v);
}
```

（出处：模块数学基础，与业界通用实现一致。）

三个关键性质：

1. **双射**：每个方向对应唯一格子，解码精确无死角；
2. **近似等面积**：每格覆盖的立体角几乎相等——均匀格 = 均匀方向采样，每条射线权重相同；
3. **半球版**：先把方向转到"法线朝上"的局部坐标系再展开上半球，格子全部落在有效方向上。

## 3. 方向格：8×8

TuanjieGI 屏幕层每采样块朝半球发 64 条射线，方向按八面体网格铺成 **8×8 格**：每格一个方向，64 格 64 条。射线结果也按方向归回这 8×8 格（归位步骤，见 [../04-屏幕层/04-QuadTraceSH主流程](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/04-屏幕层/04-QuadTraceSH主流程.md)）。

## 4. 抖动（jitter）：把规律误差打散成均匀噪声

固定网格的代价是**周期性误差**——误差呈规律排列，人眼对规律排列极其敏感（波纹、格子印）。解法：给每个采样块、每个方向格加一点**每帧不同的微小偏移**。偏移被邻域滤波与多帧累积平均后趋于零。这与 TAA 的亚像素抖动是同一个思路：牺牲瞬时严格正确，换统计上的长期正确。

模块源码事实：抖动值来自**蓝噪声**（BlueNoise，`Math/BlueNoise.h`，`ViewContextURP::GetJitter` 用 `blueNoise->Sample2D(quadCoord, frameNumber, channel=2)`）；quad 级备用的 `GetQuadJitter` 用 `frameNumber % 8` 循环的 8 个确定位置（`x = frac(idx/8)`，`y = reversebits(idx)>>16 / 65536`）。

### 4.1 为什么用蓝噪声不是白噪声

误差的**分布形态**决定观感：白噪声的误差成堆分布；**蓝噪声把误差在相邻位置均匀交错**。人眼对低频误差团敏感、对高频细噪宽容——蓝噪声把误差全部推到高频段，恰好避开人眼敏感区。

## 5. 重要性采样：按上一帧亮度派射线

均匀 64 格对"光只从少数方向来"的场景浪费配额。**重要性采样**：已知哪些方向可能有光，就把采样配额优先分给它们。TuanjieGI 的做法——**用上一帧结果指导这一帧**：上一帧该块的 9 个 SH 系数能重建出"哪个方向亮"，这一帧按亮度比例分配 64 条射线的方向。

两个工程约束：

1. **加权校正**：非均匀采样后求和须按实际立体角加权，否则统计偏色；
2. **只引导不取值**：上一帧结果只用于引导方向分配，不直接当结果——光照剧变时不产生滞后。

## 6. 快速自检

- "8×8 方向格是 64 条射线吗？" —— 是；每格对应一条射线方向（重要性采样会重分配，结果仍按真实方向归回格中）。
- "抖动的偏移多大？" —— 亚像素/格子内量级，蓝噪声采样值映射到块内偏移；每帧换、每块不同。
- "为什么不用立方体映射？" —— 立方体 6 面存储浪费且有接缝；八面体单平面、等面积、双射，逆运算精确。
