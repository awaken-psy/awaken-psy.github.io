# 01 世界层总体架构与更新流程

> 世界层 = "整个世界各自在发多少光"。四个运行时子系统 + 一个离线生成器，本文给全景与帧内协作；细节见各分册。
> 前置阅读：[00-系统总览](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/00-系统总览.md) §2（数据流图）

## 2. 一帧的更新链

```
帧事件驱动（TuanjieGIManager 三段事件，见 ../05-集成与工程/01-TuanjieGIManager与帧调度.md）
  ├─ GISDFScene::UpdateFrame
  │     增删改消费 → AllocLOD/FreeLOD（LOD 反馈环）→ 三类缓冲 ApplyDiff
  │     → onSDFSceneFrameUpdate.Emit(fctx)
  │           └─ GICascadedSDF::UpdateFrame
  │                 每相机 views[camera].Update：
  │                 级联半径翻倍递推 → 相机砖格吸附 → 新进入边带 dirty
  │                 → kernel 链：Filter → ValidateActiveBricks(砖分配/pending释放)
  │                             → WriteCascadeSDF(距离重采样+ClusterBuffer填充)
  └─ GIFacetScene::UpdateFrame（FacetSceneWithLighting）
        UpdateMeshRenderers（7 步：可见性 Job → 候选优先队列 → 图集分配 → 上传）
        ├─ [有 rasterizeRequests] RasterizeFacets：工作台重录属性 → 压缩搬回 persistent
        └─ [有 lightingRequests] LightingFacets：
              清零 DirectLighting → 直接光入账（DirectDiffuse/Directional）
              → persistent→工作台 回搬三个光照图层
              → 复合 pass1（历史 Radiosity 供射线取色）→ 发间接射线（复用六级 tracer）
              → 复合 pass2（finalLighting：混入本帧间接、写 Radiosity）→ 写回 persistent
```

**每帧推进一反弹**的机理就在最后一步：pass2 复合时"间接辐照度"的来源 = 本帧射线命中的**别的面片上一帧 Radiosity**（`indirectHistoryEnable` 开历史混合收敛到无限反弹）。

## 3. 世界层与屏幕层的解耦点

1. **无相机概念**（除级联以相机为中心组织数据）：图集与光照更新不依赖任何特定相机；级联每相机一份 view，图集只有一份。
2. **数据接口**：屏幕层/面片间射线消费的是 `persistentAtlasLayers.Radiosity`（面片取色 accessor：`GIRadiosityVisitor/GIIndIrradianceVisitor/GIRadianceCacheSH`）与 `sdfMeshRenderesRenderingDataBuffer.facetMeshRendererID`（SDF 命中→面片）。
3. **不同步**：屏幕层读到的是"本帧开始时"的图集；面片间接光的输入里有上一帧屏幕画面——松弛设计，逐帧收敛（[../01-背景知识/01-全局光照基础](学习笔记/cg/tuanjie引擎/GI_AGENTUSE/01-背景知识/01-全局光照基础.md) §4）。

## 4. 面片侧的帧数与累积

面片累积上限 **8 帧**（`maxFramesAccumlated=8`，GIFacetInclude.h:27）——新间接样本权重固定 1/8。与屏幕侧的两个累积系统（块级 2–16、像素级 8×updateSpeed）互不相干，是**第三套**帧数加权。

## 5. 快速问答

**Q：世界层每帧的全部 GPU 成本在哪？**
A：级联 kernel 链（过滤+砖分配+距离重采样，增量式）+ 面片工作台光栅化（≤`facetRasterizeFrameCount` 个面片）+ 直接光入账 + 间接射线（每光照块 1 条）+ 两次复合。全部按 dirty/优先级节流——静止场景每帧只动"没跟上"的部分。

**Q：为什么级联挂在 sdfScene 的更新事件上？**
A：级联是精场的重采样聚合——精场登记/LOD/位置变了，粗场对应区域就该重建。`dirtyRegionBuffer`（3 个 dummy 头 + 区域列表）就是两系统间的增量协议。
