# 03 - 软阴影与阴影工程

> 阅读时间：约 35 分钟
> 关键词：PCF、PCSS、半影、过滤、阴影质量预算

## 你将学到什么

- 为什么真实阴影有"软"的边缘（物理）
- PCF：用过滤把二值变柔和
- PCSS：让"离物体越远影越糊"成立（可变半影）
- 阴影质量的完整工程清单（距离、LOD、分辨率、性能预算）

---

## 1. 真实阴影不是二值的

物理真相：**光源有面积**（太阳其实有 0.5° 的角直径、灯泡有钨丝）。于是物体边缘的影子不是"0/1 突变"，而是三段：

```
── 完全受光 ──┤半影（渐变）├── 全影（本影）──
```

**半影宽度与几何关系**：

$$
w_{penumbra} \approx d_{occluder \to receiver} \cdot \frac{\text{光源直径}}{\text{光源到遮挡物距离}}
$$

离物体近的影子边缘利落；离物体越远、影子越糊（树梢在地面上的影子比树根糊得多）。**"距离越远越糊"是阴影可信度的最大视觉线索**——硬边阴影（无 PCF）最大的"假"感不来自锯齿而来自"到处一样硬"。

## 2. PCF：百分比渐近过滤

第02章知道采样 Shadow Map 会得到锯齿边。**PCF（Percentage-Closer Filtering）** 的思路：不止比较一次——**在采样点周围取 N×N 次比较，把"过/不过"的结果平均**：

$$
\text{shadow} = \frac{1}{N^2} \sum_{i,j} \text{cmp}\big(z_P,\ z_{map}[uv + \delta_{ij}]\big)
$$

注意它**平均的是比较结果（0/1）而非深度**——深度平均没有物理意义（把"墙前墙后"平均毫无意义），这正是 PCF 名字的由来（对"是否通过"做百分比）。

效果：边缘从锯齿变成柔和渐变（2×2 硬件版甚至免费——硬件 PCF）。**但 PCF 的核宽是常量**——全场景半影宽度一样，"远处更糊"的物理直觉仍然缺失。

> 引擎的"阴影软化等级"（Soft/Hard Shadows）就是 PCF 核大小：1×1（硬）到 5×5/9 次泊松采样（URP 的 soft2x/3x…）。

## 3. PCSS：距离驱动的可变半影

**PCSS（Percentage-Closer Soft Shadows）** 在 PCF 前加一步：**先估计"遮挡物离我多远"**，用它动态决定核宽：

1. **Blocker Search**：在较大范围采几针，找"真挡住我的平均深度" $\bar{z}_{blocker}$（估计遮挡距离）；
2. **核宽计算**：

$$
w_{\text{sample}} = w_{\text{light}} \cdot \frac{z_{receiver} - \bar{z}_{blocker}}{\bar{z}_{blocker}}
$$

3. **PCF**：按 $w_{\text{sample}}$ 过滤。

近处（$\bar z$ 接近 receiver）→ 核小 → 边硬；远处 → 核大 → 边糊。**物理直觉完整落地**。代价：blocker search 是额外的多次采样——PCSS 比 PCF 贵 1.5~2 倍，PC 管线可用，移动端常用简化（固定中等核）。

> 工程事实：URP 的 `Soft Shadows` 开关目前是 PCF/优化版；HDRP/PC 高配走 PCSS 类方案。团结/Unity 内置管线质量档位同样对应核大小。

## 4. 阴影工程总清单

把三篇拼成"阴影质量-性能"的实践手册：

### 4.1 参数的优先级（调优顺序）

1. **阴影距离**：覆盖多远？开放世界 100~150m，中型场景 40~80m。**先定这个，一切预算从它出发**；
2. **级联数与切点**：玩家最在意 0~20m（角色脚下与近景交互）——保证 0 级细密；远处可 1~2 级糊盖；
3. **每级分辨率**：0 级 ≥1024 是底线；远级 512 常够；
4. **Bias/Normal Offset**：先修 acne（第01篇的顺序），再审"接触硬感"；
5. **软阴影等级**：最后才动它（视觉锦上添花，性能贵的最后加）。

### 4.2 阴影的常见视觉病与速查

| 症状 | 第一嫌疑人 |
|---|---|
| 表面条纹自阴影 | depth bias 不足 / normal offset 未调 |
| 物体脚下阴影"脱开"（悬浮感） | bias 过大 → 降 bias，改用 normal offset |
| 相机移动时阴影沙沙抖 | texel snapping 缺失 / bias 太小 |
| 远处阴影块状 | 级联太粗 → 调分割或提高远级分辨率 / 拉近阴影距离 |
| 切级联处断层 | 级联混合未开 |
| 半透明物体"不投影" | 引擎标准阴影不处理半透明（正确做法：熔岩/雾不投；玻璃投"淡影"需自定义 ShadowCaster 半透版本） |
| 阴影里"额外有一条高光" | 受影材质的法线问题，或 acne 的 mipmap 采样版（SHADOW 纹理过滤应 POINT——trilinear 采深度会引入假值） |

### 4.3 预算的"三个控制器"

从贵到便宜：
1. **每帧灯的投影开关**（实时动态点光投影是奢侈品：每灯一整套 CSM/立方）；
2. **Cast Shadows 的物体面积**（编辑器统计：Shadow Casters 数量）；
3. **级联数 × 分辨率**（GPU 带宽与 FBO 尺寸）。

> 💡 **与后处理的配合**：真实半影的远处糊影由 PCSS 承担一部分；地面纹理噪点比阴影锯齿更显眼时，先修材质（第04章法线贴图质量），阴影参数是最后调的。

## 小结

- 物理阴影有三段（受光/半影/本影），半影宽 ∝ 遮挡距离×光源尺寸；
- PCF 平均"比较结果"，常量核宽——锯齿变柔但物理不完整；
- PCSS 用 blocker search 动态核宽——"越远越糊"成立，代价约 ×2；
- 调优顺序：距离 → 级联 → 分辨率 → bias → 软化等级；
- 三大预算器：灯投影数 > 投影物体数 > 级联×分辨率。
