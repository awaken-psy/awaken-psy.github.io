# 04 - 接触阴影与替代方案

> 阅读时间：约 30 分钟
> 关键词：Contact Shadow、胶囊体阴影、SSDO/屏幕空间、体积阴影、阴影伪装

## 你将学到什么

- Shadow Map 的固有短板（小物体、接触细节、大场景）
- 接触阴影（Contact Shadows）：屏幕空间短程光步进
- 胶囊体阴影：给角色/植被的"软长影"
- 面包屑式替代品与"阴影伪装"的设计智慧

---

## 1. Shadow Map 系统的三个盲区

级联+PCF 已是标准答案，但有三个固有盲区：

1. **接触细节丢失**：级联 0 纹素约 1cm，但角色脚边 5cm 的小台阶阴影、道具贴地缝的阴影，受 bias 与分辨率夹击，始终"接不上"—— peter-panning 与 acne 之间的窄缝里挤着的正是**视觉最重要的接触阴影**；
2. **大场景的分辨率死角**：中远级联糊掉后，"柱子脚下那圈影"消失——但玩家最常看的就是建筑底部；
3. **动态小光的成本**：实时点光全方向投影太贵 → 干脆没影 → "这盏灯照着角色却没影子"立刻假。

对应三族的替代技术（团结/Unity 内置与前两者、URP/HDRP 各有对应实现）。

## 2. 接触阴影：屏幕空间短程光步进

**思想**：接触阴影的本质是"**离接收面极近的遮挡**"。那就不用整张 Shadow Map——**直接在屏幕空间，从每个像素沿光方向在深度图上步进一小段**：

```hlsl
// 概念伪码（HDRP Contact Shadows / URP 同名技术）
for (s = 0; s < stepCount; s++) {
    sampleDepth = depthTex[screenPos + lightDir.xy * s * step]
    if (sampleDepth < myDepth - epsilon)   // 前方有东西更近
        occlusion += falloff(s)             // 越远的遮挡贡献越小
}
```

特点速记：

- **短程专用**：步进只走 20~50cm 的世界距离，专治"脚边接触缝"；
- **无视 Shadow Map 分辨率**：它在**屏幕像素精度**上工作——级联再糊，接触影照样锐利；
- **成本与屏幕分辨率挂钩**、与场景大小无关——这个"恒定费"很适合预算；
- 局限：被屏幕外裁掉的遮挡、深度图分辨率限制的细节（第02章 `_CameraDepthTexture` 的能力边界）。

**URP/HDRP 里它常作为"级联阴影的前 1~2 级替代"**：近处用 Contact Shadow 恒费补接触、级联从稍远处开始——两全。

## 3. 胶囊体阴影：给"柱状遮挡物"的解析软影

**思想**：有些遮挡物可以**用形状（胶囊/球）解析近似**——角色四肢、树干、植被。从每个接收点向光源方向**做线段最近距离计算**，距离越近越暗：

$$
S(\mathbf{p}) = \max(0, \; 1 - \frac{d(\mathbf{p}, \text{capsule})}{r_{soft}}) \cdot \text{intensity}
$$

特点：

- **无 Shadow Map、无采样**——纯解析计算，极便宜（几个胶囊 × 若干像素）；
- 天生"软"（半径 = 半影宽度）且物理方向正确；
- 局限：只能投"近似胶囊的物体"（角色骨盆以下、树干）；不适合复杂几何。

**典型场景**：主机游戏的角色阴影（HDRP 的 capsule shadows）、植被主干的"贴地软长影"（与远处级联互补）。**角色在级联糊区没有影 → 胶囊补一条 → 视觉完整度瞬间回来**。

## 4. 屏幕空间与体积阴影补丁族

- **SSAO/SSDO**：环境光遮蔽（第10章 GI 里会讲它作为"环境接触暗部"）；不是定向阴影但**显著强化接触可信度**——两者叠加是标配；
- **体积阴影/单散射近似**：有体积介质（雾、尘、水）时光线穿介质散射，产生"光柱间暗纹"（god ray 里夹着的影锥）。实时方案是在体积 Pass 里采 Shadow Map 判断"这段介质在不在影内"（HDRP 的 volumetric fog integrated shadows，第10章体积渲染篇）；
- **贴花/平面阴影**：把"角色的假影"烘成一张贴花贴地上——2D 游戏/手游角色的标准省钱术；跳跃的影子=贴花位置跟随（无任何 GPU 阴影成本）。

## 5. "阴影伪装"的设计智慧

实时渲染的铁律之一：**不是每个"看起来像影子的东西"都要用阴影系统做**。一个成熟团队的工具箱分层：

| 层 | 技术 | 用在 |
|---|---|---|
| 真影 | 级联 Shadow Map + PCF/PCSS | 太阳/主光的形体影 |
| 补影 | Contact Shadow / 胶囊 | 接触缝、角色近景 |
| 烘影 | 烘焙阴影/ShadowMask（第10章） | 静态场景、远处 |
| 伪影 | 贴花暗斑、blob shadow | 移动端角色、2D |
| 氛围 | SSAO、暗部调色 | 全局接触感 |

**预算哲学**：把 80% 阴影预算给玩家 20% 时间盯着看的区域（脚下 10 米），剩下的用"伪装"混过去——这与级联思想同源：**分辨率分配跟着注意力走**。

> 📁 **源码指引**：URP 的 Contact Shadows 在 `Packages/com.unity.render-pipelines.universal/Runtime/`（ScreenSpaceShadows 相关 Pass）；胶囊体阴影在 HDRP 包内；烘焙/ShadowMask 管线在第10章展开（`Runtime/Graphics/LightmapSettings.cpp` 侧的管理）。

## 小结

- Shadow Map 三盲区：接触细节、大场景底部、动态点光；
- Contact Shadow = 屏幕空间短程光步进，恒定费、抗糊级联；
- 胶囊体 = 解析软影，角色/植被补影神器；
- SSAO 补氛围、贴花做伪影——按注意力分配预算；
- 分层用影：真影补影烘影伪影氛围，五层混搭才是工程答案。
