# 07 设备信息查询

> 通过 `cudaGetDeviceProperties` 和 `cudaDeviceGetAttribute` 查询 GPU 硬件信息。CUDA 13 移除了 `cudaDeviceProp` 中的部分字段，需改用 `cudaDeviceGetAttribute`。
> 关联：[[学习笔记/cg/cuda/cuda_freshman/03-显存分配与浮点误差.md|03 显存分配与浮点误差]]

---

## 1. 两套查询 API

CUDA 提供两种方式查询设备属性：

### 方式一：`cudaGetDeviceProperties` — 一次性获取全部

```cpp
cudaDeviceProp deviceProp;
cudaGetDeviceProperties(&deviceProp, dev);
// 之后通过 deviceProp.xxx 读取各字段
```

一次调用拿到一个结构体，包含几十个字段，适合批量获取。

### 方式二：`cudaDeviceGetAttribute` — 逐个查询

```cpp
int value;
cudaDeviceGetAttribute(&value, attribute_enum, dev);
```

按需查询单个属性，是 CUDA 推荐的方式。

> [!tip] 实践建议
> 两者可以混用：`cudaGetDeviceProperties` 批量拿大部分属性，`cudaDeviceGetAttribute` 补充结构体中没有的属性（如核心频率、显存频率）。

---

## 2. 常用设备属性 API 对照表

| 属性 | `cudaDeviceProp` 字段 | `cudaDeviceGetAttribute` 枚举 | 说明 |
|---|---|---|---|
| 设备名称 | `deviceProp.name` | `cudaDevAttrName` | GPU 型号名 |
| 计算能力 | `deviceProp.major` / `deviceProp.minor` | `cudaDevAttrComputeCapabilityMajor` / `cudaDevAttrComputeCapabilityMinor` | sm_XX 的主次版本号 |
| 全局显存 | `deviceProp.totalGlobalMem` | `cudaDevAttrTotalGlobalMem` | 总显存（字节） |
| GPU 核心频率 | — | `cudaDevAttrClockRate` | kHz |
| 显存频率 | — | `cudaDevAttrMemoryClockRate` | kHz |
| 内存总线宽度 | `deviceProp.memoryBusWidth` | `cudaDevAttrMemoryBusWidth` | bits |
| L2 缓存 | `deviceProp.l2CacheSize` | `cudaDevAttrL2CacheSize` | bytes |
| 常量内存 | `deviceProp.totalConstMem` | `cudaDevAttrTotalConstantMemory` | bytes |
| 每 Block 共享内存 | `deviceProp.sharedMemPerBlock` | `cudaDevAttrMaxSharedMemoryPerBlock` | bytes |
| 每 Block 寄存器数 | `deviceProp.regsPerBlock` | `cudaDevAttrRegistersPerBlock` | 个 |
| Warp 大小 | `deviceProp.warpSize` | `cudaDevAttrWarpSize` | 通常 32 |
| 每 SM 最大线程数 | `deviceProp.maxThreadsPerMultiProcessor` | `cudaDevAttrMaxThreadsPerMultiProcessor` | 个 |
| 每 Block 最大线程数 | `deviceProp.maxThreadsPerBlock` | `cudaDevAttrMaxThreadsPerBlock` | 通常 1024 |
| Block 最大维度 | `deviceProp.maxThreadsDim[3]` | `cudaDevAttrMaxBlockDimX/Y/Z` | x, y, z |
| Grid 最大维度 | `deviceProp.maxGridSize[3]` | `cudaDevAttrMaxGridDimX/Y/Z` | x, y, z |
| SM 数量 | `deviceProp.multiProcessorCount` | `cudaDevAttrMultiProcessorCount` | 个 |
| 内存对齐宽度 | `deviceProp.memPitch` | `cudaDevAttrMaxPitch` | bytes |

> [!tip] 实践建议
> 两者可以混用：`cudaGetDeviceProperties` 批量拿大部分属性，`cudaDeviceGetAttribute` 补充结构体中没有的属性（如核心频率、显存频率）。

## 3. 其他常用 API

| API | 用途 |
|---|---|
| `cudaGetDeviceCount(&count)` | 查询系统中有多少个 CUDA 设备 |
| `cudaSetDevice(dev)` | 设置当前使用的设备 |
| `cudaDriverGetVersion(&ver)` | 查询 GPU 驱动版本 |
| `cudaRuntimeGetVersion(&ver)` | 查询 CUDA Runtime 版本 |

## 5. nvidia-smi — 命令行系统监控工具

与 CUDA API 不同，`nvidia-smi` 是**命令行工具**，直接在终端运行，用于实时监控 GPU 运行状态。

### 与 CUDA API 的区别

| | `nvidia-smi` | `cudaGetDeviceProperties` |
|---|---|---|
| 形式 | 命令行工具 | C 函数调用 |
| 用途 | 实时监控 GPU 状态 | 查询 GPU 静态属性 |
| 能看到什么 | 温度、功耗、显存占用、进程列表 | 硬件规格参数 |
| 何时用 | 运行时排查问题 | 编程时决定 launch 配置 |

### 常用命令

```bash
nvidia-smi              # 基本状态
nvidia-smi -l 1         # 每 1 秒刷新一次（类似 top）
nvidia-smi -q -d MEMORY # 只看显存详情
nvidia-smi -q -d POWER  # 只看功耗详情
nvidia-smi --query-gpu=name,temperature.gpu,memory.used,memory.total --format= csv
```

### 输出解读

```
NVIDIA-SMI 610.74          ← nvidia-smi 工具自身版本
KMD Version: 610.74        ← 内核模式驱动版本
CUDA UMD Version: 13.3     ← 用户模式驱动版本，即 CUDA Runtime 版本
```

```
GPU  Name                  Driver-Model | Bus-Id          Disp.A | Volatile Uncorr. ECC
|   0  NVIDIA GeForce RTX 3060 Ti   WDDM  |   00000000:01:00.0  On |                  N/A |
```

| 参数 | 值 | 含义 |
|---|---|---|
| GPU | 0 | 设备编号 |
| Name | NVIDIA GeForce RTX 3060 Ti | GPU 型号 |
| Driver-Model | WDDM | Windows Display Driver Model（Windows 图形驱动模式） |
| Bus-Id | 00000000:01:00.0 | GPU 在 PCIe 总线上的地址 |
| Disp.A | On | Display Active，GPU 是否正在输出画面（接了显示器） |
| Volatile Uncorr. ECC | N/A | 不可纠正的 ECC 显存错误计数（消费级 GPU 无 ECC，所以 N/A） |

```
Fan  Temp   Perf          Pwr:Usage/Cap |           Memory-Usage | GPU-Util  Compute M.
| 33%   38C    P8             18W /  200W |    1953MiB /   8192MiB |     17%      Default |
```

| 参数 | 值 | 含义 |
|---|---|---|
| Fan | 33% | 风扇转速百分比 |
| Temp | 38C | GPU 核心温度 |
| Perf | P8 | 性能状态（P0 最高，P12 最低；P8 是空闲节能状态） |
| Pwr:Usage | 18W | 当前实际功耗 |
| Pwr:Cap | 200W | 功耗上限（可调） |
| Memory-Usage | 1953MiB / 8192MiB | 已用显存 / 总显存 |
| GPU-Util | 17% | GPU 计算单元利用率 |
| Compute M. | Default | 计算模式（Default = 允许多进程同时用 GPU） |
| MIG M. | N/A | Multi-Instance GPU 模式（消费级 GPU 不支持） |

### 性能状态（Perf）等级

| 状态 | 含义 |
|---|---|
| P0 | 最高性能，全速运行 |
| P8 | 空闲节能，GPU 没活干时自动降频 |

> [!tip] 跑 CUDA 程序时 GPU 会从 P8 切到 P0，跑完又回到 P8。可以用 `nvidia-smi -l 1` 实时观察这个变化。
