# 02 检查线程索引与维度

> 通过 `checkIndex.cu` 实际打印四个内置变量的值，理解线程编号机制和 `dim3` 的用法。
> 关联：[[学习笔记/cg/cuda/cuda_freshman/01-hello-world与线程层级.md|01 Hello World 与 CUDA 线程层级]]

---

## 0. 源码速览

```cpp
#include <cuda_runtime.h>
#include <stdio.h>

__global__ void checkIndex(void)
{
  printf("threadIdx:(%d,%d,%d) blockIdx:(%d,%d,%d) blockDim:(%d,%d,%d)\
  gridDim(%d,%d,%d)\n", threadIdx.x, threadIdx.y, threadIdx.z,
  blockIdx.x, blockIdx.y, blockIdx.z, blockDim.x, blockDim.y, blockDim.z,
  gridDim.x, gridDim.y, gridDim.z);
}

int main(int argc, char **argv)
{
  int nElem = 6;
  dim3 block(3);
  dim3 grid((nElem + block.x - 1) / block.x);
  printf("grid.x %d grid.y %d grid.z %d\n", grid.x, grid.y, grid.z);
  printf("block.x %d block.y %d block.z %d\n", block.x, block.y, block.z);
  checkIndex<<<grid, block>>>();
  cudaDeviceReset();
  return 0;
}
```

运行结果：

```cpp
grid.x 2 grid.y 1 grid.z 1
block.x 3 block.y 1 block.z 1
threadIdx:(0,0,0) blockIdx:(0,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
threadIdx:(1,0,0) blockIdx:(0,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
threadIdx:(2,0,0) blockIdx:(0,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
threadIdx:(0,0,0) blockIdx:(1,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
threadIdx:(1,0,0) blockIdx:(1,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
threadIdx:(2,0,0) blockIdx:(1,0,0) blockDim:(3,1,1)  gridDim(2,1,1)
```

共 2 个 Block × 3 个 Thread = 6 个线程，每个线程打印自己的坐标。

---

## 1. 四个内置变量回顾

| 变量 | 含义 | 类型 | 谁能看到 |
|---|---|---|---|
| `threadIdx` | 当前 Thread 在 Block 中的位置 | `uint3` | 设备端（GPU） |
| `blockIdx` | 当前 Block 在 Grid 中的位置 | `uint3` | 设备端（GPU） |
| `blockDim` | 一个 Block 有多少 Thread | `dim3` | 设备端（GPU） |
| `gridDim` | 一个 Grid 有多少 Block | `dim3` | 设备端（GPU） |

每个变量都有 `.x` `.y` `.z` 三个分量。

---

## 2. `dim3` —— 主机端配置维度

`dim3` 是基于 `uint3` 的结构体，在**主机端（CPU）**用来配置 grid 和 block 的形状。

```cuda
dim3 block(3);           // 等价于 dim3(3, 1, 1) → 3×1×1 = 3 个线程
dim3 grid(2);            // 等价于 dim3(2, 1, 1) → 2×1×1 = 2 个 Block
```

> [!tip] 只传一个参数时，y 和 z 自动填 1
> `dim3 block(3)` 等价于 `dim3(3, 1, 1)`。需要二维时才显式写 `dim3(3, 2, 1)`。

### `dim3` vs `uint3` 的区别

| | `dim3` | `uint3` |
|---|---|---|
| 谁能看到 | **主机端**（CPU 代码） | **设备端**（GPU 核函数内） |
| 能否修改 | ✅ 启动前可以设定 | ❌ 只读，启动后固定不变 |
| 用途 | CPU 端**配置** `<<<grid, block>>>` | GPU 执行时**读取**自己的编号 |

流程：CPU 用 `dim3` 设定维度 → CUDA 运行时转为 `uint3` → 传给 GPU → 每个线程在核函数内只读访问。

---

## 3. 向上取整公式

```cuda
int nElem = 6;
dim3 block(3);
dim3 grid((nElem + block.x - 1) / block.x);
```

这是 CUDA 中最常见的写法，目的：**根据数据总量和每 Block 的线程数，算出需要多少个 Block**。

```
grid = ceil(nElem / blockDim) = (nElem + blockDim - 1) / blockDim
```

| nElem | block.x | grid.x | 说明 |
|---|---|---|---|
| 6 | 3 | 2 | 6 ÷ 3 = 2，刚好整除 |
| 7 | 3 | 3 | 7 ÷ 3 = 2.33，向上取整 → 3 |
| 100 | 32 | 4 | 100 ÷ 32 = 3.125，向上取整 → 4 |

## 4. 运行结果解读

6 个线程的坐标分布：

```
Block 0                          Block 1
┌──────────────────────────┐     ┌──────────────────────────┐
│ threadIdx.x = 0          │     │ threadIdx.x = 0          │
│ blockIdx.x  = 0          │     │ blockIdx.x  = 1          │
│                          │     │                          │
│ threadIdx.x = 1          │     │ threadIdx.x = 1          │
│ blockIdx.x  = 0          │     │ blockIdx.x  = 1          │
│                          │     │                          │
│ threadIdx.x = 2          │     │ threadIdx.x = 2          │
│ blockIdx.x  = 0          │     │ blockIdx.x  = 1          │
└──────────────────────────┘     └──────────────────────────┘

blockDim = (3,1,1)               blockDim = (3,1,1)
gridDim  = (2,1,1)               gridDim  = (2,1,1)
```

每个线程看到的 `blockDim` 和 `gridDim` 值相同（全局常量），但 `blockIdx` 和 `threadIdx` 各不相同（自身坐标）。

## 5. 全局线程编号

实际编程中最常用的计算——把 `(blockIdx, threadIdx)` 转成一维全局索引：

```cuda
int gid = blockIdx.x * blockDim.x + threadIdx.x;
```

| blockIdx.x | threadIdx.x | 全局索引 gid |
|---|---|---|
| 0 | 0 | 0 |
| 0 | 1 | 1 |
| 0 | 2 | 2 |
| 1 | 0 | 3 |
| 1 | 1 | 4 |
| 1 | 2 | 5 |

这样每个线程就能用 `gid` 索引到数组中属于自己的那份数据。

> [!tip] 二维场景的全局索引
> ```cuda
> int x = blockIdx.x * blockDim.x + threadIdx.x;
> int y = blockIdx.y * blockDim.y + threadIdx.y;
> int gid = y * width + x;  // 行优先存储的一维索引
> ```
