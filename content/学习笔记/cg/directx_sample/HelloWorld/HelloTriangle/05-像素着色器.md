# 05 像素着色器

上一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/04-顶点着色器.md|顶点着色器]]  
下一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/06-输入布局.md|输入布局]]

## 为什么需要像素着色器

顶点着色器只处理三个角。光栅化阶段根据这三个角形成三角形覆盖区域，并产生许多候选像素，但还需要决定每个位置最终输出什么颜色。

【核心】像素着色器就是为这些候选像素计算颜色的小程序。

因果关系是：

> 顶点着色器输出三个角 → 光栅化形成覆盖区域并插值数据 → 像素着色器为每个候选像素输出颜色。

【可略】更严格地说，像素着色器处理的是光栅化产生的片段或采样点，并不保证一次调用必然对应最终可见的一个屏幕像素。HelloTriangle 当前没有深度和多重采样等复杂情况，先按“候选像素”理解即可。

## PSMain 的输入

```hlsl
float4 PSMain(PSInput input) : SV_TARGET
```

`PSInput` 是上一节中顶点着色器返回的结构。对于三角形内部的某个位置，`input.color` 不是简单选取某一个顶点的颜色，而是由三个顶点颜色插值得到。

因此：

- 靠近红色顶点的位置会更红；
- 靠近绿色顶点的位置会更绿；
- 靠近蓝色顶点的位置会更蓝；
- 中间区域会混合这三种颜色。

插值由固定的光栅化阶段完成，不是 `PSMain` 中手写的循环或混色代码。

## PSMain 的输出

```hlsl
return input.color;
```

本例不采样纹理、不计算光照，也不修改颜色，直接返回插值后的 `float4`：

- `x`：红色分量；
- `y`：绿色分量；
- `z`：蓝色分量；
- `w`：透明度分量。

源码使用 `SV_TARGET` 标记返回值：

```hlsl
float4 PSMain(...) : SV_TARGET
```

【核心】`SV_TARGET` 是像素着色器的输出契约，表示返回的 `float4` 将作为当前颜色渲染目标的输出。HelloTriangle 当前绑定的颜色渲染目标就是交换链的后台缓冲区。

## 与顶点着色器的数量差异

绘制这个三角形时，逻辑上只有三个输入顶点，因此顶点着色器处理三个顶点；但三角形可能覆盖大量候选像素，所以像素着色器通常会被调用很多次。

这说明二者职责不同：

- 顶点着色器决定角点的位置并准备待插值的数据；
- 像素着色器决定覆盖区域中每个候选像素的输出颜色。

## 像素着色器没有做什么

- 它没有读取顶点缓冲区；
- 它没有决定三角形的三个角在哪里；
- 它没有在源码中自行计算红、绿、蓝插值；
- 仅仅定义 `PSMain` 还不会自动执行，后面仍要将编译后的字节码放进图形管线状态。

【可略】`PSInput.position` 也会传入像素着色器，但这个最小示例没有使用它。

## API 边界

这里只关注像素着色器的输入、返回值和 `SV_TARGET` 契约，不深入光栅化硬件、驱动调度或着色器编译器内部实现。

## 暂时只需记住

1. 光栅化先产生三角形覆盖的候选像素。
2. 顶点颜色会在三角形内部插值。
3. 像素着色器为每个候选像素返回颜色。
4. `SV_TARGET` 表示返回值是颜色渲染目标的输出。
