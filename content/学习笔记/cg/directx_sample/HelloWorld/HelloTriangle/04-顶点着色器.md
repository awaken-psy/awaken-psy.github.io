# 04 顶点着色器

## 为什么需要顶点着色器

顶点缓冲区和视图已经解决了“顶点字节在哪里、每个顶点有多大”。但这些数据还不能直接变成屏幕上的三角形，因为图形管线还需要知道每个顶点最终应处在什么位置，以及要向后传递哪些附加数据。

【核心】顶点着色器是一个由 GPU 对每个顶点调用一次的小程序。它接收一个顶点的属性，至少输出后续光栅化所需的位置。

因果关系是：

> 读到一份顶点数据 → 顶点着色器处理这一个顶点 → 输出可供光栅化继续使用的位置和颜色。

它只处理顶点，不会独自生成完整三角形，也不会直接给每个像素着色。

## VSMain 的输入

```hlsl
PSInput VSMain(float4 position : POSITION, float4 color : COLOR)
```

本例每次调用接收：

- `position`：当前顶点的位置；
- `color`：当前顶点携带的颜色。

`POSITION` 和 `COLOR` 是语义，用来表达数据用途。它们如何与 C++ `Vertex` 结构中的字段对应，稍后的“输入布局”一节再解释。

【可略】C++ 侧位置目前保存三个分量，而 HLSL 参数写成 `float4`。这个补全规则也属于输入布局与格式匹配问题，现在只需知道这不是漏写了数据。

## VSMain 的输出

```hlsl
struct PSInput
{
    float4 position : SV_POSITION;
    float4 color : COLOR;
};
```

`PSInput` 是本例自定义的输出结构。它的名字可以改变，真正连接管线阶段的是字段后面的语义。

### SV_POSITION

【核心】顶点着色器必须向后续光栅化阶段提供顶点位置。本例通过 `SV_POSITION` 标明 `position` 字段承担这个职责。

顶点着色器通常会利用世界、观察和投影矩阵计算这个位置。HelloTriangle 为了保持简单，直接把输入坐标当作裁剪空间坐标：

```hlsl
result.position = position;
```

因此这里没有矩阵计算，只是原样传递。

### COLOR

```hlsl
result.color = color;
```

颜色也被原样传向后续阶段。光栅化三角形时，三个顶点的红、绿、蓝会在三角形内部产生平滑插值；下一节的像素着色器将接收插值后的颜色。

## 顶点着色器没有做什么

- 它没有读取整个顶点数组；一次调用只处理一个顶点。
- 它没有自己组装三角形。
- 它没有生成最终像素颜色。
- 仅仅存在 `VSMain` 函数还不会触发执行；后面还要把编译后的着色器放进图形管线状态，并发出绘制命令。

## API 边界

HLSL 源码会在构建时编译成 GPU 可使用的着色器字节码。这里关注输入、输出和语义的调用契约，不深入着色器编译器、D3D12 Runtime 或驱动如何实现它。

## 暂时只需记住

1. 顶点着色器对每个顶点执行一次。
2. 它必须输出带 `SV_POSITION` 语义的位置。
3. 本例不变换位置，只把位置和颜色原样向后传。
4. 顶点着色器不会直接产生最终像素。
