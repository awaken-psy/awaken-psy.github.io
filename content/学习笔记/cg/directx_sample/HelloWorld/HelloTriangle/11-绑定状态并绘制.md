# 11 绑定状态并绘制

上一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/10-视口与裁剪矩形.md|视口与裁剪矩形]]  
下一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/12-HelloTriangle整体流程.md|HelloTriangle 整体流程]]

## 创建对象不等于使用对象

`LoadAssets()` 已经创建根签名、PSO、顶点缓冲区和顶点缓冲区视图。但是，只创建这些对象还不会画出三角形。

【核心】`PopulateCommandList()` 的职责是把“一帧该如何使用这些对象”按顺序记录进命令列表。

```text
创建对象：准备长期存在的资源和规则
绑定对象：选择本次绘制采用哪些资源和规则
Draw：记录一次绘制请求
提交列表：GPU 才真正执行
```

## 1. 重置记录空间和命令列表

```cpp
m_commandAllocator->Reset();
m_commandList->Reset(m_commandAllocator.Get(), m_pipelineState.Get());
```

Allocator 只有在 GPU 不再使用上一帧记录后才能重置。HelloTriangle 每帧末尾等待 GPU，因此这里能安全复用同一个 Allocator。

命令列表 `Reset` 后重新进入录制状态，并将 `m_pipelineState` 设为初始 PSO。

## 2. 绑定根签名、Viewport 和 Scissor Rect

```cpp
m_commandList->SetGraphicsRootSignature(m_rootSignature.Get());
m_commandList->RSSetViewports(1, &m_viewport);
m_commandList->RSSetScissorRects(1, &m_scissorRect);
```

这三项分别确定：

- 着色器资源绑定契约；
- 标准化坐标映射到哪块像素区域；
- 哪个矩形范围内允许继续产生像素。

## 3. 把后台缓冲区变为渲染目标

```cpp
PRESENT → RENDER_TARGET
```

交换链交出的后台缓冲区原本用于呈现。清屏和绘制前必须记录资源屏障，把当前缓冲区转换为 `RENDER_TARGET` 状态。

## 4. 选择并绑定本帧 RTV

```cpp
CD3DX12_CPU_DESCRIPTOR_HANDLE rtvHandle(
    m_rtvHeap->GetCPUDescriptorHandleForHeapStart(),
    m_frameIndex,
    m_rtvDescriptorSize);

m_commandList->OMSetRenderTargets(1, &rtvHandle, FALSE, nullptr);
```

RTV Heap 中有两个后台缓冲区描述符，`m_frameIndex` 选择当前正在绘制的那一个。

`OM` 表示 Output Merger。绑定后，像素着色器的 `SV_TARGET` 输出会进入该后台缓冲区。最后的 `nullptr` 表示本例没有深度模板视图。

## 5. 清屏

```cpp
const float clearColor[] = {0.0f, 0.2f, 0.4f, 1.0f};
m_commandList->ClearRenderTargetView(...);
```

它记录将颜色目标清为深蓝色的命令。清屏仍不是立即执行。

## 6. 配置输入装配阶段

```cpp
m_commandList->IASetPrimitiveTopology(
    D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST);

m_commandList->IASetVertexBuffers(0, 1, &m_vertexBufferView);
```

`IA` 表示 Input Assembler：

- `TRIANGLELIST`：每连续三个顶点组成一个独立三角形；
- 第一个 `0`：从输入槽 0 开始绑定；
- `1`：绑定一个顶点缓冲区视图；
- `m_vertexBufferView`：提供 GPU 地址、步长和总范围。

输入布局的 `POSITION` 和 `COLOR` 也都从槽 0 取数据。

## 7. DrawInstanced

```cpp
m_commandList->DrawInstanced(3, 1, 0, 0);
```

四个参数依次是：

| 参数 | 本例值 | 含义 |
| --- | ---: | --- |
| `VertexCountPerInstance` | 3 | 每个实例读取三个顶点 |
| `InstanceCount` | 1 | 只绘制一个实例 |
| `StartVertexLocation` | 0 | 从顶点 0 开始 |
| `StartInstanceLocation` | 0 | 从实例 0 开始 |

GPU 执行该命令时发生：

```text
读取三个 Vertex
    ↓
三次 VSMain
    ↓
组装为一个 TRIANGLELIST 三角形
    ↓
光栅化并插值 COLOR
    ↓
多次 PSMain
    ↓
SV_TARGET 写入当前 RTV
```

本例没有索引缓冲区，所以使用 `DrawInstanced` 而不是 `DrawIndexedInstanced`。

## 8. 转回 PRESENT 并关闭列表

```cpp
RENDER_TARGET → PRESENT
m_commandList->Close();
```

绘制后必须把后台缓冲区转换回可呈现状态。`Close` 表示本帧命令录制结束，之后才能交给 `ExecuteCommandLists`。

## 最关键的边界

调用 `DrawInstanced` 时，CPU 仍然只是在记录命令。真正执行发生在 `OnRender()` 随后的：

```cpp
m_commandQueue->ExecuteCommandLists(...);
```

## 暂时只需记住

1. 对象必须绑定到命令列表后才成为本次绘制的当前状态。
2. `OMSetRenderTargets` 选择输出目标，`IASet*` 选择输入数据和图元解释方式。
3. `DrawInstanced(3, 1, 0, 0)` 请求绘制一个由三个顶点组成的三角形。
4. Populate 只记录；提交到 Queue 后 GPU 才执行。
