# 01 顶点与三角形

下一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/02-顶点缓冲区.md|顶点缓冲区]]

## 为什么需要顶点

【核心】GPU 不会凭空知道“三角形”长什么样。程序必须先给出三角形三个角的数据，这三个角就是三个顶点。

一个顶点不是屏幕上的像素，而是一份输入记录。HelloTriangle 规定每份记录包含：

- `position`：这个角在哪里。
- `color`：这个角带有什么颜色。

因此，这一小节的因果关系是：

> 想画三角形 → 必须描述三个角 → 用三份结构相同的 `Vertex` 数据表示它们。

## 源码中的顶点结构

`D3D12HelloTriangle.h` 中的结构为：

```cpp
struct Vertex
{
    XMFLOAT3 position;
    XMFLOAT4 color;
};
```

【核心】结构的意义不只是把变量放在一起，而是建立一份数据约定：每个顶点都先存三个位置分量，再存四个颜色分量。之后的输入布局和着色器必须与这份约定对应。

【可略】`XMFLOAT3` 和 `XMFLOAT4` 是 CPU 侧保存浮点数的简单内存结构。此时不用研究它们的库实现。

## 三个具体顶点

`D3D12HelloTriangle.cpp` 在 `LoadAssets()` 中准备了三份数据：

| 顶点 | 大致位置 | 颜色 |
| --- | --- | --- |
| 第 1 个 | 上方 | 红色 |
| 第 2 个 | 右下 | 绿色 |
| 第 3 个 | 左下 | 蓝色 |

这三份数据目前只存在于 CPU 内存中。它们还没有自动进入 GPU，也不会因为数组名叫 `triangleVertices` 就自动被绘制。

下一节要解决的问题正是：**怎样把这三份顶点数据放到 GPU 能读取的位置。**

## 暂时只需记住

1. 三角形由三个顶点描述。
2. 每个顶点是结构相同的一份输入数据。
3. 本例的每个顶点包含位置和颜色。
4. 当前数组仍是 CPU 数据，真正绘制还需要后续步骤。
