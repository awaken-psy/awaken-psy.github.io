# 10 视口与裁剪矩形

上一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/09-HLSL语法与GLSL对照.md|HLSL 语法与 GLSL 对照]]  
下一篇：[[学习笔记/cg/directx_sample/HelloWorld/HelloTriangle/11-绑定状态并绘制.md|绑定状态并绘制]]

## 为什么需要 Viewport

顶点着色器输出 `SV_POSITION` 后，管线经过透视除法得到标准化坐标。渲染目标却是一个具有实际像素宽高的二维区域，因此还需要规定这些坐标映射到哪块像素区域。

【核心】Viewport 负责坐标映射：把标准化坐标映射到渲染目标中的像素矩形，同时定义深度映射范围。

本例在构造函数中创建：

```cpp
m_viewport(
    0.0f,
    0.0f,
    static_cast<float>(width),
    static_cast<float>(height))
```

它从窗口左上角 `(0, 0)` 开始，宽高等于客户区宽高，所以三角形会映射到整个窗口。

`CD3DX12_VIEWPORT` 在这里还使用默认深度范围 `0～1`。HelloTriangle 没有深度缓冲区，目前只需知道这个范围是 Viewport 描述的一部分。

## 为什么还需要 Scissor Rect

Viewport 已经决定映射区域，但有时程序还希望在其中只允许一个更小的矩形产生像素，例如 UI 面板或分屏区域。

【核心】Scissor Rect 不重新映射坐标，只把落在矩形外的候选像素裁掉。

本例创建：

```cpp
m_scissorRect(0, 0,
              static_cast<LONG>(width),
              static_cast<LONG>(height))
```

它同样覆盖整个客户区，因此正常情况下不会额外裁掉三角形。

## 二者区别

```text
Viewport     ：改变“标准化坐标映射到哪块像素区域”
Scissor Rect ：保留映射后矩形内的候选像素，裁掉矩形外部分
```

可以把它们想象为：Viewport 决定画布摆放和缩放，Scissor Rect 再在画布上放一块矩形遮罩。

## 绘制前绑定

```cpp
m_commandList->RSSetViewports(1, &m_viewport);
m_commandList->RSSetScissorRects(1, &m_scissorRect);
```

`RS` 表示 Rasterizer Stage。两个调用都把状态记录进命令列表：

- 第一个参数 `1`：绑定一个 Viewport 或 Scissor Rect；
- 第二个参数：指向对应描述结构。

这些调用不会立即执行光栅化，必须等命令列表提交后由 GPU 执行。

## 暂时只需记住

1. Viewport 负责从标准化坐标到像素区域的映射。
2. Scissor Rect 负责裁掉矩形外的候选像素。
3. 本例二者都覆盖整个窗口。
4. 它们是绘制前需要记录到命令列表的光栅化状态。
