# 08 IBL 的局限、探针修补与 PRT 对照

> 本篇在思维链上的位置：**收官**。清算 IBL 的三个边界假设，看引擎如何打补丁，最后把它与 PRT 专题并排放好——两个专题其实是**同一个渲染方程的两次相反拆分**。

## 三个边界假设

IBL 的每个局限都对应推导里一个具体位置：

| 假设 | 卡在哪一步 | 表现 |
|---|---|---|
| $V=1$ | [[学习笔记/cg/games202/专题/ibl/02-环境贴图作为光源.md|02 环境贴图作为光源：两个根基假设]] 根基；拆分公式里从未出现遮挡 | **无阴影、穿墙漏光**：室内物体被"天上"的光照亮 |
| 无限远 | [[学习笔记/cg/games202/专题/ibl/02-环境贴图作为光源.md|02 环境贴图作为光源：两个根基假设]] 根基一 | 贴图里的近处灯**没有正确位置**：走到哪都一样亮 |
| 单弹 | 只有直接对环境贴图求积 | 镜面反射看到的是天空，**看不到场景自己的 GI** |

## 工程补丁

### 遮挡：SSAO / bent normal

$V$ 不在场，就在外面**乘一个近似可见性**：

- **SSAO**：屏幕空间估计每个点的平均遮挡，给环境光乘一个系数；
- **Bent normal**：把法线"掰向"未被遮挡的平均方向再查辐照图，同时缓解漏光与方向错误；
- 掠射角镜面遮挡：用 bent normal + 粗糙度驱动一个镜面遮挡衰减。

它们都是**启发式**——不像 PRT 那样从积分里精确算出来，只在"低频遮挡"上效果好。

### 位置：探针系统

把"一张无限远的图"换成"**若干张放在具体位置的图**"：

- **反射探针**：在场景各点烘焙/捕获一张 cubemap，各自跑完整的 IBL 离线流程（[[学习笔记/cg/games202/专题/ibl/07-实现管线.md|07 实现管线：预滤波、LUT 与运行时]]）；
- **代理体校正**：给探针配一个 box/sphere 简化几何，把无限远假设修正为"光从这个盒子/球反射过来"，缓解视差错误；
- **逐像素探针混合**：像素在多个探针之间按权重混合，平滑过渡。

探针 = **IBL 的局部化**。代价是每个探针都要重新预滤波，更新成本成倍增加。

### 多弹与 GI：DDGI 一类

DDGI 等现代探针 GI：每个探针存辐照度 + **深度信息**（用以判断遮挡），射线在探针之间**弹射两跳**，逐帧增量更新。它本质上是"PRT 的传输思想 + IBL 的探针组织方式"的杂交后裔。

## 终极对照：IBL × PRT

两个专题处理的是**同一个积分**：

$$
L_o = \int_{\Omega^+} L(\omega_i)\; f_r\; \cos\theta_i\; \underbrace{V(p,\omega_i)}_{\text{谁记住它？}}\; d\omega_i
$$

| | PRT（SH） | IBL（split-sum） |
|---|---|---|
| 预计算什么 | 光照压低频（9 系数）+ **传输精确积分（含 $V$）** | 光照按粗糙度滤波（mip 链）+ 材质压 LUT |
| $V$ 的去向 | **精确保留**（阴影、GI 多弹都在系数里） | **假设为 1**（丢掉） |
| 光照频率 | 只剩低频（小光源/锐高光丢失） | **全频率保留**（镜面反射清晰） |
| 场景动态 | 必须静止 | **随便动**（没有几何信息，也就没有几何负担） |
| 材质 | 冻结在传输里（diffuse/低频 glossy） | 任意 GGX 参数实时可调 |
| 光照旋转 | 旋转系数，几乎免费 | 重跑预滤波链，很贵 |
| 擅长 | 漫反射阴影 + 烘焙 GI | 镜面/glossy 反射天空 |

$$
\boxed{
\text{PRT：用光照的频率，买传输的精确}
\qquad
\text{IBL：用传输的精确，买光照的频率}
}
$$

所以两者在引擎里**长期共存**，各守一端：

```text
现代引擎的环境光照（简化版分工）
    镜面：split-sum 预滤波 mip 链 + LUT      ← IBL 专题
    漫反射：SH 探针（每探针 9 系数）          ← PRT 的 V=1 形态
    阴影/遮挡：SSAO、bent normal、探针深度    ← 各自打补丁
    未来：RTRT 直接每帧积分，预计算整体退位
```

## 思想回扣：统一两个专题

把两个专题的"预计算哲学"压缩成一条：

$$
\boxed{
\text{昂贵的乘积积分}
+
\text{各因子变化时间尺度不同}
\;\Longrightarrow\;
\text{把慢变因子预计算成"可查表"的东西，运行时廉价组合}
}
$$

| 慢变因子是什么 | 预计算成什么 | 就是哪个专题 |
|---|---|---|
| 静止场景的传输（$V\cdot\cos\cdot f_r$，逐点） | SH 系数，点乘组合 | **PRT** |
| 共享的天空（全场景一份） | 卷积好的 mip 链 | **IBL 光照项** |
| 材质响应（只依赖少数参数） | 2D LUT | **IBL 材质项** |
| 材质响应（只依赖粗糙度/F0） | split-sum 积分近似表 | [[学习笔记/cg/games202/lecture5 Real-time Environment Mapping 1.md|lecture5 Real-time Environment Mapping 1]] 的 LUT |

RTRT 的意义对两者相同：**算力足以每帧算完整积分时，"快慢分离"不再必要**——这正是两个专题共同的黄昏，也是所有预计算技术的黄昏。

## 全专题最终结论

$$
\boxed{
L_o^{\text{IBL}}
=
\underbrace{\text{PrefilteredEnv}(r,\ \text{rough})}_{\text{光照因子：先平均，查一次}}
\times
\big(R_0\cdot\underbrace{\text{LUT.r}}_{\text{scale}}
+
\underbrace{\text{LUT.g}}_{\text{bias}}\big)
}
$$

> IBL 的实时性来自"变化时间尺度的分离"（天空共享、材质参数化）；它的全部局限来自"均值"二字——均值抹掉了遮挡、抹掉了位置、抹掉了弹射。**理解了"哪里被平均掉"，就理解了 IBL 的一切边界；理解了 PRT 与 IBL 是同一积分的两种拆分，两个专题就变成了一整个。**
