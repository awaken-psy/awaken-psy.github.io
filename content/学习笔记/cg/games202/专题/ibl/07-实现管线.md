# 07 实现管线：预滤波、LUT 与运行时

> 本篇在思维链上的位置：**落地**。[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 与 [[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]] 的两张纹理怎么生成、运行时怎么合流，本篇串成完整流水线。

## 总览

| | 离线预计算 | 运行时（每帧） |
|---|---|---|
| 产出1 | 预滤波环境贴图（mip 链 = 粗糙度） | 镜面：查一次 |
| 产出2 | BRDF LUT（(cosθ_v, roughness) → scale/bias） | 再查一次 |
| 产出3 | 辐照度图或 SH 探针（[[学习笔记/cg/games202/专题/ibl/03-漫反射-辐照度图.md|03 漫反射 IBL：辐照度图]]） | 漫反射：查一次 |
| 每像素成本 | — | **三次纹理采样 + 几次乘加** |

## 离线 A：预滤波环境贴图

对每个 mip 层级（对应一个粗糙度）、每个 texel 方向 $w$：以 $w$ 同时扮演 $n$、$v$、镜面方向 $r$（N=V 假设），重要性采样 GGX 瓣，把环境图在该瓣上做**余弦加权的均值**：

```python
for each mip m (roughness r):
    for each texel direction w:                  # w 扮演 n = v = r（N=V 假设）
        total, wsum = 0, 0
        for k in range(K):
            h = sample_GGX(axis=w, roughness=r)  # 重要性采样：pdf ∝ D(h)
            l = reflect(w, h)                    # 候选入射方向
            if dot(l, w) > 0:                    # 地平裁剪
                total += env(l) * dot(l, w)      # 余弦权重
                wsum  += dot(l, w)
        prefiltered[m][w] = total / wsum
```

两个采样细节，全是老朋友：

- **重要性采样吸收 $D$**：按 $D(h)$ 采样，估计器里 GGX 分布项与 pdf 相消——[[学习笔记/cg/rt in one weekend/rest_life/05-光线散射与散射PDF.md|第 5 章：光线散射与散射 PDF]] 与 [[学习笔记/cg/rt in one weekend/rest_life/09-直接采样光源.md|第 9 章：直接采样光源]] 的 $f/p$ 语言在这里第三次出场（PRT 预计算里余弦采样吸收 $\cos$ 是第二次）；
- **用权重和归一化**：除以 $\sum\cos$ 而不是 $K$，自动吸收地平裁剪丢掉的样本。

⚠️ 再次强调（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的伏笔）：**不要用硬件自动生成 mip**——那是各向异性的 2×2 盒滤波，形状完全不是 GGX 瓣。

## 离线 B：BRDF LUT

对 LUT 网格上每个 $(\cos\theta_v, \text{roughness})$，积分出 scale/bias 两通道（[[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]] 的公式）：

```python
for n_dot_v, rough in grid:                      # LUT 两轴
    v = (sin(acos(n_dot_v)), 0, n_dot_v)         # 各向同性：方位角任取
    scale = bias = 0
    for k in range(K):
        h = sample_GGX(n, roughness=rough)       # pdf ∝ D(h) → D 被吸收
        l = reflect(v, h)
        if dot(l, n) <= 0: continue              # 地平裁剪
        s  = (1 - dot(v, h))**5                  # Schlick 的 F0 无关部分
        gv = remaining_brdf(l, v, rough) / pdf(h)   # D·G·V 中 D 已消，剩 G·V
        scale += (1 - s) * gv                    # → LUT.r
        bias  += s * gv                          # → LUT.g
    lut[n_dot_v, rough] = (scale, bias) / K
```

LUT 是**无色的**（两个标量通道），颜色永远来自 $R_0$——这正是 $R_0$ 线性拆分的回报：一张 64×64 的小表服务所有金属度和颜色。

## 运行时：完整 IBL 着色

```glsl
vec3 ibl_shade(vec3 n, vec3 v, vec3 albedo, vec3 F0, float rough) {
    // ① 漫反射：查辐照度图（或 SH 探针，[[03-漫反射-辐照度图]]）
    vec3 E       = texture(irradianceMap, n).rgb;
    vec3 diffuse = albedo * E;                   // ρ/π 按约定已折入 E

    // ② 镜面：split-sum 两因子
    vec3 r = reflect(-v, n);
    vec3 prefiltered = textureLod(prefEnv, r, rough * MAX_MIP).rgb;
    vec2 ab  = texture(brdfLUT, vec2(dot(n, v), rough)).rg;
    vec3 specular = prefiltered * (F0 * ab.x + ab.y);

    vec3 F = F0 + (1 - F0) * pow(1 - dot(n, v), 5);   // 能量分配
    return (1 - F) * diffuse + specular;
}
```

与 [[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]] 的公式逐项对应：`prefiltered` 是光照因子，`F0*ab.x + ab.y` 是材质因子。`textureLod` 的层间插值即 [[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的三线性。

## 工程细节备忘

| 议题 | 实践 |
|---|---|
| mip ↔ 粗糙度映射 | `lod = roughness × (mipCount − 1)`，最粗糙层 ≈ 辐照度图（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的极限自检） |
| 通道 | 预滤波对 RGB 各通道分别做；LUT 本身无色 |
| 缝 | cubemap 逐面卷积时跨缝采样要用立体角正确处理，否则接缝发亮 |
| 低粗糙度 | `lod→0` 退化为原图单点查询，镜面反射仍然锯齿/欠采样——交给 SSR 或光线追踪，见 [[学习笔记/cg/games202/专题/ibl/08-局限与PRT对照.md|08 IBL 的局限、探针修补与 PRT 对照]] |
| **光照更新成本** | 换天空/时间流转 = **重跑整条预滤波链**（很贵，通常分摊到多帧）；对比 PRT：旋转光照只需旋转 SH 系数，几乎免费——两个专题在"可变性"上的账目完全相反 |
| 探针化 | 把这套离线流程在每个"探针位置"各做一份，就得到引擎的反射探针系统（[[学习笔记/cg/games202/专题/ibl/08-局限与PRT对照.md|08 IBL 的局限、探针修补与 PRT 对照]]） |

## 本篇结论

$$
\boxed{
\text{离线：}\text{GGX 重要性采样卷积}+\text{LUT 蒙特卡洛}
\qquad
\text{运行时：}\text{三次采样，合流}
}
$$

> IBL 的实现本质：**把"对每个像素沿瓣积分天空"的实时开销，变成"对整张天空离线积分一次"的预计算开销**。剩下的边界问题——没有阴影、灯没有位置、只有一弹——下一篇清算。下一站：[[学习笔记/cg/games202/专题/ibl/08-局限与PRT对照.md|08 IBL 的局限、探针修补与 PRT 对照]]。
