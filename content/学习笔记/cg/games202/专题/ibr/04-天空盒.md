# 04 天空盒：环境在无穷远的极限形态

> 本篇在思维链上的位置：[[学习笔记/cg/games202/专题/ibr/03-固定视角渲染.md|03 固定视角渲染：把答案整张存下来]] 把一切自由度冻死；本篇放松一维——**允许平移**，条件是把环境近似为无穷远。天空盒就是"环境几何压缩成以相机为中心的方向函数"。

## 视差的解药：无穷远

[[学习笔记/cg/games202/专题/ibr/03-固定视角渲染.md|03 固定视角渲染：把答案整张存下来]] 说过：平移破坏缓存答案，是因为近处物体有视差。反过来说——**只要环境的距离远大于场景尺度，平移产生的视差就可以忽略**。极限情形：环境在无穷远，"方向 → 颜色"的映射与相机位置完全无关：

$$
\boxed{
L_{\text{env}}(\mathbf{p},\,\mathbf{d})
\approx
L_{\text{env}}(\mathbf{d})
\qquad
\text{成立条件：场景尺度} \ll \text{环境距离}
}
$$

于是环境可以压成**一张以任意点为中心的方向采样图**：天空盒。相机随便平移旋转，答案永远正确（对"环境"而言）。

## 三种载体

| 载体 | 结构 | 失真特征 |
|---|---|---|
| **立方体贴图 cubemap** | 6 张正方形贴一个盒子 | 各面利用率不均（立方体顶点方向上角分辨率富余） |
| **球面贴图 sphere map** | 一张圆形贴满球 | 极点挤压 + 一张图的采样密度不均 |
| **双抛物面 dual paraboloid** | 上下两张抛物面图 | 两张，各自均匀，缺点是拼接缝 |

实时渲染几乎总是选 cubemap：6 次普通 2D 采样，硬件原生支持，各向同性够用。

## 采样：方向 → 面 + uv

```glsl
vec3 d  = normalize(worldDir);          // 视线方向
vec3 a  = abs(d);
// 主轴 = |d_i| 最大的那个分量；uv = 其余两分量除以主分量后缩到 [0,1]
// 实机上不必自己写——硬件把"选面 + 缩放"藏进一次采样：
vec3 sky = texture(skybox, d).rgb;
```

实机上只需 `texture(skybox, d)`——硬件替你完成"选面 + 除以主轴 + 缩放到 uv"（细节见 [[学习笔记/cg/LearnOpengl/Advanced OpenGL/Cubemap 与环境映射知识点详解.md|Cubemap 与环境映射知识点详解]]）。

## 渲染时机与深度技巧

天空盒必须"最后画、最便宜地画"：

| 做法 | 说明 |
|---|---|
| 屏幕空间四边形 + 深度 = 最远 | 后期一个全屏 quad，深度写到 far，被场景遮挡的像素直接不采样 |
| 单位立方体、去掉平移、缩放到 far/2 | 先画省带宽，后画省 overdraw——现代管线选后者 |
| 不写深度（depth write off） | 天空永远在最底层，透明物体无需与它排序 |

## 一张环境图，四种人生

同一张 skybox 贴图，在整个渲染管线里被采样四次、意义各不相同：

| 用途 | 采样方式 | 谁在问 |
|---|---|---|
| **背景** | 视线方向直接采样 | 相机 |
| **镜面反射** | 反射向量 $R$ 采样（配合 mip 表现粗糙度） | 着色器 |
| **漫反射辐照度** | 对整张图做余弦卷积（或运行时采样超低 mip） | 着色器 |
| **环境探针 / 光源** | 当作 radiance 场积分 | IBL |

第三、四条正是 IBL 的领地：**IBL 就是"天空盒当光源"的整套工程**（[[学习笔记/cg/games202/专题/ibl/02-环境贴图作为光源.md|02 环境贴图作为光源：两个根基假设]] → 预滤波（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]]）→ LUT）。本篇与它只共享"存什么"，IBL 关心的是"怎么读"。

## 失效边界

- **室内场景不适用**：环境距离 ≈ 场景尺度，无穷远假设崩塌——换环境探针（reflection probe / 光探针）；
- **天空会动**：云的视差虽小但存在，且日出日落是"时间维"——天空盒 + 体积云分层是现代做法；
- **拼接缝与过滤**：cubemap 跨面的双线性插值在老硬件上会断——现代硬件跨面过滤已解决；生成 mip 时若用普通盒滤波，接缝处会闪（IBL 预滤波必须先转成等面积表示，[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的伏笔）。

## 本篇结论

$$
\boxed{
\text{天空盒}
=
\text{环境的"无穷远极限形态"}
=
\text{方向函数} \; L_{\text{env}}(\theta,\phi)
\;\Longrightarrow\;
\text{平移免费、旋转免费、时间与动态不免费}
}
$$

> 记忆压缩：**视差的解药是无穷远**——固定视角靠"我不动"回避视差，天空盒靠"你太远"消灭视差。两者都把 7D 的全光函数压成一张 2D 图，只差冻结的方式。下一站正面刚视差：把真实的近景光线也采样下来——[[学习笔记/cg/games202/专题/ibr/05-光场渲染.md|05 光场渲染：把视差买回来]]。
