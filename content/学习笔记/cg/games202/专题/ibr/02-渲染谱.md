# 02 渲染谱：从几何到图像的连续谱

> 本篇在思维链上的位置：**坐标系**。IBR 专题的第一件事不是学某个技术，而是拿到一张地图——所有"基于图像"的技术排在一条谱上，谱的一端是纯几何，另一端是纯图像。看懂谱上的兑换关系，后面每一篇的位置就一目了然。

## 谱的两端

同一个场景，有两种极端的渲染方法：

- **纯几何端**：手里只有模型（三角形、材质、光源），每个像素现场算——投影、光栅化、着色、积分。答案算得慢，但数据小、视角随便动；
- **纯图像端**：手里只有一堆照片，每个视角一张。渲染 = 选一张、或插值两张贴出来。运行时几乎不算，但数据量爆炸，且只有采过的视角有答案。

$$
\boxed{
\text{几何端：计算多、数据小}
\qquad\Longleftrightarrow\qquad
\text{图像端：计算少、数据大}
}
$$

## 谱上的兑换率

这条谱（Lengyel, 1998）的核心不是"两种方法"，而是**任何技术都可以落在谱中间**，且沿谱滑动时发生一笔固定的兑换：

| 沿谱向图像端走 | 变化 |
|---|---|
| 运行时计算 | ↓（预计算替它付了） |
| 预计算 / 存储 | ↑（答案必须提前存下） |
| 视角自由度 | ↓（能动的维度越来越少） |
| 穿帮风险 | ↑（越出采样假设就露馅） |

**预计算与运行时计算的兑换**是谱的第一条性质；**自由度守恒**是第二条：想要哪一维自由（视角旋转、平移、时间、光照），就必须为那一维存足够的采样，或者现场把它算回来。[[学习笔记/cg/games202/专题/ibr/03-固定视角渲染.md|03 固定视角渲染：把答案整张存下来]] 冻结平移只留旋转，[[学习笔记/cg/games202/专题/ibr/04-天空盒.md|04 天空盒：环境在无穷远的极限形态]] 冻结位置只留方向，[[学习笔记/cg/games202/专题/ibr/05-光场渲染.md|05 光场渲染：把视差买回来]] 把平移和方向都留下（代价是 4D 数据）——**它们不是三种无关技术，是同一笔账的三种记法**。

## 采样视角：渲染 = 重采样

把谱读成"采样与重建"问题会更深刻。全光函数 $P(x,y,z,\theta,\phi,\lambda,t)$ 是连续的，任何渲染方法都在做同一件事：

$$
\boxed{
\text{渲染}
=
\underbrace{\text{采样}}_{\text{离散化哪些维度}}
+
\underbrace{\text{重建}}_{\text{在采样之间怎么补}}
}
$$

| 方法 | 预先采样了什么 | 运行时怎么重建 |
|---|---|---|
| 几何渲染 | 几何（顶点、纹理） | 逐像素现场着色积分 |
| 固定视角 | $(\theta,\phi)$ 全部 | 直接贴图 |
| 天空盒 | 以相机为中心的 $(\theta,\phi)$ | 方向查表 |
| 光场 | $(u,v,s,t)$ 4D 网格 | 四线性插值 |
| 精灵/公告板 | "该物体的外观"成 2D 图 | 贴片 + 朝向约束 |

于是谱的另一种读法浮出来：**"几何 → 图像"其实是"采样越来越提前、越来越粗，重建越来越廉价"**。

## 辨析：谱上没有"更好"的一端

常见误解：IBR 是"偷懒的低端技术"。反过来才对——**谱上每个点都是某种产品假设的忠实映射**：

| 你要什么 | 该往哪走 |
|---|---|
| 自由视角漫游 | 几何端（或光场，付存储） |
| 固定机位展示（看房、展厅、解谜过场） | 图像端：固定视角渲染，一分不浪费 |
| 无穷远环境 | 天空盒：反正没有视差 |
| 大量远景小物体 | 公告板 / 替代物：屏幕上才几个像素 |
| 电影感 | 图像端后期：观众看的是"照片"，不是"世界" |

渲染谱教的是**工程判断力**：先问产品允许冻结什么，再选谱上的点。技术没有高下，只有账算不算得平。

## 本篇结论

$$
\boxed{
\text{渲染谱}
=
\text{预计算与运行时计算的兑换}
\;+\;
\text{自由度守恒}
\;+\;
\text{采样-重建视角}
}
$$

> 记忆压缩：**所有渲染技术都在一条"几何 ↔ 图像"的谱上；向图像端滑动，就是把运行时的计算兑换成提前的采样，把自由度兑换成存储。** 后面 15 篇，每一篇都能在这条谱上找到自己的坐标。下一站去谱的最图像端：[[学习笔记/cg/games202/专题/ibr/03-固定视角渲染.md|03 固定视角渲染：把答案整张存下来]]。
