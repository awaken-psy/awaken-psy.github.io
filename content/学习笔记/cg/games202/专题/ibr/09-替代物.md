# 09 替代物（Impostor）：缓存一次渲染，顶替整个物体

> 本篇在思维链上的位置：[[学习笔记/cg/games202/专题/ibr/07-公告板.md|07 公告板：一张图冒充一个三维对象]] 贴的是美术画好的图，[[学习笔记/cg/games202/专题/ibr/08-粒子系统.md|08 粒子系统：公告板 × 数量 × 时间]] 贴的是程序给的图；替代物（impostor）贴的是**这台相机刚才看到的真实外观**——图从"冒充"升级为"缓存"。它是渲染谱（[[学习笔记/cg/games202/专题/ibr/02-渲染谱.md|02 渲染谱：从几何到图像的连续谱]]）上最标准的"中间点"：预计算发生在了运行时，一帧缓存、多帧复用。

## 定义

把物体以**当前视点**渲染到一张纹理（render-to-texture），然后在接下来的帧里，用一个 quad 贴这张纹理**顶替整个物体**：

$$
\boxed{
\text{Impostor}
=
\underbrace{\text{cache}\big(\text{render}(\text{物体},\ \text{视点})\big)}_{\text{一次}}
\times
\underbrace{\text{以 quad 顶替}}_{\text{多帧}}
}
$$

## 与公告板的本质区别

| | 公告板 | 替代物 |
|---|---|---|
| 图的来源 | 美术预先画好 | **现场渲染出来**（物体 + 当前光照 + 当前阴影） |
| 有效性 | 永远有效（画的就是"通稿照"） | 只在**视点变化容差内**有效 |
| 成本 | 零 | 一次完整渲染 |
| 语义 | 冒充 | **缓存** |

正因为图是现场渲的，它能自动继承正确的光照、雾、色调——这是手绘公告板永远做不到的。

## 为什么它有效：还是视差

有效域的判定回到 [[学习笔记/cg/games202/专题/ibr/03-固定视角渲染.md|03 固定视角渲染：把答案整张存下来]] 的同一条原理：

- 相机**绕物体做纯旋转**（距离不变）→ 无视差 → 缓存的图在这段旋转内**精确**；
- 相机**平移 / 改变距离** → 透视变化 → 缓存过期。

所以工程上给 impostor 装"保鲜期"：视点离开缓存视锥一个角度阈值、或距离变化超阈、或场景光照变化，就**重烘一次**。缓存的更新频率 = 用计算买新鲜度。

## 摆放：包围球的切平面

impostor quad 放哪？答案必须与"绕哪转都一样"兼容——**物体的包围球**：

| 设计 | 理由 |
|---|---|
| quad 中心 = 包围球心 | 旋转等价：绕球心的任意旋转不改变球投影 |
| quad 法线 = 指向相机，过球心 | 透视误差最小化 |
| quad 尺寸 = 包围球的屏幕投影 | 永远完整覆盖 |

更讲究的做法（Shade et al. 1996 的 hierarchical image caching）：把场景组织成层级，节点按屏幕尺寸决定"真渲染还是用缓存"，LOD 与缓存融合。

## Atlas / 多视角变体：家用版光场

把**多个离散视角**的缓存烘进一张图集（或八面体贴图 octahedral map），运行时按视线方向选页、相邻页混合：

- 单 billboard = **1 个视角**的采样；
- 图集 = **N 个离散视角**的采样 + 插值；
- [[学习笔记/cg/games202/专题/ibr/05-光场渲染.md|05 光场渲染：把视差买回来]] = 连续视角的全采样。

图集就是光场的低配版：**花一维的钱，买回一半的自由**。远处森林、城市、人群几乎都靠这条谱线活着。

## 失效清单

| 缺陷 | 根源 |
|---|---|
| 近距离透视/视差错误 | quad 没有内部深度（除非分层深度图 LDI） |
| 阴影不一致 | 影子是真 mesh 烘的，本体却换成 quad |
| 反射穿帮 | 镜子里的 impostor 是"从相机看的假面" |
| 闪烁 | 更新率追不上视角变化率 |
| 透明内部错误 | 一张 quad 无法表达自遮挡的前后关系 |
