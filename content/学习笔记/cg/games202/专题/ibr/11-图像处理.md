# 11 图像处理：后期滤镜的数学地基

> 本篇在思维链上的位置：**第三段开卷（11–16）**。渲染完的那帧图，本身就是一张 2D 信号。本篇把处理它的数学工具一次性铺好——卷积/PSF、可分离滤波、采样与重建——后面 12–16 全是这些工具的具名应用：一台"理想针孔相机"如何被逐项补上真实光学系统的行为。

## 管线：后处理怎么挂在渲染后面

```text
几何/光照管线 → 渲染进纹理（RTT，HDR half-float）
  → 全屏大三角形 → 算子1 → ping-pong 缓冲 → 算子2 → …
  → 色调映射（13）→ 输出到后缓冲
```

两条纪律先立好：

1. **物理类算子（模糊/合成/累积）都在线性 HDR 域做**——色调映射（[[学习笔记/cg/games202/专题/ibr/13-色调映射.md|13 色调映射：把 HDR 世界装进 LDR 显示]]）之前；
2. 每个算子一个全屏 pass，pass 之间用 RTT 交接（ping-pong），链可以任意长。

## 核心数学：卷积与 PSF

线性时不变（LTI）系统有一条万能定理：**输出 = 系统脉冲响应与输入的卷积**。图像上：

$$
\boxed{
\text{LTI 算子}
\;\Longleftrightarrow\;
\text{卷积}
\;\Longleftrightarrow\;
\text{PSF}：
\quad
\text{out}(\mathbf{x}) = \sum_{\mathbf{k}} h(\mathbf{k})\,\text{in}(\mathbf{x}-\mathbf{k})
}
$$

$h$ = 点扩散函数（PSF，Point Spread Function）——"一个理想点通过系统后糊成什么形状"。一次记住 PSF 这个词，后面三篇全是它的具名形状：

| 篇 | PSF 的形状 | 谁造成的 |
|---|---|---|
| [[学习笔记/cg/games202/专题/ibr/14-镜头眩光与泛光.md|14 镜头眩光与泛光：把光学的渗漏补回来]] | 宽尾巴的核，加在超亮像素上 | 镜片散射 / 视网膜渗漏 |
| [[学习笔记/cg/games202/专题/ibr/15-景深.md|15 景深：孔径有限，焦外成圆]] | 半径随深度变化的圆盘 | 孔径有限 |
| [[学习笔记/cg/games202/专题/ibr/16-运动模糊.md|16 运动模糊：快门不为零，像素在积分]] | 沿速度方向的一维盒 | 快门时间非零 |

针孔相机的 PSF 是 $\delta$（处处锐利）——**后三篇的本质 = 把 $\delta$ 换成真实光学系统该有的核**。

## 可分离滤波：O(k²) → O(2k)

高斯核有个便宜的特性——**可分离**：二维核 = 两个一维核的乘积，于是横一次 pass、竖一次 pass：

$$
G_{2D}(x,y) = g(x)\cdot g(y)
\quad\Longrightarrow\quad
\text{一次 } k{\times}k \text{ 卷积} = \text{两次 } k \text{ 卷积}
$$

半径 20 的模糊直接卷要 400 采样；分离后 40。**不是所有核都可分离**（如双边滤波、[[学习笔记/cg/games202/专题/ibr/15-景深.md|15 景深：孔径有限，焦外成圆]] 的圆盘核），那些要靠别的技巧（分层/降采样）。

## 采样与重建：像素网格是一张采样图

信号视角：连续图像被像素网格**采样**（Nyquist：低于 2 倍最高频率的采样必走样），显示时**重建**（插值）回连续：

| 操作 | 数学本质 | 常用滤波器 |
|---|---|---|
| 放大 | 重建（插值） | 双线性 / 双三次 |
| 缩小 | **先低通再采样**（否则走样） | mipmap = 预计算的降采样链 |
| 旋转 | 重采样 | 双线性 |
| 走样补救 | 重采样前预过滤 | MSAA / TAA（另一话题） |

mipmap 的身份重申：**它就是"盒滤波金字塔"**——同一思想在 IBL 里当粗糙度链（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]]）、在 VXGI 里当锥追踪选层（[[学习笔记/cg/games202/专题/vxgi/03-光照注入与体素mip链.md|03 光照注入：把直射光烤进体素 mip 链]]）、在 bloom 里当多尺度模糊（[[学习笔记/cg/games202/专题/ibr/14-镜头眩光与泛光.md|14 镜头眩光与泛光：把光学的渗漏补回来]]）。

| 时间 | 帧间累积 | 自动曝光适应、TAA | [[学习笔记/cg/games202/专题/ibr/13-色调映射.md|13 色调映射：把 HDR 世界装进 LDR 显示]] 的适应 |

```glsl
// 3×3 盒式模糊（一个后处理 pass 的全部）
vec3 c = tex(uv).rgb;
c += tex(uv + px*vec2( 1, 0)).rgb + tex(uv + px*vec2(-1, 0)).rgb;
c += tex(uv + px*vec2( 0, 1)).rgb + tex(uv + px*vec2( 0,-1)).rgb;

outColor = c / 9.0;
```

## 记忆压缩

> **后期 = 帧上的算子；LTI 算子 = 卷积；卷积的身份证明 = PSF。** 针孔相机的 PSF 是 $\delta$，所以完美管线"全锐"得可疑；真实相机的每个缺陷都是一个具名的 PSF，后面三篇挨个补。先处理不涉及空间的那类——逐像素的颜色映射：[[学习笔记/cg/games202/专题/ibr/12-颜色校正.md|12 颜色校正：响应曲线的艺术版]]。
