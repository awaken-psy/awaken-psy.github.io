# 14 镜头眩光与泛光：把光学的渗漏补回来

> 本篇在思维链上的位置：**PSF 家族第一篇**（[[学习笔记/cg/games202/专题/ibr/11-图像处理.md|11 图像处理：后期滤镜的数学地基]] 的伏笔兑现）。针孔相机的 PSF 是 $\delta$，亮点只是锐利的点；真实光学的 PSF 有**宽尾巴**，而且镜片之间还有**内反射**。观众把"渗漏"读成"很亮"——这两个效果是 HDR 的"看得见的部分"。

## Bloom：三个来源

夜路的汽车大灯周围那一圈光晕，来自三处物理：

| 来源 | 机制 |
|---|---|
| 镜片散射 | 光学面的 PSF 有宽而低的尾巴 |
| 传感器溢出 | 强电荷"溢出"到邻近像素（原义上的 blooming） |
| 视网膜/心理 | **人眼自己也会 bloom**——所以它不是"相机专利"，是"观看者"的属性 |

第三条最重要：**游戏没有真相机，但观众有真人眼**——bloom 恰好是不需要模拟相机就能成立的那个效果。

## 算法：阈值 → 金字塔 → 叠加

现代标准流水线（COD:AW 确立）：

```text
1. 预过滤：亮度阈值提取   L' = max(0, L − T)（软膝更平滑）
2. 逐级下采样 → 半分辨率金字塔，每级顺带做一组稀疏采样模糊
3. 逐级上采样叠加，聚合成"多尺度光晕"
4. additive 加回原 HDR 图
```

$$
\boxed{
\text{bloom}
=
\big(\text{亮部}\big) * \text{PSF}_{\text{宽核}}
\quad+\quad \text{原图}
}
$$

为什么要金字塔：大半径模糊直接卷积太贵（[[学习笔记/cg/games202/专题/ibr/11-图像处理.md|11 图像处理：后期滤镜的数学地基]] 的账）；降采样金字塔 = 多尺度盒滤波，**小半径到超大半径一次性备齐**。参数的画面语义：阈值（只有什么算"超亮"）、强度、半径、色调（蓝移还是暖移）。

## Lens Flare：结构化的内反射

眩光不是无结构的晕，而是**一组有几何纪律的像**：

| 成分 | 身份 |
|---|---|
| 核心 | 光源的像本身（常带衍射星芒 streaks） |
| Streaks | 星芒/横向拉丝（anamorphic 横蓝条 = 电影味） |
| **Ghosts** | 镜片组间多次内反射形成的**一串鬼影** |
| Halo | 面内散射的大环 |

**ghost 的几何纪律**是本篇最漂亮的观察：镜片组近似同轴 → 内反射像全部落在"**光源像 ↔ 画面中心**"的连线上，距离成比例排布、大小随强度衰减。于是屏幕空间实现极其简单：

```glsl
vec2 dir = normalize(lightScreenPos - vec2(0.5)); // 光源到中心的连线
// 在连线上按参数 u_i 放一串贴片（可越过中心对称到对面）
vec2 ghostPos = vec2(0.5) + dir * u_i;           // u_i: 递增/递减的位置参数
```

强度由三件事门控：光源在不在画面内（屏外仍有 streak 探入）、**光源有没有被几何挡住**（拿深度缓冲查一次）、光源偏离光轴的角度。flare **只该由真·超亮光源触发**——白天全场景泛 flare 就是廉价感的来源。

## Bloom vs Flare：一张对照

| | Bloom | Lens Flare |
|---|---|---|
| 结构 | 无结构渗漏 | 沿连线的鬼影序列 |
| 物理身份 | PSF 宽尾巴 | 内反射成像 |
| 输入 | 全画面亮部 | 光源的屏幕位置 |
| 触发 | 亮度统计 | 单个光源 + 遮挡/角度测试 |
| 过量症状 | 整个游戏"隔着毛玻璃" | 一堆假光斑乱飞 |

## 与 HDR 的关系

bloom/flare 是**色调映射（[[学习笔记/cg/games202/专题/ibr/13-色调映射.md|13 色调映射：把 HDR 世界装进 LDR 显示]]）之前的线性 HDR 算子**：亮度超过显示范围的部分（$L > T$）无处可去，bloom 把这些"装不下"的能量摊给邻域——**太阳在显示器上永远只是一小团白，但它的 bloom 能告诉你它有多亮**。HDR 数据看不见的部分，靠渗漏看见。

## 记忆压缩

> **亮，要靠"渗"出来**。bloom = PSF 的宽尾巴卷上超亮像素；flare = 同轴镜片的内反射在"光源-中心"连线上排成一串鬼影。两者都是"装不进显示范围的能量"的视觉出口，都发生在 tone mapping 之前的线性域。下一个缺陷是孔径——针孔没有孔径，所以什么都锐；真实镜头有一块玻璃的口径：[[学习笔记/cg/games202/专题/ibr/15-景深.md|15 景深：孔径有限，焦外成圆]]。
