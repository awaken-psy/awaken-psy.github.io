# 17 体渲染：图像升到三维的毕业篇

> 本篇在思维链上的位置：**收官 + 毕业**。前 16 篇的图像都在 2D（或 2D 流形）上；体渲染把"图像"升成 **3D 纹理**——光在介质里发射、吸收、散射。它也是全专题的合龙点：alpha 合成从 [[学习笔记/cg/games202/专题/ibr/06-精灵与层.md|06 精灵与层：图像当表面的开端]] 的层、经 [[学习笔记/cg/games202/专题/ibr/08-粒子系统.md|08 粒子系统：公告板 × 数量 × 时间]] 的粒子，到这里成为**沿射线的积分**；[[学习笔记/cg/games202/专题/ibr/02-渲染谱.md|02 渲染谱：从几何到图像的连续谱]] 的"采样-重建"升到最高维。

## 为什么表面渲染不够

三角形管线的世界假设：**光在真空中传播，物质集中在薄壳（表面）上**。但烟、云、雾、火、毛、大气、皮肤的次层——这些**参与介质**（participating media）没有表面：

| 表面渲染的假设 | 介质世界的现实 |
|---|---|
| 有边界，可以落三角形 | 边界每帧湮灭与生成 |
| 一根视线一次命中 | 光一路被吸收、被发射 |
| 答案在"表面点"上 | 答案**沿整条视线累积** |

介质的正确描述是一个**连续场**：体密度 $\sigma(\mathbf{x})$（单位长度的碰撞/吸收概率）、自发光颜色 $c(\mathbf{x})$——即一张 3D 纹理。**图像从 2D 升到 3D，采样与重建的思想原封不动**（双线性 → 三线性，mip → 体 mip）。

## Emission-Absorption 模型

视线穿过介质，沿途"拿到一点光、又被挡掉一点光"：

$$
\boxed{
L(D)
=
\int_0^{D} T(s)\,\sigma(s)\,c(s)\,ds
\;+\;
T(D)\,L_{\text{bg}}
\qquad
T(s) = \exp\Big(-\int_0^s \sigma(t)\,dt\Big)
}
$$

逐项读：$\sigma\,ds$ 是这一小段"撞上粒子"的概率，撞上就贡献一份自发光 $c$；$T(s)$ 是**透射率**——到达这一段还没被吸收的概率（指数衰减：吸收是泊松过程）。末项：穿过整个介质后剩下的背景光。

## 离散化：alpha over 的最终形态

把射线切成 $n$ 段步进（ray marching），积分变成递推：

$$
\boxed{
C \;\leftarrow\; C + T\,\alpha_i\,c_i,
\qquad
T \;\leftarrow\; T\,(1-\alpha_i),
\qquad
\alpha_i = 1 - e^{-\sigma_i\,\Delta s}
}
$$

盯着看——**这就是 [[学习笔记/cg/games202/专题/ibr/06-精灵与层.md|06 精灵与层：图像当表面的开端]] 那行公式的连乘形式**：每一小段介质 = 一张"半透明的层"，一层的 over 背后是"剩余透明度"的连乘。层（2D）→ 粒子（离散 3D）→ 体（连续 3D），同一条公式贯穿三种粒度，全专题在此合龙。

## 采样的工程

| 技术 | 作用 |
|---|---|
| 固定步长 + **jitter** | 消除等距步进的条带（加蓝噪声抖动） |
| 空区跳跃 | 用包围盒/距离场大步跨过空区（SDF 步进与 [[学习笔记/cg/tuanjie引擎/GI原理/01-数学基础/03-SDF与球体步进.md|03-SDF与球体步进]] 同源） |
| 射线微分 → 体 mip | 视锥变宽时取低分辨率 mip——与 VXGI 锥形追踪**同一原语**（[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]） |
| 半分辨率 + 重投影 | 体素成本高，常半分辨率渲染再上采样 |

**VXGI 的锥形追踪本质就是体渲染**：把"带光的三维场"用体渲染原语采样——GI 是体渲染最大的下游客户之一。

## 数据从哪来

| 来源 | 例子 | 特征 |
|---|---|---|
| **程序化** | Perlin/Worley 噪声 fbm 堆出的云 | 零数据、可动画、参数即美术 |
| **测量** | CT / MRI 切片 | 体渲染的老家（医学可视化），先有体数据后有体渲染 |
| **烘焙** | 流体/烟雾模拟的密度场 | 离线模拟 → 实时采样 |

与 [[学习笔记/cg/games202/专题/ibr/08-粒子系统.md|08 粒子系统：公告板 × 数量 × 时间]] 的桥在此兑现：粒子密度高到连续时，"无数小图元的合成"的极限就是 $\sigma(\mathbf{x})$ 的积分——**粒子是离散采样、体是连续场，同一事物的两种采样密度**。

## 记忆压缩

> **介质没有表面，答案是沿视线累积的**：$C \leftarrow C + T\alpha c$、$T \leftarrow T(1-\alpha)$——它就是那行 alpha over 公式的极限形式，从精灵一路贯通到体。至此 IBR 的答案完整：图像可以替代场景（全景/天空盒/光场）、替代几何（公告板/粒子/impostor）、替代相机（从曲线到三类 PSF）、替代介质（3D 图像）。**渲染 = 采样 + 重建；IBR = 把采样提前，把重建做便宜**——这句从 [[学习笔记/cg/games202/专题/ibr/02-渲染谱.md|02 渲染谱：从几何到图像的连续谱]] 出发的话，升到 3D 依然成立，就是本专题最好的毕业证。
