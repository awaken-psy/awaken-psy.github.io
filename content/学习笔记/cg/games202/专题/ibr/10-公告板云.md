# 10 公告板云：用一簇图重构几何

> 本篇在思维链上的位置：**方向反转**。至此的图像替身都是"一个对象 → 一张图"（[[学习笔记/cg/games202/专题/ibr/07-公告板.md|07 公告板：一张图冒充一个三维对象]]、[[学习笔记/cg/games202/专题/ibr/09-替代物.md|09 替代物（Impostor）：缓存一次渲染，顶替整个物体]]）；公告板云（billboard clouds）反过来：**一个对象 → 一簇静态的小公告板**，逼近它的表面。图不再是"看过的答案"，而是**造型的材料**。

## 动机：远景植被的三角账

远景要画成千上万棵树/岩石/杂波：

- 真 mesh：三角形数不可承受；
- 单 billboard：相机一转，侧影穿帮（[[学习笔记/cg/games202/专题/ibr/07-公告板.md|07 公告板：一张图冒充一个三维对象]] 的老问题）；
- impostor：为每个对象维护缓存与更新，管理成本高。

公告板云取中间形态：**每个对象烘成少数几张静态贴片，各自角度不同**——从任何"主视方向"看都略有厚度，且**完全静态**（不需要每帧重算朝向）。静态，就是它便宜的原因。

## 形式化：一个优化问题

给定 mesh 的面片集合 $\{f_i\}$（法线 $\mathbf{n}_i$），求一组平面 $\{(\mathbf{P}_j, T_j)\}$（平面 + 纹理）：

$$
\boxed{
\text{目标：}
\begin{cases}
\text{覆盖：每个面片 } f_i \text{ 被某张贴片接住}\\
\text{保真：面片法线与所属平面夹角} \le \varepsilon\\
\text{经济：贴片数与纹理重叠最小}
\end{cases}
}
$$

精确求解是组合难题 → **贪心**（RANSAC 风格）：

1. **候选平面池**：从面片法线/位置参数化出候选平面空间；
2. **选最优**：找"能接住最多面片（按面积计）"的平面；
3. **烘焙**：把落在该平面附近、法线接近的面片**正交投影**进这张贴片的纹理（render-to-texture）；同时做 **hole cutting**——从外部视线测试，只保留最外层可见的纹素，被遮挡的镂空掉（$\alpha$ 通道）；
4. **标记已覆盖**，重复直到全覆盖。

于是贴片纹理里装的是**该视角簇下的"外壳投影"**：既不是照片，也不是 texture map，是"按用途裁剪过的外观"。

## 与前两篇的谱系对照

| | [[学习笔记/cg/games202/专题/ibr/07-公告板.md|07 公告板：一张图冒充一个三维对象]] | [[学习笔记/cg/games202/专题/ibr/09-替代物.md|09 替代物（Impostor）：缓存一次渲染，顶替整个物体]] | 公告板云 |
|---|---|---|---|
| 图数 | 1 / 对象 | 1 / 视角（动态） | **N / 对象（静态）** |
| 更新 | 每帧重算朝向 | 视点变化时重烘 | **从不更新** |
| 冒充的是什么 | 一个视角 | 一次观看 | **表面本身** |
| 属于哪类简化 | 视角冻结 | 答案缓存 | **几何的图像化重构** |

一句判词：impostor 是"时间的函数"（跟着相机走），公告板云是"空间的函数"（固定于物体）。它真正的亲戚是 **LOD 简化**——三角形简化的极限替代品。

## 误差与工程

- **误差 = 贴片与真实表面的夹角**（≤ ε）：平行于表面的部分零误差，斜面区域像"纸片楼梯"；远距离下不可见；
- 纹理重叠区域会出现**半透明叠加**：预乘 alpha（[[学习笔记/cg/games202/专题/ibr/06-精灵与层.md|06 精灵与层：图像当表面的开端]]）+ 近似排序，或干脆 alpha test 一刀切；
- 常与 impostor 组合出**完整的远景 LOD 棱柱**：近处 mesh → 中景公告板云（树群）→ 远景单树 impostor。

## 应用画像

| 对象 | 效果 |
|---|---|
| 远景森林 | 每树 2–5 张贴片，视差感假但有 |
| 云团 | 一组朝向随机的软贴片 |
| 岩石/碎屑地被 | 贴片阵列铺地 |

## 记忆压缩

> **一簇不动的贴片替一棵树**。公告板云把"图像"从视角的缓存升级成造型的材料——贪心选平面、正交投影烘焙、镂空遮挡，全部离线一次做完，运行时零成本。视差误差被距离吃掉，静态换来极致便宜。**图像既能"存看过的"，也能"拼没看过的"**——这是本篇最值得带走的一句话。
