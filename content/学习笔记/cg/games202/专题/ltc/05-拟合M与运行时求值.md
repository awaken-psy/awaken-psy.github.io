# 05 拟合 M 与运行时求值：一张小纹理买下整个面积光

> 本篇在思维链上的位置：**落地**。[[学习笔记/cg/games202/专题/ltc/04-线性变换的魔法.md|04 线性变换的魔法：M 揉捏瓣，M⁻¹ 转嫁灯]] 假设"M 已经到手"，本篇补齐两个工程环节：M 怎么来（离线拟合成小纹理）、每帧怎么组装（运行时几十次乘加）。

## M 从哪来：离线拟合进一张 2D 纹理

关键观察：**M 不依赖灯**。它只描述"这个材质参数、这个视角下的 GGX 瓣像什么形状"——与灯的形状、大小、位置全部无关：

$$
\boxed{
M = M(\alpha,\ \cos\theta_v)
\qquad
\alpha=\text{粗糙度}，\quad\cos\theta_v=n\cdot v
}
$$

于是离线流程：

```text
for 每个格点 (α, NdotV)：
    计算 GGX 瓣的真实形状（该视角下 D·G·V·cos 的方向分布）
    求解 4 个矩阵参数，最小化 [整形余弦 ↔ GGX 瓣] 的差异
    把 M 的 4 个数写进 2D 纹理
```

**又是 (粗糙度, NdotV) 二维纹理**——与 IBL 的 BRDF LUT（[[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]]）同轴同款，因为它们压缩的本来就是同一个量："GGX 响应随材质参数的变化"。LTC 的 M 纹理与 IBL 的 scale/bias LUT 是**一对象文字**：一张服务于环境光，一张服务于面积光。

> 漫反射不需要拟合——它本身就是 clamped cosine，$M\approx$ 单位阵（缩放修正后）。整个 LTC 框架里 diffuse 是 specular 的特例：**一套公式从镜面连续滑到漫反射**。

## 运行时：每盏灯每像素的完整流程

```glsl
// 输入：着色点 p、法线 n、视线 v、粗糙度 α、灯多边形顶点（世界系）、灯颜色 L
mat2 M  = texture(M_LUT, vec2(NdotV, alpha));          // ① 取 M
mat2 Mi = inverse(M);                                   // ② 求逆（闭式可解）
for (j in 灯顶点)                                       // ③ 变形顶点
    pj_tangent = Mi * toTangent(p - p_shading);
    pj' = normalize(pj_tangent);
I = 0;
for (j in 灯的每条边)                                   // ④ 逐边闭式求和
    I += edge_term(pj', p[j+1]');                       //    经典多边形辐照闭式
color = L * fresnel(v) * albedo * I_norm * I;           // ⑤ 归一化 × 幅度
```

成本：**每灯每像素 ~几十次乘加**（4 顶点变换 + N 边求和 + 一次纹理查询）——比一次额外点光着色贵不了多少。多边形灯从此变得和点光一样便宜，**这是 LTC 在工业界迅速铺开的原因**（UE4/UE5 及多数现代引擎的矩形/管状面积光都用 LTC 系方法）。

### 球形面积光

球被 $M^{-1}$ 变形后不再是球（是椭球）——多边形闭式用不上。工程做法：**把球近似成它对着色点张的锥**，clamped cosine 对"球/锥"的积分同样有解析形式（Â_l 表所在的那一族经典结果，[[学习笔记/cg/games202/专题/prt/04-球谐函数.md|04 球谐函数：球面上的正交基]]），在 LTC 空间里照搬即可。精度足够，方向性完整保留。

## 多灯：线性叠加

渲染方程对光照是线性的，LTC 每盏灯独立求值：

$$
L_o = \sum_{\text{灯}} \text{LTC}(\text{灯})
$$

没有全局耦合、没有迭代、没有收敛问题——**"加灯 = 加法"** 是 LTC 与 GI 类方法（LPV/VXGI 要传播/烘焙）在工程舒适度上的天壤之别。

## 与阴影的配合

LTC 求的是**无遮挡**的面积光直接光——它自己不做 visibility（[[学习笔记/cg/games202/专题/ltc/06-边界与三部曲收官.md|06 LTC 的边界与"谁被变形"三部曲收官]] 的清单）。工业组合：

```text
LTC（正确的软边直接光）
× shadow map / RT 阴影（可见性）
≈ 阴影边缘由灯面积软化，内部由 LTC 给出正确的能量
```

## 本篇结论

$$
\boxed{
\text{离线：}\ M(\alpha,\cos\theta_v)\to\text{2D 纹理}
\qquad
\text{运行时：取 M → 逆变换顶点 → 逐边闭式 → ×幅度}
}
$$

> 记忆压缩：**M 不认识灯，只认识材质**——所以一张 (粗糙度, NdotV) 的小表通吃任意多边形、任意数量、任意位置的面积光。运行时的全部动作：查表、揉四个顶点、逐边加一加。面积光的"贵"，被离线一次性付清了。
