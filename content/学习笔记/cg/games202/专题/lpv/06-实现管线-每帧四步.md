# 06 LPV 实现管线：每帧的全流程与账单

> 本篇在思维链上的位置：**落地**。PRT/IBL 的管线是"离线一次 + 运行时查表"；LPV 的管线是**四步全在每帧**。每帧的结构决定了它的一切工程性格。

## 每帧流水线

```mermaid
flowchart LR
    A["① RSM 渲染<br/>光源视角，多存法线/通量"] --> B["② 注入<br/>几百个 VPL → 3D 纹理 SH"]
    B --> C["③ 传播 × k 轮<br/>compute shader，ping-pong"]
    C --> D["④ 渲染查询<br/>像素着色器三线性 + SH 求值"]

    classDef process fill:#4a90d9,stroke:#2980b9,stroke-width:2px,color:#fff
    class A,B,C,D process
```

对照一下就会明白 LPV 的分量：PRT/IBL 的 ②③（昂贵部分）在离线，这里**全部四步挤进 16 毫秒**。

## 每步的数据与实现

### ① RSM 渲染

从光源视角渲染到多张附件：深度（反推世界坐标）、法线、通量。**每帧一次**，光源移动/场景变化即时生效——这是动态 GI 的入场券。

### ② 注入：散射写入

几百个 VPL 各自往自己格子里**加** SH 系数。GPU 上"多个线程往同一位置累加"要用 scatter + atomic 或**点精灵光栅化进 3D 纹理**。输出是一张 $32^3\times 12$ 通道的 3D 纹理（RGB 各 4 个 SH 系数）。

$$
\text{存储账}：32^3 \times 4 \times 3\ \text{float} \approx 0.6\ \text{MB（每级格）}
\qquad\text{——小得惊人}
$$

### ③ 传播：ping-pong 迭代

[[学习笔记/cg/games202/专题/lpv/04-传播-光在格子间流动.md|04 传播：光在格子间一格一格流动]] 的公式在 compute shader 里执行：

```glsl
// 每个格子一个线程：读旧场（6 邻居），写新场
vec4 c_new = c_old[cell];
for (int d = 0; d < 6; ++d) {
    vec4 c_nb = readOld(cell + dir[d]);        // 邻居的 4 系数
    c_new += T[d] * c_nb;                       // 预计算的 SH→SH 传输矩阵
}
writeNew(cell, c_new);
```

两块 3D 纹理**乒乓读写**（读旧写新，一轮换一次），迭代 $k$ 次（4~8）。每轮全场 $32^3$ 个线程，各 ~百次乘加——对现代 GPU 而言是零头。

### ④ 渲染查询

像素着色器里（[[学习笔记/cg/games202/专题/lpv/05-渲染查询-从场中读光.md|05 渲染查询：着色点从场里读出自己的入射光]] 的两步）：硬件三线性采 8 格 → 逐通道 SH 求值 → $\rho/\pi$。全屏像素各一次。

## 每帧成本总账

| 步骤 | 成本 | 备注 |
|---|---|---|
| RSM | 光源视角全场景一遍 | 与 shadow map 同量级 |
| 注入 | 几百个 VPL | 微不足道 |
| 传播 ×k | $k\times 32^3$ 格子更新 | 小 |
| 渲染查询 | 每像素 1 次 3D 采样 + SH 求值 | 与一张阴影贴图的采样同量级 |

**结论：整条管线没有一步是大开销，加起来也才"几张 shadow map"的量级**——这就是 LPV 在 2010 年前后被 CryEngine 3 收编（Crysis 2 系列作品）的原因。

## 覆盖范围与级联（CLPV）

$32^3$ 格子在户外场景远远不够铺。借鉴级联阴影贴图（CSM，[[学习笔记/cg/games202/tolearnlist.md|tolearnlist]] 第一项）的思路——**级联 LPV（Cascaded LPV）**：

```text
粗格子（大 cellSize）：铺满户外 100m，光走得很远
细格子（小 cellSize）：只铺近处 10m，光影更细
多级嵌套 → 渲染时按位置选级/混合
```

代价与 CSM 同款：级间边界的接缝、各级独立传播带来的不一致。这是**内存×空间覆盖×精细度**三角的又一次谈判。

## 本篇结论

$$
\boxed{
\text{LPV 每帧}
=
\text{RSM}
\to
\text{注入}
\to
\text{传播}\times k
\to
\text{查询}
\qquad
\text{无离线步骤，全程 GPU}
}
$$
