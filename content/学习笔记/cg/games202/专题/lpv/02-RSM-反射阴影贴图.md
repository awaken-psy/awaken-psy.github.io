# 02 RSM 反射阴影贴图：把"被照亮的表面"收集起来

> 本篇在思维链上的位置：**提供燃料**。动态 GI 的第一步永远是回答"光打到了哪里、被弹起来的能量是多少"。RSM 的答案：从光源视角渲染一张 shadow map，并顺手多存两个通道。

## 核心观察：shadow map 的每个像素都是一盏小灯

普通 shadow map 只存深度，只为回答"这个点可见吗"。换个视角看：

```text
从光源看出去的一张图
    每个像素 = 一个被光照直接命中的表面点
    每个被照亮的表面点 = 一个朝场景里反射能量的小面积光源

shadow map 的像素 → 二级光源（VPL，Virtual Point Light）
```

这就是 **RSM（Reflective Shadow Map）**：把 shadow map"增值"成一张二级光源清单。

## RSM 存什么

从光源视角渲染一次，每个像素存三件套：

| 通道 | 内容 | 作用 |
|---|---|---|
| 深度 | 反推**世界坐标** $x_p$ | 小灯在哪（VPL 位置） |
| 法线 | 表面朝向 $n_p$ | 小灯朝哪发光（diffuse 半球） |
| 通量 | 反射能量 $\Phi_p$ | 小灯多亮、什么颜色 |

其中 VPL 的通量：

$$
\boxed{
\Phi_p
=
\rho_p\cdot\max(0,\,n_p\cdot \omega_{light})\cdot\Phi_{light}
}
$$

读法：光源能量 × 该表面的朝向因子（cos）× 表面反射率。**朝向光源的 cos 一次就折进通量里**——后面聚集时会看到这个细节的后果。

> RSM 有一个默认假设：所有表面当 **diffuse** 处理。shadow map 里根本看不到视线方向，glossy 无从谈起——这是"燃料"自带的第一个粗糙。

## 用 RSM 做一次直接可见的 GI

有了 VPL 清单，任何着色点 $x_n$ 的**一次反弹间接光**可以暴力聚集：

$$
\text{物理版：}\quad
dE_p
=
\frac{\Phi_p\;\max(0,n_n\cdot\omega_{np})\;\max(0,n_p\cdot\omega_{pn})}{\pi\,r^2}
\qquad
\text{课程简化版：}\quad
\boxed{
E(x_n)\ =\ \sum_p \frac{\Phi_p}{\|x_n-x_p\|^2}
}
$$

| 项 | 物理版 | 简化版去哪了 |
|---|---|---|
| 接收面 cos | $\max(0,n_n\cdot\omega_{np})$ | **略去**（diffuse 假设下的近似） |
| 发光面 cos | $\max(0,n_p\cdot\omega_{pn})$ | **已折进** $\Phi_p$ 的生成 |
| $\pi$ | diffuse 归一化 | 略去 |
| $1/r^2$ | 立体角衰减 | 保留——这是 [[学习笔记/cg/rt in one weekend/rest_life/09-直接采样光源.md|第 9 章：直接采样光源]] 面积→立体角换元里的同一个 $r^2$ |

物理版推导路径就是小面积源的经典公式：小片辐射亮度 $L=\Phi/(\pi A)$，立体角 $d\omega = A\cos/r^2$，乘接收 cos。课程公式是它的"全 diffuse 一刀切"。

### 采样策略

RSM 的 texel 数是百万级，不可能全加。实践按重要性采样几百个：

```text
偏向采哪些 VPL
    ① 世界空间离 x_n 近的（1/r² 权重大）
    ② RSM 上相邻的（相邻 texel ≈ 相邻表面 ≈ 光的近邻）
    → 按距离分布做随机采样，几百个 VPL 即可出像样的单弹 GI
```

这套"直接用 RSM 出一弹 GI"本身就是一个能用的技术（RSM 是 LPV 的前辈，也是最快的一弹 GI 方法之一），**但它有一个每像素的代价**：

## 为什么 RSM 本身不够快

| 消耗 | 数量 |
|---|---|
| 每着色像素 | 采样几百个 VPL，每个一次 $1/r^2$ 聚集 |
| 全屏像素 × VPL 数 | ~百万 × 几百 = **每帧几十亿次聚集** |

对每个接收点都要"重新找一遍所有小灯"——**光的信息没有复用结构**。两盏接收点相距半米，各自独立采样几百个 VPL，得到的结果其实高度相关，但计算做了两遍。

> 这就是 LPV 的切入点：能不能**算一次、处处复用**？答案：把 VPL 的光**散布到一个共享的空间结构**（3D 格子场）上，然后让光在结构里自己流动。压进去 → 推几轮 → 人人查表。下一站：[[学习笔记/cg/games202/专题/lpv/03-注入-从VPL到格子场.md|03 注入：把 VPL 倒进格子场]]。

## 本篇结论

$$
\boxed{
\text{RSM}
=
\text{shadow map}
+
\underbrace{\{\text{世界坐标},\ \text{法线},\ \text{通量}\}}_{\text{VPL 三件套}}
\qquad\text{每帧从光源视角渲染一次}
}
$$

> 记忆压缩：**shadow map 是一张"灯单"**——每个像素一个二级小灯，位置、朝向、亮度俱全。LPV 要做的就是把这张百万行的灯单，压缩成一张小而流动的光场图。
