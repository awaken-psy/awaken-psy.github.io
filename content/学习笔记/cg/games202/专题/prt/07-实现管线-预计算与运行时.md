# 07 实现管线：系数怎么算、怎么存、怎么用

> 本篇在思维链上的位置：**落地**。[[学习笔记/cg/games202/专题/prt/05-漫反射PRT-从积分到点乘.md|05 漫反射 PRT：把整个渲染方程压成一次点乘]] 与 [[学习笔记/cg/games202/专题/prt/06-光泽PRT-传输矩阵.md|06 光泽 PRT：出射方向依赖让向量升级为矩阵]] 的推导不涉及任何实现细节，本篇把"预计算"和"运行时"两个阶段各自的输入、工具、输出摆到流水线上。

## 总览：完全分离的两个阶段

| | 离线预计算 | 运行时（每帧） |
|---|---|---|
| 输入 | 场景 + 环境贴图 | 系数数据 + 相机 |
| 工具 | 射线追踪 + 蒙特卡洛 | 像素着色器 |
| 输出 | 光照系数 $\mathbf l$ + 传输系数 $\mathbf T(p)$ / $\mathbf T_{nm}(p)$ | 带阴影的环境光着色 |
| 耗时 | 分钟~小时级，一次 | 每点 9~256 次乘加 |

## 离线阶段 A：环境贴图 → 光照系数

直接把 [[学习笔记/cg/games202/专题/prt/04-球谐函数.md|04 球谐函数：球面上的正交基]] 的投影公式离散成对贴图的求和：

```python
# 每个颜色通道独立做一份；N = 9（3 阶）常用
for n in range(N):
    l[n] = 0.0
    for each texel (u, v):
        w  = texel_direction(u, v)          # 该 texel 对应的球面方向
        dw = texel_solid_angle(u, v)         # 该 texel 的立体角（纬度越高越大）
        l[n] += envmap[u, v] * sh_B[n](w) * dw
```

要点：

- $\Delta\omega$ 不是常数——等经纬贴图在两极的 texel 覆盖的立体角更小，必须用 [[学习笔记/cg/rt in one weekend/rest_life/04-球面方向积分与均匀采样.md|第 4 章：球面方向积分与均匀采样]] 的 $\sin\theta$ 面积元加权；
- 全场景只做一次；换贴图或改基础光照时重算。

## 离线阶段 B：传输系数预计算（核心开销）

### 用余弦重要性采样消掉 $\cos\theta$ 因子

漫反射传输系数：

$$
T_n(p)=\int_{S^2} B_n(\omega)\,\frac{\rho}{\pi}\max(0,\cos\theta)\,V(p,\omega)\,d\omega
$$

被积函数里自带 $\cos\theta$——最好的采样分布就是余弦加权（[[学习笔记/cg/rt in one weekend/rest_life/08-正交归一基ONB.md|第 8 章：正交归一基 ONB]] 生成方向，[[学习笔记/cg/rt in one weekend/rest_life/09-直接采样光源.md|第 9 章：直接采样光源]] 的 PDF 语言）：

$$
q(\omega)=\frac{\max(0,\cos\theta)}{\pi}
\qquad\Longrightarrow\qquad
T_n(p)=\rho\cdot E_q\!\left[B_n\cdot V\right]
\approx
\boxed{\frac{\rho}{K}\sum_{k=1}^{K} B_n(\omega_k)\,V(p,\omega_k)}
$$

> $\cos\theta/\pi$ 被采样分布 $q$ 吸收，估计器里只剩"SH 基函数值 × 可见性"。这是 [[学习笔记/cg/rt in one weekend/rest_life/05-光线散射与散射PDF.md|第 5 章：光线散射与散射 PDF]] 中"物理项与采样项相消"思想的又一次出场：选对采样分布，公式就自己变短。

### 每条 shadow ray 同时服务全部基函数

关键效率点：采出的 $K$ 个方向和它们的可见性 $V(\omega_k)$，对**所有** $n=0..8$ 共享。

```python
for each shading point p:
    for k in range(K):                       # 每点只发 K 条射线
        w[k] = sample_cosine_hemisphere(p.normal)
        V[k] = 0.0 if occluded(p, w[k]) else 1.0   # 一条 shadow ray
    for n in range(N):                       # 基函数只是多项式求值，无射线
        T[n] = albedo * sum(sh_B[n](w[k]) * V[k] for k in range(K)) / K
```

成本：每点 $K$ 条 shadow ray（比如 100~1000），外加 $9K$ 次 SH 多项式求值。**shadow ray 是唯一的昂贵项**——全部发生在离线。

### 传输可以塞进更多东西

$V$ 只是"一次反弹"的响应。如果离线渲染器不只用一条 shadow ray，而是从 $p$ 出发做**完整路径追踪**（让光弹射多次、累积互反射），那么 $T_n$ 里封存的就是**多次反弹的全局光照响应**——PRT 的同一个数学结构立刻升级成"预计算全局光照"。这就是 [[学习笔记/cg/games202/专题/prt/01-PRT原理主线.md|PRT 原理主线：从环境光阴影难题到实时点乘]] 里"PRT 能给出离线级 GI"的含义：传输的定义权在实现者手里。

## 存储与插值

| 方案 | 适用 | 备注 |
|---|---|---|
| 顶点属性 | 网格不密、阴影要求不高 | 每顶点 9 个 vec3 |
| 纹理（per-texel） | 高频阴影细节 | 需要参数化；存储量 = 分辨率 × 9 |
| Glossy 矩阵 | 低频反射 | $N^2$ 项/点，常配低秩/聚类压缩（[[学习笔记/cg/games202/专题/prt/06-光泽PRT-传输矩阵.md|06 光泽 PRT：出射方向依赖让向量升级为矩阵]]） |

**插值的合法性**：SH 系数线性插值是安全的。因为 SH 是线性空间——系数插值 = 函数插值：

$$
\alpha\,T_n(p_1)+(1-\alpha)T_n(p_2)
=
\int B_n\left[\alpha T(p_1,\omega)+(1-\alpha)T(p_2,\omega)\right]d\omega
$$

插值出来的系数仍然是一个"合法传输函数"的投影。这与 [[学习笔记/cg/games202/专题/prt/05-漫反射PRT-从积分到点乘.md|05 漫反射 PRT：把整个渲染方程压成一次点乘]] 的推导完全一致。

## 运行时阶段

### 漫反射着色器

```glsl
// uniform vec3 lighting_sh[9];   换灯/旋转时由 CPU 更新
// in     vec3 transport_sh[9];   顶点属性或纹理查询
vec3 color = vec3(0.0);
for (int n = 0; n < 9; ++n)
    color += lighting_sh[n] * transport_sh[n];
```

9 次乘加/通道，比一次普通的光照计算还便宜。

### 光泽着色器

```glsl
// T_mn 存在纹理/uniform 块中按点索引
vec3 c[9];                                   // ① 矩阵×向量：入射系数 → 出射系数
for (int m = 0; m < 9; ++m) {
    c[m] = vec3(0.0);
    for (int n = 0; n < 9; ++n)
        c[m] += T[m][n] * lighting_sh[n];
}
vec3 color = vec3(0.0);                      // ② 用出射 SH 重建观察方向亮度
for (int m = 0; m < 9; ++m)
    color += c[m] * sh_B[m](view_dir);
```

$O(N^2)$ 的矩阵乘 + $O(N)$ 的重建，与 [[学习笔记/cg/games202/专题/prt/06-光泽PRT-传输矩阵.md|06 光泽 PRT：出射方向依赖让向量升级为矩阵]] 的公式一一对应。

### 光照旋转：全流水线最"白赚"的一步

利用 [[学习笔记/cg/games202/专题/prt/04-球谐函数.md|04 球谐函数：球面上的正交基]] 的旋转性质（每阶闭环）：

```text
旋转环境光
= 对 l 的每一阶各乘一个 (2l+1)×(2l+1) 小旋转矩阵
= 1×1 + 3×3 + 5×5 三个小矩阵，CPU 侧几微秒

传输系数：一个数都不用动
```

于是"PRT 场景里把天空从早转到晚"几乎免费；而"挪动场景里任何一件物体"则要重跑整个离线阶段——**便宜与昂贵在两种变化上的极端不对称，是 PRT 全部工程特性的根源**。

## 工程细节备忘

| 议题 | 实践 |
|---|---|
| 阶数选择 | 漫反射 3 阶（9）即可；glossy 常到 4~5 阶，矩阵 $16\times16$ 起步 |
| 振铃抑制 | 截断重建会产生过冲（类 Gibbs 现象），把环境贴图预先轻度模糊再投影可显著缓解 |
| 阴影细节上限 | 由传输的**存储密度**决定：每顶点存的 PRT 阴影边缘糊，每 texel 存储才能咬住细结构 |
| 法线扰动 | 静态场景逐点算 $T_n$ 时用的是真实法线；扰动后的法线不会重算传输，细节靠存储密度 |
| 与自发光 | $L_e$ 项与 PRT 无关，直接相加即可 |

## 本篇结论

$$
\boxed{
\text{离线：}\underbrace{\text{shadow ray}+\text{MC}}_{\text{贵，一次}}
\to \mathbf T(p)
\qquad
\text{运行时：}\underbrace{\mathbf l\cdot\mathbf T(p)}_{\text{9 次乘加}}
}
$$

> PRT 实现的本质，是把"每个点对每个方向的遮挡回答"这个巨大的查询表，压缩成每个点 9 个数——压缩损耗（光照截断）与压缩收益（实时）的边界，就是下一篇的主题。
