# 04 球谐函数：球面上的正交基

> 本篇在思维链上的位置：**选定武器**。[[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]] 证明了"正交基能让积分变点乘"，本篇介绍球面这套基的具体长相，以及它恰好匹配环境光照的三个性质。

## 为什么是球面

着色积分对**方向**积分：

$$
L_o(p)=\int_{\Omega^+} L(\omega_i)\,T(p,\omega_i)\,d\omega_i
$$

方向 $\omega$ 是单位向量，所有方向的集合是**单位球面** $S^2$（[[学习笔记/cg/rt in one weekend/rest_life/04-球面方向积分与均匀采样.md|第 4 章：球面方向积分与均匀采样]] 里已经建立过这个图像）。所以光照 $L(\omega)$、传输 $T(p,\omega)$ 都是**球面上的函数**，需要一组定义在球面上的正交基。

一维傅里叶基（sin/cos）无法直接搬上来：球面是二维、无边界、有弯曲的域。球谐函数（Spherical Harmonics, SH）正是"球面上的傅里叶级数"。

## SH 的结构：阶、带、频率

SH 记作 $Y_l^m$，两个下标组织成一个金字塔：

| 阶 $l$ | 该阶基函数个数 $2l+1$ | 频率 | 直觉 |
|---|---|---|---|
| 0 | 1 | 直流/常数 | 全球的平均值 |
| 1 | 3 | 一次（很平滑） | 天空从一侧亮到另一侧 |
| 2 | 5 | 二次 | 亮暗相间的大块斑纹 |
| 3 | 7 | 三次 | 更细的斑纹 |
| $\dots$ | $\dots$ | $\dots$ | 阶越高，振荡越快 |

取前 $k$ 阶（习惯叫 $k$ bands），基函数总数为：

$$
N = \sum_{l=0}^{k-1}(2l+1) = k^2
$$

PRT 常用前 3 阶（$N=9$）或前 4 阶（$N=16$）。

![SH 各阶可视化：白/黑为绝对值大小，蓝为正、黄为负](<Attachments/Pasted image 20260808134749.png>)

图中的关键读法：**0 阶没有正负交替（常数），阶数越高，球面上正负交替的次数越多**——和一维傅里叶级数"低频平滑、高频振荡"完全同构，只是把"周期"换成了"球面"。

## 前三阶的显式公式

实数化 SH（$r=\sqrt{x^2+y^2+z^2}=1$，即单位方向向量的分量）：

$$
\begin{aligned}
\text{0 阶：}\quad
&Y_0^0 = \frac{1}{2}\sqrt{\frac{1}{\pi}}\\[4pt]
\text{1 阶：}\quad
&Y_1^{-1} = \frac{1}{2}\sqrt{\frac{3}{\pi}}\cdot\frac{y}{r},
\quad
Y_1^{0} = \frac{1}{2}\sqrt{\frac{3}{\pi}}\cdot\frac{z}{r},
\quad
Y_1^{1} = \frac{1}{2}\sqrt{\frac{3}{\pi}}\cdot\frac{x}{r}\\[4pt]
\text{2 阶：}\quad
&Y_2^{-2} = \frac{1}{2}\sqrt{\frac{15}{\pi}}\cdot\frac{xy}{r^2},
\quad
Y_2^{-1} = \frac{1}{2}\sqrt{\frac{15}{\pi}}\cdot\frac{yz}{r^2},
\quad
Y_2^{0} = \frac{1}{4}\sqrt{\frac{5}{\pi}}\cdot\frac{3z^2-r^2}{r^2}\\
&Y_2^{1} = \frac{1}{2}\sqrt{\frac{15}{\pi}}\cdot\frac{xz}{r^2},
\quad
Y_2^{2} = \frac{1}{4}\sqrt{\frac{15}{\pi}}\cdot\frac{x^2-y^2}{r^2}
\end{aligned}
$$

两个值得立刻注意的观察：

1. **都是多项式**：$z, x, xy, x^2-y^2$……在着色器里算 SH 值就是几次乘法，非常便宜。
2. **正负瓣**：除 0 阶外，每个基函数都有正区域和负区域（可视化图中的蓝/黄）。**这决定了后面的传输系数可以是负数**，是初学者最容易不安的地方，[[学习笔记/cg/games202/专题/prt/05-漫反射PRT-从积分到点乘.md|05 漫反射 PRT：把整个渲染方程压成一次点乘]] 会专门辨析。

## 性质一：正交归一

$$
\boxed{
\int_{S^2} B_i(\omega)\,B_j(\omega)\,d\omega = \delta_{ij}
}
$$

正是 [[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]] 要求的性质——投影独立、积分变点乘的全部前提。

## 性质二：频率分层，低频光照极少系数

Ramamoorthi & Hanrahan（2001）的经典结论：**自然天空/室内环境光的能量 99% 集中在前 3 阶（9 个系数）**。

![prefiltering + 3 阶 SH 重建环境光即可达到 99% 精度](<Attachments/Pasted image 20260808141825.png>)

这与 [[学习笔记/cg/games202/lecture6 Real-time Environment Mapping 2.md|lecture6 Real-time Environment Mapping 2]] 中"积分结果的频率取决于最低频率项"的论证互相印证：环境光本身就是低频信号，用低频基截断重建损失极小。

反面对照——SH **不适合**的信号：

| 信号 | 为什么难 | 需要的系数 |
|---|---|---|
| 完美镜面（delta 函数） | 冲激的频谱无限宽 | $\to\infty$ |
| 小面积点光源 | 天空中的尖锐亮点 | 非常多 |
| 硬阴影边缘（方向域） | 0/1 突变 | 很多 |

> 这张表是 PRT 适用范围的"预警清单"：SH 适合表达的是**光照**（天然低频），不适合表达**锐利的方向信息**。[[学习笔记/cg/games202/专题/prt/08-局限边界与思想延伸.md|08 PRT 的边界：它为什么没能统治实时渲染，以及留下了什么]] 里"SH-PRT 的阴影总是偏软"的根源就在这里。

## 性质三：旋转 = 同阶内的线性组合

对任意旋转 $R$：

$$
\boxed{
Y_l^m(R\,\omega)
=
\sum_{m'=-l}^{l} D_{m m'}^{(l)}(R)\;Y_l^{m'}(\omega)
}
$$

读法：**把一个 SH 基函数旋转之后，结果不再是单个基函数，但仍然只是同一阶内基函数的线性组合**——能量在阶与阶之间不泄漏（每阶"闭环"）。

为什么这对 PRT 至关重要：

```text
旋转环境光 = 旋转光照系数向量
    每阶一个 (2l+1)×(2l+1) 的小旋转矩阵，作用在 l 向量上
    → 9 个系数只需 1个1×1 + 1个3×3 + 1个5×5 = 廉价

而传输系数（世界系下预计算的）完全不用动
    → PRT 场景里"转动天空"几乎免费
```

这是 SH 相对其他基（比如小波，见 [[学习笔记/cg/games202/专题/prt/08-局限边界与思想延伸.md|08 PRT 的边界：它为什么没能统治实时渲染，以及留下了什么]]）的独特优势：**光照可以任意旋转而预计算依然有效**。

## 投影与重建的实践

### 投影：环境贴图 → 系数

按 [[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]] 的投影公式 $c_j=\int L\,B_j\,d\omega$，对离散的环境贴图做数值积分：

```python
# 环境贴图 W×H，每个 texel 对应方向 w 和立体角 Δω
for n in range(9):
    l[n] = 0
    for each texel (u, v):
        l[n] += envmap[u, v] * B[n](direction(u, v)) * solid_angle(u, v)
```

对每个颜色通道各算一份，得到 9 个 RGB 向量——**整张天空被压成 9 个数**。

### 重建：系数 → 球面函数

$$
L(\omega)\approx\sum_{n=1}^{9} l_n\,B_n(\omega)
$$

把重建结果"摊回"球面可视化，得到一张 3 阶 SH 重建的低频环境图。它看起来像原天空被轻度模糊——模糊掉的高频部分，正是 [[学习笔记/cg/games202/专题/prt/08-局限边界与思想延伸.md|08 PRT 的边界：它为什么没能统治实时渲染，以及留下了什么]] 中小波方法试图保留的东西。

## 经典闭式结果：clamped cosine 的 SH 系数

漫反射无遮挡时，传输里唯一的"方向函数"是：

$$
\max(0,\cos\theta)
\qquad\text{（"夹住的余弦"：上半球为 }\cos\theta\text{，下半球为 0）}
$$

把它投影到 SH（以法线为极轴，利用轴对称性只有 $m=0$ 项）：

$$
\hat A_l = 2\pi\sqrt{\frac{2l+1}{4\pi}}\int_0^{\pi/2} P_l(\cos\theta)\,\cos\theta\,\sin\theta\,d\theta
$$

| $l$ | $\hat A_l$ | 备注 |
|---|---|---|
| 0 | $\dfrac{\sqrt\pi}{2}\approx0.8862$ | 主导项 |
| 1 | $\sqrt{\dfrac{\pi}{3}}\approx1.0233$ | |
| 2 | $\dfrac{\sqrt{5\pi}}{8}\approx0.4954$ | |
| 3 | $0$ | 恰好为零 |
| $\ge 4$ | 迅速衰减到接近 0 | |

**读法**：连"接收光"这个最基本的球面函数，其内容也几乎全在前 3 阶。这从物理侧再次确认——漫反射场景用 9 个系数足够。

这个 $\hat A_l$ 表会在 [[学习笔记/cg/games202/专题/prt/05-漫反射PRT-从积分到点乘.md|05 漫反射 PRT：把整个渲染方程压成一次点乘]] 里作为无遮挡情形的 sanity check 复用，也是著名的"9 参数辐照度环境贴图"（irradiance environment map，Ramamoorthi & Hanrahan 2001）的基础。

## 本篇结论

$$
\boxed{
\text{SH} =
\text{球面正交归一基}
+
\text{频率分层}
+
\text{旋转同阶闭环}
\;\Longrightarrow\;
\text{匹配"低频 + 可旋转"的环境光照}
}
$$

| 性质 | 在 PRT 中兑现为 |
|---|---|
| 正交归一 | 积分塌缩成点乘（[[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]]） |
| 频率分层 | 9 个系数表达天空，近似可控 |
