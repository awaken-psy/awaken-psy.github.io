# 06 SSR 进阶：Hi-Z 层级追踪与粗糙反射

> 本篇在思维链上的位置：**两块补丁**。[[学习笔记/cg/games202/专题/ss/05-SSR-屏幕空间光线步进.md|05 SSR：在自己的画面里找反射]] 留下两个悬案：步进太贵（朴素 marching 数百次采样）、粗糙材质怎么办。两块补丁都来自老朋友——**mip 金字塔**。

## 补丁一：Hi-Z——深度场的 mip 金字塔

### 思想

IBL 给**颜色**建 mip（按粗糙度滤波，[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]]）；SSR 给**深度**建 mip——但不是平均值，而是**每 2×2 块取最近的深度**（保守的"地形高度"）：

```text
level 0：原始深度（逐像素地形）
level 1：每 2×2 取最近 → 更"高"的一层地形（整块表面被抬高）
...
level k：超大块的保守地形
```

### 怎么用：大步走、疑似命中再下钻

```python
level = 0; t = start
while t < end:
    # 在当前层级迈"这个层级允许的大步"（可跨越整个 level 的一个格）
    t += cell_size(level)
    z_ray  = ray_depth(t)
    z_surf = hi_z[level](t)
    if z_ray > z_surf:          # 射线钻进保守地形 → 疑似命中
        if level == 0:
            return color(t)     # 最细层确认 → 真命中，读颜色
        level -= 1               # 下钻一层重新细查
    else:
        level += 1               # 安全 → 升一层，迈更大步
```

$$
\boxed{
\text{空旷区域在粗层大步跨过，疑似命中才下钻细化}
\qquad
\text{复杂度从"每像素几百步"降到"每像素几十步"}
}
$$

这是**二维版的高度场层级光线追踪**（McGuire 的 Hi-Z tracing）：原理与 VXGI 的"半径选 mip 层"（[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]）完全同构——**查询的"不确定范围"决定查多粗的层**。

### 代价

Hi-Z 保守地形"抬高"了表面：真实命中可能被提前误判、掠射角度下的台阶伪影（staircase）——步进与层级的粒度在掠射时失去精度。

## 补丁二：粗糙反射——模糊从哪来

Glossy 反射的瓣不是一条射线，是一片方向（[[学习笔记/cg/games202/专题/vxgi/05-漫反射锥组与镜面锥.md|05 漫反射锥组与镜面锥：怎么摆锥，就是什么材质]]：GGX 瓣宽度 ∝ 粗糙度）。SSR 的三种应对：

| 方案 | 做法 | 对照 |
|---|---|---|
| **抖动 + 混合** | 每像素按 GGX 瓣随机偏转反射方向（重要性采样），多帧/多点混合出模糊 | [[学习笔记/cg/rt in one weekend/rest_life/06-重要性采样实验.md|第 6 章：重要性采样实验]] 的方差方案 |
| **命中后模糊** | 把 SSR 结果存进一张 buffer，按粗糙度做一次空间模糊（或预模糊）再采样 | IBL "prefiltering + single query" 的 SSR 版 |
| **层带 mip** | 反射结果按粗糙度生成 mip 链，查 r 方向 + 粗糙度对应层级 | 直接复刻 [[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的"瓣大多糊、瓣小多锐" |

$$
\boxed{
\text{粗糙度决定模糊半径 —— IBL 的这句话在 SSR 里原样成立，只是"图"从天空换成了屏幕}
}
$$

实践中第一种（抖动）+ 时域累积最常见，因为它不引入"整片一起糊"的错误结构（模糊会把命中/未命中的边界也糊掉，暴露回退接缝）。

## 未命中的回退：把三块拼成完整 glossy 反射

```text
SSR 命中（屏幕里有）        → 高频、场景真实的反射
SSR 未命中（屏幕外/被挡）   → 回退：预滤波环境贴图 / 探针（[[08-局限与PRT对照]]）
两者按命中遮罩混合，边缘做平滑过渡
```

回退区的频率/亮度与 SSR 区往往对不上（环境贴图是"远处的平均"，SSR 是"近处的真实"）——**接缝可见性**是所有落地实现都要处理的顽疾（按深度/距屏幕边距离淡出）。

## 本篇结论

$$
\boxed{
\text{Hi-Z：深度 mip 金字塔，大步走、疑似命中下钻}
\qquad
\text{粗糙：瓣宽决定模糊，抖动/预模糊/mip 三选}
}
$$

> 记忆压缩：**给深度也盖一座金字塔**——空旷处站到高层迈大步，脚下一沉就下钻细看；模糊的事交给 GGX 瓣宽，与 IBL 一字不差。SSR 至此凑齐了"快"与"糊"两块板，剩下的全是屏幕空间的原罪。
