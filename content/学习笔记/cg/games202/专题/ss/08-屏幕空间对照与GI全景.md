# 08 屏幕空间三兄弟对照与 GI 全景

> 本篇在思维链上的位置：**双收官**——先收官屏幕空间三兄弟，再把 GAMES202 GI 部分的全部专题（PRT / IBL / LPV / VXGI / SS）摆上一张终局地图。

## 三兄弟互比

| | SSAO | SSDO | SSR |
|---|---|---|---|
| 查询对象 | 半球**可见性**（积分） | 每采样方向的**可见性 + 挡光者颜色** | 反射方向的**辐射度** |
| 服务的频段 | 漫反射环境光（低频） | 直接光 + 一弹漫反射 | 镜面/glossy（高频） |
| 需要的数据 | 深度 | 深度 + **已渲染颜色** | 深度 + 已渲染颜色 |
| 输出 | 1 个标量（打折系数） | 直接光项 + 一弹 GI | 反射颜色 + 命中遮罩 |
| 光照假设 | 环境光均匀 | 无（真实直接光） | 无（读真实画面） |
| 典型错误 | 缺屏幕外的遮挡 | 错的 VPL 颜色/缺失 | 穿射、屏幕外空洞 |
| 一句话 | "**有多敞亮**" | "**被谁挡、它多亮**" | "**镜子里是谁**" |

三者合起来覆盖了渲染方程的三个频段需求：**低频漫反射的可见性折扣、一弹方向性 GI、高频镜面辐射**——而它们共享同一个免费场、同一套"随机 + 时域 + 双边模糊"的降噪工艺、同一组屏幕空间原罪。

> 广义化提示：把 SSDO 的"逐方向可见性 + 读屏辐射"推到极致（不再区分直接/间接、扩大采样预算），就得到 SSGI（屏幕空间全局光照）——三兄弟其实是一个家族在三个预算档位上的变体。

## 场分辨率阶梯：五个专题的终局地图

GI 的一切实时方法，都在回答同一个问题：**用什么"场"近似 $\int L\cdot f_r\cos\theta\cdot V\,d\omega$ 里的 $L$ 和 $V$？**

| 方法 | 近似 $V$ 的场 | 近似 $L$ 的场 | 场的维度 | 建场时机 | 完整性 |
|---|---|---|---|---|---|
| PRT | 每点 SH 传输系数（精确含 V） | 低频 SH | 逐点 | 离线一次 | 场景冻结 |
| IBL | **无**（V=1） | 预滤波 mip 天空 | 2D | 离线/换灯时 | 只管天空 |
| LPV | 无遮挡的传播场 | 3D SH 格子 | 3D | 每帧 | 漏光、低频 |
| VXGI | 体素 α | 体素 mip 光场 | 3D | 每帧重体素化 | 体素粒度 |
| **SS** | 深度高度场 | 已渲染画面 | **2.5D** | **免费** | **仅可见几何** |

```text
完整性/成本阶梯（按场的维度排）：

逐点精确   PRT ──── 最高保真 · 零动态
3D 体素    VXGI ── 遮挡在场 · 内存大
3D 格子    LPV ─── 便宜动态 · 漏光
2D 天空    IBL ─── 高频镜面 · 无遮挡
2.5D 屏幕  SS ──── 免费高频 · 只见视锥
                    RTRT：不算了，直接积分（终点站）
```

**没有任何一列是"更好的方法"——它们是同一根频谱上的不同取舍**。这就是为什么现代引擎的 GI 从来是组合拳：

```text
环境光 = 天空 SH / 探针（IBL 思想）
       + SSAO 补局部细节（SS 思想）
镜面反射 = split-sum 预滤波（IBL 思想）
         + SSR 补近处真实（SS 思想）
漫反射 GI = 探针 / 烘焙（PRT 思想）
           + SSDO/SSGI 补一弹动态（SS 思想）
未来 = RTRT 逐帧积分 + 降噪，上面一切转为回退链
```

## 全专题最终结论

$$
\boxed{
\begin{aligned}
&\text{屏幕空间三兄弟} = \text{免费场上的三种查询}\\
&\qquad \text{SSAO：可见性比例}\quad \text{SSDO：采样两命运}\quad \text{SSR：步进找辐射}\\
&\text{GI 全景} = \text{一条"场"的阶梯}\quad \text{——而屏幕是最细、最便宜、最残缺的一层}
\end{aligned}
}
$$

> 记忆压缩：**相机看见什么，屏幕空间方法就拥有什么**。它的分辨率让 PRT 羡慕、它的成本让 VXGI 嫉妒、它的视野让所有人摇头——所以它永远是"细节补丁"，从不当主角。
