# 05 SSR：在自己的画面里找反射

> 本篇在思维链上的位置：**换频段**。SSAO/SSDO 服务漫反射低频光；SSR（Screen Space Reflection）服务**镜面与 glossy 的高频反射**——它需要的不再是"可见性比例"，而是**反射方向的场景辐射度本身**。

## 反射需要什么

镜面反射的着色积分（microfacet，view 附近一束方向）：

$$
L_o^{\text{spec}}
\approx
\int_{\text{镜面方向附近}}
L_i(\omega)\,
\underbrace{f_r\cos\theta}_{\text{高频窄瓣}}
\,d\omega
\qquad\Longrightarrow\qquad
\text{核心需求：}L_i(r)\ \text{附近一小片区域的平均辐射}
$$

IBL 的答案是"查预滤波的天空"（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]]）——但**反射里最有信息量的往往不是天空，是场景自己**（角色、道具、火光在湿地板上的倒影）。VXGI 用体素锥追回答了这个问题（[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]），SSR 给出**零成本场版本**。

## 关键观察：已渲染画面就是辐射场

这一帧光栅化已经把**所有可见表面**的着色结果算好了：

$$
\boxed{
\text{屏幕颜色图} \;=\; \text{所有可见表面的出射辐射}\ L_o\ \text{（从相机方向看）}
}
$$

于是"我在镜子里看到什么"变成一个纯几何问题：

```text
1. 从 p 出发，沿镜面方向 r 发一条射线
2. 射线撞到哪个可见表面 q
3. 撞到的那个像素里已渲染的颜色 ≈ 我在反射中看到的颜色
```

> 注意这里隐含一个近似：读到的是 q **朝相机**的辐射，用作 q **朝 p** 的辐射——SSR 的视角误差从出生就内置（与 SSDO 读屏幕颜色当 VPL 同款）。

## 在深度场上"步进"这条射线

真实场景求交没有——但**深度缓冲是可见表面的 2.5D 高度场**，把射线放到屏幕坐标系里对它做 ray marching：

```python
# p 的反射射线 r（世界系）→ 转到屏幕/视图系
ray = reflect(view_dir, normal)
step = screen_pos, depth = project(p)
for i in range(MAX_STEPS):
    step += ray_stride                  # 屏幕空间里前进
    z_ray  = ray_depth_at(step)         # 射线此刻的深度
    z_surf = depth_buffer[step]         # 场景表面的深度
    if z_ray > z_surf:                  # 射线钻到表面后面 → 命中！
        return color_buffer[step]       # 读那个像素的已渲染颜色
```

```text
        视线 → 屏幕上的射线像一条"逐渐沉入地平线"的斜线
              ╲   ╲   ╲
          ╲   ╲   ╲  ← 与深度场比较，钻进去的那格 = 命中
        ▁▁▁▁▁▂▂▂▂▂▃▃▃   （深度高度场）
```

$$
\boxed{
\text{命中判定} = \text{ray}_z \ge \text{depth}_z
\qquad
\text{取值} = \text{命中点的屏幕颜色}
}
$$

## 朴素步进的三个工程问题

| 问题 | 现象 | 缓解 |
|---|---|---|
| **步长两难** | 步长小 → 几百次采样太贵；步长大 → 薄物体、小物件直接跳过 | 按深度缩放步长（远处迈大步）；命中后**二分细化** |
| **透视畸变** | 屏幕等距步进 ≠ 世界等距（透视下挤在一起） | 在视图/世界空间参数化射线，每步反投影到屏幕 |
| **命中误差** | 一次比较只知"钻过去了"，不知精确交点 | 命中后做几次二分/固定回退，收紧交点 |

**步长两难是朴素 SSR 的命门**——每像素几百次深度采样，4K 下不可负担。下一站专门解决它。

## 未命中怎么办：回退链

射线走完没钻进任何表面（反射的东西在屏幕外、或被前景挡住）时：

```text
命中 SSR     → 用屏幕颜色（高频、锐利）
未命中      → 回退到 IBL：预滤波环境贴图 / 反射探针（[[08-局限与PRT对照]]）
```

SSR 与 IBL 不是竞争关系而是**接力关系**：SSR 补 IBL 的近处细节，IBL 兜 SSR 的屏幕外世界。现代引擎的 glossy 反射 = SSR 优先 + 环境贴图兜底，按命中状态混合。

## 本篇结论

$$
\boxed{
\text{SSR}
=
\underbrace{\text{反射方向的射线}}_{\text{需要的是辐射}}
+
\underbrace{\text{深度场上的屏幕空间步进}}_{\text{免费场的求交}}
+
\underbrace{\text{命中读已渲染颜色}}_{\text{免费的辐射}}
}
$$

> 记忆压缩：**反射就是"看一眼镜子方向的自己这一帧"**——把反射射线压进屏幕坐标，沿深度场走，钻进表面的那一刻，抄走那个像素的颜色。不用体素、不用探针，画面自己照自己。
