# 03 SSAO：在深度场上估那个半球积分

> 本篇在思维链上的位置：**算法与工艺**。[[学习笔记/cg/games202/专题/ss/02-AO的物理-遮蔽积分.md|02 AO 的物理：遮蔽积分从哪来]] 给出目标量 $A(p)=\frac{1}{\pi}\int V\cos\theta\,d\omega$，本篇看它在屏幕空间怎么被估出来、以及每个工程细节在保护什么。

## 核心替代：可见性测试 → 深度比较

把 $V(p,\omega)$ 的可见性判断换成"**对着屏幕里的深度图问一句**"：

```text
从 p 沿方向 ω 走一小段，取一个采样点 q
把 q 投影到屏幕，读深度图：
    depth(q 投影处) < q.z   （屏幕里的表面比 q 更近）
        → 这个方向被挡了
    否则
        → 这个方向敞亮
```

**不发射线、不做场景求交——一次纹理采样顶一条 shadow ray**。这就是屏幕空间方法的全部魔法：深度缓冲被当作一张"2.5D 高度图"，遮挡判断变成图上的高度比较。

$$
\boxed{
A(p)\ \approx\ \frac{1}{K}\sum_{k=1}^{K}
[\text{采样点 } q_k \text{ 没被深度场挡住}]
\qquad\text{（蒙特卡洛估计半球积分）}
}
$$

## 采样怎么摆

| 变体 | 摆法 | 需要什么 |
|---|---|---|
| 球形采样（Crysis 原版） | 在以 p 为中心、半径 R 的**球**内撒点 | 只要深度（用深度差自动判断上下） |
| 半球采样 | 在沿法线的**上半球**内撒点（可余弦加权） | 深度 + 法线 |

球采样版连法线都不用（靠"屏幕上这一点的表面深度"把球切成上下两半），最便宜；半球版更准（真正符合 $\Omega^+$ 积分域）。法线可以从深度图数值差分重建——G-buffer 时代通常直接有现成法线。

## 每个细节都在保护一个积分项

### 半径 R：决定"什么算遮挡"

$$
\text{只有 } p \text{ 附近 R 范围内的几何才算挡光}
$$

- R 太大：一米外的地板、天花板都来"遮挡"，整张图斑驳发黑；
- R 太小：只挡到自己，AO 消失；
- **R 必须用世界单位**（随距离缩放采样半径），否则近处糊远处碎。

### Range check：深度差超过 R 的不算

屏幕里远处的表面虽然"投影到这个方向"，但它离 p 有 20 米——不该参与 AO。采样时对深度差做衰减：

$$
\text{贡献} \times \max\left(0,\ 1-\frac{|z_q - z_{\text{screen}}|}{R}\right)
$$

这一条是工业实现与玩具实现的最大分水岭。

### 自遮挡：起点要沿法线偏一点

p 自己就在表面上，采样点贴着表面出发会把**自己**当遮挡物（整片均匀变黑）。**沿法线偏移一两个 texel** 再投影，或对深度差给一个小容差。

### 噪声 → 模糊

每像素只有 8~32 个采样，直接出结果是噪点。经典处理链：

```text
按 pattern 随机旋转采样方向（每像素不同朝向）
    → 结果是"漂亮的噪"而不是固定条带
    → 深度感知的双边模糊（不跨越深度断崖，避免轮廓糊）
    → 时域累积（上一帧混合）
```

这一套"随机化 + 模糊 + 时域"是所有屏幕空间技术共享的降噪范式，SSR 会原样再演一遍（[[学习笔记/cg/games202/专题/ss/06-SSR进阶-层级追踪与粗糙.md|06 SSR 进阶：Hi-Z 层级追踪与粗糙反射]]）。

## 伪影清单（每条都能指回某个决定）

| 伪影 | 原因 |
|---|---|
| 阴影断裂/条带 | 采样数不足、固定 pattern |
| 均匀发灰（自遮挡） | 没沿法线偏移 |
| 远处地板"挡住"近处点 | 没有 range check |
| 大面积糊黑（晕轮） | 半径 R 过大 |
| 屏幕外的遮挡物缺席 | **深度场只含可见几何**（见 [[学习笔记/cg/games202/专题/ss/07-屏幕空间的共同缺陷.md|07 屏幕空间的共同缺陷：看不见就不算]]） |

最后一条是本质性的：桌子在屏幕里、桌子腿在屏幕外——腿底下的 AO 会被"忘记"。这不是 SSAO 特有的 bug，是整个屏幕空间哲学的税。

## 本篇结论

$$
\boxed{
\text{SSAO}
=
\underbrace{\text{半球采样}}_{\text{积分域}}
+
\underbrace{\text{深度比较替代可见性}}_{\text{免费场}}
+
\underbrace{\text{R/range check/偏移/模糊}}_{\text{工艺}}
}
$$

> 记忆压缩：**在 p 头顶撒一把点，问深度图"每个点被地面挡住了吗"**。挡的比例就是 AO。所有工程细节（半径、容差、偏移、模糊）都在保护那个半球积分的物理含义不被屏幕的离散性破坏。
