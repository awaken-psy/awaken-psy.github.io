# 04 半球采样与屏幕步进：预算的分配艺术

> 本篇在思维链上的位置：**采样**。SSGI 的画质公式里，"每根射线读什么"上一篇已定，本篇定"射线怎么发、怎么走"——余弦重要性采样决定样本的**值**，交错探针网格决定样本的**数**，Hi-Z 步进决定命中的**准**。三个组件全部是老朋友，SSGI 只是给它们换了一套预算。

## 方向：余弦加权的半球采样

漫反射着色的被积函数自带 $\cos\theta$（Lambert 项），重要性采样直接按它分布：

$$
\boxed{
\omega_i \sim \frac{\cos\theta}{\pi}
\qquad\Longrightarrow\qquad
L_{\text{GI}} \approx \frac{1}{N}\sum_{i=1}^{N} L_{\text{hit}}(\omega_i)\,\rho_{\text{albedo}}
}
$$

余弦项已被采样分布吸收——每根样本只需读色乘 albedo，**估计器方差最小化**（与 PRT/离线路径追踪同一套重要性采样数学，[[学习笔记/cg/games202/专题/prt/07-实现管线-预计算与运行时.md|07 实现管线：系数怎么算、怎么存、怎么用]] 的余弦采样估计器遥相呼应）。

## 随机化：让误差变成"均匀的噪声"

样本方向加随机抖动（interleaved gradient noise / 蓝噪声序列，逐像素异相）——目的不是消除误差，而是**把结构性误差（条纹、网纹）打散成高频噪声**，交给 [[学习笔记/cg/games202/专题/ssgi/05-重建-时空降噪.md|05 重建：时空降噪]] 的滤波器收拾。这与 brick 边界加噪（[[学习笔记/cg/games202/专题/apv/05-运行时查询-插值与SH求值.md|05 运行时查询：插值与 SH 求值]]）、抖动一族的思路完全同源：**误差打不散就均匀化，均匀化交给滤波**。

## 数量：交错探针网格——每像素几根，每探针几十根

每像素发 64 根射线是破产价。工业方案（Metro 的 SGGI，也是 [[学习笔记/cg/tuanjie引擎/GI原理/00-全景/01-TuanjieGI是什么.md|TuanjieGI 是什么]] 屏幕层的原型）：

| 设计 | 数值 | 作用 |
|---|---|---|
| 屏幕切成探针格 | 每 **8×8 像素**一个探针 | 代价摊到块上，而不是每像素 |
| 每探针射线 | **64 根**（余弦加权） | 半球积分的基本盘 |
| 探针结果 | 聚合成**八面体方向图 / SH L2** | 方向化的辐照——跟 LPV/APV 存的是同一种货（[[学习笔记/cg/games202/专题/lpv/05-渲染查询-从场中读光.md|05 渲染查询：着色点从场里读出自己的入射光]]） |
| 像素取光 | 块内像素查邻近探针 + 插值 | 8×8×64 = 每像素 **1 根**的等效预算，攒出 64 根的统计量 |

**探针 = 共享样本池**：把"每像素必须独立采半球"的执念换掉，让 64 个像素共用 64 根射线——方差由块承担，细节由重建补。这与 TAA 的"每像素一样本、时间凑帧"是同一个思想在空间维的版本。

## 步进：深度场 + Hi-Z 的老手艺

射线在屏幕空间对**深度缓冲这个 2.5D 高度场**步进求交——整套机制 SSR 已打磨成熟（[[学习笔记/cg/games202/专题/ss/05-SSR-屏幕空间光线步进.md|05 SSR：在自己的画面里找反射]]）：粗步走 Hi-Z 金字塔大步跨越、命中区下钻精步；命中判定用"深度差 + **厚度假设**"（屏幕里没有背面，只能假一个 slab 厚度）。

| | SSR | SSGI 的步进 |
|---|---|---|
| 射线形态 | 一束镜面反射方向（多在最远端命中） | 半球各方向，**大量近距短命中**（墙边、家具边） |
| 步进调校 | 长射线、步长自适应 | 短半径截断 + 近距优先（GI 的贡献集中在近处，配 [[学习笔记/cg/games202/专题/ssgi/03-辐射缓存-上一帧的画面.md|03 辐射缓存：上一帧的画面]] 的距离衰减） |
| 命中后 | 直接读色 | 读色 + 四道拒收关卡 |

厚度假设的软肋原样继承：**薄墙/薄板的背命中**（射线从"背面"穿出去被误判命中）——SSGI 的漏光源头之一，[[学习笔记/cg/games202/专题/ssgi/07-缺陷与混合管线.md|07 缺陷与混合管线：屏幕之外没有世界]] 再算总账。

## 记忆压缩

> **采样三件套：余弦定向、探针共享、Hi-Z 步进**——方向交给重要性采样（方差最小），数量交给交错网格（64 像素共用 64 根，预算从破产价砍到每像素一根），命中交给深度场老手艺（短半径近距优先）。SSGI 的采样层没有新数学，只有**新预算**——钱不够，坑位共享、误差转噪声、滤波兜底。下一站看滤波怎么兜：[[学习笔记/cg/games202/专题/ssgi/05-重建-时空降噪.md|05 重建：时空降噪]]。
