# 05 重建：时空降噪

> 本篇在思维链上的位置：**工程重心**。上一样本 [[学习笔记/cg/games202/专题/ssgi/04-半球采样与屏幕步进.md|04 半球采样与屏幕步进：预算的分配艺术]] 把 GI 估计打成"每像素约一根射线"的噪声信号，本篇的重建管线决定最终画质。两板斧——时间累积（用历史平掉噪声）与空间滤波（用邻居平掉噪声）——以及防止两板斧砸出新 artifact 的安全阀。

## 重建问题的本质

$$
\boxed{
\text{目标：}\;\hat L = L + \varepsilon,
\;\; \varepsilon \sim \text{噪声}
\qquad
\text{手段：}\;\text{时间上平均 } \uparrow \text{ 有效样本数} + \text{空间上平均 } \uparrow \text{ 邻居样本数}
}
$$

噪底来自蒙特卡洛估计的方差 $\propto 1/N$——**累积 K 帧等效于 N×K 个样本**，方差除以 K；空间聚合 M 个邻居再除一次。两轴都是"加样本"，只是样本来自不同的时间与像素。

## 时间累积：指数滑动平均 + 安全阀

```text
命中历史（重投影到本帧，用 motion vector）
  EMA：     L_hist' = α·L_hist + (1−α)·L_curr        （α 高达 0.9+：一帧新样本占一两成）
  安全阀1： clamp 历史到本帧邻域的 [min, max]        （防历史值漂走 → 鬼影/拖影）
  安全阀2： 动态几何/快速运动降 α（history rejection）（刚露出的像素没有可信历史）
```

这套三件套就是 TAA 的全部——**SSGI 是 TAA 的思想在"二次信号"上的重演**：TAA 重建的是抗锯齿位置信号，SSGI 重建的是辐照信号，数学一模一样（[[学习笔记/cg/games202/专题/ibr/16-运动模糊.md|16 运动模糊：快门不为零，像素在积分]] 提过 motion vector 的一份数据两处消费）。

## 空间重建：可分离双边滤波

探针/半分辨率信号升回全屏前，先空间聚合。核不是普通高斯——**边要保住**（法线跳变、深度断层的地方不能把隔壁房间的光混过来）：

| 权重 | 作用 |
|---|---|
| 深度相似 | 别把地板的光糊到桌上 |
| 法线相似 | 别把墙面的光糊到天花板 |
| （进阶）SVGF：方差引导 | 噪声大的区域多糊，干净的区域少糊——**滤波强度自适应噪声** |

工程提速：**可分离滤波**（横一遍竖一遍，O(k²)→O(2k)，[[学习笔记/cg/games202/专题/ibr/11-图像处理.md|11 图像处理：后期滤镜的数学地基]] 的老账）+ 半分辨率重建再上采样。SGGI 的完整版还有一招"方向化存辐照"：探针结果存 SH L2/八面体图再做滤波——**滤波的是 SH 系数**，等于在方向域也做了一次正则化（与 LPV 注入前滤 SH、APV 的 SH 插值同属一族）。

## 重建的失败模式

| Artifact | 根源 | 对策 |
|---|---|---|
| 鬼影/拖尾 | 历史权重过高 + 移动几何 | history clamp + rejection |
| 边缘渗光 | 空间滤波跨过法线/深度边 | 双边权重 |
| 过糊（细节丢失） | 滤波半径随噪声走极端 | 方差引导的半径 + SSGI 信号本身低频（漫反射 GI 是"糊"得起的量） |
| 闪烁 | 时间累积在快速变化处失效 | rejection + 噪声序列蓝噪声化（误差转高频） |

最后一条是 [[学习笔记/cg/games202/专题/ss/07-屏幕空间的共同缺陷.md|07 屏幕空间的共同缺陷：看不见就不算]] 一族的老结论：**漫反射 GI 恰好是全管线对"糊"最宽容的信号**——它本来就低频，重建的失真大部分落在人眼不敏感的频段。这是 SSGI 敢用"1 根/像素"预算的物理许可。

## 记忆压缩

> **重建 = 时间平均（EMA + clamp + rejection）× 空间平均（可分离双边 + 方差引导）**，两轴都是"凑样本"：TAA 的思想原样重演到辐照信号上。SSGI 的画质下限不取决于采样多聪明，取决于这套重建管线多稳。但时间累积还藏着一个更大的彩蛋——历史里不只攒了样本，还攒了"弹射"：[[学习笔记/cg/games202/专题/ssgi/06-反馈循环-多弹射的诞生.md|06 反馈循环：多弹射的诞生]]。
