# 07 缺陷与混合管线：屏幕之外没有世界

> 本篇在思维链上的位置：**原罪的清算与救赎**。SSGI 把屏幕空间方法推到最高级，也把 [[学习笔记/cg/games202/专题/ss/07-屏幕空间的共同缺陷.md|07 屏幕空间的共同缺陷：看不见就不算]] 继承到最满——信息只来自屏幕，转身它就忘。出路只有一条：承认自己是"细节层"，找一个"持续性层"搭伙。本篇讲清缺陷清单与两层混合的分工哲学。

## 原罪继承清单

| 原罪 | SSGI 的症状 |
|---|---|
| **屏幕外无信息** | 转身红光消失：红墙出了画面，它照进房间的间接光也跟着消失（[[学习笔记/cg/games202/专题/ss/01-屏幕空间方法原理主线.md|屏幕空间方法原理主线：深度缓冲是免费的场景代理]] 的经典演示） |
| **第二视角误差** | 读到的是"朝相机"的辐射——漫反射下勉强豁免，glossy 下露馅（[[学习笔记/cg/games202/专题/ssgi/03-辐射缓存-上一帧的画面.md|03 辐射缓存：上一帧的画面]]） |
| **厚度假设** | 薄墙背命中、薄地板漏光（[[学习笔记/cg/games202/专题/ssgi/04-半球采样与屏幕步进.md|04 半球采样与屏幕步进：预算的分配艺术]] 继承自 SSR 的老伤） |
| **动态场景砍时间累积** | 快速移动/剧烈变化时 rejection 砍掉历史——降噪与多弹同时失效，画面"洗回噪声"（[[学习笔记/cg/games202/专题/ssgi/06-反馈循环-多弹射的诞生.md|06 反馈循环：多弹射的诞生]] 的收敛条件被破坏） |
| **反馈循环的双刃** | 多弹来自历史，历史错了一样会"多弹地错"（鬼影自增殖） |

一句话：**SSGI 的上限被屏幕边界钉死**——屏幕内它近乎完美（像素级、含全部光源、多弹、便宜），屏幕外它不存在。

## 救赎：两层分工的混合管线

[[学习笔记/cg/tuanjie引擎/GI原理/00-全景/01-TuanjieGI是什么.md|TuanjieGI 是什么]] 的哲学句在这里原样生效——**"细节从屏幕来，持续性从世界来"**：

| 层 | 谁来当 | 给什么 |
|---|---|---|
| **细节层**（像素级一弹 + 时空细节） | SSGI / 屏幕踪迹 | 屏幕内高细节的间接光：墙角红光、桌下阴影、emissive 照亮 |
| **持续性层**（视角无关的底座） | APV 探针场（[[学习笔记/cg/games202/专题/apv/01-APV原理主线.md|APV 原理主线：把"摆探针"变成"铺体积"]]）/ DDGI / 世界 Radiosity 场 | 屏幕外的间接光、转身后仍在的反弹、离屏光源 |

两层怎么合：SSGI 命中处读"世界层"，未命中处由世界层兜底；或者按屏幕覆盖率/置信度加权混合：

$$
\boxed{
L_{\text{GI}}(p)
=
w_{\text{screen}}\cdot L_{\text{SSGI}}(p)
+
(1-w_{\text{screen}})\cdot L_{\text{world}}(p)
\qquad
w_{\text{screen}} = \text{屏幕内可命中的置信度}
}
$$

**UE5 Lumen 就是这个架构的工业标准件**：screen traces（本质就是 SSGI 的射线版）+ 世界侧 Final Gather——TuanjieGI 的屏幕层 + Facet 世界层是同一设计哲学的国产镜像。

## 平台分层的现实账

| 平台预算 | GI 组合 |
|---|---|
| 低端/手机 | 只探针（APV / [[学习笔记/cg/games202/专题/apv/08-实现管线与GI赛道对照.md|08 实现管线与 GI 赛道对照]] 一档），SSGI 关 |
| 中端 | 探针底座 + SSGI 细节（或 SSGI 独挑小场景） |
| 高端/光追硬件 | SSGI 让位给 **RTGI**（硬件射线 + ReSTIR/SVGF 降噪，[[学习笔记/cg/games202/专题/ssgi/05-重建-时空降噪.md|05 重建：时空降噪]] 的滤波器原样复用） |

注意最后一行：**SSGI 与 RTGI 的差距只在"射线怎么走"**——SSGI 在屏幕深度场里步进（便宜但受屏幕边界钳制），RTGI 在真实 BVH 里求交（贵但物理正确）。采样、缓存、重建、反馈四层完全共享——这就是为什么硬件光追普及后 SSGI 的工程经验没有作废，只是换了求交器。

## 记忆压缩

> **SSGI 屏幕内近乎完美、屏幕外根本不存在**：原罪不是它的错，是屏幕空间的户口；救赎也只有一条路——当"细节层"，让探针/世界层当"持续性层"。Lumen 与 TuanjieGI 都是这个两层哲学的工业实现，而 SSGI 的采样-缓存-重建-反馈四层功夫在光追时代原样可迁移。终局对照见 [[学习笔记/cg/games202/专题/ssgi/08-实现管线与赛道收官.md|08 实现管线与赛道收官]]。
