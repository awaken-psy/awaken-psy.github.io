# 02 从光探针到 APV：一段"采样点的进化史"

> 本篇在思维链上的位置：**动机与前提**。APV 不是从天上掉下来的——它是烘焙 GI 里"探针"这条路线的终点。先看清两个问题：为什么必须有探针（lightmap 的什么补不了）、探针为什么必须是 SH（一点的"光"到底是个什么函数）——然后手工时代（LPG/LPPV）的三个瓶颈自然推出 APV 的三连升级。

## 烘焙 GI 的两种载体

离线算好的间接光，总要有个"住处"。历史上只有两种选择：

| 载体 | 住在哪 | 覆盖谁 | 致命短板 |
|---|---|---|---|
| **Lightmap（光照贴图）** | 物体**表面**（2D 纹理） | 静态几何，逐纹素 | 动态物体（角色、载具、可动物）**照不到** |
| **光探针** | 场景**空间**（3D 中的点） | 空间里的一切（动态物体路过就采样） | 采样密度极低，全靠手工摆位 |

动态物体是探针存在的全部理由：角色走进红墙的巷子，皮肤上要有红光——贴图长在墙上管不到它，**空间中的"光值"才管得到它**。

## 一颗探针到底存什么：为什么要 SH

探针是空间中一点 $p$ 的间接光答案。但"一点的光"不是三个数——从这点四周望去，每个方向亮度都不同（窗户方向亮、墙角方向暗）。漫反射着色恰恰要问的是**任意法线方向**的入射光：

$$
\boxed{
\text{探针} \;=\; \text{一个定义在方向上的函数：}\; L(p,\,\omega)
\quad\xrightarrow{\ \text{低频，SH 压缩}\ }\quad
\text{少量系数}
}
$$

为什么是 SH 而不是 cubemap：间接漫反射光是极低频的信号（[[学习笔记/cg/games202/专题/prt/04-球谐函数.md|04 球谐函数：球面上的正交基]] 的截断讨论），低频信号用几个系数就够——**探针的存储预算逼着它选最狠的压缩**。这与 PRT 压传输、IBL 压光照是同一个判据（[[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]] 的频率内容决定系数数量）。

## 手工时代：Light Probe Group 的三个瓶颈

经典方案（LPG）：美术手工摆一堆探针点，运行时把物体包进四面体、按重心坐标插值四个角的探针。

| 瓶颈 | 症状 |
|---|---|
| **摆位靠玄学** | 探针密度与光照复杂度无关——亮暗突变处没摆点就糊成一片，摆密了又浪费 |
| **点云拓扑差** | 四面体插值要求点云"合理"，过稀过密、贴墙穿墙都会出错 |
| **覆盖靠耐心** | 大世界里手工铺探针？没人铺得完 |

LPPV（Light Probe Proxy Volume）给了个局部补丁：给单个大物体自动生成一个局部探针盒——但场是"每物体各自的"，场景级的问题没解决。

## APV 的三连升级

| 升级 | 手工时代 | APV |
|---|---|---|
| **自动放置** | 美术逐个摆 | 拉一个 Volume，引擎按几何密度生成探针 |
| **自适应密度** | 均匀（其实是不均匀的乱） | 几何密集处细、空旷处粗（brick 细分级，[[学习笔记/cg/games202/专题/apv/03-砖块与自适应细分.md|03 砖块与自适应细分：结构层的智慧]]） |
| **场景级覆盖** | 局部点云 | 全局/局部 Volume + cell 流式，大世界按需加载 |

## 辨析：APV 与 lightmap 是分工，不是你死我活

| | Lightmap | APV |
|---|---|---|
| 住处 | 表面 2D 纹理 | 空间 3D 探针场 |
| 静态几何间接光 | 逐纹素，极精细 | 探针粒度，偏"雾化" |
| 动态物体 | ✗ | ✓（插值探针） |
| 方向性 | 无（flat 档）或贴图自带 | SH，有 |
| 内存 | 大（间接光也全贴图） | 小（约 32 字节/探针，[[学习笔记/cg/games202/专题/apv/04-烘焙-探针里存什么.md|04 烘焙：探针里存什么]]） |
| 烘焙时间 | 长（全表面采样） | 较短 |

社区实践常直接"只用 APV 烘间接光 + 实时直接光 + 实时 AO"——lightmap 的岗位被拆走一半。**选择标准回到产品：要纹素级精度的静态特写用 lightmap，要大世界 + 动态物体 + 流式就用 APV**——[[学习笔记/cg/games202/专题/ibr/02-渲染谱.md|02 渲染谱：从几何到图像的连续谱]] 的账本在这里又一次生效。

## 记忆压缩

> **贴图住表面、探针住空间**：动态物体是探针存在的全部理由，SH 是探针存下"方向上的光"的唯一经济手段，而 APV 干的事就是把"摆点"自动化、把密度自适应化、把覆盖体积化。下一站进到它最漂亮的结构发明——brick：[[学习笔记/cg/games202/专题/apv/03-砖块与自适应细分.md|03 砖块与自适应细分：结构层的智慧]]。
