# 04 烘焙：探针里存什么

> 本篇在思维链上的位置：**内容**。结构（brick）只是容器，本篇讲每颗探针里到底装什么、怎么算出来、以及三个不存"光照"的副频道——validity、virtual offset、天空可见度。存储方案的每个选择都踩在同一条老判据上：辐照度是低频信号。

## 烘焙：一次离线的积分

对每颗探针位置 $p$，Progressive（GPU）Lightmapper 从 $p$ 向四周**大量投射光线、沿光路积分**，得到该点"从各方向进来的间接光"，再把方向函数投影到 SH（投影的数学在 [[学习笔记/cg/games202/专题/prt/03-函数即向量-基函数与投影.md|03 函数即向量：基函数、投影与正交]]）：

$$
\boxed{
c_k(p)
=
\int_{\Omega}
L(p,\omega)\,
\max(0,\,\omega\cdot\mathbf n)\,
B_k(\omega)\,d\omega
\quad\text{——按法线余弦加权过的辐照度系数}
}
$$

一个重要的措辞：**探针存的是"辐照度"（irradiance）不是"辐射度"（radiance）**——烘焙时已经把 $\cos$ 卷积进去了（上式的 $\max(0,\omega\cdot n)$）。于是运行时求值不需要再加 Â 修正（对照 [[学习笔记/cg/games202/专题/prt/05-漫反射PRT-从积分到点乘.md|05 漫反射 PRT：把整个渲染方程压成一次点乘]] 里"辐射度系数 → 辐照度"那一步修正），**查询更便宜，这正是探针为运行时预算做的取舍**。

## L1 / L2：档位与信号学

| 档 | 每通道系数 | RGB 总系数 | 直觉 |
|---|---|---|---|
| **L1** | 4（1 常数 + 3 线性） | 12 | "一个平均色 + 一个主方向" |
| **L2** | 9 | 27 | 双峰可辨，更锐利 |

为什么 L1 是默认甜点档：**辐照度是极平滑（模糊）的信号**，一个"平均亮度 + 主亮方向"就刻画了大部分场景。经典反例：**暗室里两盏强灯同时照到一点**——方向函数出现双峰，L1 只能摆出一个折中的"中间方向"，L2 才摆得下两个峰。这个"系数数量 vs 信号频率"的账，与 [[学习笔记/cg/games202/专题/prt/04-球谐函数.md|04 球谐函数：球面上的正交基]] 的截断讨论是同一笔。

## 存储编码：32 字节装下一颗探针

工程上 APV 把一颗探针的辐照度压到约 **32 字节**：

| 手段 | 说明 |
|---|---|
| L1 = 12 系数 | 恰好装进 3 张 RGBA 纹理（每通道 4 系数） |
| **Frostbite 式有界压缩** | 辐照度的 L1 项可被 L0 项上界约束 → 其中一张纹理能压进 LDR 范围，HDR 只留给真正需要的部分 |
| brick/纹理化组织 | 3D 纹理 + brick 索引，采样走硬件三线性 |

"辐照度系数间存在不等式"这种结构性冗余，是压缩的最后一块肉——和 IBL 把 Schlick 拆成 scale/bias 存 LUT（[[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]]）是同一种"利用已知关系省存储"的手艺。

## 三个不存光照的副频道

| 频道 | 内容 | 谁消费 |
|---|---|---|
| **validity** | 每探针一个二值状态：位于几何内部/采样不一致 → 无效 | 运行时插值时**排除或降权**无效探针（[[学习笔记/cg/games202/专题/apv/06-漏光与修补.md|06 漏光与修补：几何不进场的代价]] 的主力） |
| **virtual offset（虚拟偏移）** | 探针离几何太近/太贴墙时，记录一个自动外推的方向修正 | 采样位置在查询前先做平移（[[学习笔记/cg/games202/专题/apv/05-运行时查询-插值与SH求值.md|05 运行时查询：插值与 SH 求值]]） |
| **天空可见度（sky occlusion）** | 探针对天空的可见程度（+ 主方向） | 运行时拿**当前**天空重新积分——动态昼夜的钥匙（[[学习笔记/cg/games202/专题/apv/07-天空遮蔽与光照场景.md|07 天空遮蔽与光照场景：把可变的拆出来]]） |

validity 与 virtual offset 都在干同一件事：**把"几何与探针的相对位置"这个烘焙时才知道的信息，提前存进答案里**——几何本身不进场，但它的"影子"以校正量的身份进了场。

## 记忆压缩

> **一颗探针 = 余弦卷积过的 SH 辐照度 + 三个校正频道**。L1 四系数说"平均色 + 主方向"，两盏灯的双峰才轮到 L2；辐照度系数间的上界关系把一颗探针压到 32 字节。而 validity/偏移/天空可见度告诉我们：**APV 存的不只是光，还有"生成这颗探针时几何长什么样"的记忆**。下一站看这套数据怎么被花掉：[[学习笔记/cg/games202/专题/apv/05-运行时查询-插值与SH求值.md|05 运行时查询：插值与 SH 求值]]。
