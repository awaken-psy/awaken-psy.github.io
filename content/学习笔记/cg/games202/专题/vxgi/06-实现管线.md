# 06 VXGI 实现管线：三大 pass 与真实的账单

> 本篇在思维链上的位置：**落地**。前四篇攒出了完整机制，本篇把它们排进每帧的 pass 结构，并把 VXGI 贵在哪、贵多少讲清楚。

## 每帧流水线

```mermaid
flowchart LR
    A["Pass 1 体素化<br/>3 向保守光栅化 → SVO"] --> B["Pass 2 光照注入<br/>shadow map 判定 → 烤入叶子 → 自底向上 mip"]
    B --> C["Pass 3 锥形追踪<br/>每像素 9+1 锥，α 合成"]
    C --> D["合流<br/>直接光 + 间接光"]

    classDef process fill:#4a90d9,stroke:#2980b9,stroke-width:2px,color:#fff
    classDef output fill:#3bb4c1,stroke:#16a085,stroke-width:2px,color:#fff
    class A,B,C process
    class D output
```

| Pass | 内容 | 频率 | 主要消耗 |
|---|---|---|---|
| 1 体素化 | 三向保守光栅化、写 α/albedo/normal、更新 SVO | 静态场景一次；**动态场景每帧** | 光栅化 ×3 + 原子写入 |
| 2 光照注入 | shadow map 可见性判定 → 叶子烤直射光 → 自底向上 mip | 每帧（光会动） | SVO 遍历 + 逐层归约 |
| 3 锥形追踪 | 漫反射 9 锥 + 镜面 1 锥，每锥 N 步 mip 采样 | 每帧全屏 | **像素 × 锥 × 步 的采样海啸** |

两弹 GI（[[学习笔记/cg/games202/专题/vxgi/03-光照注入与体素mip链.md|03 光照注入：把直射光烤进体素 mip 链]]）即：Pass 2 追加一轮"把上一帧锥追结果再注入再 mip"。

## 性能账：贵在 Pass 3

粗算一笔（1080p、9+1 锥、每锥 ~10 步）：

$$
2\,\text{M 像素}\ \times\ 10\ \text{锥}\ \times\ 10\ \text{步}\ \approx\ 2\times10^8\ \text{次 3D 纹理采样 / 帧}
$$

每次采样含：SVO 寻址 + mip 层间三线性（8 tap）+ α/光双通道。**这就是"拉"的代价**：LPV 把全场算一次推出去，VXGI 每个点自己拉 100 次。

### 标准降级手段

| 手段 | 思路 |
|---|---|
| **半分辨率锥追** | 间接光低频 → 1/2 或 1/4 分辨率跑 Pass 3，再双边上采样 |
| 距离裁剪 | 只对近处做锥追，远处退化为 IBL 天空/探针 |
| 提前终止 | $\alpha_{\text{acc}}\to1$ 就停（被墙挡住后面的步全省） |
| 稀疏性 | SVO 空节点整枝跳过（锥追在空旷处大步流星） |

半分辨率 + 双边上采样是几乎所有落地实现的标配——因为间接光本来就是低频的（这句结论再次来自频率论证：[[学习笔记/cg/games202/lecture6 Real-time Environment Mapping 2.md|lecture6 Real-time Environment Mapping 2]]）。

## 内存账

| 结构 | 量级 | 说明 |
|---|---|---|
| SVO（$128^3\sim256^3$ 叶子） | 数百 MB 级 | α + albedo + normal + 光照 radiance，多通道 ×3 |
| mip 链 | 随层数线性小增长 | 高层体素少、快速稀疏 |
| 稀疏化 + clipmap | 砍到几十 MB~百 MB | 只存相机周围 / 有几何处；远处直接没数据 |

对照：LPV 的光场只要 **0.6MB**（[[学习笔记/cg/games202/专题/vxgi/06-实现管线.md|06 VXGI 实现管线：三大 pass 与真实的账单]]）。**"拉"的遮挡精度是用内存和采样数买回来的**——这笔账决定 VXGI 只在中高端硬件 + 静态为主的场景里划算。

## 与 LPV 管线的并排对照

| | LPV | VXGI |
|---|---|---|
| 场的内容 | 光（SH） | 几何（α/albedo/normal）+ 光 |
| 场的尺寸 | ~MB | 数百 MB |
| 每帧建场成本 | 注入+传播（小） | 体素化+mip（大，动态场景每帧） |
| 着色成本 | 1 次场采样 | ~100 次 mip 采样 |
| 遮挡 | 无 | α 合成近似 |

两个方法共享"每帧动态 GI"的目标，成本结构恰好互补：**LPV 便宜在查询、亏在场的信息量；VXGI 贵在查询、赢在场的信息量**。

## 本篇结论

$$
\boxed{
\text{VXGI 每帧}
=
\underbrace{\text{体素化}}_{\text{大，可离线/增量}}
+
\underbrace{\text{注入 + mip}}_{\text{中，每帧}}
+
\underbrace{\text{锥追} \times 10\ \text{锥}}_{\text{像素级采样海啸}}
}
$$

> 记忆压缩：**建场贵、充光中、查询狂**。三个 pass 的成本分布注定它要靠"半分辨率 + 静态体素化 + 提前终止"三条命活着。
