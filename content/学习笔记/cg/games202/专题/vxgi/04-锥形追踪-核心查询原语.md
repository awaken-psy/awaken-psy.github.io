# 04 锥形追踪：一次查询同时拿到平均光与沿途遮挡

> 本篇在思维链上的位置：**核心原语**。场已备好（几何 SVO + 预滤波光），本篇解决 VXGI 与 LPV 拉开差距的那一步：如何让着色点**自己**从场里拉出"光 + 挡光"，一次搞定。

## 锥：把"一束方向"打包成一次查询

对着色点，间接光来自一个**方向范围**（漫反射是整个半球，glossy 是绕镜面方向的一片）。逐方向发 ray marching 太贵。VXGI 的解法是**锥形追踪**：

$$
\text{锥} = (\text{起点 } p,\ \text{方向 } \mathbf d,\ \text{半角 } \theta)
\qquad
r(t) \approx t\cdot\tan\theta
$$

```text
        ╲        ╱   ← 锥随距离张开的半径 r(t)
         ╲      ╱
          ╲    ╱   ← 沿轴一步步走，每步查 mip 的一个点
           ╲  ╱
            ╲╱
            p        起点：着色点（沿法线偏一点避免自交）
```

一次锥追 = **同时对一束方向积分**（预滤波的意义，[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的"先平均再查"思想从 2D 天空搬到了 3D 场），且天然处理"距离越远越该看糊层"。

## 沿锥步进：半径决定 mip 层

锥在位置 $t$ 处的横截面半径 $r(t)$ 不断变大。**用半径去选 mip 层**：

$$
\boxed{
\text{level}(t)
=
\log_2\!\left(\frac{r(t)}{\text{叶子体素尺寸}}\right)
}
$$

```text
锥的窄头 → 查细层（近处锐利：谁在旁边、光从哪个小方向来）
锥的宽尾 → 查糊层（远处粗糙：远处环境光的平均）
层与层之间三线性插值（半径连续 → 层级连续）
```

这正是 IBL 的"瓣有多大，mip 有多高"的 3D 翻版——只是粗糙度换成了**锥的物理半径**。

## 遮挡藏在 α 里：前到后合成

体素场里除了光还有**几何的 α（占据程度）**。沿锥前到后合成（front-to-back alpha blending）：

$$
\boxed{
\begin{aligned}
C &\ {+}{=}\ (1-\alpha_{\text{acc}})\cdot\alpha_v\cdot L_v\\
\alpha_{\text{acc}} &\ {+}{=}\ (1-\alpha_{\text{acc}})\cdot\alpha_v
\end{aligned}
}
$$

读法：**前面的体素先报名**（乘上剩余透光率 $1-\alpha_{\text{acc}}$）；越往后的体素，被前面挡得越多，贡献越打折扣；一旦 $\alpha_{\text{acc}}\to1$（锥被堵死），后面全部不要。**"锥里先撞到谁、谁挡住了谁"——遮挡近似就住在 α 合成里。**

对照 LPV：传播算子里没有遮挡的位置 → 光逢格必过。VXGI 从查询方向入手，**不额外花一步**，遮挡顺路解决——这就是"拉"对"推"的结构性优势。

## 伪代码

```python
def cone_trace(p, d, half_angle, max_dist):
    C, a_acc, t = 0.0, 0.0, start_offset
    while t < max_dist and a_acc < 1.0:
        r = t * tan(half_angle) + 1.0          # 锥横截面半径（+起始voxel）
        level = log2(r / leaf_size)            # 半径 → mip 层
        (a_v, L_v) = sample_SVO(level, p + t*d)  # 三线性采样 α 与预滤波光
        C    += (1 - a_acc) * a_v * L_v        # 前到后合成
        a_acc += (1 - a_acc) * a_v
        t += max(r * step_ratio, min_step)    # 按当前半径前进
    return C                                   # 该锥方向的平均间接光
```

三个工程要点：起点沿法线偏移一两个体素（防自交）；步长按当前半径伸缩（宽处迈大步）；α 低于阈值时提前终止（远处空旷直接跳）。

## 遮挡近似的账单

α 是**占据概率**而非几何实体，于是遮挡近似有三笔误差：

1. **单点采样**：锥在某一层只采一个点代表整个横截面 → 锥切到墙角时结果抖动/条带（噪声的来源，[[学习笔记/cg/games202/专题/vxgi/07-问题与边界.md|07 VXGI 的问题与边界：每个瑕疵指回推导现场]]）；
2. **糊层混面**：高层体素把"墙前 + 墙后"两个表面平均进一个 α → 遮挡变软（远处漏光）；
3. **α 概率化**：半透明的格子让"可能挡住"变成"部分挡住" → 阴影偏浅。

修补方向：同一锥内抖动/多次采样、各向异性 mipmap——都是老朋友"频率/采样预算"的谈判。

## 本篇结论

$$
\boxed{
\text{锥形追踪}
=
\underbrace{\text{一束方向}}_{\text{预滤波：一次查询}}
+
\underbrace{\text{半径} \to \text{mip 层}}_{\text{多尺度}}
+
\underbrace{\alpha\text{ 合成}}_{\text{遮挡近似}}
}
$$

> 记忆压缩：**沿锥走、按宽度查层、先到先得**。锥的两重身份：方向上它是"一次问一束方向"；空间上它是"自动从细层滑向糊层"的多尺度查询。
