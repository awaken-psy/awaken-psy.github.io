# 05 漫反射锥组与镜面锥：怎么摆锥，就是什么材质

> 本篇在思维链上的位置：**材质出现在摆锥策略里**。锥形追踪（[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]）只回答"这一束方向的光"。漫反射要整个半球、镜面只要一束——**材质不同，摆锥的姿势不同**。

## 漫反射：9 个锥铺满上半球

漫反射的间接 irradiance 是半球方向积分。一根锥的张角做不了太宽（太宽 → 起点附近就查到非常糊的层，信息全毁），所以课程口径**用 8~9 个锥拼出半球**：

```text
              ·  n                 锥组：
           ·（ ）·                  1 根沿法线 n
        ·（  ）   ·                8 根环绕（在半球面上均匀摆开，
          （ ）（ ）                 半角约 30°~60°，互相搭肩）
        ·—————— ————·
```

$$
\boxed{
E_{\text{indirect}}
=
\sum_{i=1}^{9}\ w_i\cdot\underbrace{\text{cone\_trace}(p,\ \mathbf d_i,\ \theta_i)}_{\text{一束方向的平均辐射}}
\qquad
L_o^{\text{diffuse}} = \frac{\rho}{\pi}\,E
}
$$

**9 个锥的物理意义**：把连续的半球方向积分**离散成 9 片方向区域**，每片"先平均再查"（锥追就是那片区域的预滤波采样）。这正是 [[学习笔记/cg/games202/专题/ibl/03-漫反射-辐照度图.md|03 漫反射 IBL：辐照度图]] 里"用低通核卷积光照"的采样版——只是光照不再是无限远的 2D 图，而是带遮挡的 3D 场，所以卷积变成了逐点锥追。

> 为什么不用 1 个 90° 的大锥？锥越宽，锥面越早撞进"很糊的高层"——半球的预滤波过头，间接光糊成一锅。9 个窄锥是"方向分辨率"和"每像素成本"的折中。

## 镜面：1 根锥，张角 = 粗糙度

Glossy/镜面反射集中在**镜面方向** $r$ 附近，瓣的宽度由粗糙度决定。VXGI 直接用一根锥：

$$
\boxed{
\text{specular}
=
\text{cone\_trace}\big(p,\ r,\ \theta(\text{roughness})\big)
\qquad
\theta\ \text{随粗糙度增大}
}
$$

这里出现全笔记最美的一次跨专题对仗——**GGX 瓣 ↔ 锥角**：

| | IBL split-sum | VXGI 镜面锥 |
|---|---|---|
| 瓣的表达 | GGX 核 → 决定**查 mip 哪一层**（[[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]]） | GGX 瓣 → 决定**锥的张角** |
| 材质积分项 | BRDF LUT（[[学习笔记/cg/games202/专题/ibl/06-BRDF查找表.md|06 BRDF 查找表：把材质积分压成一张 2D 纹理]]，$R_0$ 线性拆分） | **不需要**（锥追顺路把"这一束方向的 BRDF 加权平均"直接拿走了） |
| 高频能力 | 高（保留到 mip 第 0 层的锐利） | 低（锥宽 ≥ 体素尺寸，镜面被体素分辨率封顶） |

$$
\boxed{
\text{GGX 瓣有多宽，锥就张开多大}
\quad
\text{——同一句"瓣大查糊、瓣小查锐"，IBL 用在 mip 上，VXGI 用在锥角上}
}
$$

VXGI 省掉 LUT 的代价：**镜面质量被体素分辨率和 α 概率化封死**——它适合"低频镜面 GI"，不适合清晰的锐利反射。

## 能量视角小结

| 材质 | 锥的摆法 | 对应的积分近似 |
|---|---|---|
| 漫反射 | 9 锥覆盖半球 + 权重求和 | irradiance 环境卷积的采样版 |
| Glossy | 1 锥沿 $r$，张角 ∝ 粗糙度 | GGX 瓣内的一次性平均 |
| 完美镜面 | 张角→0（就是一根 ray marching） | 退化为 SDF/光线追踪——**不属于 VXGI 的舒适区** |

## 本篇结论

$$
\boxed{
\text{材质}
=
\text{摆锥策略}
\qquad
\text{漫反射}\to\text{9 锥求和}\quad\text{镜面}\to\text{1 锥，粗糙度定张角}
}
$$

> 记忆压缩：**漫反射朝天摆一圈伞，镜面顺着倒影方向开一把枪**。锥的宽窄 = 瓣的胖瘦 = 查询的糊锐——IBL 与 VXGI 在这里说出了同一句话。
