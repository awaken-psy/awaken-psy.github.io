# 03 光照注入：把直射光烤进体素 mip 链

> 本篇在思维链上的位置：**给场充上光**。[[学习笔记/cg/games202/专题/vxgi/02-体素化-把场景变成格点.md|02 体素化：把三角形的世界变成格点世界]] 建好了"几何场"，本篇回答：间接光的**源**在哪里？答案：被直射光照亮的体素，就是间接光的源——然后自底向上一层层**预滤波**。

## 注入：每个可见体素 = 一个粗化的 VPL

对照 RSM（[[学习笔记/cg/games202/专题/lpv/02-RSM-反射阴影贴图.md|02 RSM 反射阴影贴图：把"被照亮的表面"收集起来]]）看最快：

| | RSM | VXGI |
|---|---|---|
| 二级光源的载体 | shadow map 像素（百万个） | **叶子体素**（少几个量级） |
| 从谁的视角判定"被照亮" | 光源 | 光源（一张 shadow map） |
| 存什么 | 位置/法线/通量 | 位置（格子）/albedo/normal + **直射光 → 反射 radiance** |

流程：从光源渲染 shadow map → 对每个**有几何的叶子体素**查一次遮挡 → 未被挡住的体素获得直射光 → 按体素 normal 与 albedo 算出**它将向场景反射的 radiance**，烤进体素。

$$
\boxed{
L_{\text{leaf}}(\omega)
=
\underbrace{f_r(\text{体素normal},\ \omega)}_{\text{当 diffuse：} \rho/\pi}
\times
\underbrace{L_{\text{direct}}}_{\text{shadow map 判定}}
}
$$

> 读法：**"场景里所有被太阳照到的地方"被一次登记进体素**。这一步与 LPV 注入（[[学习笔记/cg/games202/专题/lpv/03-注入-从VPL到格子场.md|03 注入：把 VPL 倒进格子场]]）的区别：LPV 把光注入"光场"，VXGI 把光注入"几何+光二合一的场"——体素既发光又挡光，这是后面遮挡近似的物质基础。

## 自底向上 mip：把预滤波思想搬进 3D

叶子体素烤上光后，**逐层向上聚合**：

```text
父体素的 radiance = 8 个子体素 radiance 的加权平均（含 α 权重）
        level k-1          ← 每上一层，信息在 2 倍边长上被"糊匀"
父体素的 α          = 子体素 α 的聚合
```

这一步就是 [[学习笔记/cg/games202/专题/ibl/05-预滤波环境贴图.md|05 预滤波环境贴图：把"光照均值"烧进 mip 链]] 的 3D 重演：

| | IBL 的 mip | VXGI 的 mip |
|---|---|---|
| 滤波对象 | 天空（无限远、全场景共享） | **场景自己**（有位置、有遮挡） |
| 层级索引 | 粗糙度 | **锥的半径**（[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]） |
| 滤波意义 | "瓣有多大，mip 有多高" | "锥走多远半径多宽，查多糊的层" |

$$
\boxed{
\text{SVO 的 mip 层} \equiv \text{“场景自照明”在不同空间尺度上的预滤波版本}
}
$$

**“IBL 是把天空压成 mip 图，VXGI 是把场景压成 mip 场”** ——查询逻辑自然也就从"查一次"推广成"沿锥查一路"。

## 第二弹：迭代注入

到此为止只算了一弹（直射光 → 体素反射）。想要两弹 GI，再走一轮：把**上次锥形追踪收集到的间接光**也烤回体素（作为新的入射光），重新 mip——**注入与查询交替迭代**，每轮 GI 弹数 +1。课程口径：实践中做**约两弹**；更多弹在动态成本下不划算。

```text
弹 1：direct light → 体素 → mip → 锥追收集（一弹 GI）
弹 2：把一弹结果再注入 → 再 mip → 再锥追（两弹 GI）
```

## 本篇结论

$$
\boxed{
\text{注入}
=
\underbrace{\text{shadow map 判定可见}}_{\text{谁的表面被照亮}}
\times
\underbrace{\text{反射 radiance 烤进叶子}}_{\text{成为间接光源}}
\times
\underbrace{\text{自底向上 mip}}_{\text{空间尺度的预滤波}}
}
$$

> 记忆压缩：**太阳晒到哪块乐高，哪块就是新灯**；然后把灯的光在金字塔里层层调匀——高处代表"一大片糊匀的区域光"，低处代表"一格一格的锐利小灯"。接下来每个着色点要做的，就是决定"该看哪一层、看多远"。

那个决定就是锥形追踪——全专题的核心原语，下一站：[[学习笔记/cg/games202/专题/vxgi/04-锥形追踪-核心查询原语.md|04 锥形追踪：一次查询同时拿到平均光与沿途遮挡]]。
