# 04 水库采样 WRS：O(1) 的流式赢家

> 本篇在思维链上的位置：**核心发明二**。RIS 的最后一步"以正比权重选一个"看着要存全部候选——水库采样（Weighted Reservoir Sampling, WRS）证明只需要**三个变量**就能流式做到，而且水库之间可以**合并**。合并律是整个"时空复用"的引擎。

## 水库：三个变量的赢家

每像素一个水库，状态只有三样：

```text
reservoir = {
    y      : 当前赢家（样本，如灯索引）
    w_sum  : 见过的所有候选权重之和
    M      : 见过的候选总数
}
```

流式更新：来一个新候选 $(x_i, w_i)$——

$$
\boxed{
w_{\text{sum}} \leftarrow w_{\text{sum}} + w_i,\qquad
M \leftarrow M+1,\qquad
P(\,y \leftarrow x_i\,) = \frac{w_i}{w_{\text{sum}}}
}
$$

**归纳一下就知道它正确**：第 $i$ 个候选在到达时以 $w_i/w_{\text{sum}}$ 上位，之后每个新来者都只会以更小的概率把它挤掉——最终每个候选获胜的概率恰是 $w_i/w_{\text{sum}}$（对所有到达顺序成立）。RIS 要的"按权重抽一个"在 O(1) 状态下完成，**不需要存任何候选列表**。

## 合并律：复用的引擎

两个水库（各自做完流式选择后）合并，只要把"对方整体"当作一个新候选：

$$
\boxed{
w_{\text{sum}} \leftarrow w_A+w_B,\qquad
M \leftarrow M_A+M_B,\qquad
P(\text{保留 } A \text{ 的赢家}) = \frac{w_A}{w_A+w_B}
}
$$

一眼看穿：**合并水库 = 把两边的候选池拼起来重新抽一次**，而不用真的碰任何候选——这正是 [[学习笔记/cg/games202/专题/restir/05-时空复用.md|05 时空复用：邻居的赢家也是候选]] 能"白拿邻居的 64 个候选"的原因。M 相加还让"我总共见过多少候选"这笔账自动记准——它直接进 [[学习笔记/cg/games202/专题/restir/03-RIS-重采样重要性采样.md|03 RIS：重采样重要性采样]] 估计器的 $1/M$。

## 工程账：为什么它天生适配 GPU

| 性质 | 收益 |
|---|---|
| 状态 12–24 字节（$y$ + $w_{\text{sum}}$ + $M$ + 少量簿记） | 常驻寄存器/低带宽，无需中间缓冲 |
| 候选逐个到达即可处理 | 与"每周期查一盏灯"的流式循环天然契合 |
| 合并 = 几次乘加，零射线 | 邻居/历史复用的单价近乎为零 |

伪码（一个像素的初始生成阶段）：

```glsl
Reservoir r = init();
for (int i = 0; i < M; ++i) {
    uint lightId = sampleLight(p_source);   // 便宜的源分布
    float w = unshadowedContribution(lightId) / p_source(lightId);
    update(r, lightId, w);                   // P(换人) = w / w_sum
}
// 此后：r.y ≈ 从"逐像素理想分布"重采样出的赢家
```

## 辨析：与经典数据结构采样器

- **别名表/CDF**：完美 IS 的查询结构，但必须**预先构建**——[[学习笔记/cg/games202/专题/restir/02-多光的采样困境.md|02 多光的采样困境：理想分布拿不到]] 已证逐像素构建付不起；水库是它的流式替身，分布边来边估；
- **分层/抖动**（[[学习笔记/cg/rt in one weekend/rest_life/02-简单蒙特卡洛与分层采样.md|第 2 章：简单蒙特卡洛与分层采样]]）：改善样本的"空间布点"；WRS 改善的是"**选择**"——两者正交，可叠加；
- 水库的随机性集中在"换人时刻"，与蓝噪声序列配合可以把残留方差均匀化（交给降噪器，[[学习笔记/cg/games202/专题/ssgi/05-重建-时空降噪.md|05 重建：时空降噪]] 的下游）。

## 记忆压缩

> **水库 = 三个变量记住一个赢家**：$w_{\text{sum}}$ 管账、$M$ 记人数、$y$ 存冠军；新候选按 $w_i/w_{\text{sum}}$ 随时上位，归纳保证最终概率恰比权重。**合并律让两个水库拼池子不用碰候选池**——这是 ReSTIR 敢把"上一帧、邻像素"当候选池的物理基础。下一站就是那个大胆的动作：[[学习笔记/cg/games202/专题/restir/05-时空复用.md|05 时空复用：邻居的赢家也是候选]]。
