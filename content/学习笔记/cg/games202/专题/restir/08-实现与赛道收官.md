# 08 实现与赛道收官

> 本篇在思维链上的位置：**收官**。先看 GPU 上的 ReSTIR 长什么样（数据布局、护栏、与降噪器的接缝），再把它放进多光谱系与 GI 赛道终局——在那里它的身份是：**RTRT"算"派的样本复用引擎，采样-重建两件套里的采样器**。

## GPU 实现速写

| 件 | 做法 |
|---|---|
| 水库布局 | 12–24 字节（样本 id、$w_{\text{sum}}$、$M$、可选 MIS 簿记），常驻寄存器/小缓冲 |
| 候选生成 | 源分布 $p$：灯表上均匀或能量加权抽样；流式进水库（[[学习笔记/cg/games202/专题/restir/04-水库采样WRS.md|04 水库采样 WRS：O(1) 的流式赢家]]） |
| 空间复用 | 每像素随机选 2–3 个邻居，法线/深度 gate + [[学习笔记/cg/games202/专题/restir/06-偏置与GRIS.md|06 偏置与 GRIS：跨域复用的无偏化]] 的三件套换算 |
| 时间复用 | motion vector 重投影历史水库 + 动态/出屏拒绝 |
| 可见性 | **只对每像素最终赢家打一根阴影射线**——预算的钉子户 |
| 随机性 | 逐像素逐帧确定性种子 + 蓝噪声/IGN 相位（残留方差转高频，交给下游） |
| 下游 | 降噪器（SVGF/AML 一族，[[学习笔记/cg/games202/专题/ssgi/05-重建-时空降噪.md|05 重建：时空降噪]]）——ReSTIR 输出的仍是有噪估计 |

最后一行值得再强调：**ReSTIR 不消灭噪声，它把"该在哪儿采"的方差吃掉，把"每像素只有一根"的方差留给降噪器**——两件套各管一半，缺一不可。

## 工业落地

| 产品 | 用法 |
|---|---|
| **NVIDIA RTXDI** | ReSTIR 的工程化/驱动化版本；Cyberpunk 2077 的 RT: Overdrive 用它扛海量动态光源的直射 |
| **Unreal（RTXDI / MegaLights）** | UE 光追直射与 MegaLights（UE5.5+ 多光方案）同属重采样家族——百万灯实时直射的产品化 |
| **Alan Wake 2** | 全路径追踪模式 = ReSTIR PT + 降噪器——"游戏里跑全 PT"的第一代工业证据 |

## 多光谱系终局：从"压少"到"选对"

| | 压少派（VPL/Lightcuts/RSM→LPV） | 选对派（ReSTIR） |
|---|---|---|
| 对百万灯的态度 | 聚类/近似成少量代理光 | 保留全部灯，只挑对的看 |
| 数据结构 | 树/格（灯单） | 水库（O(1)/像素） |
| 逐像素分布 | 全局一套 | **逐像素逼近理想 IS** |
| 动态灯 | 结构要重建 | 天然支持（每帧重新采样） |
| 硬件门槛 | 低（raster 时代设计） | **需要光追**（那根阴影射线要打真 BVH） |

读法：**压少派是 raster 时代的答案（结构换精度），选对派是 RTRT 时代的答案（样本换结构）**——[[学习笔记/cg/games202/专题/restir/02-多光的采样困境.md|02 多光的采样困境：理想分布拿不到]] 的鸡生蛋问题，靠"一根射线"被解开：BVH 让"问一盏灯可不可见"从 O(遮蔽物) 变成 O(log)，理想分布才追得起。

## GI 赛道上的位置

放进 [[学习笔记/cg/games202/专题/ssgi/08-实现管线与赛道收官.md|08 实现管线与赛道收官]] 的"场从哪来"五档（ssgi 专题的收官表）：ReSTIR 属于"**算**"派，但它是算派里唯一**靠样本复用把预算缩到每像素一根**的：

| 路线 | 一根射线的价值 | 谁决定这根射线去哪 |
|---|---|---|
| 朴素 RTRT | 一根 = 一次均匀采样 | 随机 |
| **ReSTIR** | 一根 = 一次"理想分布"采样 | **时空复用攒出的水库** |
| 对照：SSGI | 零射线（读上一帧） | 深度场步进（[[学习笔记/cg/games202/专题/ssgi/08-实现管线与赛道收官.md|08 实现管线与赛道收官]]） |
| 对照：APV | 零射线（查探针场） | 烘焙时的几何密度（[[学习笔记/cg/games202/专题/apv/08-实现管线与GI赛道对照.md|08 实现管线与 GI 赛道对照]]） |

$$
\boxed{
\text{ReSTIR}
=
\underbrace{\text{加权便宜、评估昂贵}}_{\text{成本分离}}
+
\underbrace{\text{O(1) 水库}}_{\text{流式合并}}
+
\underbrace{\text{时空复用}}_{\text{邻居的赢家}}
+
\underbrace{\text{GRIS 三件套}}_{\text{无偏汇率}}
\;\Longrightarrow\;
\text{百万灯、一根射线、逐像素理想 IS}
}
$$

## 记忆压缩

> **ReSTIR = RTRT 时代的采样器标准答案**：成本分离（代理便宜、真值贵）给方向，水库给引擎，时空复用给弹药，GRIS 给签证——百万盏灯压进每像素一根阴影射线。它与降噪器组成 RTRT 两件套，与"压少派"完成多光问题的新旧交替，与 SSGI/APV 在混合管线里各就各位。**选择即采样，复用即样本**——这两句话，是 ReSTIR 留给整个实时渲染的资产。
