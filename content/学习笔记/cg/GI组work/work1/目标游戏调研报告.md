# 目标游戏调研报告

> 日期：2026-07-07
> 依据：`技术选型文档.md` 中的目标游戏筛选标准
> 方法：网络搜索 + Thunderstore BepInExPack 类型判断（Mono 包 vs IL2CPP 包）+ UnknownCheats 游戏保护列表 + 社区/论坛信息交叉验证

---

## 1. 筛选标准回顾

| 条件 | 要求 |
|---|---|
| 引擎 | Unity |
| 平台 | Windows |
| 脚本后端 | Mono 优先（注入最简单） |
| 渲染管线 | Built-in RP 优先（Camera + targetTexture 直接可用） |
| 反作弊 | 无（EAC / BattlEye / nProtect / 自研校验） |
| 加密 | 无 IL2CPP metadata 加密、无 pak/资源加密 |
| 场景 | 3D（多视角注入才有意义） |
| 知名度 | 有一定知名度（社区有经验可参考） |

---

## 2. 候选游戏总览

### 第一梯队：强烈推荐

#### 1. Valheim

| 属性 | 值 | 置信度 |
|---|---|---|
| 引擎 | Unity 2019.4.16f1 | ✅ 已确认（YouTube 视频提及版本号） |

| 反作弊 | **无** | ✅ 已确认（co-op 生存游戏，无 PvP 反作弊） |
| 加密 | 无 | ✅ 社区可自由 dnSpy 反编译 Assembly-CSharp.dll |
| 平台 | Windows (Steam) | ✅ |
| 场景 | 3D 开放世界 | ✅ 维京生存，地形/建筑/生物/洞穴，几何丰富 |
| 知名度 | 极高（1000 万+ 销量） | ✅ |
| BepInEx 社区 | 极活跃（Thunderstore + Nexus 大量 mod） | ✅ |

## 4. 最终推荐

### 首选：Valheim

理由：
1. **Mono + Built-in RP**：两项最关键的技术条件同时满足，PoC 代码最简单（`Camera` + `targetTexture` 直接可用，无需 SRP 回调）
2. **无反作弊、无加密**：注入零障碍
3. **BepInEx 社区极活跃**：大量现成工具和经验，遇到问题有参考
4. **3D 开放世界**：地形、建筑、洞穴、生物，几何足够丰富来验证剔除效果
5. **知名度极高**：信息多，长期维护有保障
6. **Unity 2019.4 LTS**：版本成熟稳定，BepInEx 5 稳定版完全支持

### 备选：Subnautica

如果 Valheim 因任何原因不适用，Subnautica 是最佳备选：
- 单人游戏，绝对不会触发反作弊
- 水下场景的体积光和雾效对"视角相关效果正确性"验证有额外价值
- Unity 版本较老，需验证 BepInEx 兼容性

## 5. 下一步

确认目标游戏后，需要：
1. 获取并安装游戏
2. 安装 BepInEx 5 到游戏目录
3. 验证 BepInEx 成功加载（检查 `BepInEx/LogOutput.txt`）
4. 确认游戏的渲染管线类型（运行时代码检测 `GraphicsSettings.currentRenderPipeline`）
5. 搭建插件项目骨架
