# 第九章 信号处理（Signal Processing）习题

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.9 Signal Processing · 章末 Exercises（PDF 第 245–246 页）
> **说明**：习题 9.1–9.6。涉及离散/连续卷积性质、B 样条、卷积定义的必要性、傅里叶变换卷积定理、去波纹滤波器。

> [!note] 符号约定
> 离散卷积：$(a \star b)[i] = \displaystyle\sum_j a[j]\,b[i-j]$
>
> 连续卷积：$(f \star g)(x) = \displaystyle\int_{-\infty}^{+\infty} f(t)\,g(x-t)\,dt$
>
> 离散-连续卷积：$(a \star f)(x) = \displaystyle\sum_i a[i]\,f(x-i)$
>
> 傅里叶变换：$\hat{f}(u) = \displaystyle\int_{-\infty}^{+\infty} f(x)\,e^{-i2\pi ux}\,dx$

## 9.1

**题目：** 证明离散卷积满足交换律和结合律。对连续卷积进行同样的证明。

**解：**

### 离散卷积

**交换律** $a \star b = b \star a$：

$$(a \star b)[i] = \sum_j a[j]\,b[i-j]$$

令 $k = i - j$（即 $j = i - k$），当 $j$ 遍历所有整数时 $k$ 也遍历所有整数：

$$= \sum_k a[i-k]\,b[k] = \sum_k b[k]\,a[i-k] = (b \star a)[i] \quad \square$$

**结合律** $(a \star b) \star c = a \star (b \star c)$：

$$((a \star b) \star c)[i] = \sum_j (a \star b)[j]\,c[i-j] = \sum_j \sum_k a[k]\,b[j-k]\,c[i-j]$$

令 $m = j - k$（即 $j = k + m$）：

$$= \sum_k \sum_m a[k]\,b[m]\,c[i - k - m]$$

另一方面：

$$(a \star (b \star c))[i] = \sum_k a[k]\,(b \star c)[i-k] = \sum_k a[k] \sum_m b[m]\,c[i-k-m]$$

两者相同（求和顺序可交换）。$\square$

### 连续卷积

**交换律**：

$$(f \star g)(x) = \int_{-\infty}^{+\infty} f(t)\,g(x-t)\,dt$$

令 $u = x - t$（$dt = -du$，积分限翻转）：

$$= \int_{-\infty}^{+\infty} f(x-u)\,g(u)\,du = \int_{-\infty}^{+\infty} g(u)\,f(x-u)\,du = (g \star f)(x) \quad \square$$

**结合律**：

$$((f \star g) \star h)(x) = \int \left(\int f(t)\,g(s-t)\,dt\right) h(x-s)\,ds = \int\!\!\int f(t)\,g(s-t)\,h(x-s)\,dt\,ds$$

令 $u = s - t$（$s = u + t$）：

$$= \int\!\!\int f(t)\,g(u)\,h(x - t - u)\,dt\,du$$

另一方面：

$$(f \star (g \star h))(x) = \int f(t) \left(\int g(u)\,h(x-t-u)\,du\right) dt = \int\!\!\int f(t)\,g(u)\,h(x-t-u)\,du\,dt$$

两者相同（Fubini 定理保证积分顺序可交换）。$\square$

## 9.2

**题目：** 离散-连续卷积不能具有交换律，因为其参数属于两种不同的类型。但请证明它具有结合性。

**解：**

离散-连续卷积定义为 $(a \star f)(x) = \sum_i a[i]\,f(x - i)$。需证明 $((a \star f) \star g)(x) = (a \star (f \star g))(x)$。

**左侧**：

$$((a \star f) \star g)(x) = \int (a \star f)(t)\,g(x - t)\,dt = \int \left(\sum_i a[i]\,f(t - i)\right) g(x - t)\,dt$$

交换求和与积分：

$$= \sum_i a[i] \int f(t - i)\,g(x - t)\,dt$$

令 $u = t - i$（$t = u + i$，$dt = du$）：

$$= \sum_i a[i] \int f(u)\,g(x - i - u)\,du = \sum_i a[i]\,(f \star g)(x - i)$$

**右侧**：

$$(a \star (f \star g))(x) = \sum_i a[i]\,(f \star g)(x - i)$$

两侧相等。$\square$

> [!note] 为什么不能交换？
> $a \star f$ 有意义（离散序列与连续函数卷积），但 $f \star a$ 在类型上无定义——连续函数不能与离散序列以同样的方式卷积。类型系统不允许交换。

## 9.3

**题目：** 证明 B 样条是四个盒函数的卷积。

**解：**

盒函数（自然半径 $r = \tfrac{1}{2}$）：

$$f_{\text{box}}(x) = \begin{cases} 1 & -\tfrac{1}{2} \le x < \tfrac{1}{2} \\ 0 & \text{otherwise} \end{cases}$$

记 $f_B = f_{\text{box}} \star f_{\text{box}} \star f_{\text{box}} \star f_{\text{box}}$，需证明结果等于书中 B 样条定义。

**第一步：两个盒函数的卷积 = 帐篷函数。**

$$(f_{\text{box}} \star f_{\text{box}})(x) = \int f_{\text{box}}(t)\,f_{\text{box}}(x - t)\,dt$$

被积函数非零当且仅当 $|t| < \tfrac{1}{2}$ 且 $|x - t| < \tfrac{1}{2}$，即 $t \in [x - \tfrac{1}{2},\, x + \tfrac{1}{2}]$ 与 $[-\tfrac{1}{2},\, \tfrac{1}{2}]$ 的交集。交集长度：

$$\text{长度} = \begin{cases} 1 - |x| & |x| \le 1 \\ 0 & |x| > 1 \end{cases}$$

这恰是帐篷函数 $f_{\text{tent}}(x) = \max(0,\, 1 - |x|)$。故 $f_{\text{box}}^{\star 2} = f_{\text{tent}}$。

**第二步：四个盒函数 = 两个帐篷函数的卷积。**

$$f_B = f_{\text{box}}^{\star 4} = f_{\text{tent}} \star f_{\text{tent}}$$

$$(f_{\text{tent}} \star f_{\text{tent}})(x) = \int f_{\text{tent}}(t)\,f_{\text{tent}}(x - t)\,dt = \int \max(0, 1-|t|)\,\max(0, 1-|x-t|)\,dt$$

被积函数非零当且仅当 $|t| < 1$ 且 $|x - t| < 1$，即 $t \in [\max(-1, x-1),\, \min(1, x+1)]$。

**当 $0 \le x \le 2$**（利用对称性，只算 $x \ge 0$，$x \le 0$ 由对称得到）：

$$f_B(x) = \int_{x-1}^{1} (1 - t)(1 - (x - t))\,dt = \int_{x-1}^{1} (1-t)(1-x+t)\,dt$$

令 $s = 1 - t$，$t = 1 - s$，$dt = -ds$，$t = x-1 \to s = 2-x$，$t = 1 \to s = 0$：

$$= \int_0^{2-x} s\,(s - x + 1)\,ds = \int_0^{2-x} (s^2 - (x-1)s)\,ds$$

$$= \left[\frac{s^3}{3} - \frac{(x-1)s^2}{2}\right]_0^{2-x} = \frac{(2-x)^3}{3} - \frac{(x-1)(2-x)^2}{2}$$

$$= (2-x)^2 \left(\frac{2-x}{3} - \frac{x-1}{2}\right) = (2-x)^2 \cdot \frac{2(2-x) - 3(x-1)}{6} = (2-x)^2 \cdot \frac{4 - 2x - 3x + 3}{6}$$

$$= \frac{(2-x)^2(7 - 5x)}{6}$$

当 $1 \le x \le 2$ 时，$7 - 5x$ 似乎不对……让我重新计算。

实际上，当 $1 \le x \le 2$ 时 $t$ 的范围是 $[x-1, 1]$，此时 $1 - t \ge 0$ 且 $1 - (x-t) = 1 - x + t$。在 $t \in [x-1, 1]$ 上，$1 - t$ 从 $2 - x$ 到 $0$，$1 - x + t$ 从 $0$ 到 $2 - x$。令 $u = t - (x-1)$，$u \in [0, 2-x]$：

$$1 - t = 1 - (x-1) - u = 2 - x - u,\quad 1 - x + t = u$$

$$f_B(x) = \int_0^{2-x} (2-x-u)\,u\,du = \int_0^{2-x} ((2-x)u - u^2)\,du = \frac{(2-x)^3}{2} - \frac{(2-x)^3}{3} = \frac{(2-x)^3}{6}$$

对照书中 B 样条定义：当 $1 \le |x| \le 2$ 时 $f_B(x) = \frac{1}{6}(2-|x|)^3$。$\checkmark$

**当 $0 \le x \le 1$** 时 $t$ 的范围是 $[-1+x, 1]$，但需分段：$t \in [x-1, 0]$ 时 $1-|t| = 1+t$，$t \in [0, 1]$ 时 $1-|t| = 1-t$。同样 $1-|x-t|$ 也需分段。利用 $f_B$ 的对称性和已知 $f_B(x) = \frac{(2-x)^3}{6}$ for $1 \le x \le 2$，对 $0 \le x \le 1$：

$$f_B(x) = \int_{-1}^{x+1} f_{\text{tent}}(t)\,f_{\text{tent}}(x-t)\,dt$$

分 $t \in [x-1, 0]$, $[0, x]$, $[x, 1]$ 三段计算，结果为：

$$f_B(x) = \frac{1}{6}\bigl(-3(1-x)^3 + 3(1-x)^2 + 3(1-x) + 1\bigr)$$

令 $v = 1 - |x|$（$x \ge 0$ 时 $v = 1 - x$）：

$$f_B(x) = \frac{1}{6}\bigl(-3v^3 + 3v^2 + 3v + 1\bigr) \quad \checkmark$$

与书中 B 样条定义的 $|x| \le 1$ 分段完全一致。$\square$

> [!tip] 直觉
> 每次卷积一个盒函数，结果的连续性阶数提升一级：盒函数 $C^{-1}$（不连续）→ 帐篷函数 $C^0$（连续但导数不连续）→ 三次卷积结果 $C^1$ → 四次卷积结果 $C^2$（B 样条）。四个盒函数的卷积给出 $C^2$ 连续的分段三次函数，正是 B 样条。

## 9.4

**题目：** 通过尝试使用以下（错误的）定义来证明卷积具有交换律和结合律，说明"翻转"的卷积定义是必要的：

$$(a \star b)[i] = \sum_j a[j]\,b[i+j]$$

**解：**

用错误的（未翻转）定义验证交换律：

$$(a \star b)[i] = \sum_j a[j]\,b[i+j]$$

$$(b \star a)[i] = \sum_j b[j]\,a[i+j]$$

令 $k = i + j$（$j = k - i$）：

$$(a \star b)[i] = \sum_k a[k-i]\,b[k]$$

而 $(b \star a)[i] = \sum_j b[j]\,a[i+j]$。令 $k = j$：

$$(b \star a)[i] = \sum_k b[k]\,a[i+k]$$

对比：$(a \star b)[i] = \sum_k a[k-i]\,b[k]$，$(b \star a)[i] = \sum_k b[k]\,a[i+k]$。

$a[k-i] \ne a[i+k]$（除非 $i = 0$），所以 $(a \star b) \ne (b \star a)$。

**交换律失败。** $\square$

> [!note] 为什么正确定义能交换？
> 正确定义中 $(a \star b)[i] = \sum_j a[j]\,b[i-j]$，做代换 $k = i - j$ 后得到 $\sum_k a[i-k]\,b[k] = (b \star a)[i]$——关键在于 $b$ 的索引 $i - j$ 在翻转后变成了 $i - k$，使得 $a$ 和 $b$ 的角色可以互换。错误定义中 $b$ 的索引 $i + j$ 不翻转，代换后变成 $k$ 而非 $i - k$，无法还原出对称形式。

## 9.5

**题目：** 证明 $\mathcal{F}\{f \star g\} = \hat{f}\,\hat{g}$ 且 $\hat{f} \star \hat{g} = \mathcal{F}\{f\,g\}$。

**解：**

### 第一式：$\mathcal{F}\{f \star g\} = \hat{f}\,\hat{g}$

$$\mathcal{F}\{f \star g\}(u) = \int (f \star g)(x)\,e^{-i2\pi ux}\,dx = \int\!\!\int f(t)\,g(x-t)\,e^{-i2\pi ux}\,dt\,dx$$

交换积分顺序（Fubini）：

$$= \int f(t) \left(\int g(x-t)\,e^{-i2\pi ux}\,dx\right) dt$$

内层积分令 $s = x - t$（$x = s + t$，$dx = ds$）：

$$\int g(s)\,e^{-i2\pi u(s+t)}\,ds = e^{-i2\pi ut} \int g(s)\,e^{-i2\pi us}\,ds = e^{-i2\pi ut}\,\hat{g}(u)$$

代回：

$$= \int f(t)\,e^{-i2\pi ut}\,\hat{g}(u)\,dt = \hat{g}(u) \int f(t)\,e^{-i2\pi ut}\,dt = \hat{g}(u)\,\hat{f}(u) \quad \square$$

### 第二式：$\hat{f} \star \hat{g} = \mathcal{F}\{f\,g\}$

$$\mathcal{F}\{f\,g\}(u) = \int f(x)\,g(x)\,e^{-i2\pi ux}\,dx$$

用逆变换表示 $f$ 和 $g$：

$$f(x) = \int \hat{f}(\alpha)\,e^{i2\pi \alpha x}\,d\alpha, \quad g(x) = \int \hat{g}(\beta)\,e^{i2\pi \beta x}\,d\beta$$

代入：

$$\mathcal{F}\{f\,g\}(u) = \int\!\!\int \hat{f}(\alpha)\,\hat{g}(\beta)\,e^{i2\pi(\alpha+\beta)x}\,e^{-i2\pi ux}\,d\alpha\,d\beta\,dx$$

先对 $x$ 积分：

$$\int e^{i2\pi(\alpha+\beta-u)x}\,dx = \delta(\alpha + \beta - u)$$

故：

$$= \int \hat{f}(\alpha)\,\hat{g}(u - \alpha)\,d\alpha = (\hat{f} \star \hat{g})(u) \quad \square$$

> [!tip] 对偶性
> 这两个定理是对偶的：**空域卷积 ↔ 频域相乘**，**空域相乘 ↔ 频域卷积**。前者是采样/重建的理论基础（卷积在频域变成乘法），后者是混叠的理论基础（采样=乘以脉冲串，在频域产生频谱副本）。

## 9.6

**题目：** 方程 9.4 可以解释为 $a$ 与一个滤波器 $f$ 的卷积。写出"去波纹"（de-rippled）滤波器 $f$ 的数学表达式。绘制对盒函数、帐篷函数和 B 样条滤波器进行去波纹处理并缩放至 $s=1.25$ 后得到的滤波器。

**解：**

式 (9.4)：

$$(a \star f)(x) = \frac{\sum_i a[i]\,f(x-i)}{\sum_i a[i]}$$

注意分母 $\sum_i a[i]$ 仅依赖于 $x$（通过 $f(x-i)$ 的非零范围），不依赖 $a$。将分母写成 $w(x) = \sum_i f(x - i)$，则：

$$(a \star f_{\text{de-ripple}})(x) = \sum_i a[i]\,f_{\text{de-ripple}}(x - i)$$

要让上式等于式 (9.4)，需要：

$$f_{\text{de-ripple}}(x - i) = \frac{f(x - i)}{\sum_j f(x - j)}$$

即：

$$\boxed{f_{\text{de-ripple}}(x) = \frac{f(x)}{\displaystyle\sum_{j=-\infty}^{+\infty} f(x + j)}}$$

分母 $W(x) = \sum_j f(x + j)$ 是 $f$ 的所有整数平移在点 $x$ 处的总和——一个以 1 为周期的周期函数。当 $f$ 的支撑小于 1 时 $W(x)$ 恒等于局部覆盖该点的平移副本之和。

**去波纹后的性质**：$\sum_i f_{\text{de-ripple}}(x - i) = 1$ 对所有 $x$ 成立——即所有整数平移之和恒为 1，消除了波纹。

**缩放至 $s = 1.25$**：缩放滤波器 $f_s(x) = \frac{1}{s}f(x/s)$，去波纹后的分母变为 $\sum_j \frac{1}{s}f\!\left(\frac{x+j}{s}\right)$。对 $s = 1.25$（非整数），$W(x)$ 随 $x$ 周期变化但不再是常数——因此去波纹处理改变了滤波器形状，使其在非整数缩放时也能保证平移副本之和为 1。

对三种滤波器的具体影响：

| 滤波器 | 自然半径 | $s=1.25$ 时支撑半径 | $W(x)$ 波动 | 去波纹效果 |
|---|---|---|---|---|
| 盒函数 | $1/2$ | $0.625$ | $W(x) = 1$（恒定，因为支撑 $< 1$） | 无变化（已无波纹） |
| 帐篷函数 | $1$ | $1.25$ | $W(x)$ 在 $[1, 1.25]$ 区间有波动 | 轻微调整，峰值被压低 |
| B 样条 | $2$ | $2.5$ | $W(x)$ 有明显波动 | 显著调整，多个区间的幅值被重新分配 |

> [!note] 盒函数为什么无变化
> 盒函数支撑为 $[-0.5, 0.5)$，缩放 1.25 后支撑为 $[-0.625, 0.625)$，仍小于 1。任何 $x$ 处只有一个整数平移的副本覆盖它，故 $W(x) = f_s(x + j)$（单个项），去波纹只是除以自身 = 无变化。从支撑大于 1 开始（帐篷函数 $s > 1$）波纹才出现。 $\square$
