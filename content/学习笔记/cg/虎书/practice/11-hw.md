# 第十一章 纹理映射（Texture Mapping）习题

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.11 Texture Mapping · 章末 Exercises（PDF 第 294 页）
> **说明**：习题 11.1–11.4。涉及棋盘格实现、透视校正等式验证、实体纹理实现、三线性 mipmap 展开。

> [!note] 符号约定
> 透视校正插值：在屏幕空间对 $u/w_r$、$v/w_r$、$1/w_r$ 做重心插值后相除恢复 $(u,v)$（式 11.2）。
>
> 式 (11.3)：$\displaystyle\frac{1}{w_r} + \alpha(t)\!\left(\frac{1}{w_R} - \frac{1}{w_r}\right) = \frac{1}{w_r + t(w_R - w_r)}$
>
> 三线性 mipmap 采样：选层 $k=\log_2 D$，在 $\lfloor k \rfloor$ 和 $\lceil k \rceil$ 各做双线性插值后线性混合。

## 11.1

**题目：** 找出几种使用表面技术和实体技术实现无限二维棋盘格的方法。哪种方法最好？

**解：**

### 方法一：表面纹理——平铺 2D 棋盘格图像

准备一张 $2\times2$ 的棋盘格纹理（黑白各一块），设环绕模式为平铺（tiling/wrap），纹理坐标用平面投影 $u = ax,\; v = by$。

```
checker = texture("checker_2x2.png", wrap=REPEAT)
u = x * scale;  v = y * scale
color = checker.lookup(u, v)
```

优点：简单。缺点：需要纹理图像；棋盘格随表面变形而变形（球面上极点畸变）；跨越接缝时纹理连续但棋盘格可能错位。

### 方法二：表面纹理——解析棋盘格函数

不使用图像，直接用纹理坐标计算：

$$\mathbf{c}(u, v) = \begin{cases} \mathbf{c}_0 & \lfloor u \rfloor + \lfloor v \rfloor \text{ 为偶数} \\ \mathbf{c}_1 & \lfloor u \rfloor + \lfloor v \rfloor \text{ 为奇数} \end{cases}$$

或等价地用 `floor(u) + floor(v)` 的奇偶性。无图像、无限延伸，但仍依赖纹理坐标函数 $\varphi$——在球面等曲面上会畸变。

### 方法三：实体纹理——3D 棋盘格

直接用世界空间坐标，不经过 2D 纹理坐标函数：

$$\mathbf{c}(\mathbf{p}) = \begin{cases} \mathbf{c}_0 & \lfloor x \rfloor + \lfloor y \rfloor + \lfloor z \rfloor \text{ 为偶数} \\ \mathbf{c}_1 & \lfloor x \rfloor + \lfloor y \rfloor + \lfloor z \rfloor \text{ 为奇数} \end{cases}$$

其中 $\mathbf{p} = (x, y, z)$ 是表面点的世界坐标。三个轴各自的 `floor` 之和的奇偶性决定颜色。

优点：
- 无需纹理坐标函数——没有畸变、没有接缝
- 棋盘格在 3D 空间中无限延伸，适合"雕刻"出的物体
- 物体移动时棋盘格固定在空间中（适合判断物体尺寸/运动）

缺点：
- 棋盘格方向固定于世界坐标轴，不可独立调整朝向
- 3D 棋盘格在曲面上会产生不规则格子和摩尔纹

### 方法四：实体纹理——简化 2D 棋盘格（仅用两个坐标）

$$\mathbf{c}(\mathbf{p}) = \begin{cases} \mathbf{c}_0 & \lfloor x \rfloor + \lfloor z \rfloor \text{ 为偶数} \\ \mathbf{c}_1 & \text{否则} \end{cases}$$

只用两个坐标（如 $x, z$），忽略第三个。比 3D 棋盘格简单，且在地平面上的效果就是标准 2D 棋盘格。

### 哪种最好？

**对于平面表面（如地板）**：方法二（解析表面纹理）最好——简单、无图像开销、棋盘格无畸变。

**对于任意形状的 3D 物体**：方法三（实体 3D 棋盘格）最好——无需纹理坐标函数、无畸变、无接缝、天然无限延伸。

> [!note] 实体纹理的核心优势
> 实体纹理不需要 $\varphi$ 函数——表面已嵌入 3D 空间，直接用坐标查值。这消除了纹理映射最头疼的两个问题（坐标函数设计、畸变控制）。代价是无法像 2D 纹理那样精确控制图案在表面上的布局。 $\square$

## 11.2

**题目：** 通过暴力代数验证方程 (11.3) 是一个有效的等式。

**解：**

式 (11.3)：

$$\frac{1}{w_r} + \alpha(t)\left(\frac{1}{w_R} - \frac{1}{w_r}\right) = \frac{1}{w_r + t(w_R - w_r)}$$

其中 $\alpha(t) = \dfrac{w_R\,t}{w_r + t(w_R - w_r)}$（式 11.1 的第二个式子）。

**左边**：

$$\text{LHS} = \frac{1}{w_r} + \frac{w_R\,t}{w_r + t(w_R - w_r)}\left(\frac{1}{w_R} - \frac{1}{w_r}\right)$$

计算括号内：

$$\frac{1}{w_R} - \frac{1}{w_r} = \frac{w_r - w_R}{w_r\,w_R}$$

代回：

$$\text{LHS} = \frac{1}{w_r} + \frac{w_R\,t}{w_r + t(w_R - w_r)} \cdot \frac{w_r - w_R}{w_r\,w_R}$$

$$= \frac{1}{w_r} + \frac{t(w_r - w_R)}{w_r\,(w_r + t(w_R - w_r))}$$

注意 $w_r - w_R = -(w_R - w_r)$：

$$= \frac{1}{w_r} - \frac{t(w_R - w_r)}{w_r\,(w_r + t(w_R - w_r))}$$

通分（公分母 $w_r\,(w_r + t(w_R - w_r))$）：

$$= \frac{w_r + t(w_R - w_r) - t(w_R - w_r)}{w_r\,(w_r + t(w_R - w_r))}$$

分子化简：

$$w_r + t(w_R - w_r) - t(w_R - w_r) = w_r$$

故：

$$\text{LHS} = \frac{w_r}{w_r\,(w_r + t(w_R - w_r))} = \frac{1}{w_r + t(w_R - w_r)} = \text{RHS} \quad \square$$

> [!note] 这意味着什么？
> 左边是"在屏幕空间中按 $\alpha(t)$ 插值 $1/w$"，右边是"在世界空间中按 $t$ 插值 $w$ 后取倒数"。两者相等 → $1/w$ 可以在屏幕空间中线性插值，这正是透视校正插值的理论基础。 $\square$

## 11.3

**题目：** 如何利用 z-buffer 深度和矩阵变换来实现实体纹理？

**解：**

实体纹理需要表面点的世界空间坐标 $(x_q, y_q, z_q)$。在光栅化管线中，顶点经过变换后我们手上有的是**屏幕空间坐标** $(x_s, y_s, z_s)$ 和 z-buffer 深度——世界坐标已被透视变换"扭曲"。

**思路**：用 z-buffer 深度 $z_s$ 逆推回世界空间坐标，再送入实体纹理函数。

**具体步骤**：

**（1）记录逆变换矩阵。** 顶点经过的变换链：世界 $\xrightarrow{M_{\text{view}}\,M_{\text{proj}}}$ 齐次 $\xrightarrow{\text{齐次化}}$ 屏幕。逆变换链：屏幕 $\xrightarrow{\text{逆齐次化}}$ 齐次 $\xrightarrow{M_{\text{proj}}^{-1}\,M_{\text{view}}^{-1}}$ 世界。

记 $M = M_{\text{view}} \cdot M_{\text{proj}}$（世界→齐次），则 $M^{-1} = M_{\text{proj}}^{-1} \cdot M_{\text{view}}^{-1}$（齐次→世界）。

**（2）从屏幕坐标恢复齐次坐标。** 对屏幕点 $(x_s, y_s, z_s)$，其齐次坐标为：

$$\mathbf{r} = \begin{bmatrix} x_s \cdot w_r \\ y_s \cdot w_r \\ z_s \cdot w_r \\ w_r \end{bmatrix}$$

但 $w_r$ 未知。由于齐次化时 $w_r = z$（透视矩阵第四行为 $(0,0,1,0)$），且 $z_s = z_r / w_r$，需要从 $z_s$ 恢复 $w_r$。

实际上，$z_s$ 本身就是齐次化后的深度 $z_r / w_r$，而齐次化前的 $w_r = z_q$（世界空间 $z$ 坐标，经透视矩阵后 $w_r$ 等于世界 $z$）。所以：

$$\mathbf{r} = w_r \begin{bmatrix} x_s \\ y_s \\ z_s \\ 1 \end{bmatrix}$$

**（3）用逆矩阵恢复世界坐标。** $\mathbf{q} = M^{-1}\,\mathbf{r} = w_r \cdot M^{-1}\begin{bmatrix} x_s \\ y_s \\ z_s \\ 1 \end{bmatrix}$。由于齐次化的自由度，得到的是 $w_r$ 的标量倍数——齐次化后除以第四分量即得世界坐标：

$$\mathbf{q} = \frac{M^{-1}\begin{bmatrix} x_s \\ y_s \\ z_s \\ 1 \end{bmatrix}}{\left(M^{-1}\begin{bmatrix} x_s \\ y_s \\ z_s \\ 1 \end{bmatrix}\right)_w}$$

其中下标 $w$ 取第四分量。

**（4）传入实体纹理函数。** 用恢复的 $(x_q, y_q, z_q)$ 查找实体纹理 $\mathbf{c}_r(\mathbf{p})$。

> [!warning] 透视校正
> 上述恢复必须用**透视校正插值**后的 $z_s$（见 §11.2.4）——否则 $z_s$ 在三角形内部插值错误，恢复出的世界坐标也不对。在实践中，z-buffer 存储的 $z_s = z_r/w_r$ 在屏幕空间中可以线性插值（这是透视校正的结论），所以 z-buffer 的值本身是正确的。 $\square$

## 11.4

**题目：** 将函数 `mipmap_sample_trilinear` 展开为单个函数。

**解：**

原函数：

```
Color mipmap_sample_trilinear(Texture mip[], float u, float v, matrix J):
    D = max_column_norm(J)
    k = log2(D)
    k0 = floor(k); k1 = k0 + 1
    a = k1 - k; b = 1 - a
    c0 = tex_sample_bilinear(mip[k0], u, v)
    c1 = tex_sample_bilinear(mip[k1], u, v)
    return a * c0 + b * c1
```

其中双线性插值：

```
Color tex_sample_bilinear(Texture t, float u, float v):
    u_p = u * t.width - 0.5
    v_p = v * t.height - 0.5
    iu0 = floor(u_p); iu1 = iu0 + 1
    iv0 = floor(v_p); iv1 = iv0 + 1
    a_u = iu1 - u_p; b_u = 1 - a_u
    a_v = iv1 - v_p; b_v = 1 - a_v
    return  a_u*a_v*t[iu0][iv0] + a_u*b_v*t[iu0][iv1] +
            b_u*a_v*t[iu1][iv0] + b_u*b_v*t[iu1][iv1]
```

展开为单个函数（将双线性插值的每一步直接内联）：

```
Color mipmap_sample_trilinear_expanded(Texture mip[], float u, float v, matrix J):
    // --- 选层 ---
    D = max_column_norm(J)
    k = log2(D)
    k0 = floor(k)
    k1 = k0 + 1
    a = k1 - k          // k0 的权重
    b = 1 - a           // k1 的权重

    // --- 第 k0 层双线性插值 ---
    t0 = mip[k0]
    u0 = u * t0.width - 0.5
    v0 = v * t0.height - 0.5
    iu0_0 = floor(u0);   iu0_1 = iu0_0 + 1
    iv0_0 = floor(v0);   iv0_1 = iv0_0 + 1
    au0 = iu0_1 - u0;    bu0 = 1 - au0
    av0 = iv0_1 - v0;    bv0 = 1 - av0
    c0 = au0*av0 * t0[iu0_0][iv0_0] + au0*bv0 * t0[iu0_0][iv0_1] +
         bu0*av0 * t0[iu0_1][iv0_0] + bu0*bv0 * t0[iu0_1][iv0_1]

    // --- 第 k1 层双线性插值 ---
    t1 = mip[k1]
    u1 = u * t1.width - 0.5
    v1 = v * t1.height - 0.5
    iu1_0 = floor(u1);   iu1_1 = iu1_0 + 1
    iv1_0 = floor(v1);   iv1_1 = iv1_0 + 1
    au1 = iu1_1 - u1;    bu1 = 1 - au1
    av1 = iv1_1 - v1;    bv1 = 1 - av1
    c1 = au1*av1 * t1[iu1_0][iv1_0] + au1*bv1 * t1[iu1_0][iv1_1] +
         bu1*av1 * t1[iu1_1][iv1_0] + bu1*bv1 * t1[iu1_1][iv1_1]

    // --- 层间线性混合 ---
    return a * c0 + b * c1
```

**展开后的计算量**：
- 2 次双线性插值 = $2 \times 4 = 8$ 次纹素查找
- 每次双线性 = 3 次乘法 + 3 次加法（用 3 次乘 3 次加实现 4 点加权平均）
- 1 次层间混合 = 2 次乘法 + 1 次加法
- 总计：8 次纹素查找、8 次乘法、7 次加法 + 选层/索引计算

> [!note] 为什么展开有意义？
> 原始版本调用两次 `tex_sample_bilinear` 函数，有函数调用开销和局部变量重复存储。展开后所有中间变量显式可见，编译器可以更好地优化寄存器分配，且可以复用 $u, v$ 相关的计算（如 `floor(u*t.width)` 在两层中可能部分重用——虽然两层的宽高不同，但 `u*t.width` 的浮点计算可以流水线化）。 $\square$
