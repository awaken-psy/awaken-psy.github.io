# 第十二章 图形数据结构（Data Structures for Graphics）习题

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.12 · 章末 Exercises（PDF 第 336 页）
> **说明**：习题 12.1–12.4。涉及翼边结构存储量、场景图设计、平铺数组查表、BSP 树三角形数量。

> [!note] 符号约定
> 索引网格：$n_t \approx 2n_v$（大网格经验值）
>
> 翼边结构：每条边存 4 邻接边 + 2 顶点 + 2 面引用，每顶点和每面各存 1 条边指针
>
> BSP 树：跨切割平面的三角形被切成 3 个，遍历时间正比于节点数（与平衡度无关）

---

## 12.1

**题目：** 对于一个简单的四面体，分别以四个独立三角形存储和以翼边数据结构存储，其内存差异是多少？

**解：**

四面体有 $n_v = 4$ 个顶点、$n_t = 4$ 个三角形面、$n_e = 6$ 条边。

假设 float、int、pointer 等宽（各 1 单位存储）。

### 方法一：四个独立三角形

每个三角形存 3 个顶点位置（各 3 个 float = 3 单位），共 $3 \times 3 = 9$ 单位/三角形。

$$\text{总存储} = 4 \times 9 = 36 \text{ 单位}$$

### 方法二：翼边结构

**顶点**：每个顶点存 3 个坐标 + 1 条关联边指针 = 4 单位。共 $4 \times 4 = 16$。

**面**：每个面存 1 条关联边指针 = 1 单位。共 $4 \times 1 = 4$。

**边**：每条边存 4 条邻接边指针 + 2 顶点指针 + 2 面指针 = 8 单位。共 $6 \times 8 = 48$。

$$\text{总存储} = 16 + 4 + 48 = 68 \text{ 单位}$$

### 对比

| 方案 | 存储 | 备注 |
|---|---|---|
| 独立三角形 | 36 | 无邻接信息，顶点重复存储 |
| 翼边结构 | 68 | 完整邻接信息，$O(1)$ 遍历 |
| 索引网格（参照） | $3n_v + 3n_t = 12 + 12 = 24$ | 无邻接信息 |

翼边结构存储量是独立三角形的约 1.9 倍，但提供了完整的拓扑查询能力。对于四面体这种极小模型，邻接信息的开销比例很大；大网格中翼边约 $\approx 16n_v$ vs 索引网格 $9n_v$，比值约 1.8 倍。 $\square$

## 12.2

**题目：** 绘制一辆自行车的场景图。

**解：**

自行车可分解为以下层次结构：

```
根（世界变换）
└─ 自行车整体（车架变换）
    ├─ 车架（主梁 + 座管 + 头管）
    │   ├─ 前踏板曲柄（绕中轴旋转）
    │   │   ├─ 左踏板
    │   │   └─ 右踏板
    │   ├─ 后齿轮组（绕后轴旋转）
    │   └─ 链条（跟随前后齿轮）
    ├─ 座椅（座管上的位置/角度）
    ├─ 前轮组（头管转向 + 前叉）
    │   ├─ 前叉
    │   │   └─ 前轮（绕前轴旋转）
    │   └─ 车把（与前叉共享转向变换）
    └─ 后轮组（固定在车架后端）
        └─ 后轮（绕后轴旋转）
```

**变换层次说明**：

| 节点 | 局部变换 | 继承效果 |
|---|---|---|
| 自行车整体 | 平移到世界位置 | 整车移动 |
| 前踏板曲柄 | 绕中轴旋转 $R_{\text{pedal}}(t)$ | 踏板随曲柄转动，但整车位置不变 |
| 前轮组（头管） | 绕头管轴旋转 $R_{\text{steer}}(\theta)$ | 前叉、前轮、车把一起转向 |
| 前轮 | 绕前轴旋转 $R_{\text{wheel}}(t)$ | 前轮在转向方向上自转 |
| 后轮 | 绕后轴旋转 $R_{\text{wheel}}(t)$ | 后轮自转，但不受转向影响 |
| 车把 | 与前叉共享 $R_{\text{steer}}$ | 车把随前叉转向，但无需独立旋转 |

> [!tip] 关键设计点
> - 前轮和车把共享头管转向变换——放在同一父节点下
> - 前后踏板和后齿轮的旋转有联动关系（链条传动），但场景图不直接表达约束，需在动画代码中同步旋转角度
> - 车架是"主体"，座椅和轮组挂在车架下——修改车架变换自动移动整车

$\square$

## 12.3

**题目：** 单层平铺一个 $n$ 维数组需要多少张查找表？

**解：**

虎书 §12.5.1 中，2D 平铺数组的索引公式可分解为：

$$\text{index} = F_x(x) + F_y(y)$$

需要 2 张查找表（$F_x$ 和 $F_y$），各有 $N_x$ 和 $N_y$ 个元素。

推广到 $n$ 维：索引公式分解为各维独立贡献之和：

$$\text{index} = F_1(x_1) + F_2(x_2) + \cdots + F_n(x_n)$$

$$\boxed{\text{需要 } n \text{ 张查找表}}$$

第 $i$ 维的表 $F_i$ 有 $N_i$ 个元素（该维的大小）。总表大小 $\sum_{i=1}^{n} N_i$，即使数组很大也能放入 L1 缓存。 $\square$

> [!note] 为什么能分解？
> 平铺索引公式中，各维的贡献通过加法组合（不是乘法），因为平铺后的线性布局使得各维偏移可以独立计算后相加。这与行优先布局中 `index = x + Nx*y` 的乘法耦合不同——平铺消除了维间耦合。

## 12.4

**题目：** 给定 $N$ 个三角形，添加到生成的 BSP 树中的三角形的最小数量是多少？最大数量是多少？

**解：**

BSP 树的节点数 = 原始三角形数 + 因切割产生的额外三角形。每切割一个三角形产生 3 个新三角形（净增 2 个）。

### 最小数量

**最小值 = $N$**（无切割）。

如果每个三角形都完全在已添加三角形的某一侧（不跨平面），则无需切割，每个三角形恰好对应一个节点。

最佳情况：三角形按"从远到近"的顺序排列，或几何上互不穿越对方的平面。

### 最大数量

每次添加一个三角形时，如果它跨越当前路径上所有已有节点的切割平面，每经过一个节点被切一刀，一变三（净增 2）。但这不是简单的 $3^N$ 指数增长，因为切割后的片段仍可能继续被后续平面切割。

精确分析：第 $i$ 个添加的三角形最多被前 $i-1$ 个三角形的平面切割 $i-1$ 次。每次切割使三角形数 +2（1→3 增 2，但后续切割作用在已经分裂出的片段上）。

实际上，一个三角形被 $k$ 个平面切割最多产生 $k+1$ 个片段（如果平面不共线且每次切割增加一个片段）。但 BSP 切割将 1 个三角形变 3 个（不是 2 个），所以更精确地：

- 第 1 个三角形：1 个节点
- 第 $i$ 个三角形（$i \ge 2$）：如果被路径上每个节点的平面都切割，最坏情况下每个已有节点都使三角形数翻倍左右

经典结论：最坏情况下 BSP 树节点数为 $O(N^2)$。精确最大值取决于切割策略，但一个常用的上界是：

$$\boxed{\text{最小} = N, \quad \text{最大} = O(N^2)}$$

**直觉**：第 $i$ 个三角形最多被前 $i-1$ 个平面切割，产生 $O(i)$ 个片段。所有 $N$ 个三角形的总片段数 $\le \sum_{i=1}^{N} O(i) = O(N^2)$。

> [!example] 小例子验证
> 3 个三角形，如果 $T_1$ 的平面切割 $T_2$（→3 个片段）和 $T_3$（→3 个片段），且 $T_2$ 的某片段的平面又切割 $T_3$ 的某片段：
> - $T_1$：1 节点
> - $T_2$ 被切：3 片段，但其中 1 个成为 $T_2$ 节点，另外 2 个继续向下
> - $T_3$ 被切多次：可能产生 $5\sim7$ 个片段
>
> 总节点数远超 $N=3$ 但远小于 $3^3 = 27$。$\square$
