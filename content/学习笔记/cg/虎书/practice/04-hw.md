# 第四章 光线追踪（Ray Tracing）习题

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.4 Ray Tracing · 章末 Exercises（PDF 第 103 页）
> **说明**：习题 4.1–4.3。涉及光线-球求交、光线-三角形求交、光线追踪时间复杂度分析。

> [!note] 符号约定
> 光线方程：$\mathbf{p}(t) = \mathbf{e} + t\,\mathbf{d}$
>
> 球体方程：$(\mathbf{p} - \mathbf{c})\cdot(\mathbf{p} - \mathbf{c}) = r^2$
>
> 重心坐标：$\mathbf{p} = \alpha\,\mathbf{a} + \beta\,\mathbf{b} + \gamma\,\mathbf{c}$，$\alpha+\beta+\gamma=1$

---

## 4.1

**题目：** 光线 $(1,1,1) + t(-1,-1,-1)$ 与球心位于原点、半径为 1 的球体的交点对应的光线参数是什么？

**解：**

光线 $\mathbf{e} = (1,1,1)$，$\mathbf{d} = (-1,-1,-1)$，球心 $\mathbf{c} = \mathbf{0}$，$r = 1$。

代入球体方程 $(\mathbf{e} + t\mathbf{d} - \mathbf{c})\cdot(\mathbf{e} + t\mathbf{d} - \mathbf{c}) = r^2$：

$$(\mathbf{e} + t\mathbf{d})\cdot(\mathbf{e} + t\mathbf{d}) = 1$$

展开：$\mathbf{d}\cdot\mathbf{d}\,t^2 + 2\,\mathbf{e}\cdot\mathbf{d}\,t + \mathbf{e}\cdot\mathbf{e} - 1 = 0$。

计算各项：

- $\mathbf{d}\cdot\mathbf{d} = (-1)^2+(-1)^2+(-1)^2 = 3$
- $\mathbf{e}\cdot\mathbf{d} = 1\cdot(-1)+1\cdot(-1)+1\cdot(-1) = -3$
- $\mathbf{e}\cdot\mathbf{e} = 1+1+1 = 3$

方程：$3t^2 - 6t + 2 = 0$，即 $t^2 - 2t + \tfrac{2}{3} = 0$。

$$t = \frac{2 \pm \sqrt{4 - \tfrac{8}{3}}}{2} = 1 \pm \sqrt{\frac{1}{3}} = 1 \pm \frac{\sqrt{3}}{3}$$

$$\boxed{t = 1 - \frac{\sqrt{3}}{3} \approx 0.423, \qquad t = 1 + \frac{\sqrt{3}}{3} \approx 1.577}$$

验证：交点为 $(1-t,\; 1-t,\; 1-t)$，$|(1-t,\;1-t,\;1-t)| = \sqrt{3}\,|1-t| = 1$ → $|1-t| = \tfrac{1}{\sqrt{3}}$ → $t = 1 \pm \tfrac{\sqrt{3}}{3}$。$\checkmark$ $\square$

## 4.2

**题目：** 光线 $(1,1,1) + t(-1,-1,-1)$ 命中顶点为 $(1,0,0)$、$(0,1,0)$、$(0,0,1)$ 的三角形的重心坐标和射线参数是多少？

**解：**

光线 $\mathbf{e} = (1,1,1)$，$\mathbf{d} = (-1,-1,-1)$。三角形顶点 $\mathbf{a}=(1,0,0)$，$\mathbf{b}=(0,1,0)$，$\mathbf{c}=(0,0,1)$。

交点条件：$\mathbf{e} + t\mathbf{d} = \alpha\,\mathbf{a} + \beta\,\mathbf{b} + \gamma\,\mathbf{c}$，即：

$$(1-t,\; 1-t,\; 1-t) = (\alpha,\; \beta,\; \gamma)$$

故 $\alpha = 1-t$，$\beta = 1-t$，$\gamma = 1-t$。

重心坐标约束 $\alpha + \beta + \gamma = 1$：

$$3(1-t) = 1 \quad\Rightarrow\quad t = \frac{2}{3}$$

$$\boxed{t = \frac{2}{3}, \qquad \alpha = \beta = \gamma = \frac{1}{3}}$$

验证：交点为 $(\tfrac{1}{3}, \tfrac{1}{3}, \tfrac{1}{3})$，确实在三角形内部（三个分量相等且和为 1）。$\checkmark$ $\square$

## 4.3

**题目：** 对"良好"（非对抗性）模型上光线追踪的近似时间复杂度进行粗略估算。将分析分为预处理和计算图像两种情况，以便预测对静态模型进行多帧光线追踪时的行为。

**解：**

设场景有 $N$ 个图元，图像分辨率为 $M$ 个像素，使用加速结构（如 BVH 或 BSP 树）。

### 预处理

构建加速结构（BVH/BSP）的代价为 $O(N \log N)$——排序或递归划分 $N$ 个图元。

- **BVH**：排序 + 递归构建，$O(N \log N)$
- **均匀网格**：$O(N)$（遍历一次分配到网格）
- **BSP 树**：每插入一个三角形 $O(\log N)$，共 $O(N \log N)$

预处理只需对静态模型做**一次**。

### 计算图像

对每个像素发射一条主光线。在"良好"模型上（图元分布均匀，无对抗性排列），加速结构使每条光线的求交代价为 $O(\log N)$——递归遍历树，每层只深入少量子树。

每条光线还可能产生：
- 阴影光线（每个光源一条）：$O(\log N)$ per light
- 反射/折射光线（递归深度 $D$）：$O(D \log N)$

单帧总代价：

$$\boxed{\text{单帧} = O(M \cdot \log N)}$$

其中 $M$ = 像素数 × 平均每像素光线数（含阴影/反射）。

### 多帧行为

| 阶段 | 代价 | 频率 |
|---|---|---|
| 预处理 | $O(N \log N)$ | 一次 |
| 每帧渲染 | $O(M \log N)$ | 每帧 |

对于静态模型渲染 $F$ 帧：总代价 = $O(N\log N) + F \cdot O(M\log N)$。当 $F$ 大时预处理被摊薄，瓶颈完全在每帧的 $O(M\log N)$。

> [!note] 对比暴力搜索
> 无加速结构时每条光线 $O(N)$，单帧 $O(MN)$。加速结构带来从 $O(N)$ 到 $O(\log N)$ 的改善。$\square$
