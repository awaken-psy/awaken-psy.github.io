# 第八章 光栅化：线段与三角形画进像素

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.8 Rasterization（线段绘制 + 三角形覆盖）
> **定位**：经过观察变换后，顶点已是屏幕浮点坐标。光栅化的任务是把连续图元（线段、三角形）**映射到离散像素网格**——决定哪些像素被「点亮」。这篇讲两个最基础的算法：画线、画三角形。

---

## 1. 光栅化的本质与难点

输入是顶点的屏幕坐标（浮点），输出是一组被覆盖的像素（整数索引）。把连续图形采样到离散网格，必然产生**走样（aliasing）**——最直观就是边界锯齿。

核心问题两个：
- **画线**：给定两端点，哪些像素最接近这条直线？
- **画三角形**：给定三个顶点，哪些像素的中心落在三角形内部？

---

## 2. 画线段

### 2.1 DDA（数值微分法）——最直白

沿**主轴**（变化较大的轴）每步 +1，用斜率算另一轴坐标，四舍五入取像素。对斜率 $|m|=\left|\Delta y/\Delta x\right|\le1$ 的情况沿 $x$ 步进：

```
m = (y1-y0)/(x1-x0)
y = y0
for x = x0 to x1:
    亮 (x, round(y))
    y += m
```

简单直观，但有浮点运算和舍入误差。$|m|>1$ 时改为沿 $y$ 步进、用 $1/m$ 插值 $x$。

### 2.2 中点画线法（Midpoint Algorithm）

虎书用隐式直线方程驱动判定。先写出直线的隐式方程（式 8.1）：

$$f(x,y)\equiv(y_0-y_1)\,x+(x_1-x_0)\,y+x_0 y_1-x_1 y_0=0 \tag{8.1}$$

约定 $x_0\le x_1$，讨论 $m\in(0,1]$（第一八分角）。其余三个八分角由对称变换得到。

核心思想：$x$ 每步 $+1$，候选像素为 $(x+1,\,y)$ 和 $(x+1,\,y+1)$，取两者中点 $(x+1,\,y+0.5)$。若直线经过中点**上方**（$f>0$），选下方像素；经过中点**下方**（$f<0$），选上方像素。

```
        ●
       /
      ●
     /
    ●        ← 选离理想直线最近的像素
   /
  ●
●
```

#### 非增量版（直白但每步重算 $f$）

```
y = y0
for x = x0 to x1 do
    draw(x, y)
    if f(x+1, y+0.5) < 0 then     // 中点在线下方 → 选上方像素
        y = y + 1
```

#### 增量版（复用上一步的 $f$ 值，避免每步重算）

注意到 $f(x+1,y)=f(x,y)+(y_0-y_1)$，$f(x+1,y+1)=f(x,y)+(y_0-y_1)+(x_1-x_0)$。设决策变量 $d=f(x_0+1,\,y_0+0.5)$，每步只需做一次加法：

```
y = y0
d = f(x0+1, y0+0.5)                    // 决策变量初值
for x = x0 to x1 do
    draw(x, y)
    if d < 0 then                       // 选上方像素
        y = y + 1
        d = d + (x1-x0) + (y0-y1)       // 增量 = Δx - Δy
    else                                // 选下方像素
        d = d + (y0-y1)                 // 增量 = -Δy
```

> [!tip] 与 Bresenham 的关系
> 令 $D=2d$，则初值 $D=2(y_0-y_1)+(x_1-x_0)=2\Delta x-\Delta y$（注意书中 $y_0-y_1=-\Delta y$），E 步 $D\mathrel{+}=2(y_0-y_1)=-2\Delta y$，NE 步 $D\mathrel{+}=2[(y_0-y_1)+(x_1-x_0)]=2(\Delta x-\Delta y)$——恰好就是 Bresenham 的整数误差项，只差一个常数因子 $2$。两者完全等价。

## 3. 画三角形

### 3.1 核心：判断像素中心在不在三角形内

三角形光栅化 = 对每个可能被覆盖的像素，判断其中心 $\mathbf{p}$ 是否在三个顶点 $\mathbf{a},\mathbf{b},\mathbf{c}$ 构成的三角形内。工具有两种，本质等价：

**edge function（边函数）**——对有向边 $\mathbf{a}\to\mathbf{b}$，定义

$$
E_{ab}(\mathbf{p})=(x_b-x_a)(y_p-y_a)-(y_b-y_a)(x_p-x_a)
$$

这是 $\overrightarrow{ab}\times\overrightarrow{ap}$ 的 $z$ 分量，表示 $\mathbf{p}$ 在边的哪一侧（$>0$ 左、$<0$ 右、$=0$ 在线上）。**三条边符号一致**（绕向相同）⇒ 点在三角形内。

**重心坐标**——把 $\mathbf{p}=\alpha\mathbf{a}+\beta\mathbf{b}+\gamma\mathbf{c}$，$\alpha+\beta+\gamma=1$。三个分量 $\ge0$ ⇔ 在内部。它与 edge function 成正比（面积比）：

$$
\alpha=\frac{E_{bc}(\mathbf{p})}{E_{bc}(\mathbf{a})},\quad \beta=\frac{E_{ca}(\mathbf{p})}{E_{ca}(\mathbf{b})},\quad \gamma=\frac{E_{ab}(\mathbf{p})}{E_{ab}(\mathbf{c})}
$$

重心坐标的额外价值：**插值顶点属性**（颜色、法线、纹理坐标、深度）——这正是 $\alpha\mathbf{c}_a+\beta\mathbf{c}_b+\gamma\mathbf{c}_c$。

### 3.2 包围盒遍历

不必扫全屏，只遍历三角形的**轴对齐包围盒**（bounding box），逐像素算重心坐标判断。虎书用边函数 $f_{ij}$ 定义重心坐标：

$$f_{01}(x,y)=(y_0-y_1)x+(x_1-x_0)y+x_0 y_1-x_1 y_0$$

$$f_{12}(x,y)=(y_1-y_2)x+(x_2-x_1)y+x_1 y_2-x_2 y_1$$

$$f_{20}(x,y)=(y_2-y_0)x+(x_0-x_2)y+x_2 y_0-x_0 y_2$$

重心坐标即为对应边函数的归一化：$\alpha=f_{12}(x,y)/f_{12}(x_0,y_0)$，$\beta=f_{20}(x,y)/f_{20}(x_1,y_1)$，$\gamma=f_{01}(x,y)/f_{01}(x_2,y_2)$。三者均为正即知在三角形内部（因为 $\alpha+\beta+\gamma=1$ 保证都 $<1$）。

```
xmin = floor(xi)
xmax = ceiling(xi)
ymin = floor(yi)
ymax = ceiling(yi)
fα = f12(x0, y0)
fβ = f20(x1, y1)
fγ = f01(x2, y2)
for y = ymin to ymax do
    for x = xmin to xmax do
        α = f12(x, y) / fα
        β = f20(x, y) / fβ
        γ = f01(x, y) / fγ
        if (α ≥ 0 and β ≥ 0 and γ ≥ 0) then
            if (α > 0 or fα·f12(−1,−1) > 0) and
               (β > 0 or fβ·f20(−1,−1) > 0) and
               (γ > 0 or fγ·f01(−1,−1) > 0) then
                c = α·c0 + β·c1 + γ·c2
                drawpixel(x, y) with color c
```

```
   c ─────────────┐   ← 包围盒：只扫框内像素
   │ ╲            │
   │  ╲           │
   │   ╲          │
   │    ╲         │
   │ a─────── b   │
   └──────────────┘
```

> [!warning] 边界平局（tie-breaking）
> 像素中心恰好落在边上时，$\alpha$/$\beta$/$\gamma$ 恰为 $0$，内层 `if` 用 `> 0` 严格判定会将其排除。为避免相邻三角形共享的边上出现空洞或重叠，虎书引入**屏幕外点 $(-1,-1)$** 做偏向：当 $\alpha=0$（像素在边 $f_{12}$ 上）时，检查 $f_\alpha\cdot f_{12}(-1,-1)>0$——即屏幕外点与非共享顶点 $(x_0,y_0)$ 是否在边同侧。对两个共享边的三角形，边方向相反，$f_{ij}$ 符号翻转，故恰好一个三角形通过测试，边界像素**唯一归属**。
>
> 该测试不完美：边恰好经过 $(-1,-1)$ 时乘积为 $0$，仍需额外处理。但已大幅减少问题案例。退化三角形（$f_\gamma=0$）会导致除零，需另行检查。

### 3.3 采样与走样

像素取**中心点**单次采样，三角形边界会出现锯齿。缓解办法都是「提高采样频率」：

- **超采样 SSAA**：每像素采多个子样本（如 4×4=16 个），求平均——质量最好但开销大。
- **多重采样 MSAA**：只在像素覆盖/边缘处多采，深度和颜色仍每像素算一次——性价比高，GPU 标配。

> [!warning] 顶点绕向决定正反面
> 三角形顶点顺序（逆时针/顺时针）即正反面。管线常用**背面剔除**：屏幕空间绕向与约定相反的三角形视为朝后，在光栅化前直接丢弃，可省下近一半工作量。

---

## 4. 顺带：隐藏面消除

多个三角形覆盖同一像素时谁可见，由 **z-buffer（深度缓冲）**解决：每个像素存当前最近深度，光栅化时用重心坐标插值出当前三角形在该像素的深度，比 buffer 里的更近才写入颜色并更新深度。

线段和三角形的光栅化 + z-buffer，就是早期到现代光栅化渲染器绘制几何的最底层机制。
