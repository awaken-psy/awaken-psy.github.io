# 第四章 射线追踪：射线与多边形求交

> **来源**：《Fundamentals of Computer Graphics》(Marschner & Shirley) · Ch.4 Ray Tracing · §4.4 Ray–Object Intersection（Ray–Polygon）
> **定位**：射线–多边形求交分两步——① 求射线与多边形所在**无限平面**的交点 $p$；② 用**奇偶射线法**判断 $p$ 是否在多边形内。
> **关联**：同章 03-射线与球求交（待写）· 上游 [[学习笔记/cg/虎书/01-光栅图像与Gamma校正.md|第三章 光栅图像：像素、显示器与 Gamma 校正]]

---

## 1. 第一步：射线与无限平面求交

### 1.1 两个方程

| | 方程 | 含义 |
|---|---|---|
| **射线** | $\mathbf{p}=\mathbf{e}+t\mathbf{d}$ | $\mathbf{e}$ 起点、$\mathbf{d}$ 方向，$t\ge 0$ 为正向 |
| **平面** | $(\mathbf{p}-\mathbf{p}_1)\cdot\mathbf{n}=0$ | 过点 $\mathbf{p}_1$、法线 $\mathbf{n}$ 的隐式方程 |

### 1.2 代入求解 $t$

把射线方程代入平面方程：

$$
(\mathbf{e}+t\mathbf{d}-\mathbf{p}_1)\cdot\mathbf{n}=0 \;\Longrightarrow\; t\,(\mathbf{d}\cdot\mathbf{n})+(\mathbf{e}-\mathbf{p}_1)\cdot\mathbf{n}=0
$$

解得：

$$
\boxed{\,t=\frac{(\mathbf{p}_1-\mathbf{e})\cdot\mathbf{n}}{\mathbf{d}\cdot\mathbf{n}}\,}
$$

回代 $\mathbf{p}=\mathbf{e}+t\mathbf{d}$ 即得交点 $\mathbf{p}$。

> [!warning] 退化：$\mathbf{d}\cdot\mathbf{n}=0$
> 分母为零意味着射线与平面**平行**——要么无交点，要么躺在平面内（无穷多个），工程实现必须单独处理。另外求出的 $t$ 若为负，交点在射线**背后**，不计命中（光线只朝正向传播）。

---

## 2. 第二步：判断交点是否在多边形内（奇偶射线法）

交点 $p$ 只落在**无限平面**上，还得确认它在多边形边界内。多边形是平面图形，投影到 2D 后用**奇偶射线法**：从 $p$ 沿 +x 发一条射线，数它与多边形边界的交点——

$$
\text{交点数} \begin{cases}\text{奇数} & \Rightarrow \text{点在内部}\\ \text{偶数} & \Rightarrow \text{点在外部}\end{cases}
$$

原理：射线**进一次必出一次**、进出成对，故外部点交点为偶；只有从内部出发的射线，首穿出后才剩奇数个。

> [!warning] 退化：射线穿过顶点会重复计数
> 顶点被两条边共享，都计入就把奇偶搞反。用**半开区间**解决：每条边只认下端点、不认上端点（两端点都用严格 `>` 比较），每个顶点就只被一条边认领；水平边两端同真假、自动跳过。实现见 §4 代码第 ③ 步。

---

## 3. 投影退化与自适应选平面

### 3.1 问题：投影可能退化成线

若固定投影到 xy 平面，当多边形所在平面**恰好垂直于 xy 平面**时，投影后所有顶点**共线**，多边形被压成一条线段——射线法对一条线无法判断内外。

### 3.2 解法：丢弃法线分量绝对值最大的轴

不固定 xy 平面，而在 **xy / yz / zx** 中选最合适的一个。规则是：**丢弃法线 $\mathbf{n}=(x_n,y_n,z_n)$ 中绝对值最大的那个分量所对应的轴，投影到剩下两轴构成的平面**。

为什么丢最大分量就一定不退化？法线某分量最大 = 法线**主方向沿该轴** = 平面**垂直于该轴** = 平面**平行于另两轴构成的坐标面**。投影到那个坐标面时，多边形**面积最大、绝不共线**。一句话：**法线指哪，平面就「躺」在垂直于它的那个坐标面上，往那个面投影最舒展**。

### 3.3 代码：用 index0 / index1 统一三种情况

把点实现成可索引（$p(0)=x_p,\ p(1)=y_p,\ p(2)=z_p$），三种投影就归并成一套代码：

```text
if (abs(zn) > abs(xn)) and (abs(zn) > abs(yn)) then
    index0 = 0          // |zn| 最大 → 丢 z，投 xy 面，用 (x, y)
    index1 = 1
else if (abs(yn) > abs(xn)) then
    index0 = 0          // |yn| 最大（且 zn 非最大）→ 丢 y，投 zx 面，用 (x, z)
    index1 = 2
else
    index0 = 1          // |xn| 最大（或并列）→ 丢 x，投 yz 面，用 (y, z)
    index1 = 2
```

三个分支对应的丢弃 / 投影：

| 分支条件 | 丢弃 | 投影面 | (index0, index1) |
|---|---|---|---|
| $\|z_n\|$ 最大 | z | xy | (0, 1) = (x, y) |
| $\|y_n\|$ 最大（zn 非最大）| y | zx | (0, 2) = (x, z) |
| $\|x_n\|$ 最大 / 并列 | x | yz | (1, 2) = (y, z) |

引入 index0 / index1 后，后续所有 2D 计算统一写成 $p(\text{index0})$、$p(\text{index1})$，**不用为三种投影各写一套代码**。（奇偶射线法出自 Sutherland, Sproull & Schumacker (1974)、Glassner (1989) 的经典光线追踪文献。）

## 4. 完整实现（三步合一）

```cpp
// 射线 e + t*d 与平面多边形求交。
// verts[]/N：共面顶点（取 verts[0] 为 p1）与面法线。命中返回 true 并写出 hit_t。
bool rayPolygonHit(const Vec3 &e, const Vec3 &d,
                   const Vec3 verts[], int n, const Vec3 &N, float &hit_t)
{
    // ① 射线与多边形所在平面求交：t = (p1−e)·N / (d·N)
    float denom = dot(d, N);
    if (fabs(denom) < 1e-8f) return false;        // d·N=0：射线与平面平行，未命中
    float t = dot(verts[0] - e, N) / denom;
    if (t < 0) return false;                       // 交点在射线背后，未命中
    Vec3 p = e + t * d;

    // ② 选投影面：丢法线 |分量| 最大的轴，投影面积最大、不退化
    float ax = fabs(N.x), ay = fabs(N.y), az = fabs(N.z);
    int i0, i1;
    if      (az > ax && az > ay) { i0 = 0; i1 = 1; }   // |Nz| 最大 → 丢 z，投 xy
    else if (ay > ax)            { i0 = 0; i1 = 2; }   // |Ny| 最大 → 丢 y，投 zx
    else                         { i0 = 1; i1 = 2; }   // |Nx| 最大 → 丢 x，投 yz

    // ③ 2D 奇偶射线法（半开区间）：从 p 沿 +i0 数边界交点，奇内偶外。
    //    投影后 i0 相当于 x 轴、i1 相当于 y 轴；测试射线沿 +i0 方向（水平向右）。
    float pu = p[i0], pv = p[i1];                  // 测试点 p 的 2D 坐标 (pu, pv)
    bool inside = false;                            // 奇偶标志：每命中一个有效交点就翻转一次
    for (int k = 0; k < n; k++) {
        // 取当前边 a→b，并用 (i0, i1) 投影成 2D 坐标
        const Vec3 &a = verts[k];
        const Vec3 &b = verts[(k + 1) % n];         // % n：最后一条边连回 verts[0]，闭合多边形
        float au = a[i0], av = a[i1];               // 端点 a 的 2D = (au, av)
        float bu = b[i0], bv = b[i1];               // 端点 b 的 2D = (bu, bv)

        // —— 跨越判定（半开区间）——
        // 边的两端「一上一下」才算跨越测试水平线 i1 = pv。
        // 用严格 > 比较：av>pv 与 bv>pv 真假不同 ⇒ 一端严格在上方、另一端在下方或恰好在线上(≤)。
        // 为什么用 > 而非 >=：恰好 ==pv 的端点被归到「下方」，于是每个顶点只被
        //   「以其为下端点」的那条边认领，避免射线穿顶点时被两边重复计数、奇偶翻车。
        // 附带好处：水平边 av==bv 时两端同真假 ⇒ 条件不成立、自动跳过，
        //   下面的 bv-av 也就绝不会为零，除法安全。
        if ((av > pv) != (bv > pv)) {
            // 线性插值求边与水平线 i1=pv 交点的 i0 坐标：
            // 沿 a→b 走到 i1=pv 处的参数为 (pv-av)/(bv-av)，对应的 i0 值即 cross。
            float cross = au + (pv - av) * (bu - au) / (bv - av);
            // 只数在测试点「右侧」（+i0 方向，cross>pu）的交点，左侧的不管。
            // 每命中一个就翻转 inside；循环结束 inside==true ⇔ 交点数为奇 ⇔ p 在多边形内部。
            if (cross > pu) inside = !inside;
        }
    }
    if (!inside) return false;
    hit_t = t;
    return true;
}
```

> [!info] 代码要点
> - `Vec3` 需支持 `operator[]`（`v[0]=x, v[1]=y, v[2]=z`）——正是原文设想的「可索引点」，让三种投影共用一套 2D 代码。
> - `(av > pv) != (bv > pv)` 一行同时搞定**跨越判定 + 半开区间**：水平边（`av==bv`）两端同真假、自动跳过，`bv-av` 不会为零，除法安全。
> - 三步合一：**求交 → 选面 → 奇偶**，无分支复用同一套 2D 实现。

## 📌 速查表

| 问 | 答案要点 |
|---|---|
| 两步走 | ① 射线和平面求交点 ② 判交点是否在多边形内 |
| 求 $t$ | $t=(\mathbf{p}_1-\mathbf{e})\cdot\mathbf{n}/(\mathbf{d}\cdot\mathbf{n})$ |
| $\mathbf{d}\cdot\mathbf{n}=0$ | 射线与平面平行，退化处理 |
| $t<0$ | 交点在射线背后，不命中 |
| 判内外法 | 奇偶射线法：从 $p$ 发 2D 射线数边界交点，**奇内偶外** |
| 奇偶原理 | 进出成对 → 偶；内部出发首穿出 → 奇 |
| 射线方向 | 沿 x 轴正向最省算：$(x,y)=(x_p,y_p)+s(1,0)$ |
| 投影退化 | 多边形投影成一条线 → 射线法失效 |
| 自适应投影 | 丢法线 $\|n\|$ 最大分量轴，投影面积最大、不退化 |
| index0/index1 | 三种投影归并为一套 2D 代码 |
| 退化（穿顶点/共线）| 半开区间 $y_{\min}\le y_p<y_{\max}$：下端点闭、上端点开，每顶点只被一边认领；水平边自动跳过 |
