# 第十五章 曲线（Curves）

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.15 · PDF 第 352–417 页
> **定位**：本章系统介绍计算机图形学中自由曲线的表示方法——从最基础的多项式片段，到 Bézier 曲线、B 样条，最终到 NURBS。这是几何建模的基础篇章。
> **关联**：依赖第 2 章（向量运算）、第 6 章（矩阵变换）；与第 13 章（光线追踪中的 CSG/实例化）互补

---

## 1. 基础概念（§15.1–15.2）

### 1.1 参数曲线

用参数 $u$ 表达曲线：$\mathbf{f}(u)$ 随 $u$ 变化扫出曲线上的点。

- **自然参数化**：直接用数学函数定义（如 $y = f(x)$），但会限制曲线的形状（竖直部分无法表示）
- **弧长参数化**（$s$）：参数值正比于曲线上走过的距离。需满足 $\left\|\frac{d\mathbf{f}(s)}{ds}\right\|^2 = c$。弧长可表示为 $s = \int_0^v \left\|\frac{d\mathbf{f}(t)}{dt}\right\|^2 dt$

### 1.2 分段表示与样条（Spline）

复杂曲线无法用单一简单函数表达 → **分而治之**：将曲线分成多个小段。权衡三个因素：

1. 逼近精度
2. 每段的复杂程度
3. 段的数量

**样条（Spline）**原指绘图员用的弹性金属条，数学上指**分段多项式函数**。

### 1.3 连续性（Continuity）

- **$C^0$**：位置连续（不断开）
- **$C^1$**：位置 + 一阶导连续（无尖角）
- **$C^n$**：所有 $n$ 阶以下导数均连续

**参数连续性（$C^n$）**依赖参数化速度，**几何连续性（$G^n$）**只关心形状。$G^1$ 条件：$\mathbf{f}'_1(1) = k\mathbf{f}'_2(0)$（同方向即可，大小可不一致）。

---

## 2. 多项式片段（§15.3）

### 2.1 规范形式与基函数

多项式的规范形式（canonical form）：

$$f(t) = a_0 + a_1 t + a_2 t^2 + \cdots + a_n t^n = \sum_{i=0}^n a_i t^i$$

推广为基函数形式：

$$f(t) = \sum_{i=0}^n c_i b_i(t)$$

其中 $b_i(t)$ 是基函数（basis/blending functions），$c_i$ 是系数（控制点）。

### 2.2 约束矩阵与基矩阵

用控制点 $\mathbf{p}$ 来表示曲线的位置/导数等约束，设约束矩阵 $C$：

$$\mathbf{p} = C\,\mathbf{a}$$

则基矩阵 $B = C^{-1}$，曲线可写为：

$$f(u) = \mathbf{u}\,B\,\mathbf{p}$$

其中 $\mathbf{u} = [1, u, u^2, u^3, \ldots, u^n]$。

**混合函数**：$\mathbf{b}(u) = \mathbf{u}B$，每个分量 $b_i(u)$ 表示对应控制点的权重，曲线上每点都是控制点的加权平均。

---

## 3. 组装分段曲线（§15.4）

**结点（knot）**：分段函数的参数区间端点。

**结点向量（knot vector）**：按升序排列的所有结点值。

三种连接相邻段的方式：
1. **共享点法（shared-point）**：相邻段共用端点
2. **依赖传播法（dependency）**：通过等式约束关联
3. **显式数值方程**

**局部性（locality）**：移动一个控制点只影响曲线的有限区域。依赖传播法往往失去局部性——一处改动波及整条曲线。

---

## 4. 三次曲线（§15.5）

三次曲线是图形学中最常用的参数阶数，原因：
- $C^2$ 连续性（视觉上足够光滑）
- 可给出穿过点集的最小曲率插值
- 位置和导数可在两端同时指定
- 数值计算与光滑性之间的良好折中

**不可能同时满足**：每段三次 + 插值控制点 + 局部控制 + $C^2$ 连续性（只能三选四）。

### 4.1 自然三次样条（Natural Cubics）

$C^2$ 连续，插值控制点，但**无局部性**且**病态**——起点的微小改变导致后面大幅变化。只有首段可控制导数。

### 4.2 Hermite 三次样条

指定每段的**首尾位置 + 首尾一阶导数**。$C^1$ 连续，有局部控制。缺点：用户需手动指定导数。

### 4.3 Cardinal 样条 & Catmull-Rom 样条

$C^1$ 插值样条。给定 $n$ 个控制点，产生 $n-2$ 个三次段。每段用 4 个连续控制点——曲线在中间两点间插值，首尾两点的向量决定导数方向。

**张力参数 $t \in [0, 1)$** 控制曲线的"松紧"。$t=0$ 即为 **Catmull-Rom 样条**（最常用的插值样条之一）。

> **vs. 单一插值多项式**：Cardinal 样条有局部性、（计算量 $O(1)$ vs $O(n)$）、不振荡。

---

## 5. 逼近曲线（§15.6）

插值方案往往连续性不足、中间不可控。**逼近方案**虽然曲线不过控制点，但获得更好的行为和局部控制。

### 5.1 Bézier 曲线（§15.6.1）

图形学中最常用的自由曲线表示。$d$ 次 Bézier 曲线由 $d+1$ 个控制点定义。

**关键性质**：
- 插值首尾控制点
- 首端切线 $= d(\mathbf{p}_1 - \mathbf{p}_0)$，尾端切线 $= d(\mathbf{p}_d - \mathbf{p}_{d-1})$
- **凸包性**：曲线始终在控制点的凸包内
- **变差缩减性**：任意直线与曲线的交点数 ≤ 与该直线与控制多边形的交点数
- **对称性**：反转控制点顺序得到相同曲线
- **仿射不变性**

**Bernstein 基多项式**（$n$ 次 Bézier 曲线的混合函数）：

$$b_{k,n}(u) = C(n,k)\,u^k(1-u)^{n-k},\quad C(n,k) = \frac{n!}{k!(n-k)!}$$

三次 Bézier（$n=3$）的混合函数：
$$b_{0,3} = (1-u)^3,\quad b_{1,3} = 3u(1-u)^2,\quad b_{2,3} = 3u^2(1-u),\quad b_{3,3} = u^3$$

基矩阵：
$$B = \begin{bmatrix} 1 & 0 & 0 & 0 \\ -3 & 3 & 0 & 0 \\ 3 & -6 & 3 & 0 \\ -1 & 3 & -3 & 1 \end{bmatrix}$$

#### de Casteljau 算法

通过**反复线性插值**计算 Bézier 曲线上任意点 $u$：
- 将相邻控制点用 $u$ 线性插值，得到 $n-1$ 个新点
- 重复直到只剩一个点——即曲线上 $u$ 处的点

**同时实现细分（subdivision）**：算法中间产出的点正好是被切开的两个子 Bézier 段的新控制点。这催生了高效的 divide-and-conquer 渲染与求交算法。

**几何直觉**：Bézier 曲线 = 反复切角（corner cutting）的极限。

#### 连接 Bézier 段

共享端点 → $C^0$。要让 $G^1$ 连续：两段在连接点处的控制点必须共线。要让 $C^1$ 连续：共线且等距。

### 5.2 B 样条（§15.6.2–15.6.3）

B 样条提供了一种非常通用的方法：$d$ 次多项式、$C^{(d-1)}$ 连续、$n$ 个控制点。

**参数 $k = d+1$**（B 样条的"阶"）。B 样条的通用写法：

$$f(t) = \sum_{i=1}^n \mathbf{p}_i b_{i,k,\mathbf{t}}(t)$$

其中 $b_{i,k,\mathbf{t}}$ 是第 $i$ 个 B 样条基函数，$\mathbf{t}$ 是结点向量（$n+k$ 个非降序值）。

**B 样条的性质**：
- **$C^{(k-2)}$ 连续**
- 每段是 $k-1$ 次多项式
- **局部控制**：曲线上任一点只受 $k$ 个相邻控制点影响
- 凸包性、变差缩减性
- 基函数和为 1（平移不变性）
- B 样条在其 $k+1$ 个结点之外为零
- 曲线总共有 $n+k$ 个结点

#### 均匀 B 样条

**线性 B 样条（$k=2$）**：三角帽形基函数，曲线退化为线性插值折线。

**二次 B 样条（$k=3$）**：由三段二次多项式拼成，$C^1$ 连续。

**三次 B 样条（$k=4$）**：图形学中最常用的 B 样条。在区间 $[t_i, t_{i+1}]$ 内：

$$f(u) = \tfrac{1}{6}(-u^3 + 3u^2 - 3u + 1)\mathbf{p}_i + \tfrac{1}{6}(3u^3 - 6u^2 + 4)\mathbf{p}_{i+1} + \tfrac{1}{6}(-3u^3 + 3u^2 + 3u + 1)\mathbf{p}_{i+2} + \tfrac{1}{6}u^3\mathbf{p}_{i+3}$$

三次均匀 B 样条基矩阵：
$$M_b = \frac{1}{6}\begin{bmatrix} -1 & 3 & -3 & 1 \\ 3 & -6 & 3 & 0 \\ -3 & 0 & 3 & 0 \\ 1 & 4 & 1 & 0 \end{bmatrix}$$

#### Cox–de Boor 递推公式

计算 B 样条的通用递推方程：

$$b_{i,1,\mathbf{t}}(t) = \begin{cases} 1 & \text{if } t_i \le t < t_{i+1} \\ 0 & \text{otherwise} \end{cases}$$

$$b_{i,k,\mathbf{t}}(t) = \frac{t - t_i}{t_{i+k-1} - t_i}\,b_{i,k-1,\mathbf{t}}(t) + \frac{t_{i+k} - t}{t_{i+k} - t_{i+1}}\,b_{i+1,k-1,\mathbf{t}}(t)$$

#### 非均匀 B 样条与重复结点

**非均匀结点间距**的两个用途：
1. 控制每个控制点的参数影响范围
2. **重复结点**：使曲线插值特定控制点（代价是失去光滑性）

**端点插值技巧**：让开头 $k$ 个结点取相同值、结尾 $k$ 个取相同值 → 曲线插值首尾控制点。

### 5.3 NURBS（§15.6.4）

B 样条不能精确表示圆锥曲线。**NURBS**（Nonuniform Rational B-Splines）用两个 B 样条的比值来克服此限制：

$$f(u) = \frac{\sum_{i=1}^n h_i \mathbf{p}_i b_{i,k,\mathbf{t}}(u)}{\sum_{i=1}^n h_i b_{i,k,\mathbf{t}}(u)}$$

每个控制点 $\mathbf{p}_i$ 关联一个**权重** $h_i$。NURBS 广泛用于几何建模（CAD/CAM），因为它能精确表示所有圆锥曲线，且保留了 B 样条的全部优良性质。

## 📌 核心知识点速查

| 概念 | 要点 |
|---|---|
| **弧长参数化** | $\|\frac{d\mathbf{f}(s)}{ds}\|^2 = c$，参数正比于实际长度 |
| **样条** | 分段多项式函数 |
| **$C^n$ vs $G^n$** | 参数连续性 vs 几何连续性（后者只关心方向） |
| **基矩阵 $B$** | $B = C^{-1}$，将控制点转为规范系数：$f(u) = \mathbf{u}B\mathbf{p}$ |
| **局部性** | 移动控制点只影响曲线的有限区域 |
| **四种性质不可兼得** | 三次段 + 插值 + 局部控制 + $C^2$ → 只能三选四 |
| **自然三次** | $C^2$ + 插值，但无局部性且病态 |
| **Hermite** | 指定端点位置+导数，$C^1$，用户需手动给导数 |
| **Catmull-Rom** | Cardinal 样条的特例（$t=0$），插值+局部+$C^1$ |
| **张力参数 $t$** | Cardinal 样条中控制松紧，$t \in [0, 1)$ |
| **Bézier 曲线** | 逼近型，Bernstein 基，凸包性，变差缩减性 |
| **de Casteljau 算法** | 反复线性插值，同时计算点+细分 |
| **Bernstein 多项式** | $b_{k,n}(u) = C(n,k)u^k(1-u)^{n-k}$ |
| **三次 Bézier 基矩阵** | 见 §5.1 公式 |
| **B 样条参数 $k$** | $k = d+1$，决定连续性和多项式次数 |
| **均匀三次 B 样条** | $C^2$，局部控制，基矩阵见 §5.2 |
| **Cox–de Boor 递推** | 通用 B 样条计算方法，支持任意 $k$ 和非均匀结点 |
| **重复结点** | 使 B 样条插值控制点，代价是失去光滑性 |
| **端点插值 B 样条** | 首尾 $k$ 个结点相等 → 曲线插值首尾控制点 |
| **NURBS** | B 样条的比值形式，带权重 $h_i$，可精确表示圆锥曲线 |

## 🔗 曲线类型选择指南

| 需求 | 推荐方案 |
|---|---|
| 简单插值、够用即可 | Catmull-Rom / Cardinal 样条 |
| 交互设计、自由造型 | 三次 Bézier（直觉控制、de Casteljau 细分高效） |
| 高光滑度（$C^2$ 以上） | 三次 B 样条（$k=4$） |
| 需精确圆锥曲线（CAD） | NURBS |
| 穿过大量点的高次多项式 | ❌ 不推荐（振荡、非局部、计算量大） |
