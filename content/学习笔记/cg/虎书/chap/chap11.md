# 第十一章 纹理映射（Texture Mapping）

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.11 Texture Mapping · PDF 第 258–294 页
> **定位**：真实世界几乎没有无特征的表面——木纹、皱纹、编织结构、划痕……纹理映射用一张图像（纹理贴图）存储这些细节，再数学地"映射"到表面上。本章是图形学中最实用的章节之一，涵盖纹理坐标函数、抗锯齿查找、以及纹理映射的各类应用。
> **关联**：依赖第 9 章（信号处理/采样）、第 8 章（光栅化/重心插值）、第 7 章（透视投影）、第 10 章（着色模型）

## 1. 纹理值查找（§11.1）

### 1.1 基本流程

着色器在计算某个表面点的颜色时，需要知道该点处的纹理颜色。过程分两步：

1. **纹理坐标函数** $\varphi$：将表面上的三维点 $(x,y,z)$ 映射到纹理空间中的二维坐标 $(u,v)$。
2. **纹理查找**：在纹理图像中读取 $(u,v)$ 处的颜色值（纹素，texel），用于着色计算。

```python
Color texture_lookup(Texture t, float u, float v):
    i = round(u * t.width - 0.5)
    j = round(v * t.height - 0.5)
    return t.get_pixel(i, j)

Color shade_surface_point(Surface s, Point p, Texture t):
    normal = s.get_normal(p)
    (u, v) = s.get_texcoord(p)
    diffuse_color = texture_lookup(t, u, v)
    # 用 diffuse_color 和 normal 计算着色
```

### 1.2 三个空间

纹理渲染涉及三个空间和两个映射：

| 映射 | 方向 | 作用 |
|---|---|---|
| $\pi$（观察投影） | 3D 表面 → 2D 图像 | 决定着色结果放在图像的哪个像素 |
| $\varphi$（纹理坐标函数） | 3D 表面 → 2D 纹理空间 | 决定从纹理的哪里取值 |

$\varphi$ 是**从表面到纹理**的映射（而非反过来），这一点初看反直觉，但正是渲染所需的函数。与 $\pi$ 不同，$\varphi$ 可以取多种形式，且场景中每个对象可以有独立的纹理坐标函数。

### 1.3 两个根本问题

1. **定义纹理坐标函数**——如何为表面上的每个点指定 $(u,v)$？（§11.2）
2. **抗锯齿查找**——如何在查找纹理值时不引入过多混叠？（§11.3）

## 2. 纹理坐标函数（§11.2）

### 2.1 设计目标

设计 $\varphi$ 类似于制图师设计地图投影——将弯曲的曲面展平到平面不可避免地产生畸变。四个相互竞争的目标：

| 目标 | 含义 |
|---|---|
| **双射性** | 表面上每个点映射到纹理空间中不同的点；避免意外的一对多 |
| **尺寸畸变小** | $\varphi$ 的导数幅值在表面上不应变化过大 |
| **形状畸变小** | $\varphi$ 的导数在不同方向上不应差异过大（小圆映射后仍近似圆） |
| **连续性** | 相邻表面点映射到相邻纹理点；不连续（接缝）应尽量少且放在不显眼处 |

### 2.2 几何确定的坐标（§11.2.1）

几何确定的纹理坐标用于简单形状或特殊场景，作为快速解决方案或手动调整的起点。核心思路：直接从表面点的三维空间坐标 $(x,y,z)$ 计算纹理坐标 $(u,v)$，不需要顶点存储。所有函数适用于中心在原点、包围盒 $[-1,1]^3$ 的对象。

#### 2.2.1 平面投影（Planar Projection）

最简单的 3D→2D 映射。沿一个方向做平行投影——与正交视图完全相同的机制，只是把输出从"屏幕像素"换成"纹理坐标"。

用一个 $4\times4$ 仿射矩阵 $M_t$ 乘以齐次坐标，取前两行作为 $(u,v)$，丢弃第三行：

$$\begin{bmatrix}u\\v\\*\\1\end{bmatrix} = M_t \begin{bmatrix}x\\y\\z\\1\end{bmatrix}$$

$M_t$ 可以包含旋转、缩放和平移，使得投影方向不必拘泥于坐标轴。选投影方向的一个实用方法是取表面的**平均法线**——对大部分平坦的表面，这给出畸变最小的方向。

**适用场景**：大部分平坦、法线变化不大的表面（地面、墙面、标牌）。

**致命缺陷**：对任何封闭形状，平面投影**不单射**——沿投影方向的正反两面映射到纹理空间的同一点。在投影方向与表面相切处（侧面），纹理被极端拉伸。

> [!example] 具体例子
> 一个球体沿 $z$ 轴做平面投影：$u=x, v=y$。球的"前面"和"后面"都映射到纹理空间的同一个圆盘上——纹理在正反两面完全重合。赤道附近（$z\approx0$）的法线几乎垂直于投影方向，纹理被严重拉伸，形成一条挤压带。

#### 2.2.2 投影纹理坐标（Projective Coordinates）

将平面投影中的正交投影换成**透视投影**，就得到投影纹理坐标。矩阵 $P_t$ 的最后一行不再是 $[0,0,0,1]$，而是可以包含任意值，使得所有光线汇聚到一个点：

$$\begin{bmatrix}\tilde{u}\\\tilde{v}\\*\\w\end{bmatrix} = P_t \begin{bmatrix}x\\y\\z\\1\end{bmatrix},\qquad \varphi(x,y,z) = \left(\frac{\tilde{u}}{w},\;\frac{\tilde{v}}{w}\right)$$

几何上，这相当于从一个点出发向所有方向发射光线，光线打到表面上某点的方向决定该点的纹理坐标。

**典型应用——阴影贴图（§11.4.4）**：光源在某个位置向场景投射，从光源视角渲染深度图。渲染主场景时，将每个片段的位置用投影纹理坐标映射回"从光源看到的深度图"，判断该片段是否被遮挡。这本质就是把光源当作一台"纹理投影器"。

**与平面投影的关系**：平面投影是 $w\equiv1$（仿射变换）的特例；投影纹理坐标允许 $w$ 随空间位置变化（透视除法），所以能模拟聚光灯式的放射状映射。

#### 2.2.3 球坐标（Spherical Coordinates）

对球体或近似球形的物体，经纬度参数化是最直觉的选择——就像地球仪展开成世界地图。

**方法**：从球心出发，穿过表面点作一条射线，找到射线与单位球的交点。该交点的球坐标 $(\theta,\varphi)$（丢弃半径 $\rho$）即为纹理坐标。

使用 §2.5.8 的球坐标约定，将 $(\theta,\varphi)$ 各自映射到 $[0,1]$：

$$\varphi(x,y,z) = \left(\underbrace{\frac{\pi + \text{atan2}(y,x)}{2\pi}}_{u\text{（经度→水平）}},\;\underbrace{\frac{\pi - \arccos(z/\|\mathbf{x}\|)}{\pi}}_{v\text{（纬度→垂直）}}\right)$$

- $u$ 分量：$\text{atan2}(y,x) \in [-\pi,\pi]$ 是方位角（经度），加 $\pi$ 平移到 $[0,2\pi]$，除 $2\pi$ 归一化到 $[0,1]$。
- $v$ 分量：$\arccos(z/\|\mathbf{x}\|) \in [0,\pi]$ 是极角（polar angle / 余纬度），即从 $+z$ 轴量起的角度。$v$ 的构造分三步：
  1. **算极角**：$\varphi = \arccos(z/\|\mathbf{x}\|)$，北极 $\varphi=0$、赤道 $\varphi=\pi/2$、南极 $\varphi=\pi$。
  2. **翻转**：$\pi - \varphi$，把"从北极量起"翻转为"从南极量起"——否则直接归一化会导致北极 $v=0$、南极 $v=1$，纹理上下颠倒。
  3. **归一化**：除 $\pi$ 映射到 $[0,1]$。

**双射性**：若整个表面从球心可见（如凸物体的外表面），则除两极外处处双射。

**畸变特征**：
- **极点压缩**：所有经线汇聚到极点，$u$ 方向的纹理被极端压缩。赤道处一个纹素覆盖的表面面积远小于极点处。直观地说，如果在球面上画一个均匀网格，展开后越靠近极点，水平方向的格子越挤。
- **接缝**：$\text{atan2}$ 在 $+\pi$ 和 $-\pi$ 之间跳变，形成一条从北极到南极的经线接缝（通常放在太平洋，180°经线）。

**适用场景**：近似球形的物体（行星、圆顶、蛋形物体）。对远非球形的物体（如花瓶）畸变严重，应改用柱面坐标。

> [!example] 具体例子
> 一个花瓶用球坐标映射：花瓶的中部（最宽处）纹理密度合理，但花瓶顶部和底部（接近极点处）的纹理被严重挤压——原本竖直的木纹在瓶口处挤成一团。改用柱面坐标后，沿高度方向均匀分布，效果显著改善。

#### 2.2.4 柱面坐标（Cylindrical Coordinates）

对更"柱状"而非"球状"的物体（花瓶、柱子、管道），从中心轴向外投影到包围圆柱面上比从球心投影到球面更自然。

**方法**：转换为柱面坐标 $(r,\theta,z)$，丢弃半径 $r$，将角度 $\theta$ 和高度 $z$ 映射到 $[0,1]$：

$$\varphi(x,y,z) = \left(\underbrace{\frac{1}{2\pi}[\pi + \text{atan2}(y,x)]}_{u\text{（角度→水平）}},\;\underbrace{\frac{1}{2}[1+z]}_{v\text{（高度→垂直）}}\right)$$

- $u$ 分量：与球坐标的 $u$ 完全相同——方位角归一化到 $[0,1]$，绕轴一圈对应纹理水平方向一个周期。
- $v$ 分量：直接用 $z$ 坐标（物体在 $[-1,1]$ 内），$(1+z)/2$ 映射到 $[0,1]$。不再用极角，所以**没有极点压缩**——$v$ 沿高度方向线性均匀分布。

**优势**：高度方向无畸变，角度方向只在远离轴心时有一致的拉伸（可接受）。适合沿一个轴有延伸、截面近圆的物体。

**局限**：
- 截面非圆形时畸变（方形截面用柱面坐标会有四角拉伸）
- 仍有 $\text{atan2}$ 的角度接缝（一条竖直缝）
- 端面（圆柱顶底面）法线平行于轴，柱面投影退化

#### 2.2.5 立方体贴图（Cubemaps）

球坐标在极点畸变严重，产生明显的视觉瑕疵。立方体贴图用一种更均匀的替代方案：投影到包围的立方体上，而非球面。

**方法**：从中心出发，沿 $(x,y,z)$ 方向射线与立方体 $[-1,1]^3$ 相交。交点落在六个面之一上，该面上的二维坐标即为纹理坐标。六个面各自有一张独立的方形纹理。

**选择哪个面**：取绝对值最大的坐标轴。例如 $|x|>|y|$ 且 $|x|>|z|$ → 投影到 $+x$ 或 $-x$ 面，取决于 $x$ 的符号。这保证每个方向唯一对应一个面。

**投影计算**：投影到平面只需一次除法——与透视投影相同。例如投到 $+z$ 面：

$$(x,y,z) \mapsto \left(\frac{x}{z},\;\frac{y}{z}\right)$$

**OpenGL 六面公式**（约定从立方体内部观察时 $u$ 相对于 $v$ 为顺时针）：

$$\varphi_{-x}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(+z,\,-y\bigr)/|x|\Bigr]$$

$$\varphi_{+x}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(-z,\,-y\bigr)/|x|\Bigr]$$

$$\varphi_{-y}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(+x,\,-z\bigr)/|y|\Bigr]$$

$$\varphi_{+y}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(+x,\,+z\bigr)/|y|\Bigr]$$

$$\varphi_{-z}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(-x,\,-y\bigr)/|z|\Bigr]$$

$$\varphi_{+z}(x,y,z) = \tfrac{1}{2}\Bigl[1 + \bigl(+x,\,-y\bigr)/|z|\Bigr]$$

**逐步拆解——以 $+z$ 面 $\varphi_{+z}$ 为例**：

$$\varphi_{+z}(x,y,z) = \frac{1}{2}\left[1 + \frac{(+x,\,-y)}{|z|}\right]$$

1. **选面**：$z>0$ 且 $|z|$ 是三个分量中绝对值最大的 → 投影到 $+z$ 面。
2. **归一化到 $[-1,1]$**：除以主轴绝对值 $|z|$。因为 $|x|\le|z|$ 且 $|y|\le|z|$（选面规则保证），所以 $x/|z|\in[-1,1]$、$y/|z|\in[-1,1]$。
3. **确定 $u,v$ 取哪个坐标**：$+z$ 面上 $u$ 取 $+x$、$v$ 取 $-y$。即 $u_{\text{raw}} = x/|z|$，$v_{\text{raw}} = -y/|z|$。
4. **映射到 $[0,1]$**：加 $1$ 平移到 $[0,2]$，除 $2$ 缩放到 $[0,1]$：

$$u = \frac{1 + x/|z|}{2},\qquad v = \frac{1 + (-y/|z|)}{2} = \frac{1 - y/|z|}{2}$$
**优势**：
- **畸变低**：每个面上投影近似均匀，没有球坐标的极点汇聚问题。形状和面积畸变都远小于球面映射。
- **计算便宜**：只需比较绝对值和一次除法，比球坐标的 `atan2` + `arccos` 快得多。

**代价**：
- **更多不连续**：六条立方体边上纹理坐标突变（从一个面切换到另一个面），需要六张独立纹理。
- **接缝处理**：跨越立方体边的三角形需要特殊处理（类似球坐标的经线接缝问题）。

**典型应用**：环境映射（§11.4.5）——从立方体内部观察，六个面分别记录六个方向的远处环境。六张纹理通常以"展开的立方体"（如水平十字）排列在一张图像中存储。

> [!example] 对比球坐标与立方体贴图
> 对一个天空环境贴图：球坐标在极点处把大面积天空压缩到纹理的一个点，导致极点附近的天空模糊或出现伪影。立方体贴图把天空均匀分到六个面，每个面内畸变很小——代价是六面边上有接缝，但天空纹理通常连续性要求不高，接缝可以隐藏在不显眼的方向。

#### 小结：五种几何坐标函数对比

| 方法 | $u$ 来源 | $v$ 来源 | 适合形状 | 主要缺陷 | 计算量 |
|---|---|---|---|---|---|
| 平面投影 | 仿射变换取两行 | 同左 | 平坦表面 | 封闭形状非单射；切向拉伸 | 最低（矩阵乘法） |
| 投影纹理 | 透视除法 $\tilde{u}/w$ | $\tilde{v}/w$ | 阴影/聚光灯 | 同平面投影 | 低（矩阵+除法） |
| 球坐标 | 方位角 | 余纬度 | 球/椭球/蛋形 | 极点畸变严重 | 高（atan2+arccos） |
| 柱面坐标 | 方位角 | 高度 $z$ | 柱/管/花瓶 | 端面退化；非圆截面畸变 | 中（atan2） |
| 立方体贴图 | 面上坐标 | 面上坐标 | 环境/天空 | 六条边接缝 | 低（比较+除法） |

### 2.3 插值纹理坐标（§11.2.2）

对三角形网格，最灵活的方式是在**每个顶点**存储纹理坐标 $(u,v)$，然后用**重心坐标插值**在三角形内部平滑过渡：

$$\mathbf{c} = \alpha\,\mathbf{c}_0 + \beta\,\mathbf{c}_1 + \gamma\,\mathbf{c}_2$$

与颜色、法线等的插值完全相同。共享顶点的网格上，纹理坐标自动连续——相邻三角形在共享边上达成一致。但双射性不自动保证：如果三角形在纹理空间中重叠，纹理中的同一点会出现在表面的多个位置。

**可视化方法**：将网格的三角形在纹理空间中画出来（顶点放在其纹理坐标位置），可以看到哪些纹理区域被哪些三角形使用，是调试纹理映射的利器。

**畸变评估**：
- **尺寸畸变**：纹理空间中三角形的面积与 3D 面积不成比例时出现。例如鼻子被压缩到纹理空间的小区域，导致纹理在鼻子上被放大。
- **形状畸变**：纹理空间中三角形形状与 3D 中差异大时出现。例如球面坐标在极点附近的极端拉伸。
 
### 2.4 平铺、环绕模式与纹理变换（§11.2.3）

纹理坐标超出 $[0,1]^2$ 时需要处理：

| 模式                  | 做法                   | 用途          |
| ------------------- | -------------------- | ----------- |
| **平铺（tiling/wrap）** | 用取余运算 `i % width` 环绕 | 重复图案（砖墙、棋盘） |
| **钳制（clamp）**       | 坐标限制在边缘像素            | 纹理只覆盖部分表面   |
| **背景色**             | 越界返回常量颜色             | 徽标/贴花       |

**纹理变换矩阵**：

模型自带的纹理坐标函数 $\varphi_{\text{model}}(\mathbf{x})$ 把表面点映射到 $[0,1]^2$，覆盖整张纹理。但实际需求常常是：

- **纹理只覆盖表面的一部分**——比如徽标只贴在墙的中间一块，其余留白
- **纹理重复多次**——砖墙图案在表面上重复 $5\times3$ 次
- **纹理旋转或偏移**——把图案转 $45°$ 或挪一点位置

直接改顶点存储的 $(u,v)$ 值可以做到，但很麻烦——要遍历每个顶点改数据。纹理变换矩阵的做法是：**不改顶点数据**，在 $\varphi_{\text{model}}$ 的输出和最终采样之间插入一个矩阵 $M_T$：

$$\varphi(\mathbf{x}) = M_T\,\varphi_{\text{model}}(\mathbf{x})$$

用齐次坐标写成矩阵乘法（$(u,v,1)$ 是齐次化的纹理坐标）：

$$\begin{bmatrix}u'\\v'\\1\end{bmatrix} = M_T \begin{bmatrix}u\\v\\1\end{bmatrix}$$

$M_T$ 是 $3\times3$ 矩阵，可以表示仿射变换（缩放+旋转+平移）甚至投影变换。

**具体例子——三种常见操作**：

**① 缩放（让纹理重复多次）**：想把纹理在 $u$ 方向重复 4 次、$v$ 方向重复 2 次：

$$M_T = \begin{bmatrix}4&0&0\\0&2&0\\0&0&1\end{bmatrix} \Rightarrow \begin{cases}u'=4u\\v'=2v\end{cases}$$

原来 $u\in[0,1]$ 现在变成 $u'\in[0,4]$，配合平铺环绕模式，纹理自动重复 4 次。

**② 平移（挪动纹理位置）**：想把整体右移 0.3、上移 0.1：

$$M_T = \begin{bmatrix}1&0&0.3\\0&1&0.1\\0&0&1\end{bmatrix} \Rightarrow \begin{cases}u'=u+0.3\\v'=v+0.1\end{cases}$$

**③ 缩小并居中（纹理只覆盖中间一小块）**：把纹理缩小到原来的 $1/10$ 并放到表面中心。先缩 $1/10$ 再平移到中心：

$$M_T = \begin{bmatrix}0.1&0&0.45\\0&0.1&0.45\\0&0&1\end{bmatrix} \Rightarrow \begin{cases}u'=0.1\,u+0.45\\v'=0.1\,v+0.45\end{cases}$$

原来 $u\in[0,1]$ → $u'\in[0.45, 0.55]$，纹理只占表面中间 $10\%$ 的区域，其余靠钳制模式返回边缘色（背景色）。

**为什么不直接改顶点坐标？**

- 顶点数据可能来自外部模型文件，改了就破坏了原始数据
- 同一个网格可能被多次使用，每次需要不同的纹理摆放
- 矩阵变换在着色器中实时计算，改一行矩阵参数即可调整，无需重传顶点数据

### 2.5 透视校正插值（§11.2.4）

#### 问题：屏幕空间直接插值纹理坐标是错的

考虑一堵铺满方格纹理的墙，透视视角下近大远小——3D 中均匀的方格在图像中应该越远越密。但如果在屏幕空间中直接线性插值 $(u,v)$，远处和近处方格大小一样——纹理不对。

**为什么会出错？** 从世界空间到屏幕空间经过三步：

$$\underbrace{\begin{bmatrix}x_q\\y_q\\z_q\\1\end{bmatrix}}_{\text{世界空间 }\mathbf{q}} \xrightarrow{\text{变换}} \underbrace{\begin{bmatrix}x_r\\y_r\\z_r\\w_r\end{bmatrix}}_{\text{齐次坐标 }\mathbf{r}} \xrightarrow{\text{齐次化}} \underbrace{\begin{bmatrix}x_r/w_r\\y_r/w_r\\z_r/w_r\\1\end{bmatrix}}_{\text{屏幕空间 }\mathbf{s}}$$

朴素的光栅化代码在屏幕空间中用重心坐标 $(\alpha,\beta,\gamma)$ 插值一切：

```
compute (α, β, γ) for (xs, ys)
u = α*u0 + β*u1 + γ*u2     // ← 直接在屏幕空间插值 u
v = α*v0 + β*v1 + γ*v2
```

问题出在哪？屏幕空间等距的两个像素 $\mathbf{s}_1, \mathbf{s}_2$ 对应的世界空间点 $\mathbf{q}_1, \mathbf{q}_2$ **不等距**——透视使远处世界空间的点在屏幕上挤在一起。屏幕空间均匀插值 $\alpha$ 对应的 $t$ 不是均匀的。

**参数 $t$ 和 $\alpha$ 的关系**（式 11.1）：

世界空间中按 $t$ 等分线段 $\mathbf{q}\to\mathbf{Q}$，屏幕空间中对应按 $\alpha$ 等分线段 $\mathbf{s}\to\mathbf{S}$，但两者不相等：

$$t(\alpha) = \frac{w_r\,\alpha}{w_R + \alpha(w_r - w_R)},\qquad \alpha(t) = \frac{w_R\,t}{w_r + t(w_R - w_r)}$$

当 $w_r = w_R$（两点 $w$ 相同，如正交投影）时 $t=\alpha$，插值无误差。但透视投影中 $w_r \neq w_R$，$t$ 和 $\alpha$ 的关系是**非线性的**——屏幕上均匀的步长对应世界中不均匀的步长。

#### 关键观察：透视变换保持平面

> [!note] 核心直觉
> 透视变换保持直线和平面。如果把纹理坐标 $u$ 当作一个"额外的空间坐标"和 $(x,y,z,w)$ 一起做透视除法，它在屏幕空间中仍然是线性的——只是被 $w$ 扭曲了，但扭曲方式和位置坐标完全相同。

具体推理（降维到 1D 属性 $u$ 便于理解）：

1. 在齐次空间中，属性 $u$ 是 $x_r, y_r$ 的**线性函数**——画成高度场就是一个平面。
2. 把 $u$ 当作第三坐标 $u_r$，与 $(x_r, y_r, w_r)$ 一起送进透视除法，得到 $(x_s, y_s, u_s) = (x_r/w_r,\; y_r/w_r,\; u_r/w_r)$。
3. 透视变换保持平面，所以 $u_s = u/w_r$ 在屏幕空间 $(x_s, y_s)$ 上仍然是**线性函数**——可以在屏幕空间中直接用重心坐标线性插值，无误差。

> [!tip] 一句话总结
> 透视除法对 $u$ 和 $w$ 做了同样的扭曲（都除以 $w$），所以 $u/w$ 在屏幕空间中可以线性插值。朴素方法的错误在于：只对 $u$ 做了扭曲（用屏幕空间 $\alpha$），却没有对 $w$ 做相应处理——"组件选择不一致"。

#### 解决方案：插值 $u/w$、$v/w$、$1/w$ 再相除

把顶点属性 $(u, v)$ 和常数 $1$ 都除以 $w$，变成 $(u/w,\; v/w,\; 1/w)$，全部送进齐次坐标一起做透视除法：

$$\begin{bmatrix}u\\v\\1\\x_r\\y_r\\z_r\\w_r\end{bmatrix} \xrightarrow{\text{齐次化}} \begin{bmatrix}u/w_r\\v/w_r\\1/w_r\\x_r/w_r = x_s\\y_r/w_r = y_s\\z_r/w_r = z_s\\1\end{bmatrix}$$

齐次化之后，$u/w_r$、$v/w_r$、$1/w_r$ 都是屏幕空间的线性函数，可以安全地用重心坐标插值。但插值得到的是 $u/w_r$ 而非 $u$——需要额外存一个 $1/w_r$，最后做一次除法恢复 $(u, v)$：

$$u = \frac{u/w_r}{1/w_r},\qquad v = \frac{v/w_r}{1/w_r}$$

**为什么这恰好正确？** 屏幕空间中按 $\alpha$ 插值 $u/w_r$ 得到的是 $\alpha(u_R/w_R) + (1-\alpha)(u_r/w_r)$——这正是世界空间中按 $t(\alpha)$ 对应的点处的 $u/w$ 值。同理插值 $1/w_r$ 得到该点处的 $1/w$ 值。两者相除恰好消掉了 $w$，还原出正确的 $u$。

式 (11.3) 验证了 $1/w_r$ 可以在屏幕空间中线性插值：

$$\frac{1}{w_r} + \alpha(t)\left(\frac{1}{w_R} - \frac{1}{w_r}\right) = \frac{1}{w_r + t(w_R - w_r)}$$

左边是屏幕空间插值 $1/w$，右边是世界空间插值 $w$ 后取倒数——两者相等。

#### 完整光栅化伪代码

三个顶点 $i=0,1,2$ 已经过观察矩阵变换但**未齐次化**，附带纹理坐标 $(u_i, v_i)$，齐次坐标的 $w$ 分量为 $w_i$：

```
for all xs do
    for all ys do
        compute (α, β, γ) for (xs, ys)
        if (α ∈ [0,1] and β ∈ [0,1] and γ ∈ [0,1]) then
            // 对 u/w、v/w、1/w 做屏幕空间重心插值
            us = α(u0/w0) + β(u1/w1) + γ(u2/w2)
            vs = α(v0/w0) + β(v1/w1) + γ(v2/w2)
            1s = α(1/w0) + β(1/w1) + γ(1/w2)
            // 一次除法恢复 (u, v)
            u = us / 1s
            v = vs / 1s
            drawpixel(xs, ys) with color texture(u, v)
```

### 2.6 连续性与接缝（§11.2.5）

**拓扑学基本结论**：对任何封闭的 3D 曲面，不存在连续且双射的函数将其映射到平面纹理图像。必须引入**接缝**——表面上纹理坐标突变的曲线。

球坐标和柱面坐标的接缝在 `atan2` 从 $\pi$ 跳到 $-\pi$ 处；立方体贴图的接缝在立方体边上。

**共享顶点网格的问题**：插值纹理坐标自动连续——但这恰恰是问题所在。如果一个三角形跨越接缝（部分顶点在 $\lambda\approx+180°$，部分在 $\lambda\approx-180°$），插值会"绕远路"穿过整个纹理图，产生反向副本压缩在接缝条带中。

**解决方案——顶点复制**：在接缝处不共享纹理坐标。为接缝上的每个顶点创建一个副本，相同 3D 位置但纹理坐标相差 $360°$。接缝两侧的三角形使用不同的顶点，各自正确插值。

## 3. 抗锯齿纹理查找（§11.3）

### 3.1 像素的足迹（§11.3.1）

纹理映射是一个**采样过程**，而纹理的全部意义就是引入细节，因此纹理是混叠的主要来源。

每个像素值应该是图像在该像素面积上的平均颜色。如果像素观察单个表面，这相当于在表面上取平均，进而等于在纹理空间中对应的区域取平均——这个区域称为该像素的**纹理空间足迹（footprint）**。

三个空间的复合映射决定足迹：$\psi = \varphi \circ \pi^{-1}$（先沿 $\pi$ 反向从图像到表面，再沿 $\varphi$ 正向到纹理空间）。

足迹的大小和形状取决于：
- **观察距离**：近处足迹小，远处足迹大
- **观察角度**：斜视角使足迹拉长
- **纹理坐标函数**：面积畸变使足迹大小变化，形状畸变使足迹拉长

**线性近似**：用雅可比矩阵 $J$ 近似 $\psi$ 的导数，足迹近似为平行四边形：

$$J = \begin{pmatrix} \partial u/\partial x & \partial u/\partial y \\ \partial v/\partial x & \partial v/\partial y \end{pmatrix}$$

两列向量 $\mathbf{u}_x = (\partial u/\partial x,\;\partial v/\partial x)$ 和 $\mathbf{u}_y = (\partial u/\partial y,\;\partial v/\partial y)$ 张成的平行四边形近似像素足迹。

### 3.2 重建——放大情况（§11.3.2）

当足迹小于一个纹素时（**放大/magnification**），问题是在纹素之间插值，产生平滑图像。与图像上采样相同，用**重建滤波器**在纹素间插值。

纹理中通常使用的最高质量滤波器是**双线性插值**——读四个相邻纹素并加权平均：

```python
Color tex_sample_bilinear(Texture t, float u, float v):
    u_p = u * t.width - 0.5
    v_p = v * t.height - 0.5
    iu0 = floor(u_p); iu1 = iu0 + 1
    iv0 = floor(v_p); iv1 = iv0 + 1
    a_u = iu1 - u_p;  b_u = 1 - a_u
    a_v = iv1 - v_p;  b_v = 1 - a_v
    return  a_u*a_v*t[iu0][iv0] + a_u*b_v*t[iu0][iv1] +
            b_u*a_v*t[iu1][iv0] + b_u*b_v*t[iu1][iv1]
```

> [!note] 为什么不用更高质量的滤波器？
> 图像重采样中，规则网格使得可分离滤波器能大幅优化。但纹理查找的模式不规则（图像到纹理空间的映射是任意的），每个样本须单独计算，大型滤波器代价过高。双线性插值是性能与质量的实用折中。如果需要更平滑的效果，可以预先用更好的滤波器将纹理重采样到更高分辨率。

### 3.3 多级渐远纹理 / Mipmapping（§11.3.3–11.3.4）

当足迹覆盖多个纹素时（**缩小/minification**），需要计算大量纹素的平均值。逐个读取数千个纹素代价太高。

**Mipmap**（multum in parvo，"小空间里的大容量"）是一组同一图像在不同分辨率下的版本，构成**图像金字塔**：

| 层级 | 分辨率 | 每纹素覆盖原始纹理 |
|---|---|---|
| Level 0（基础层） | $n_u \times n_v$ | $1 \times 1$ |
| Level 1 | $n_u/2 \times n_v/2$ | $2 \times 2$ |
| Level $k$ | $n_u/2^k \times n_v/2^k$ | $2^k \times 2^k$ |

例如 $1024 \times 1024$ 的纹理可生成 11 层（Level 0 到 Level 10，最后一层只有 1 个纹素）。每层通过对上一层 2 倍下采样生成。

**三线性过滤（Trilinear filtering）**：

1. 根据足迹大小选择层级：$D$ 为足迹宽度（以纹素计），$k = \log_2 D$
2. 在 $k_0 = \lfloor k \rfloor$ 和 $k_1 = k_0 + 1$ 两层各做一次双线性插值
3. 在两层结果之间线性插值

```
D = max(‖ux‖, ‖uy‖)          // 足迹最长边
k = log2(D)
k0 = floor(k); k1 = k0 + 1
a = k1 - k;  b = 1 - a
c0 = tex_sample_bilinear(mip[k0], u, v)
c1 = tex_sample_bilinear(mip[k1], u, v)
return a * c0 + b * c1
```

> [!warning] 基础 Mipmapping 的局限
> Mipmap 用正方形区域近似足迹。当足迹被拉长（斜视角观察平面）时，正方形近似过大，导致水平方向**模糊**。这是地板场景常见的问题。

### 3.4 各向异性过滤（§11.3.5）

解决 Mipmapping 模糊问题的方案：根据足迹的**最短轴**选择 mipmap 层级（而非最长轴），然后沿**长轴方向**取多个采样并平均。这样能更好地近似拉长的各向异性足迹。

## 4. 纹理映射的应用（§11.4）

### 4.1 控制着色参数（§11.4.1）

最基本的用途：用纹理控制漫反射颜色 $\mathbf{c}_r$。但不限于颜色——**任何着色参数**都可以用纹理控制：

- 漫反射颜色 → 贴花、装饰、文字、材质颜色变化
- 镜面反射率 → 胶带区域更亮
- 高光粗糙度 → 印刷区域更粗糙
- 多参数同时变化 → 金属墨水印刷处颜色、高光、粗糙度同时改变

### 4.2 法线贴图与凹凸贴图（§11.4.2）

**法线贴图（Normal Map）**：在每个纹素存储法线向量 $(n_x, n_y, n_z)$ 而非颜色。利用着色法线不必等于几何法线的事实（§8.2 插值法线），从纹理读取法线用于着色计算。

**坐标系问题**：
- **物体空间法线贴图**：法线直接存储在物体坐标系中，简单但与几何绑定——表面变形时失效。
- **切线空间法线贴图**：定义一个附着于表面的局部坐标系（切线空间），法线在局部基中表示。因为法线大多接近平滑表面法线方向，所以接近 $(0,0,1)^T$。纹理坐标函数提供切向量（$u$ 和 $v$ 等值线方向），通过正交化得到标准正交基。

**凹凸贴图（Bump Map）**：存储高度场而非法线。高度场的**导数**即为法线贴图（在切线框架中表示）。亮区=凸起，暗区=凹陷。窄暗线=划痕，小白点=凸起。

### 4.3 位移贴图（§11.4.3）

法线贴图只是着色技巧，不改变几何。问题：轮廓仍平滑（看不到真正的凸起边缘）、动画中缺乏视差。

**位移贴图**实际改变几何：将每个表面点沿法线方向移动到新位置。实现方式：将平滑表面细分为大量小三角形，在顶点阶段用纹理查找位移顶点。特别适用于地形。

| | 法线贴图 | 位移贴图 |
|---|---|---|
| 改变几何 | 否 | 是 |
| 轮廓效果 | 平滑（看不出凸起） | 正确（有真实凸起） |
| 动画视差 | 无 | 有 |
| 开销 | 低（仅着色） | 高（需要细分会几） |

### 4.4 阴影贴图（§11.4.4）

光栅化中获取阴影的技术，利用纹理映射机制。

**核心思想**：一个点被光源照亮当且仅当它从光源位置可见——与 z-buffer 的可见性测试本质相同。

**两步法**：
1. **阴影通道**：从光源位置渲染整个场景，只保留深度图（阴影贴图 $d_{\text{map}}$），不计算颜色。
2. **渲染通道**：正常渲染，对每个片段将其位置投影到阴影贴图，比较查找的深度 $d_{\text{map}}$ 与实际距离 $d$：
   - $d \approx d_{\text{map}}$ → 被照亮
   - $d > d_{\text{map}}$ → 被遮挡（处于阴影中）

> [!warning] 阴影偏移（Shadow Bias）
> 由于精度有限，$d$ 和 $d_{\text{map}}$ 不可能精确相等。需要设置容差 $\epsilon$：当 $d - d_{\text{map}} < \epsilon$ 时视为被照亮。$\epsilon$ 太大会导致阴影漏光，太小会导致阴影瑕疵（ acne）。

**过滤**：阴影贴图查找不插值深度值（阴影边界处深度突变会导致问题），使用最近邻重建。抗锯齿用**百分比渐近过滤（PCF）**：对多个采样的 0/1 阴影结果（而非深度值）取平均。

### 4.5 环境贴图（§11.4.5）

当光来自远处时，照明仅取决于方向，与位置无关。用环境贴图表示方向到颜色的映射——定义在单位球上的函数，用纹理贴图存储。

**光线追踪中的用法**：为未命中任何物体的光线赋予颜色：

```python
trace_ray(ray, scene):
    if (surface = scene.intersect(ray)):
        return surface.shade(ray)
    else:
        u, v = spheremap_coords(r.direction)
        return texture_lookup(scene.env_map, u, v)
```

**光栅化中的反射贴图**：在着色中添加镜面反射项，直接查找环境贴图：

```python
shade_fragment(view_dir, normal):
    out_color = diffuse_shading(k_d, normal)
    out_color += specular_shading(k_s, view_dir, normal)
    u, v = spheremap_coords(reflect(view_dir, normal))
    out_color += k_m * texture_lookup(environment_map, u, v)
```

**更高级用法——环境光照**：计算来自环境贴图的全部照明（不仅是镜面反射），可用蒙特卡洛积分（光线追踪）或将环境近似为一组点光源并计算多个阴影贴图（光栅化）。

存储方式：球面坐标（极点浪费分辨率）或立方体贴图（更高效，广泛用于交互应用）。

## 5. 程序化三维纹理（§11.5）

### 5.1 动机

不定义从 3D 表面到 2D 纹理域的映射函数，而是直接创建一个**3D 纹理** $\mathbf{c}_r(\mathbf{p})$，在 3D 空间中每个点定义 RGB 值。

**优势**：
- 映射函数简单——表面已嵌入 3D 空间，无需 2D 参数化
- 无畸变——从 3D 到纹理空间没有投影变形
- 适合"雕刻"出的物体（如大理石雕塑）

**劣势**：3D 光栅图像/体积数据消耗大量内存。因此 3D 纹理几乎总是**程序化的**——用数学过程计算而非查找图像。

### 5.2 三维条纹纹理（§11.5.1）

用振荡函数在两种颜色间切换。用正弦函数：

```python
# 硬边界条纹
RGB stripe(point p, real w):
    if (sin(π * p.x / w) > 0):
        return c0
    else:
        return c1

# 平滑插值条纹
RGB stripe(point p, real w):
    t = (1 + sin(π * p.x / w)) / 2
    return (1 - t) * c0 + t * c1
```

参数 $w$ 控制条纹宽度，$t$ 在 $[0,1]$ 间平滑变化。

### 5.3 实体噪声 / Perlin 噪声（§11.5.2）

条纹等规则纹理有用，但自然纹理（鸟蛋斑驳、大理石纹路）需要"随机但不白噪"的图案。

**Perlin 噪声**——由 Ken Perlin 发明，为此获得技术学院奖。

朴素方法（每点随机数）产生电视雪花般的白噪声。Perlin 噪声在三点上改进了基础晶格插值：

1. **Hermite 插值**（而非线性）：用三次加权函数 $\omega(t) = 2|t|^3 - 3|t|^2 + 1$（$|t|<1$ 时，否则为 0），避免马赫带。
2. **随机向量而非随机值**：在格点存储随机单位向量 $\Gamma_{ijk}$，通过点积推导随机数。这把局部极值移出网格顶点，使晶格结构不明显。
3. **一维数组 + 哈希**：用排列表 $P$ 和预计算随机向量表 $G$ 创建虚拟 3D 数组，降低内存使用。

基本公式：

$$n(\mathbf{x}) = \sum_{i=\lfloor x \rfloor}^{\lfloor x \rfloor+1}\sum_{j=\lfloor y \rfloor}^{\lfloor y \rfloor+1}\sum_{k=\lfloor z \rfloor}^{\lfloor z \rfloor+1} \Omega_{ijk}(x-i,\;y-j,\;z-k)$$

$$\Omega_{ijk}(u,v,w) = \omega(u)\,\omega(v)\,\omega(w)\,\bigl(\Gamma_{ijk}\cdot(u,v,w)\bigr)$$

$$\Gamma_{ijk} = G\bigl[\varphi\bigl(i + \varphi(j + \varphi(k))\bigr)\bigr]$$

其中 $\varphi(i) = P[i \bmod n]$，实践中 $n=256$ 效果良好。

**使用噪声**：噪声值范围为 $[-1,1]$，需变换后才能用作颜色。$(n+1)/2$ 映射到 $[0,1]$，但极端值罕见所以图像较平。增大缩放可增加对比度。

### 5.4 湍流（§11.5.3）

自然纹理包含多种特征尺寸。Perlin 的伪分形"湍流"函数将多个缩放后的噪声叠加：

$$n_t(\mathbf{x}) = \sum_i \frac{|n(2^i \mathbf{x})|}{2^i}$$

每次叠加频率加倍、幅度减半——类似分形的自相似结构。项数越多细节越丰富（1–8 项）。

湍流可用于扭曲条纹函数，产生更自然的纹理：

```python
RGB turbstripe(point p, double w):
    t = (1 + sin(k1 * p.z + turbulence(k2 * p)) / w) / 2
    return t * s0 + (1 - t) * s1
```

$k_1$ 控制条纹频率，$k_2$ 控制湍流扭曲强度。
