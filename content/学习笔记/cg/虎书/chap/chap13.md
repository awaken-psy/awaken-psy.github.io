# 第十三章 更多光线追踪（More Ray Tracing）

> **来源**：《Fundamentals of Computer Graphics》第 4 版 · Ch.13 · PDF 第 338–350 页
> **定位**：光线追踪器是构建高级渲染效果的绝佳基底——许多在光栅化框架中难以实现的效果（阴影、反射、折射）在光线追踪中简单而优雅。本章扩展光线追踪的能力：透明折射、实例化、CSG、分布式光线追踪（软阴影/景深/光泽反射/运动模糊）。
> **关联**：依赖第 4 章（基础光线追踪）、第 12 章（加速结构）、第 6 章（变换矩阵）、第 2 章（向量运算/正交基）

## 1. 透明度与折射（§13.1）

### 1.1 电介质与斯涅尔定律

电介质（dielectric）是透明材质——折射光线。钻石、玻璃、水、空气都是电介质。

当光线从折射率 $n$ 的介质进入折射率 $n_t$ 的介质时，发生折射。斯涅尔定律：

$$n \sin\theta = n_t \sin\varphi$$

其中 $\theta$ 是入射角，$\varphi$ 是折射角。

常见折射率：空气 1.00、水 1.33、窗玻璃 1.51、钻石 2.42。

### 1.2 推导折射向量

直接用 $\sin$ 不方便（需要算角度），用三角恒等式 $\sin^2\theta + \cos^2\theta = 1$ 转为余弦形式：

$$\cos^2\varphi = 1 - \frac{n^2(1 - \cos^2\theta)}{n_t^2}$$

其中 $\cos\theta = -\mathbf{d}\cdot\mathbf{n}$（$\mathbf{d}$ 是入射方向单位向量，$\mathbf{n}$ 是表面法线）。

在法线 $\mathbf{n}$ 和入射方向 $\mathbf{d}$ 构成的平面内建立正交基 $\{\mathbf{n}, \mathbf{b}\}$，其中：

$$\mathbf{b} = \frac{\mathbf{d} + \mathbf{n}\cos\theta}{\sin\theta}$$

折射光线方向：

$$\mathbf{t} = \frac{n(\mathbf{d} - \mathbf{n}(\mathbf{d}\cdot\mathbf{n}))}{n_t} - \mathbf{n}\sqrt{1 - \frac{n^2(1 - (\mathbf{d}\cdot\mathbf{n})^2)}{n_t^2}}$$

> [!warning] 全内反射
> 若平方根下的值为负（$n > n_t$ 且入射角大于临界角），则不存在折射光线——所有能量被反射。这就是**全内反射（total internal reflection）**，是玻璃物体丰富外观的主要原因。

### 1.3 菲涅尔方程与 Schlick 近似

电介质的反射率随入射角变化（掠射角反射更多），遵循菲涅尔方程。实用的**Schlick 近似**：

$$R(\theta) = R_0 + (1 - R_0)(1 - \cos\theta)^5$$

其中 $R_0$ 是正入射（垂直入射）时的反射率：

$$R_0 = \left(\frac{n_t - 1}{n_t + 1}\right)^2$$

> [!note] $\cos\theta$ 始终取空气中的角度
> 即内部角度和外部角度中**较大**的那个。从内向外发射时需用 $\cos\theta$ 的对应值。

### 1.4 比尔定律（Beer's Law）

有色玻璃中，光线穿过介质时强度按指数衰减。设衰减常数 $\mathbf{a}$（RGB，表示单位距离后的透射比），距离 $s$ 处的强度：

$$I(s) = I(0)\,e^{\ln(\mathbf{a})\,s}$$

推导：$dI = -C\,I\,dx \Rightarrow I = k\,e^{-Cx}$，边界条件 $I(0)=I_0$，$I(1)=\mathbf{a}\,I_0$ → $-C = \ln(\mathbf{a})$。

### 1.5 完整的电介质着色代码

假设所有物体嵌在空气（$n \approx 1.0$）中，法线指向外（朝空气）：

```
if (p is on a dielectric):
    r = reflect(d, n)
    if (d · n < 0):                    // 光线从外进入物体
        refract(d, n, n, t)
        c = -d · n
        k = (1, 1, 1)                   // 进入时不衰减
    else:                               // 光线从内出物体
        k = (exp(-ar*t), exp(-ag*t), exp(-ab*t))   // Beer's Law 衰减
        if refract(d, -n, 1/n, t):      // 尝试折射出去
            c = t · n
        else:                           // 全内反射
            return k * color(p + t*r)  // 只反射
    R0 = ((n-1)/(n+1))²
    R = R0 + (1-R0)(1-c)⁵              // Schlick 近似
    return k * (R * color(p + t*r) + (1-R) * color(p + t*t))
```

逻辑：先尝试折射，若全内反射则纯反射；否则按 Schlick 近似的比例混合反射和折射。从物体内部出射时应用 Beer 定律衰减。

## 2. 实例化（§13.2）

### 2.1 基本思想

存储一个基础对象和变换矩阵 $M$，而非显式构造变换后的几何体。例如：单位圆经缩放 $(2,1)$ + 旋转 $45°$ + 平移变成椭圆——但只存圆和矩阵。

**光线追踪中的优势**：可以选择在哪个空间做求交。将光线**逆变换**到原始空间与未变换对象求交，而非对变换后的几何体求交：

$$\text{光线 } \mathbf{a}+t\mathbf{b} \xrightarrow{M^{-1}} \text{逆变换光线 } M^{-1}\mathbf{a}+t\,M^{-1}\mathbf{b} \xrightarrow{\text{求交}} \text{基础对象}$$

两个优势：
1. **基础对象求交更简单**——球体 vs 椭球体
2. **多个实例共享同一基础对象**——交通拥堵中的车都只是几个基础模型的变换

### 2.2 实现

```
instance::hit(ray a+tb, t0, t1, rec):
    ray r' = M⁻¹·a + t·M⁻¹·b          // 逆变换光线
    if (base-object.hit(r', t0, t1, rec)):
        rec.n = (M⁻¹)ᵀ · rec.n          // 法线用逆转置变换
        return true
    else:
        return false
```

> [!tip] $t$ 参数不需要变换
> 光线参数 $t$ 在两个空间中相同——因为光线方向 $\mathbf{b}$ 没有归一化。这也是为什么光线追踪中**不应限制光线方向为单位向量**。

法线变换用 $(M^{-1})^T$ 而非 $M$（见 §6.2.2），因为法线是伪向量，需要用逆转置矩阵正确变换。

## 3. 构造实体几何 / CSG（§13.3）

### 3.1 基本思想

用集合运算（并、交、差）组合实体形状：

- **并（union）**：$C \cup S$ — 在圆或正方形中的所有点
- **交（intersection）**：$C \cap S$ — 同时在圆和正方形中的点
- **差（difference）**：$C - S$ — 在圆中但不在正方形中的点

### 3.2 光线追踪中的实现

不需要显式修改模型——直接在光线与模型交互时做集合运算。

关键：找出光线与对象的**所有交点**（而非仅最近），形成"内部区间"。例如光线在 $t=1$ 和 $t=2$ 击中球体 → 光线在 $t \in [1,2]$ 内位于球体内部。

对多个对象的内部区间做集合运算：
- **交**：取区间交集
- **并**：取区间并集
- **差**：从 A 的区间中减去 B 的区间

最终取 $t > 0$ 的第一个命中点作为实际交点。

> [!warning] 精度问题
> 两个相邻对象的交集操作可能产生极薄区间。通过剔除厚度低于容差的区间来保证稳健性。

## 4. 分布式光线追踪（§13.4）

### 4.1 动机

传统光线追踪图像"太干净"——阴影绝对锐利、反射完全清晰、一切完美对焦。分布式光线追踪通过对每个像素发射**多条随机光线**，以简单的方式产生：软阴影、景深、光泽反射、运动模糊。

### 4.2 抗锯齿（§13.4.1）

**规则采样**：在像素内按 $n \times n$ 网格取点：

```
for each pixel (i, j):
    c = 0
    for p = 0 to n-1:
        for q = 0 to n-1:
            c += ray_color(i + (p+0.5)/n, j + (q+0.5)/n)
    cij = c / n²
```

问题：规则采样产生摩尔纹等规则伪影。

**随机采样**：用均匀随机数替代规则位置，将规则伪影转为噪声：

```
for p = 1 to n²:
    c += ray_color(i + ξ, j + ξ)
```

问题：噪声明显，除非大量采样。

**抖动/分层采样（Jittering / Stratified Sampling）**：折中方案——将像素分成 $n \times n$ 子格，每格内取一个随机点：

```
for p = 0 to n-1:
    for q = 0 to n-1:
        c += ray_color(i + (p+ξ)/n, j + (q+ξ)/n)
cij = c / n²
```

兼顾规则性（避免纯随机噪声）和随机性（避免摩尔纹）。

### 4.3 软阴影（§13.4.2）

传统光线追踪中光源是无限小的点——要么可见要么不可见，阴影边缘绝对锐利。现实中光源有面积，产生本影（umbra，完全不可见）和半影（penumbra，部分可见）。

**朴素方法**：用 $N$ 个点光源近似面光源——但需要大量点光源且半影内有锐利过渡。

**分布式光线追踪**：为每个表面点在面光源上**随机选一个点**发射阴影光线。统计上等于对面光源做积分。

若面光源是平行四边形（角点 $\mathbf{c}$，边向量 $\mathbf{a}, \mathbf{b}$），随机点：

$$\mathbf{r} = \mathbf{c} + \xi_1 \mathbf{a} + \xi_2 \mathbf{b}$$

> [!warning] 去相关性
> 像素采样位置和光源采样位置不应相关——否则像素左上角的光线总瞄准光源左上角。解决方案：生成两组独立的抖动采样，对其中一组**洗牌**（shuffle）后再配对：
>
> ```
> generate N jittered 2D points → r[]   // 像素采样
> generate N jittered 2D points → s[]   // 光源采样
> shuffle s[]
> for p = 0 to N-1:
>     c += ray_color(i + r[p].x, j + r[p].y, s[p])
> ```

### 4.4 景深（§13.4.3）

真实相机镜头有面积，并非无限小——只有焦平面上的物体清晰，远离焦平面的物体模糊。

**模拟方法**：在眼睛位置附近的一个小正方形（"镜头"）上随机取采样位置，视线从该位置出发指向焦平面上的目标点。

1. 用户设定焦平面距离
2. 像素采样位置确定焦平面上的目标点 $\mathbf{s}$
3. 镜头上的随机位置 $\mathbf{e}'$ 替代眼睛位置
4. 视线方向 = $\mathbf{s} - \mathbf{e}'$

镜头越大，景深效果越明显（模糊范围越大）。

### 4.5 光泽反射（§13.4.4）

拉丝金属等表面介于理想镜面和漫反射之间——反射可见但模糊。

**模拟方法**：在理想反射光线 $\mathbf{r}$ 周围的小正方形上随机扰动，得到扰动方向 $\mathbf{r}'$。

1. 以 $\mathbf{w} = \mathbf{r}$ 建立正交基 $(\mathbf{u}, \mathbf{v}, \mathbf{w})$（§2.4.6）
2. 在边长 $a$ 的正方形内取随机点：$u = -a/2 + \xi\,a$，$v = -a/2 + \xi'\,a$
3. 扰动方向：$\mathbf{r}' = \mathbf{r} + u\,\mathbf{u} + v\,\mathbf{v}$（需归一化）

$a$ 控制模糊程度。若 $\mathbf{r}'$ 指向表面下方则返回零颜色。

### 4.6 运动模糊（§13.4.5）

模拟相机快门开启期间物体运动产生的模糊。

**模拟方法**：为每条视线随机选择一个时间 $T$：

$$T = T_0 + \xi(T_1 - T_0)$$

物体位置随时间变化——例如球心从 $\mathbf{c}_0$ 移动到 $\mathbf{c}_1$，时间 $T$ 处的中心为线性插值。每条光线在不同时间发射，遇到物体在不同位置，最终产生模糊。

> [!note] 加速结构需覆盖整条路径
> 移动球体的包围盒应包围其整个运动路径，以便为整个时间区间构建加速结构。
