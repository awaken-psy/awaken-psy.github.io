# TAA 时序抗锯齿与运动向量知识点详解

## 1 一句话理解 TAA

> [!info] 核心概念
> 单帧渲染的采样太少，画面会有锯齿和噪声。TAA（Temporal Anti-Aliasing）的思路是：每帧只采样一点点，但用运动向量把上一帧的结果"搬"到当前帧叠加——多帧累积后相当于做了超采样，画面又干净又锐利。

---

## 2 为什么单帧渲染有噪声

### 蒙特卡洛噪声

如果每帧只发射少量射线（TuanjieGI 每个 Quad 只发 1 条射线），结果会充满噪点：

```
单帧射线追踪结果：

  ┌──────────────┐
  │ ·  ·    ··   │  ← 每个像素的射线方向不同
  │  ·    ·   ·  │     有的命中亮物体，有的命中暗物体
  │ · ··    · ·  │     → 噪声严重
  │    ·    ··   │
  └──────────────┘

  解决方案：
  1. 多采样（每帧多发射射线）→ 太慢
  2. 多帧累积（每帧不同方向，叠加）→ 运动了怎么办？
```

### 两种去噪策略

| 策略 | 思路 | 问题 |
|---|---|---|
| 空间滤波 | 把周围像素的颜色平均一下 | 边缘会模糊 |
| 多帧累积 | 每帧发射不同方向的射线，多帧叠加 | 运动了怎么办？ |

TAA 解决的是"多帧累积时运动了怎么办"。

---

## 3 TAA 的核心思想

### 用上一帧补充当前帧

> [!important] 核心原理
> 当前帧采样的信息不够，但上一帧也采过样。如果能把上一帧的结果"搬"到当前帧叠加，就相当于两帧的采样合在一起——信息翻倍。

问题是：**上一帧的像素 P' 在当前帧的哪个位置？**

```
上一帧：                    当前帧：

  P' 在 (97, 195)            P 在 (100, 200)
  ↑ 相机在左边               ↑ 相机往右移了
                              P' 对应的世界点现在到了 (100, 200)
```

需要一个"地址簿"告诉你 P' 搬到了哪——这就是**运动向量**。

### 运动向量（Motion Vector）

> [!info] 运动向量
> 运动向量记录了每个像素在相邻两帧间的位移：
> ```
> MotionVector(P) = P_prev_frame_position - P_curr_frame_position
> ```

产生运动向量的原因：

```
1. 相机移动：世界点没动，但相机动了 → 屏幕位置变了
2. 物体移动：世界点自己动了（角色走动、门打开）
3. 两者兼有
```

### TAA 的完整流程

> [!info] TAA 一帧的流程
> ```
> 对当前帧的每个像素 P：
>
>   1. 查运动向量：P 在上一帧的位置是 P'
>   2. 读取上一帧 P' 的结果（历史帧颜色）
>   3. 检查一致性：P' 和 P 的深度、法线是否匹配？
>      ├ 一致 → 这个历史数据有效 → 混合当前帧和历史帧
>      └ 不一致 → 历史数据无效（可能是遮挡变化）→ 丢弃，只用当前帧
>   4. 输出混合结果
> ```

```
当前帧像素 P (100, 200)
    ↓
查询运动向量 → P 在上一帧的位置是 (97, 195)
    ↓
读上一帧 (97, 195) 的深度和法线
    ↓
和当前帧 (100, 200) 的深度、法线比较
    ├─ 一致 → 这两个像素确实对应同一个世界点
    │        → 混合：累积结果 = (1-α) × 历史帧 + α × 当前帧
    │
    └─ 不一致 → 这个位置上一帧是别的物体（遮挡变化了）
              → 丢弃历史帧，只用当前帧
```

> [!warning] 为什么需要一致性检查
> 如果上一帧这个位置是一面墙，当前帧因为相机移动看到了墙后面的桌子——它们不是同一个点，不能混合。深度和法线的一致性检查就是用来判断"上一帧的这个像素和当前帧的是不是同一个表面"。

## 4 抖动（Jittering）

### 为什么要抖动

如果每帧都在像素正中心采样，多帧叠加只是同一个值重复——没有增加信息。抖动让每帧的采样位置在像素内**微小偏移**，多帧累积后相当于在像素内做了超采样：

```
Frame 1: 采样位置 = 像素中心 + (0.1, 0.3)
Frame 2: 采样位置 = 像素中心 + (0.7, 0.5)
Frame 3: 采样位置 = 像素中心 + (0.4, 0.8)
...

4 帧累积 ≈ 在一个像素内做了 4× 超采样
→ 抗锯齿效果
```

> [!note] TuanjieGI 中的抖动
> TuanjieGI 也有自己的抖动——每个 Quad（屏幕块）根据**蓝噪声**偏移中心位置：
> - 蓝噪声比随机噪声视觉上更"均匀"，累积后噪点不明显
> - 抖动函数是 `frac(frame / 8)` + `reversebits(frame) / 65536` 的序列
> - 这让每帧的射线采样方向略有不同，多帧累积后覆盖更全面

> [!tip] 蓝噪声 vs 白噪声
> - 白噪声：完全随机，高频，视觉上有明显颗粒感
> - 蓝噪声：低频能量少、高频能量多，视觉上看起来"均匀分布"，人眼不敏感
> - 所以蓝噪声做抖动时，残存的噪声更不容易被看到

## 5 时序累积公式

> [!info] 混合公式
> ```
> 累积结果 = (1 - α) × 历史帧结果 + α × 当前帧结果
> ```

| 参数 | 含义 | TuanjieGI 默认值 |
|---|---|---|
| α | 混合因子，控制当前帧的权重 | 由累积帧数动态决定 |
| reprojectionMaxFrames | 最大累积帧数 | 8 |

**α 的影响**：

```
α 小（如 0.05）→ 历史帧权重高
  → 画面平滑、噪声少
  → 但运动时拖影严重（旧画面更新慢）

α 大（如 0.3）→ 当前帧权重高
  → 画面锐利、拖影少
  → 但噪声多（累积不够）

TuanjieGI 的做法：
  α = 1 / outputNumFrames
  outputNumFrames 随着连续累积帧数增加而增大
  → 刚开始累积时 α 大（快速收敛），后期 α 小（稳定平滑）
  → 最大不超过 reprojectionMaxFrames（8 帧）
```

## 6 TuanjieGI 中的时序重投影

TuanjieGI 的重投影逻辑和 TAA 完全一致：

> [!info] TuanjieGI 时序重投影流程
> ```
> 1. 从 motionBuffer 读取运动向量
> 2. 当前像素 UV 减去运动向量 = 上一帧 UV
> 3. 在上一帧 UV 位置采样历史帧的颜色和累积次数
> 4. 比较上一帧该位置的深度/法线是否和当前帧一致
>    ├ 一致 → 累积：blendFactor = 1 / (numFrames + 1)
>    │        outColor = lerp(prevColor, currColor, blendFactor)
>    └ 不一致 → 丢弃历史，outColor = currColor，numFrames = 1
> 5. 写入下一帧的历史缓冲
> ```

### 深度拒绝（Depth Rejection）

```
当前帧深度 = 10.0m
历史帧深度 = 10.2m  → 差 0.2m，在容差内 → 接受

当前帧深度 = 10.0m
历史帧深度 = 25.0m  → 差太大 → 拒绝（遮挡变化了，不是同一个表面）
```

> [!note] 角度修正
> TuanjieGI 的深度拒绝不是固定容差，而是根据视角角度调整：掠射角（ grazing angle）时容差更大，正面观察时容差更小。这是因为掠射角时深度变化天然更大。

### 法线拒绝（Normal Rejection）

```
当前帧法线 = (0, 1, 0)   朝上
历史帧法线 = (0, 0.99, 0.01)  → 几乎一样 → 接受

当前帧法线 = (0, 1, 0)   朝上
历史帧法线 = (1, 0, 0)   朝右 → 完全不同 → 拒绝（不同表面）
```

> [!tip] enableAccurateHistory
> TuanjieGI 支持精确历史模式（`enableAccurateHistory`）。开启后不只比单个像素，而是用双线性采样取 4 个邻居像素的深度和法线做加权比较，更准确但更慢。

## 7 TAA 和 TuanjieGI 的关系

> [!important] TuanjieGI 直接复用 TAA 机制
> TuanjieGI 不是重新发明一套降噪方案，而是直接复用了 TAA 的核心机制：
>
> | TAA 概念 | TuanjieGI 中的对应 |
> |---|---|
> | 运动向量 | 从 motionBuffer 读取 |
> | 历史缓冲 | `historyStates`（存上一帧的间接光纹理） |
> | 一致性检查 | 深度拒绝 + 法线拒绝 |
> | 抖动 | 蓝噪声 Quad 抖动 |
> | 累积公式 | `blendFactor = 1 / outputNumFrames` |
> | 最大累积帧数 | `reprojectionMaxFrames`（默认 8） |

### TAA 之外：双边滤波

即使时序累积后仍有噪声（尤其是刚丢弃历史帧的地方）。TuanjieGI 在时序重投影之后还做了一步**双边滤波**：

```
普通模糊：周围像素平均 → 边缘模糊
双边滤波：平均时考虑深度和法线差异
  → 只在"相似"的像素间模糊
  → 平坦区域被平滑，边缘被保留
```

> [!info] 双边滤波权重
> ```
> 权重 = 空间权重 × 深度权重 × 法线权重
>
> 空间权重：距离越远权重越低（高斯分布）
> 深度权重：深度差越大权重越低（不在同一表面就不混）
> 法线权重：法线差越大权重越低（不同朝向就不混）
> ```

## 8 关键概念速查

> [!summary] 速查表
>
> | 概念 | 一句话 |
> |---|---|
> | TAA | 用运动向量把上一帧结果搬到当前帧叠加，多帧累积去噪 |
> | 运动向量 | 每个像素在相邻帧间的位移 |
> | 一致性检查 | 比较深度和法线，判断历史帧数据是否有效 |
> | 抖动 | 每帧采样位置微小偏移，多帧累积相当于超采样 |
> | 蓝噪声 | 视觉均匀的高频噪声，做抖动时残余噪点不明显 |
> | 累积公式 | `结果 = (1-α) × 历史 + α × 当前`，α = 1/累积帧数 |
> | 深度拒绝 | 深度差太大 → 不是同一表面 → 丢弃历史帧 |
> | 法线拒绝 | 法线差太大 → 不同朝向 → 丢弃历史帧 |
> | 双边滤波 | 时序之后的补充去噪，保边平滑 |
> | reprojectionMaxFrames | 最大累积帧数（默认 8） |
