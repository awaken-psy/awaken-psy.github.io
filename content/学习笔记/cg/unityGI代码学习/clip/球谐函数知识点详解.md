# 球谐函数知识点详解

## 1 一句话理解球谐函数

> [!info] 核心概念
> 球谐函数（Spherical Harmonics, SH）是一种"压缩"方式——把球面上分布的光信息压缩成几个数字。存的时候存这几个数字，用的时候从这几个数字还原出任意方向的光颜色。不需要理解数学公式，只需知道"存几个数 = 压缩了整个球面的光分布"。

---

## 2 为什么要用球谐函数

### 问题：怎么存储一个点的间接光

一个表面点接收到的间接光来自四面八方（整个半球）。如果存"每个方向的光颜色"，需要几百个方向 × 3 个颜色通道 = 几百个 float——内存爆炸。

```
       ↑ 北边亮
       │
  西 ←─┼─→ 东边暗
       │
       ↓ 南边中等

  要存这个光分布，难道每个方向存一个颜色？
  → 需要几百个值，太多
```

### 球谐的思路：用几个系数近似

> [!important] 球谐的核心思想
> 就像傅里叶变换把一段声音分解成不同频率的正弦波（低频 = 基础音，高频 = 细节），球谐把球面上的光分布分解成不同频率的基函数。
>
> 前几个系数就能抓住"整体多亮"和"大致哪个方向亮"——对漫反射间接光来说这就够了。

---

## 3 球谐的"阶"

球谐函数按"阶"（degree）分层，阶越高能表示的细节越多：

```
第 0 阶（1 个系数）：平均值
  → "整体多亮"
  → 只知道这个点接收多少光，不知道方向

第 1 阶（共 4 个系数 = 1+3）：方向趋势
  → "哪边亮一点"
  → 知道大致的亮暗方向

第 2 阶（共 9 个系数 = 1+3+5）：更细的方向变化
  → "左上方亮、右下方暗"
  → 适合表示漫反射间接光

第 3 阶（共 16 个系数）：更精细
  → 开始有高频信息
  → 但对漫反射来说已经过剩
```

> [!note] 系数数量公式
> 前 n 阶的系数总数 = (n+1)²
> - 前 0 阶：1 个
> - 前 1 阶：4 个
> - 前 2 阶：9 个 ← TuanjieGI 用的
> - 前 3 阶：16 个


## 4 为什么只用 3 阶（9 个系数）

> [!important] 漫反射光天生低频
> 漫反射是光线打到粗糙表面后被均匀散射到各方向。这个过程把光"抹匀"了——高频细节丢失，只保留低频的趋势。
>
> 所以用 9 个球谐系数就能很好地表示漫反射间接光。用更多阶也不会更准——信息本来就被抹掉了。

```
高频光（镜面反射）：       低频光（漫反射间接光）：

  ╱╲╱╲╱╲╱╲              ────光滑的曲线────
  快速变化                 平缓变化
  
  → 需要很多系数           → 9 个系数够用
  → 球谐不适合             → 球谐完美匹配
```

> [!warning] 镜面反射不能用球谐
> 镜面反射是高频的——一个方向的反射颜色可能和旁边方向完全不同。球谐的低频特性无法表示这种突变。所以镜面反射直接存方向颜色，不用 SH。

## 5 球谐的两个操作：编码和解码

### 编码（投影 / Project）

> [!info] 编码
> 把射线命中的颜色"投影"到球谐系数。就像把一段声音录成 MP3——压缩。

```
射线命中 → 读到命中点的颜色 (0.8, 0.5, 0.2)
         → 从命中方向算出贡献
         → 累加到 9 个球谐系数

  SH[0] += color × Y0(direction)    ← 第 0 阶基函数
  SH[1] += color × Y1(direction)    ← 第 1 阶基函数
  ...
  SH[8] += color × Y8(direction)    ← 第 2 阶基函数

多根射线命中 → 不断累加 → 最终 9 个系数描述了
                这个点接收到的全部间接光分布
```

### 存储

球谐系数存在 **Facet 场景**的 `IndIrradiance` 纹理中。每个面片纹素存 9 个系数（RGB × 3 = 9）。

```
Facet Atlas 纹理：
  ┌───────────────────────────┐
  │  每个纹素存 9 个 SH 系数    │
  │  (3个RGB × 3阶 = 9)       │
  │                            │
  │  → 编码了该面片接收的       │
  │    间接辐照度分布            │
  └───────────────────────────┘
```

### 解码（评估 / Evaluate）

> [!info] 解码
> 渲染时，给定一个方向（通常是法线方向），从 9 个球谐系数重建出该方向的间接光颜色。就像从 MP3 还原声音——解压。

```
渲染像素时：
  从 Facet 纹理读到 9 个 SH 系数
  → 用法线方向 N 作为输入
  → SH.Evaluate(N) → 输出这个方向的间接光颜色

  result = SH[0]×Y0(N) + SH[1]×Y1(N) + ... + SH[8]×Y8(N)
         = 间接光颜色
```

> [!tip] 通俗类比
> - **编码** = 拍照存成 JPEG（压缩原始光线信息为几个数字）
> - **存储** = 把 JPEG 存到硬盘（存到 Facet 纹理）
> - **解码** = 打开 JPEG 查看（从系数还原出某个方向的颜色）

## 6 TuanjieGI 怎么用球谐

### 完整流程

![[学习笔记/cg/unityGI代码学习/clip/球谐-图3-TuanjieGI管线.svg]]

*图 3 · TuanjieGI 单帧 SH 管线 — Build 阶段（追踪→编码→存储）→ Render 阶段（解码→输出）*

```
TuanjieGI 一帧中球谐出现的位置：

1. 追踪射线命中
   → 从 Facet 场景读取命中点的颜色/法线
   ↓
2. 编码（投影）
   → 将命中点的入射光投影到 9 个 SH 系数
   → 累加到 Facet 场景的 IndIrradiance 纹理
   ↓
3. 存储
   → SH 系数存在 Facet 纹理中，多帧累积
   ↓
4. 解码（评估）
   → 渲染时，根据法线方向从 SH 系数重建间接光颜色
   → diffuse = SH.Evaluate(bentNormal) × INV_PI
   ↓
5. 输出
   → 间接光颜色写入输出纹理
```

### 漫反射 vs 粗糙镜面

> [!note] SH 在漫反射和粗糙镜面中的不同用法
>
> **漫反射间接光**：
> - 用 9 个 SH 系数（前 3 阶）
> - 解码时用法线方向：`SH.Evaluate(normal)`
> - 乘以 `1/π`（漫反射归一化）
>
> **粗糙镜面间接光**：
> - 也用 SH 系数，但用"锥形"解码
> - 解码时用反射方向和锥角：`SH.EvaluateRoughSpecular(reflection, coneCos)`
> - 锥角由粗糙度决定——越粗糙锥越大，结果越模糊

### 为什么存 SH 而不直接存颜色

> [!important] SH 的优势
> 如果直接存颜色，一个点只能存一个方向的颜色。但间接光来自四面八方，不同法线方向的表面需要不同的间接光。
>
> 存 SH 系数 → 任意方向的表面都能从同一组系数解码出自己的间接光。一个面片被多个角度的表面看到时，不用重复存储——9 个系数通吃所有方向。

## 7 球谐函数的"余弦钳制"（Clamped Cosine）

> [!info] 漫反射的余弦项
> 渲染方程里有一个 `cos(θ)` 项——光线越斜，能量越分散。漫反射间接光在解码时也要乘这个余弦。
>
> TuanjieGI 在 SH 解码时使用**预计算的余弦钳制系数**——把 `cos(θ)` 也编码到球谐中，这样解码时一步就算出 `入射光 × cos(θ)`，不需要额外计算。

```
原始 SH 编码：存的是入射光分布
余弦钳制 SH：存的是 入射光 × cos(θ) 的分布

→ 解码时直接就是漫反射结果，不用再乘 cos(θ)
```
