# 法线贴图与视差映射知识点详解

原教程：[法线贴图](https://learnopengl-cn.readthedocs.io/zh/latest/05%20Advanced%20Lighting/04%20Normal%20Mapping/)、[视差贴图](https://learnopengl-cn.readthedocs.io/zh/latest/05%20Advanced%20Lighting/05%20Parallax%20Mapping/)

## 1 两张图分别改变什么

- **法线贴图**：不改几何，只改变片段参与光照的法线。
- **视差映射**：不改几何，只根据观察方向改变采样 UV。

两者组合时：**先算新 UV，再用同一新 UV 采颜色、法线，最后照明。**

```glsl
vec3 viewDir = normalize(TangentViewPos - TangentFragPos);
vec2 uv = ParallaxMapping(TexCoords, viewDir);

vec3 color  = texture(diffuseMap, uv).rgb;
vec3 normal = texture(normalMap, uv).rgb;
normal = normalize(normal * 2.0 - 1.0);
```

法线图 RGB 从 `[0,1]` 映射到 `[-1,1]` 后才是方向。

## 2 为什么需要 TBN 切线空间

法线图的方向是“相对表面”保存的。表面旋转后，需要一套贴在表面上的坐标轴：切线 T、副切线 B、法线 N。

顶点 Shader 建立 TBN，并把世界空间位置转换到切线空间：

```glsl
vec3 T = normalize(mat3(model) * aTangent);
vec3 N = normalize(mat3(model) * aNormal);
T = normalize(T - dot(T, N) * N);
vec3 B = cross(N, T);

mat3 worldToTangent = transpose(mat3(T, B, N));
TangentLightPos = worldToTangent * lightPos;
TangentViewPos  = worldToTangent * viewPos;
TangentFragPos  = worldToTangent * FragPos;
```

这样采样法线、光源方向、观察方向处在同一空间，点积才有意义。

## 3 三种视差怎样找新 UV

基础版只采一次深度：

```glsl
float depth = texture(depthMap, texCoords).r;
vec2 offset = viewDir.xy * depth * heightScale;
return texCoords - offset;
```

本地 `5.1` 没有除以 `viewDir.z`，属于限制偏移的版本。

Steep Parallax 将虚拟深度分层，沿观察方向逐层前进：

```glsl
float layers = mix(32.0, 8.0, abs(dot(vec3(0,0,1), viewDir)));
float layerDepth = 1.0 / layers;
vec2 deltaUV = (viewDir.xy / viewDir.z * heightScale) / layers;

while (currentLayerDepth < texture(depthMap, uv).r) {
    uv -= deltaUV;
    currentLayerDepth += layerDepth;
}
```

POM 在最后穿越表面的前后两层之间再插值，减少分层跳变。三种算法是替换关系，不是连续画三遍。

## 4 它们仍然是“假凹凸”

- 真实轮廓和顶点没有改变。
- 当前 Shader 没写 `gl_FragDepth`，与其他物体的深度遮挡仍基于原平面。
- POM 只沿观察方向找 UV，本例没有沿光源方向计算凹凸自阴影。
- `heightScale` 越大，错位和边缘破绽也越明显。

本地深度图直接读取 `.r`，按“0 接近表面、1 向内更深”使用；不要与帧缓冲深度混淆。颜色图可做 sRGB 解码，法线图和深度图属于数据纹理，不应解码。

> [!summary] 一句话回忆
> **TBN 把方向统一到切线空间；法线图改变受光方向，视差图改变采样位置，Steep/POM 用更多采样提高 UV 估计。**
