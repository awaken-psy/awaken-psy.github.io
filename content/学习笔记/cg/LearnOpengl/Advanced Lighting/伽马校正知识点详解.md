# 伽马校正知识点详解

原教程：[LearnOpenGL-CN · Gamma 校正](https://learnopengl-cn.readthedocs.io/zh/latest/05%20Advanced%20Lighting/02%20Gamma%20Correction/)

## 1 正确的数据流

**颜色图片通常按 sRGB 保存；光照计算需要线性颜色；最终显示前再编码一次。**

```text
sRGB 颜色图片 → 解码成线性颜色 → 光照/HDR/Bloom → 最终编码 → 显示
```

| 纹理内容 | 是否按 sRGB 解码 |
|---|---|
| diffuse、albedo 等颜色 | 通常需要 |
| 法线、深度、粗糙度等数据 | 不需要 |

Gamma 不是让画面“随便变亮”，而是让加法、乘法和光照衰减使用正确的数值。

## 2 输入：颜色纹理自动解码

加载颜色图片时使用 sRGB 内部格式：

```cpp
GLenum internalFormat;
if (nrComponents == 3)
    internalFormat = gammaCorrection ? GL_SRGB : GL_RGB;
else
    internalFormat = gammaCorrection ? GL_SRGB_ALPHA : GL_RGBA;

glTexImage2D(GL_TEXTURE_2D, 0, internalFormat,
             width, height, 0, dataFormat, GL_UNSIGNED_BYTE, data);
```

之后 Shader 仍正常调用 `texture(...)`。如果纹理是 `GL_SRGB/GL_SRGB_ALPHA`，采样得到的 RGB 已是线性值；alpha 不转换。不要再手动解码一次。

## 3 线性光照，最后编码一次

```glsl
float distance = length(lightPos - FragPos);
float attenuation = 1.0 / (distance * distance);
vec3 linearColor = albedo * lighting * attenuation;

vec3 encoded = pow(linearColor, vec3(1.0 / 2.2));
FragColor = vec4(encoded, 1.0);
```

最终编码也可以由 `GL_FRAMEBUFFER_SRGB` 在写入 sRGB 目标时完成。**Shader 手动编码与硬件编码选一种，不能重复。** 中间 FBO 还要做 HDR、Bloom 时通常保持线性。

## 4 对照本地开关

本地空格键同时切换：普通/sRGB 纹理、`1/d` 与 `1/d²` 衰减、是否执行最终 `pow(1/2.2)`。所以画面变化不只来自最后一行。

> [!summary] 一句话回忆
> **颜色图片先解码，光照与中间处理保持线性，最终显示前只编码一次；数据贴图不解码。**
