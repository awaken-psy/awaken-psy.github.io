# 面剔除知识点详解

原教程：[LearnOpenGL-CN · 面剔除](https://learnopengl-cn.readthedocs.io/zh/latest/04%20Advanced%20OpenGL/04%20Face%20culling/)

## 1 为什么可以少画一些面

从外面看一个封闭、不透明的箱子，背朝我们的外壳通常看不到。**面剔除就是根据朝向，跳过这些三角形。**

它在生成片段之前起作用，主要节省后续光栅化、片段着色的工作；不是把模型中的顶点删除，也不是自动跳过所有被其他物体挡住的面。

## 2 怎样知道哪一面朝着我们

看三角形**投影到屏幕后的顶点连接顺序**，也叫绕序：

| 默认约定 | 判定 |
|---|---|
| 逆时针 `CCW` | 正面 |
| 顺时针 `CW` | 背面 |

![[学习笔记/cg/LearnOpengl/Advanced OpenGL/assets/LearnOpenGL-面剔除-正背面.png|550]]

*从相反的一侧观察，绕序会反过来。图源：[LearnOpenGL](https://learnopengl.com/img/advanced/faceculling_frontback.png)。*

把 `A → B → C` 改成 `A → C → B`，三角形位置没变，正背面却翻转了。有 EBO 时看索引次序，没有 EBO 时看顶点数组的次序。

> [!important] 判断依据是绕序，不是法线
> 法线通常用于光照计算。仅修改法线方向，不会直接改变面剔除结果。

## 3 配置只记三个调用

```cpp
glEnable(GL_CULL_FACE); // 开启剔除
glFrontFace(GL_CCW);    // 规定逆时针是正面
glCullFace(GL_BACK);    // 剔除背面
```

这三句分别是：**开不开 → 谁算正面 → 丢哪一面**。OpenGL 默认关闭面剔除，后两项的默认值分别是 `GL_CCW` 和 `GL_BACK`。

| 想改变什么 | 设置 |
|---|---|
| 改成顺时针为正面 | `glFrontFace(GL_CW)` |
| 保留背面、剔除正面 | `glCullFace(GL_FRONT)` |
| 两面都允许绘制 | `glDisable(GL_CULL_FACE)` |

改变正面约定只是重新分类，并没有修改顶点数据。

## 4 复习时别混淆这几件事

- **面剔除看朝向，深度测试看遮挡。** 一个正面也可能被别的物体挡住，所以保留下来的面仍需要 [[学习笔记/cg/LearnOpengl/Advanced OpenGL/深度测试与模板测试知识点详解.md|深度测试与模板测试知识点详解]] 中的深度比较。
- **草叶、窗户等薄片可能需要两面可见。** 此时通常关闭该次绘制的剔除；有透明度不代表背面会自动保留。
- **站进箱子里，可能什么内壁都看不到。** 外壳朝向一致并开启背面剔除时，从内部看到的是它们的背面。
- **切换 VAO 或 Shader 不会恢复剔除设置。** 画薄片时关掉了，接下来画封闭物体时需要按需打开。

> [!note]- 对照本地练习
> 本地 face_culling_exercise1.cpp 给出的立方体从外侧看采用 CW 绕序，要配合 `glFrontFace(GL_CW)`。文件只有顶点数据和提示，不是完整可运行的 demo。

> [!summary] 一句话回忆
> **顶点绕序决定正背面；剔除设置决定丢哪面；深度测试再决定留下的面谁挡住谁。**
