# 几何着色器知识点详解

原教程：[LearnOpenGL-CN · 几何着色器](https://learnopengl-cn.github.io/04%20Advanced%20OpenGL/09%20Geometry%20Shader/)

## 1 一个点，怎样变成一栋房子

CPU 只提交一个点。几何着色器以它为中心，生成左下、右下、左上、右上、屋顶五个顶点，连成三个三角形，就得到一栋小房子。

**几何着色器（GS）就是在绘制途中，拿到一个图元，再决定输出哪些图元。** 输入可以是一个点，也可以是整个三角形的三个顶点。

这次绘制可以这样回忆：

**输入点 → 顶点着色器处理位置 → GS 生成房子 → 光栅化 → 片段着色器填颜色。**

普通顶点着色器主要处理单个顶点；GS 能一起看到一个图元的顶点，因此可以改变它的形状、数量或类型。它是可选阶段，不是每个 Shader 都要添加。

## 2 输出只记两个动作

| 调用 | 含义 |
|---|---|
| `EmitVertex()` | 把刚准备好的位置、颜色等作为一个顶点输出 |
| `EndPrimitive()` | 结束当前输出带，之后的顶点不再与它相连 |

房子用 `triangle_strip`（三角形带）连接五个顶点：前三个构成一个三角形，后面每增加一个顶点，再接出一个三角形。

下面省略五个偏移量 `offsets` 的定义及颜色输出，只保留动作：

```glsl
layout (points) in;
layout (triangle_strip, max_vertices = 5) out;

void main() {
    for (int i = 0; i < 5; ++i) {
        gl_Position = gl_in[0].gl_Position + offsets[i];
        EmitVertex();
    }
    EndPrimitive();
}
```

`gl_in` 里是当前输入图元的顶点；房子输入只有一个点，所以取 `[0]`。`max_vertices` 声明这次调用最多输出多少顶点。

> [!important] 最后画出三角形，不代表 Draw 要提交三角形
> 房子例子仍调用 `glDrawArrays(GL_POINTS, 0, 4)`，提交四个点。GS 对每个点生成一栋房子，输出才是三角形。

## 3 用三个例子记住它能做什么

| 教程例子 | GS 做的事情 |
|---|---|
| 房子 | 一个点扩展成三个三角形 |
| 爆破模型 | 读取三角形的三个顶点，一起向外偏移；随时间展开、收回 |
| 法线可视化 | 读取三角形，在每个顶点处沿法线生成一条线 |

法线可视化要**先正常画模型，再用显示法线的 Shader 画一次**。第二次复用同一份模型数据，却输出线段，方便观察法线方向。

这三例分别提醒我们：GS 可以增加几何、移动几何，也可以把三角形转换成线。

## 4 复习时别混淆

- **GS 一次处理一个图元，不是整个模型。** 输入三角形时，拿到的是这一组三个顶点。
- **生成结果不会自动保存回 Mesh。** 这些例子只改变本次绘制，下一帧仍从原始几何开始。
- **顶点不只有位置。** 后面需要颜色或 UV 时，GS 也要随输出顶点传递它们。
- **增加 GS 不保证更快。** 只移动顶点时可能用 VS 就够；大量重复岩石可以用 [[学习笔记/cg/LearnOpengl/Advanced OpenGL/实例化知识点详解.md|实例化知识点详解]]。

> [!note]- 对照本地示例时再看坐标空间
> 法线可视化 在观察空间构造线段，再投影；爆破示例 则使用裁剪空间位置做演示偏移，不是物理碎裂模拟。

> [!summary] 一句话回忆
> **GS 拿到一个图元，逐个输出新顶点，再交给后面的管线绘制。**
