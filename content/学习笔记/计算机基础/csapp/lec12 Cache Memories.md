## 1.缓存的组织与操作

### 1.1 缓存结构
![第6页缓存的组与行|872](Attachments/lec12-cache-memories/page-06.png)

| 符号      | 含义               |
| ------- | ---------------- |
| S = 2^s | 缓存的组数            |
| E = 2^e | 每组的缓存行数，也称路数     |
| B = 2^b | 每个缓存块的数据字节数      |
| v       | 有效位，表示该行是否保存有效内容 |
| tag     | 标记，用来识别该行对应的内存块  |

### 1.2 缓存读
![第7页地址分段与读取|689](Attachments/lec12-cache-memories/page-07.png)

1. 定位组。
2. 检查组内是否有一行具有匹配的 tag。
3. tag 匹配且该行有效，就命中。
4. 按块内偏移找到所需数据。

~~~text
[tag，t位][组索引，s位][块内偏移，b位]
~~~
$$S=2^s,\qquad B=2^b,\qquad t=m-s-b$$
设请求的字节地址为 A

$$\text{内存块号}=\left\lfloor A/B\right\rfloor$$
$$\text{组号}=\text{内存块号}\bmod S$$
$$\text{tag}=\left\lfloor\text{内存块号}/S\right\rfloor$$
$$\text{块内偏移}=A\bmod B$$
#### 1.2.1 检查有效位与标记

命中条件可以写成
$$
\text{hit}=(v=1)\land(\text{存储的tag}=\text{地址中的tag})
$$
- 有效位说明这行内容能否使用，tag 说明它保存的是映射到本组的哪一个内存块。
- 如果 tag 不匹配，旧缓存行会被驱逐并由请求块替换。


#### 1.2.2 直接相联
![811](<Attachments/Pasted image 20261107174727.png>) ![第11页直接映射模拟原例|809](Attachments/lec12-cache-memories/page-11.png)

> 可寻址内存空间 M = 16 B，地址为 4 位。
>
> 每块 B = 2 B，共 S = 4 组，每组 E = 1 行。
>
> 依次读取字节地址 0、1、7、8、0，每次读 1 字节。

因此
$$
m=4,\quad b=1,\quad s=2,\quad t=1,\quad C=4\times1\times2=8\text{ B}
$$
M 描述本例的可寻址内存范围，C 描述缓存的数据容量。初始各行有效位为 0。

| 2 | 1 | 0001 | 0 | 0 | 1 | 命中 | 读取已装入块中的第二个字节 |
| 3 | 7 | 0111 | 0 | 3 | 1 | 不命中 | 第 3 组装入 M[6–7] |
| 4 | 8 | 1000 | 1 | 0 | 0 | 不命中 | 第 0 组改放 M[8–9] |
| 5 | 0 | 0000 | 0 | 0 | 0 | 不命中 | 第 0 组重新装入 M[0–1] |

最终状态为

| 组 | 有效位 | tag | 保存的字节范围 |
|---|---:|---|---|
| 0 | 1 | 0 | M[0–1] |
| 1 | 0 | — | — |
| 2 | 0 | — | — |
| 3 | 1 | 0 | M[6–7] |

共 1 次命中、4 次不命中，命中率 20%，不命中率 80%。

#### 1.2.3 两路组相联

> 可寻址空间仍为 16 B，每块 2 B。
>
> 改为 S = 2 组、每组 E = 2 行。
>
> 字节地址序列仍为 0、1、7、8、0。

$$
m=4,\quad b=1,\quad s=1,\quad t=2,\quad C=2\times2\times2=8\text{ B}
$$

|---|---:|---|---|---:|---:|---|---|
| 1 | 0 | 0000 | 00 | 0 | 0 | 不命中 | 第 0 组第一行装入 M[0–1] |
| 2 | 1 | 0001 | 00 | 0 | 1 | 命中 | 使用已有行 |
| 3 | 7 | 0111 | 01 | 1 | 1 | 不命中 | 第 1 组装入 M[6–7] |
| 4 | 8 | 1000 | 10 | 0 | 0 | 不命中 | 第 0 组另一行装入 M[8–9] |

共 2 次命中、3 次不命中，命中率 40%，不命中率 60%。

#### 1.2.4 组相联、全相联与直接映射

设缓存数据容量为 C，每块数据大小为 B，组数为 S，每组行数为 E，则$$C = S\times E\times B $$
令 C=64 B、B=8 B，因此缓存总共有 8 行。

| 组织方式                        | 组数 S | 每组行数 E | 一个内存块允许放在哪里 |
| --------------------------- | ---: | -----: | ----------- |
| 直接映射 Direct-mapped          |    8 |      1 | 映射到的组内唯一一行  |
| 两路组相联 2-way set-associative |    4 |      2 | 映射到的组内两行之一  |
| 全相联 Fully associative       |    1 |      8 | 缓存中任意一行     |

### 1.3 缓存写

| 情形   | 策略                     | 操作                      |
| ---- | ---------------------- | ----------------------- |
| 写命中  | Write-through，写直达      | 更新本层缓存，同时向下层传播写入        |
| 写命中  | Write-back，写回          | 更新本层缓存并标记为脏，在替换等需要时写回下层 |
| 写不命中 | Write-allocate，写分配     | 先把目标块带入本层，再更新该缓存行       |
| 写不命中 | No-write-allocate，非写分配 | 直接向下层写入，本层此次保持原有缓存内容    |

- 常见组合是写直达+非写分配，以及写回+写分配。
- 脏位记录的是本层数据相对下层的修改状态。

### 1.5 缓存性能指标

平均访问时间的常用简化表达式是$$\boxed{T_{\text{avg}}=T_{\text{hit}}+r_{\text{miss}}\times P_{\text{miss}}}$$
- 命中时间包含检查数据是否位于缓存、并返回命中数据的时间。
- 命中率很重要，因为少数昂贵访问对平均时间的影响很大。整段程序的加速还取决于它有多少时间花在这些访问上。

## 2.缓存对性能的影响

### 2.1 存储器山（The Memory Mountain）

- 读取吞吐量（Read throughput），也称读取带宽，表示每秒读取的字节数，单位 MB/s。
- 存储器山把测得的读取吞吐量表示为空间局部性和时间局部性的函数，描述存储系统性能。

#### 2.1.1 性能实验

| 参数 | 含义 | 主要影响 |
|---|---|---|
| Size | 遍历数据的规模、地址跨度 | 工作数据能否保留在某级缓存中 |
| Stride | 相邻访问之间相隔多少个元素 | 一条缓存行中的数据能被使用多少 |

先运行一次进行缓存预热，再运行并测量读取吞吐量。

~~~c
long data[MAXELEMS];

int test(int elems, int stride)
{
    long i;
    long sx2 = stride * 2;
    long sx3 = stride * 3;
    long sx4 = stride * 4;
    long acc0 = 0, acc1 = 0, acc2 = 0, acc3 = 0;
    long length = elems;
    long limit = length - sx4;

    for (i = 0; i < limit; i += sx4) {
        acc0 += data[i];
        acc1 += data[i + stride];
        acc2 += data[i + sx2];
        acc3 += data[i + sx3];
    }

    for (; i < length; i += stride) {
        acc0 += data[i];
    }

    return (int)((acc0 + acc1) + (acc2 + acc3));
}
~~~

| 图中量 | 读取方式 |
|---|---|
| 高度 Read throughput | 越高，每秒完成的有效读取越多 |
| Stride（×8 bytes） | 步长乘 8 字节，得到本平台相邻元素访问的字节间隔 |

- 沿数据规模方向看，工作数据超出某级缓存后，重复读取需要更多地依赖下一层，形成不同高度的区域。具体转折还受到替换、映射、预取等影响。

### 2.2 循环重排（改善空间局部性）

矩阵乘法的定义为
$$
C[i][j]=\sum_{k=0}^{n-1} A[i][k]\times B[k][j]
$$
~~~c
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        sum = 0.0;
        for (k = 0; k < n; k++)
            sum += a[i][k] * b[k][j];
        c[i][j] = sum;
    }
}
~~~

#### 2.2.1 分析假设
![第27页矩阵乘法分析模型|665](Attachments/lec12-cache-memories/page-27.png)
- 缓存块大小为 32 B，可容纳 4 个 double。
- 缓存不足以保留多行矩阵数据。
- 分析方法是观察最内层循环的访问模式。

1. 沿同一列跨行前进，会访问相距较远的元素。在当前大矩阵模型中，缺失率近似为 100%。
2. 连续访问时，理想化缺失率为
$$
\text{缺失率}\approx\frac{\text{元素大小}}{\text{缓存行大小}}
$$

| 对象 | k 增加时的变化 | 每次内层迭代的平均缺失数 |

| B[k][j] | 沿固定列跨行前进 | 1 |

#### 2.2.5 六种循环顺序对照

| 循环顺序 | 最内层变量 | A 的访问 | B 的访问 | C 的访问 | 缺失数/内层迭代 |

### 2.3 分块（改善时间局部性）

#### 2.3.1 初始未分块的缺失分析
![第39页普通乘法首次点积|717](Attachments/lec12-cache-memories/page-39.png)

假设：
1. 矩阵元素为 double， 一个缓存行容纳 8 个 double。
2. 缓存容量 C 远小于一行的元素数量 n。
推论：
- 首次迭代约发生 n/8 + n = 9n/8 次缺失。
- 总缺失数约为 (9/8)n³。

#### 2.3.2 分块矩阵乘法
![963](<Attachments/Pasted image 20261108031915.png>)

- 把大矩阵乘法拆成 B×B 子矩阵之间的小乘法。
- 外面三层循环依次选择 c、a、b 的相关子块，里面三层循环完成这三个子块的乘加。

``` c
void mmm_blocked(const double *a, const double *b, double *c, int n, int B){
    for (int i = 0; i < n; ) {
        int i_end = (n - i < B) ? n : i + B;

        for (int j = 0; j < n; ) {
            int j_end = (n - j < B) ? n : j + B;

            for (int k = 0; k < n; ) {
                int k_end = (n - k < B) ? n : k + B;

                for (int i1 = i; i1 < i_end; i1++)
                    for (int j1 = j; j1 < j_end; j1++)
                        for (int k1 = k; k1 < k_end; k1++)
                            c[(size_t)i1*n + j1] += a[(size_t)i1*n + k1] * b[(size_t)k1*n + j1];
                k = k_end;
            }
            j = j_end;
        }
        i = i_end;
    }
}
```

#### 2.3.3 分块后的缺失分析

![第42页分块缺失分析|810](Attachments/lec12-cache-memories/page-42.png)

- 三个 B×B 子块能够同时放入缓存，即 3B²<C。
- 每个子块约需要 B²/8 次缺失。
- 完成第一个目标子块，一共读取约  2n/B 个输入子块，主要读缺失约为 (2n/B)×(B²/8)=nB/4。
- 目标矩阵共有 (n/B)² 个子块，所以总缺失数约为 n³/(4B)。

#### 2.3.4 分块分析对照

- 普通版本约有 (9/8)n³ 次缺失。
- 分块版本约有 (1/4B)n³ 次缺失。
- 两种主要读缺失估算的比例为
$$
\frac{(9/8)n^3}{n^3/(4B)}=\frac92B=4.5B
$$
