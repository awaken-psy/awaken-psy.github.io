## 0. 优化概述

> [!abstract] 定义与三原则
> **优化** = 对程序进行各种**等价变换**，使变换后的程序能生成**更有效**的目标代码。三条原则：
> - **等价原则**：优化后**不改变**程序运行结果；
> - **有效原则**：目标代码**时间更短、空间更小**；
> - **合算原则**：以**较低代价**取得较好效果。

**优化的三个级别**：局部优化（基本块内）、循环优化（循环内）、全局优化（整个程序流图）。

**优化的种类**（记这张表，局部 / 循环各对应哪些）：

| 优化种类 | 局部 | 循环 |
|---|---|---|
| 删除公共子表达式（删除多余运算） | ✅ | ✅ |
| 删除无用赋值 | ✅ | ✅ |
| 合并已知量 | ✅ | |
| 复写传播 | | ✅ |
| 代码外提 | | ✅ |
| 强度削弱 | | ✅ |
| 变换循环控制条件（删除归纳变量） | | ✅ |
| 临时变量改名 / 交换语句位置 / 代数变换 | ✅ | |

> [!info] quicksort 综合例（slide 8–27）
> PPT 用一个 quicksort 片段**贯穿演示全套优化**：删公共子表达式 → 复写传播 → 删无用赋值 → 强度削弱 → 删归纳变量，一步步把代码瘦身。看懂那张图就理解了"优化到底在干什么"。下面分块讲每种优化。

## 1. 基本块与程序流图

### 1.1 基本块是什么

> [!abstract] 基本块
> 程序中一段**顺序执行**的语句序列，**只有一个入口**（第一条语句）和**一个出口**（最后一条语句）。中间没有跳进跳出。

几个术语（优化全程要用）：
- **定值**：`x := y + z` 称"对 `x` 定值"，并"引用 `y`、`z`"。
- **活跃**：某名字在某点的值**在该点之后还会被引用**，就说它在这点活跃。

### 1.2 ⭐ 划分基本块算法（三步）

**第 1 步：找所有入口语句**（满足任一）：
1. 程序的**第一个**语句；或
2. 能由**条件 / 无条件转移语句转移到的**语句（即某个 `goto` / `if` 的目标）；或
3. **紧跟在条件转移语句后面**的语句。

**第 2 步：对每个入口语句，确定其基本块** = 从该入口语句到**下一入口语句（不含）/ 一个转移语句（含）/ 一个停语句（含）** 之间的序列。

**第 3 步：未被纳入任何基本块的语句，从程序中删除**（ unreachable，不可达）。

### 1.3 ⭐ 例：给求最大公约数程序划分基本块

```text
(1) read X
(2) read Y
(3) R := X mod Y
(4) if R=0 goto (8)
(5) X := Y
(6) Y := R
(7) goto (3)
(8) write Y
(9) halt
```

**先找入口语句**：
- (1)：程序第一句 ✓（规则 1）
- (3)：被 `(7) goto (3)` 转移到 ✓（规则 2）
- (8)：被 `(4) if R=0 goto (8)` 转移到 ✓（规则 2）
- (5)：紧跟在条件转移 `(4)` 之后 ✓（规则 3）

**划分**：

| 基本块 | 语句 | 说明 |
|---|---|---|
| **B1** | (1)(2) | 入口 (1) → 下一入口 (3) 前 |
| **B2** | (3)(4) | 入口 (3) → 到转移语句 (4) 含 |
| **B3** | (5)(6)(7) | 入口 (5)（紧跟条件转移）→ 到转移语句 (7) 含 |
| **B4** | (8)(9) | 入口 (8) → 到停语句 (9) 含 |

### 1.4 程序流图

**流图** = 以**基本块为结点**的有向图。
- **首结点**：入口语句是程序第一条语句的基本块。
- **边** `B1 → B2`（B1 前驱、B2 后继）当：
  - B1 末尾有转移语句跳到 B2 开头；**或**
  - B2 紧接 B1 之后，且 B1 末尾不是无条件转移。

> [!example]- 上例的流图
> ```mermaid
> flowchart TD
>     B1([B1: read X,Y]) --> B2
>     B2{"B2: R:=X mod Y<br/>if R=0 goto B4"}
>     B2 -- R≠0 顺序执行 --> B3[["B3: X:=Y; Y:=R<br/>goto B2"]]
>     B2 -- R=0 goto --> B4([B4: write Y; halt])
>     B3 -- goto (3) --> B2
>     class B1,B4 final
>     class B2,B3 state
>     classDef state fill:#2d3748,stroke:#8a9bb0,stroke-width:1.5px,color:#e2e8f0
>     classDef final fill:#3b5278,stroke:#7fa8d6,stroke-width:2px,color:#e2e8f0
> ```
> 循环由 **B2 ↔ B3** 构成（B3 跳回 B2）。

## 2. ⭐ 局部优化（基本块内）

局限于**一个基本块**范围内的优化。包括：删除公共子表达式、删除无用赋值、合并已知量、临时变量改名、交换语句位置、代数变换（`x+0`、`x*1`、`y**2 → y*y`）。

> [!tip] 核心：用 DAG 做局部优化
> 基本块的**局部优化**统一用**基本块的 DAG** 来做——构造出 DAG 后，再从 DAG 重新生成四元式，就**自动**完成了"合并已知量 / 删公共子表达式 / 删无用赋值"。

### 2.1 基本块的 DAG 表示

- **叶结点**：标一标识符或常数，代表它的值；
- **内部结点**：标一运算符，代表对后继结点的值施加该运算的结果；
- **附加标识符**：结点上可挂多个标识符，表示这些变量**当前取该结点的值**。

四元式与 DAG 结点对应（四类）：

| 类型 | 四元式 | DAG 结点 |
|---|---|---|
| 0 型 | `A := B`（`(:=, B, -, A)`） | B 的结点附加 A |
| 1 型 | `A := op B`（`(op, B, -, A)`） | 新建 op 结点，子为 B |
| 2 型 | `A := B op C`（`(op, B, C, A)`） | 新建 op 结点，左子 B 右子 C |
| 2 型 | `A := B[C]`（`(=[], B[C], -, A)`） | 新建 =[] 结点 |
| 3 型 | `D[C] := B`（`([]=, B, -, D[C])`） | 新建 []= 结点 |

### 2.2 DAG 构造算法（对基本块每条四元式依次执行 4 步）

1. **准备操作数的结点**：若 `NODE(B)` 无定义，建标记为 B 的叶结点；
2. **合并已知量**：若操作数都是常数叶，直接算出结果建常数叶（删掉临时建的叶）；
3. **找公共子表达式**：检查是否已有"同算符、同后继"的结点，有就复用（不新建）；
4. **删除无用赋值**：把 A 附加到结点 n；若 A 原本挂在别的结点上，先从那里摘掉（叶结点的标记不摘）。

### 2.3 ⭐⭐ 例题：构造基本块 G 的 DAG，写出优化后四元式

基本块：
```text
(1)  T0 := 3.14
(2)  T1 := 2 * T0
(3)  T2 := R + r
(4)  A  := T1 * T2
(5)  B  := A
(6)  T3 := 2 * T0
(7)  T4 := R + r
(8)  T5 := T3 * T4
(9)  T6 := R - r
(10) B  := T5 * T6
```

> [!example]- 逐步构造 DAG（体会合并已知量 / 公共子表达式 / 删无用赋值）
> - (1) `T0:=3.14` → 建叶 **n1(3.14)**，附加 T0。
> - (2) `T1:=2*T0`：2、T0(=3.14) 都是常数 → **合并已知量** 2×3.14=6.28 → 建叶 **n2(6.28)**，附加 T1。
> - (3) `T2:=R+r`：建叶 R(n3)、r(n4)，建内部 **n5(+)** 子为 n3,n4，附加 T2。
> - (4) `A:=T1*T2`：T1=n2、T2=n5 → 建内部 **n6(\*)** 子为 n2,n5，附加 A。
> - (5) `B:=A`：**复写**，B 附加到 n6（A 所在结点）。
> - (6) `T3:=2*T0`：2\*T0 已合并成 n2(6.28) → **公共子表达式，复用 n2**，T3 也附加到 n2。
> - (7) `T4:=R+r`：R+r 已有 n5 → **公共子表达式，复用 n5**，T4 附加到 n5。
> - (8) `T5:=T3*T4`：T3=n2、T4=n5 → n2\*n5 已有 **n6**！T5 附加到 n6（不新建）。
> - (9) `T6:=R-r`：建内部 **n7(-)** 子为 n3,n4，附加 T6。
> - (10) `B:=T5*T6`：T5=n6、T6=n7 → 建内部 **n8(\*)** 子为 n6,n7，附加 B（B 从 n6 **摘下**移到 n8，因为 B 在此重新定值）。
>
> 最终 DAG：
> ```mermaid
> flowchart TD
>     n8(("﹡ B")) --> n6(("﹡ A,T5"))
>     n8 --> n7(("﹣ T6"))
>     n6 --> n2(("6.28 T1,T3"))
>     n6 --> n5(("﹢ T2,T4"))
>     n7 --> n3((R))
>     n7 --> n4((r))
>     n5 --> n3
>     n5 --> n4
>     n1(("3.14 T0"))
>     class n5,n6,n7,n8 state
>     class n1,n2,n3,n4 leaf
>     classDef state fill:#2d3748,stroke:#8a9bb0,stroke-width:1.5px,color:#e2e8f0
>     classDef leaf fill:#3b5278,stroke:#7fa8d6,stroke-width:2px,color:#e2e8f0
> ```

> [!success] 从 DAG 重新生成的优化后四元式
> ```text
> (1) T0 := 3.14
> (2) T1 := 6.28          ← 合并已知量（2*3.14）
> (3) T3 := 6.28          ← 公共子表达式，复用（与 T1 同结点 n2）
> (4) T2 := R + r
> (5) T4 := T2            ← 公共子表达式（R+r 复用 n5）
> (6) A  := 6.28 * T2     ← 公共子表达式（T1*T2 复用 n6）
> (7) T5 := A             ← 公共子表达式（T3*T4 复用 n6）
> (8) T6 := R - r
> (9) B  := A * T6
> ```
> **10 条 → 9 条**，且把重复的 `2*T0`、`R+r`、乘法都合并了。

> [!example]- 进一步：若只有 A、B 出基本块后活跃
> 则 T0~T6 出块后都没人用，可以全删，只保留给 A、B 定值的：
> ```text
> (1) T2 := R + r
> (2) A  := 6.28 * T2
> (3) T6 := R - r
> (4) B  := A * T6
> ```
> 这就是"删除无用赋值"——**只在基本块内用、出块后不活跃的临时变量，其定值可删**。

## 3. ⭐ 循环优化

对循环中的代码可实行：**代码外提**、**强度削弱**、**删除归纳变量**（变换循环控制条件）、循环展开、循环合并。

### 3.1 ⭐ 代码外提

> [!abstract] 循环不变运算 & 代码外提
> **循环不变运算**：四元式 `A := B op C`，若 B、C 是常数，**或它们的定值点都在循环外**（循环里没改过 B、C），这条就是不随循环变的运算。
> **代码外提**：把循环不变运算提到**循环外面**（一个新建的**前置结点** B₂′，循环入口前），每轮就不用重算了。
>
> "定值点 d 到达 u"：从 d 到 u 有通路，且路上没有该变量的其它定值。

> [!danger] ⭐ 代码外提的三个条件（必考：不是所有不变运算都能外提！）
> 不变运算 `s: A := B op C` 能外提，必须满足下列条件之一：
> - **条件 (1)** 三条全成立：
>   - (i) `s` 所在结点是循环 L **所有出口结点的必经结点**；
>   - (ii) `A` 在 L 中**其他地方未再定值**；
>   - (iii) L 中所有 `A` 的引用点，**只有 `s` 的定值能到达**。
> - **或条件 (2)**：`A` 在离开 L 后**不活跃**，且 (1)(ii)(1)(iii) 成立。

> [!example]- 反例：三条件缺一不可（必考：会用反例判断"能否外提"）
> **① 违反条件 (i) 必经结点 —— 最经典反例**
> ```mermaid
> flowchart TD
>     B1(["B1: A := 0"]) --> B2{"B2 入口<br/>if x=0 goto B5"}
>     B2 -- "x≠0" --> B3["B3: A := 2  (s: 不变运算)<br/>if y=0 goto B5"]
>     B2 -- "x=0" --> B5(["B5 出口<br/>write A"])
>     B3 -- "y≠0" --> B4["B4: x:=x﹣1<br/>y:=y﹣1"]
>     B3 -- "y=0" --> B5
>     B4 -- goto B2 --> B2
>     class B2,B3,B4 state
>     class B1,B5 final
>     classDef state fill:#2d3748,stroke:#8a9bb0,stroke-width:1.5px,color:#e2e8f0
>     classDef final fill:#3b5278,stroke:#7fa8d6,stroke-width:2px,color:#e2e8f0
> ```
> 循环 `L={B2,B3,B4}`，s 所在的 **B3 不是 B5 的必经结点**（`x=0` 时 B2 可直达 B5、绕过 B3）。
> - **原程序**：若首轮 `x=0`，走 B2→B5，s 未执行，`write A` 输出 **0**。
> - **外提 s 到前置结点后**：每次入循环都先 `A:=2`，即便 `x=0` 直跳 B5，A 已被置 2，输出 **2 ≠ 0** ❌。
> - 直觉：s 本没出现在所有"出口路径"上，外提 = 强行让绕过 s 的路径也用上 s 的结果。
>
> **② 违反条件 (ii) A 在 L 中重复定值**：L 中除 s 外还有别处给 A 定值（如某结点 `A:=5`）。外提 s 后每轮入口 A 都先被 s 置值，原程序里"L 内另一处 A 的定值本该在后续被引用"的语义被覆盖。
>
> **③ 违反条件 (iii) A 的引用有 s 以外的定值到达**：L 内引用 A 的点，到达它的定值除 s 外还有别的（如循环外 `B1: A:=0` 沿绕过 s 的路径到达）。外提 s 到前置结点后，s 每次执行都覆盖旧定值，原本该拿旧值的引用就拿不到了。
>
> > [!tip] 一句话记三条件
> > **s 必经所有出口** ＋ **A 在 L 内只定值这一次** ＋ **L 内对 A 的引用只能来自 s**。任一不满足，外提必改变 A 在某些路径上的取值 → 不等价。

> [!example]- 例：`for I:=1 to 10 do A[I, 2*J] := A[I, 2*J] + 1`
> **设** `array A[1:10, 1:10]`（行主序、下界 1、元素大小 1）；J、A 在循环中不变。
>
> 先把 `A[I, 2*J]` 的地址拆成**不变部分 + 可变部分**（数组地址公式的固定套路）：
> ```text
> &A[I, 2*J] = CONSPART + VARPART
> CONSPART = addr(A) - (low1*d2 + low2)*w = addr(A) - (1*10+1)*1 = addr(A) - 11   ← 编译时常量
> VARPART   = (I*d2 + 2*J)*w              = 10*I + 2*J                            ← 随 I,J 变
> ```
> 于是 `A[I,2*J] := A[I,2*J] + 1` 展开成四元式序列：
> ```text
> T1 := 2*J           ← VARPART 的 j 项    (J 不变 → 循环不变运算)
> T2 := 10*I          ← VARPART 的 i 项    (I 变 → 留循环)
> T3 := T2 + T1       ← VARPART
> T4 := addr(A) - 11  ← CONSPART (11 = d2+1 = 10+1)   (A 不变 → 循环不变运算)
> T5 := T3 + T4       ← = &A[I, 2*J]
> T6 := A[T5]         ← 取 A[I, 2*J]
> T7 := T6 + 1
> A[T5] := T7         ← 写回 A[I, 2*J]
> I  := I + 1
> ```
> **外提**：`T1`、`T4` 是循环不变运算（J、A 在循环里没改）→ 提到前置结点 B₂′；`T2` 及后续随 I 变，留在循环体：
> ```text
> B2'(前置):  T1 := 2*J;  T4 := addr(A) - 11
> B2(循环体): if I>10 goto 出口
>             T2 := 10*I;  T3 := T2+T1;  T5 := T3+T4
>             T6 := A[T5];  T7 := T6+1;  A[T5] := T7
>             I := I+1;  goto B2
> ```
> 每轮省下重算 `2*J` 和 `addr(A)-11`（少一次乘法 + 一次减法）。

### 3.2 ⭐ 强度削弱

> [!abstract] 强度削弱
> 把**执行时间长的运算换成时间短的**。最典型：循环里的**乘法**用**递归加法**替换。

> [!example]- 例：`T2 := 10 * I`（I 每轮 +1）→ 强度削弱成 `T2 := T2 + 10`
> 循环里 `I := I+1`，所以 `T2 = 10*I` 每轮递增 10。于是：
> ```text
> 原循环:              强度削弱后:
> T2 := 10*I           T2 := 10*I      ← 在前置结点算一次初值
> ...                  ...
> I := I+1             T2 := T2 + 10   ← 循环里用加法代替乘法
> ```
> 把每轮的**乘法** `10*I` 换成**加法** `T2+10`（加法比乘法快）。
>
> 进一步，`T3 := T2 + T1` 里的 `T2` 每轮 +10、`T1` 不变 → `T3` 每轮也 +10，可再强度削弱成 `T3 := T3 + 10`。**对下标地址计算的削弱特别有效**（数组下标 `10*I+2*J` 这类）。

### 3.3 ⭐ 删除归纳变量（变换循环控制条件）

> [!abstract] 归纳变量
> - **基本归纳变量**：循环中对变量 I 只有唯一的形如 `I := I ± C` 的赋值（C 是循环不变量）。如 `I := I+1` 的 I。
> - **（同族）归纳变量**：若 J 在循环中的定值可化为基本归纳变量 I 的**线性函数** `J := C₁*I ± C₂`（C₁、C₂ 循环不变），称 J 是归纳变量，与 I **同族**。如 `T2 := 10*I` 的 T2 与 I 同族。

> [!danger] 删除归纳变量怎么优化
> 强度削弱后，`I` 往往**只剩控制循环**这一个用处（计算都被 T2 等取代了）。于是：
> 1. 选取一个与 I **同族的归纳变量** M，把循环控制条件 `if I rop Y` 换成用 M 表示（如 `if T3 rop R`）；
> 2. **删掉**对基本归纳变量 I 的递归赋值 `I := I+1`。
>
> 这样 I 及其自增代码都被删除，循环更精简。

> [!example]- ⭐ 详细例题：删除归纳变量（承接 3.1 的 `A[I,2*J]` 例子；slide 81）
> **起点**：3.1/3.2 的例子经"代码外提 + 强度削弱"后，循环如下（`T2`、`T3` 已用加法递增代替乘法重算）：
> ```text
> B2'(前置):  T1 := 2*J           ← 外提（不变）
>             T4 := addr(A) - 11  ← 外提（不变）
>             I  := 1
>             T2 := 10*I          ← T2 初值（=10），强度削弱
>             T3 := T2 + T1       ← T3 初值（=10+T1），强度削弱
> B2(循环体): if I > 10 goto 出口
>             T5 := T3 + T4       ← &A[I, 2*J]
>             T6 := A[T5];  T7 := T6 + 1;  A[T5] := T7
>             T2 := T2 + 10       ← 强度削弱（随 I 每轮 +10）
>             T3 := T3 + 10       ← 强度削弱（随 I 每轮 +10）
>             I  := I + 1
>             goto B2
> ```
> **观察**：此时 I 的"算下标地址"功能已被 `T2`/`T3` 接管，I **只剩 `if I>10` 这一个用处** —— 典型的可删基本归纳变量。
>
> **第 1 步 · 找与 I 同族的归纳变量，建立线性关系**
> - `T2 = 10*I`（C₁=10, C₂=0）→ 与 I 同族；
> - `T3 = T2 + T1 = 10*I + T1`（C₁=10, C₂=T1）→ 与 I 同族。
> 选 **T3** 来替换 I（它直接参与地址计算 `T5 := T3 + T4`，保留它最划算）。
>
> **第 2 步 · 变换循环控制条件 `if I > 10 goto 出口`**
> 由 `T3 = 10*I + T1`，把 `I > 10` 等价改写（两边同乘 10 再加 T1）：
> ```text
> I > 10  ⟺  10*I + T1 > 10*10 + T1  ⟺  T3 > 100 + T1
> ```
> 在前置结点引入循环不变量 `R := 100 + T1`，控制条件改成 `if T3 > R goto 出口`。
>
> **第 3 步 · 删除基本归纳变量**
> I 在循环体内不再被引用 → 删掉 `I := I + 1`。（前置结点的 `I := 1` 因给 `T2` 算初值仍保留，若再做常量折叠可消去，但那已不属于本优化。）
>
> **优化后**：
> ```text
> B2'(前置):  I  := 1                       ← 保留：给 T2 初值用
>             T1 := 2*J;  T4 := addr(A) - 11
>             T2 := 10*I;  T3 := T2 + T1
>             R  := 100 + T1                ← 新引入的循环不变边界
> B2(循环体): if T3 > R goto 出口            ← 改用 T3 控制循环
>             T5 := T3 + T4
>             T6 := A[T5];  T7 := T6 + 1;  A[T5] := T7
>             T2 := T2 + 10;  T3 := T3 + 10
>             (I := I+1 已删除)
>             goto B2
> ```
> **验证**：I=1..10 各轮 T3 = 10+T1 .. 100+T1，`T3 > R` 在 I=10 时为 `100+T1 > 100+T1`（假），仍执行第 10 轮；I=11 时 T3=110+T1 > R（真）跳出 —— 与原 `I > 10` 完全一致，共 10 轮。✅
>
> **效果**：循环体少一条 `I := I+1`，控制条件与地址计算统一走 T3 这一条线，I 在循环体内彻底退场 —— 这就是"删除归纳变量（= 变换循环控制条件）"。

### 3.4 强度削弱 + 删除归纳变量 统一算法

1. 找循环中所有**基本归纳变量**；
2. 找其它**归纳变量** A，建立它与某基本归纳变量 X 的线性关系 `F_A(X)`；
3. 对每个归纳变量 A **强度削弱**；
4. **删除**对归纳变量的无用赋值；
5. **删除基本归纳变量**：若 B 出循环后不活跃、且循环里只在 `if B rop Y goto L` 中被引用，则选一同族归纳变量 M 替换 B 做条件控制，删掉 `B := B ± C`。

## ✅ 自测题（先自己想，再展开答案）

> [!question]- Q1. 优化的三原则？三个级别？
> 三原则：等价（不改结果）、有效（时空更优）、合算（低成本好效果）。三级别：局部（基本块内）、循环、全局。

> [!question]- Q2. ⭐ 划分基本块的入口语句是哪三种？
> (1) 程序第一个语句；(2) 能由条件/无条件转移转移到的语句（转移目标）；(3) 紧跟在条件转移语句后面的语句。

> [!question]- Q3. ⭐ DAG 局部优化能自动完成哪几种优化？
> 合并已知量、删除公共子表达式、删除无用赋值（复写传播的效果也有）。从 DAG 重新生成四元式即得优化结果。

> [!question]- Q4. ⭐ DAG 构造算法的 4 步？
> (1) 准备操作数结点（无定义就建叶）；(2) 合并已知量（操作数都是常数叶就直接算）；(3) 找公共子表达式（已有同算符同后继的结点就复用）；(4) 删除无用赋值（把 A 附加到新结点，从旧结点摘掉）。

> [!question]- Q5. ⭐ 代码外提的三个条件是什么？为什么不能无条件外提？
> 不变运算 `s:A:=B op C` 外提须满足：s 所在结点是 L 所有出口的必经结点、A 在 L 中其他地方未再定值、L 中 A 的引用点只有 s 的定值能到达（三者全成立）；或 A 出 L 不活跃且后两条成立。不能无条件外提是因为外提可能**改变 A 的定值到达关系**，导致引用 A 的地方拿到错误的值。

> [!question]- Q6. 什么是强度削弱？举例。
> 把耗时运算换快的，典型是循环里乘法换递归加法。`T2:=10*I`（I 每轮+1）→ 前置算初值 `T2:=10*I`，循环里改 `T2:=T2+10`。

> [!question]- Q7. 基本归纳变量和归纳变量的定义？删除归纳变量怎么做？
> 基本归纳变量：循环中唯一 `I:=I±C`（C 不变量）的 I。归纳变量：与基本归纳变量成线性关系 `J:=C₁*I±C₂` 的 J，与 I 同族。删除：选同族归纳变量 M 替换循环控制条件 `if I rop Y` 成用 M 表达，再删 `I:=I±C`。

> [!question]- Q8. 为什么强度削弱和删除归纳变量常常一起做？
> 强度削弱后，基本归纳变量 I 的计算（如 `10*I`）被同族归纳变量 T2 的递增取代，I 只剩控制循环一个用处；于是可以删除归纳变量——用 T2 替 I 做控制、删 `I:=I+1`。两者联动才完整。
