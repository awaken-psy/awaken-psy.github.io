## 题 1

> [!question] 题目
> 文法 G₁：`S → a | Λ | (T)`；`T → T,S | S`
> (1) 消去 G₁ 的左递归。然后对每个非终结符，写出不带回溯的递归子程序。
> (2) 改写后的文法是否 LL(1)？给出预测分析表。

> [!success] (1) 消左递归
> `T → T,S | S` 含**直接左递归**，引入 `T'` 改写：
> ```text
> S  → a | Λ | (T)
> T  → S T'
> T' → ,S T' | Λ
> ```

> [!success] (1) 不带回溯的递归子程序
> 设 `SYM` 为当前符号、`ADVANCE` 读下一符号。消左递归后每非终结符候选首符互不相交，看一个符号即可定候选：
> ```text
> PROCEDURE S:
>   IF SYM='a' THEN ADVANCE                         (* S→a *)
>   ELSE IF SYM='(' THEN                            (* S→(T) *)
>          BEGIN ADVANCE; CALL T;
>                IF SYM=')' THEN ADVANCE ELSE ERROR END
>   ELSE IF SYM IN FOLLOW(S) THEN  {空}             (* S→Λ，SYM∈{),,,#} *)
>   ELSE ERROR
>
> PROCEDURE T:  BEGIN CALL S; CALL T' END           (* T→ST' *)
>
> PROCEDURE T':
>   IF SYM=',' THEN                                 (* T'→,ST' *)
>          BEGIN ADVANCE; CALL S; CALL T' END
>   ELSE IF SYM IN FOLLOW(T') THEN  {空}            (* T'→Λ，SYM∈{)} *)
>   ELSE ERROR
> ```

> [!success] (2) 是 LL(1)；预测分析表
> FIRST/FOLLOW/SELECT 的完整推导见 [[学习笔记/计算机基础/编译原理/exam/2022-2023-A.md#四、文法 `S→a|Λ|(T)`；`T→T,S|S`（15 分）|A 卷第四题]]（同一文法）。SELECT 两两不冲突 ⇒ LL(1)。
>
> | | a | ( | ) | , | # |
> |---|---|---|---|---|---|
> | **S** | `S→a` | `S→(T)` | `S→Λ` | `S→Λ` | `S→Λ` |
> | **T** | `T→ST'` | `T→ST'` | `T→ST'` | `T→ST'` |  |
> | **T'** |  |  | `T'→Λ` | `T'→,ST'` |  |
>
> 表内无多重定义，再次确认 LL(1)。

## 题 2

> [!question] 题目
> 文法 G：`E→TE'`；`E'→+E|ε`；`T→FT'`；`T'→T|ε`；`F→PF'`；`F'→*F'|ε`；`P→(E)|a|b|∧`
> (1) 求各非终结符的 FIRST、FOLLOW；(2) 证明是 LL(1)；(3) 构造预测分析表；(4) 构造递归下降分析程序。

> [!success] (1) FIRST / FOLLOW
> （`∧` 在本题是**终结符**，不是空串）
>
> | 非终结符 | FIRST | FOLLOW |
> |---|---|---|
> | E  | `( a b ∧` | `# )` |
> | E' | `+ ε` | `# )` |
> | T  | `( a b ∧` | `+ # )` |
> | T' | `( a b ∧ ε` | `+ # )` |
> | F  | `( a b ∧` | `( a b ∧ + # )` |
> | F' | `* ε` | `( a b ∧ + # )` |
> | P  | `( a b ∧` | `* ( a b ∧ + # )` |
>
> 推导要点：E 是开始符号 → `#∈FOLLOW(E)`；`P→(E)` 中 E 后跟 `)` → `)∈FOLLOW(E)`；E' 在 `E→TE'` 末尾 → `FOLLOW(E')=FOLLOW(E)`；`+∈FOLLOW(T)`（T 后跟 E'，FIRST(E')含+），E' 可空再传 FOLLOW(E)；逐层经 `T→FT'`、`F→PF'` 传递（带 ε 的非终结符把所属 FOLLOW 往下传）。

> [!success] (2) 证明 LL(1)（每个非终结符候选的 SELECT 集两两不相交）
> - `E'→+E`/`{+}` 与 `E'→ε`/`FOLLOW(E')={#,)}` 不相交 ✓
> - `T'→T`/`{(,a,b,∧}` 与 `T'→ε`/`{+,#,)}` 不相交 ✓
> - `F'→*F'`/`{*}` 与 `F'→ε`/`{(,a,b,∧,+,#,)}` 不相交 ✓
> - `P` 四候选首符 `{(}`/`{a}`/`{b}`/`{∧}` 互不相交 ✓
> - E、T、F 单候选 ✓
>
> ⇒ **是 LL(1) 文法**。

> [!success] (3) 预测分析表
>
> | | ( | ) | a | b | ∧ | + | * | # |
> |---|---|---|---|---|---|---|---|---|
> | **E**  | `E→TE'` |  | `E→TE'` | `E→TE'` | `E→TE'` |  |  |  |
> | **E'** |  | `E'→ε` |  |  |  | `E'→+E` |  | `E'→ε` |
> | **T**  | `T→FT'` |  | `T→FT'` | `T→FT'` | `T→FT'` |  |  |  |
> | **T'** | `T'→T` | `T'→ε` | `T'→T` | `T'→T` | `T'→T` | `T'→ε` |  | `T'→ε` |
> | **F**  | `F→PF'` |  | `F→PF'` | `F→PF'` | `F→PF'` |  |  |  |
> | **F'** | `F'→ε` | `F'→ε` | `F'→ε` | `F'→ε` | `F'→ε` | `F'→ε` | `F'→*F'` | `F'→ε` |
> | **P**  | `P→(E)` |  | `P→a` | `P→b` | `P→∧` |  |  |  |

> [!success] (4) 递归下降分析程序
> ```text
> PROCEDURE E:   BEGIN CALL T; CALL E' END          (* E→TE' *)
> PROCEDURE E':
>   IF SYM='+' THEN BEGIN ADVANCE; CALL E END       (* E'→+E *)
>   ELSE { SYM∈{),#} → E'→ε，空 }
> PROCEDURE T:   BEGIN CALL F; CALL T' END          (* T→FT' *)
> PROCEDURE T':
>   IF SYM IN {(,a,b,∧} THEN CALL T                (* T'→T *)
>   ELSE { SYM∈FOLLOW(T')={+,#,)} → T'→ε，空 }
> PROCEDURE F:   BEGIN CALL P; CALL F' END          (* F→PF' *)
> PROCEDURE F':
>   IF SYM='*' THEN BEGIN ADVANCE; CALL F' END      (* F'→*F' *)
>   ELSE { SYM∈FOLLOW(F') → F'→ε，空 }
> PROCEDURE P:
>   IF SYM='(' THEN                                (* P→(E) *)
>        BEGIN ADVANCE; CALL E;
>              IF SYM=')' THEN ADVANCE ELSE ERROR END
>   ELSE IF SYM='a' THEN ADVANCE                    (* P→a *)
>   ELSE IF SYM='b' THEN ADVANCE                    (* P→b *)
>   ELSE IF SYM='∧' THEN ADVANCE                    (* P→∧ *)
>   ELSE ERROR
> ```

## 题 3

> [!question] 题目
> 下面文法中哪些是 LL(1)，说明理由。
> (1) `S → Abc`；`A → a | ε`；`B → b | ε`
> (2) `S → Ab`；`A → a | B | ε`；`B → b | ε`

> [!success] (1) 是 LL(1)
> `FIRST(A)={a,ε}`；A 在 `S→Abc` 中后跟 `b` → `FOLLOW(A)={b}`。
> - `SELECT(A→a)={a}`，`SELECT(A→ε)=FOLLOW(A)={b}`，不相交 ✓
> - S 单候选；B 虽不被 S 引用，`SELECT(B→b)={b}` 与 `SELECT(B→ε)=FOLLOW(B)=∅` 也不冲突
>
> 各非终结符候选 SELECT 均不相交 ⇒ **是 LL(1)**。

> [!success] (2) 不是 LL(1)
> `FIRST(B)={b,ε}`；`FIRST(A)={a,b,ε}`；A 在 `S→Ab` 中后跟 `b` → `FOLLOW(A)={b}`。
> - `SELECT(A→a)={a}`
> - `SELECT(A→B)=FIRST(B)\{ε} ∪ FOLLOW(A)`（B 可空）`= {b}∪{b}` = **`{b}`**
> - `SELECT(A→ε)=FOLLOW(A)` = **`{b}`**
>
> `SELECT(A→B) ∩ SELECT(A→ε) = {b} ≠ ∅` → **冲突**：输入 `b` 时，A 不知该用 `A→B` 还是 `A→ε`。⇒ **不是 LL(1)**。

## 题 4

> [!question] 题目
> 文法：`Expr → -Expr`；`Expr → (Expr) | Var ExprTail`；`ExprTail → -Expr | ε`；`Var → id VarTail`；`VarTail → (Expr) | ε`
> (1) 构造 LL(1) 分析表；(2) 给出对句子 `id--id((id))` 的分析过程。

> [!success] (1) FIRST / FOLLOW + LL(1) 分析表
> - FIRST：`FIRST(Expr)={-,(,id}`；`FIRST(ExprTail)={-,ε}`；`FIRST(Var)={id}`；`FIRST(VarTail)={(,ε}`
> - FOLLOW：`FOLLOW(Expr)={#,)}`；`FOLLOW(ExprTail)={#,)}`；`FOLLOW(Var)={-,#,)}`；`FOLLOW(VarTail)={-,#,)}`
>
> 规则编号：①`Expr→-Expr` ②`Expr→(Expr)` ③`Expr→Var ExprTail` ④`ExprTail→-Expr` ⑤`ExprTail→ε` ⑥`Var→id VarTail` ⑦`VarTail→(Expr)` ⑧`VarTail→ε`
>
> | | id | - | ( | ) | # |
> |---|---|---|---|---|---|
> | **Expr** | ③ | ① | ② |  |  |
> | **ExprTail** |  | ④ |  | ⑤ | ⑤ |
> | **Var** | ⑥ |  |  |  |  |
> | **VarTail** |  | ⑧ | ⑦ | ⑧ | ⑧ |
>
> （各非终结符候选 SELECT 不相交 ⇒ LL(1)，表无多重定义）

> [!success] (2) 分析 `id --id((id))#`（栈顶在左）
> 输入符号序列：`id  -  -  id  (  (  id  )  )  #`
>
> | 步 | 栈（左=栈顶） | 剩余输入 | 动作 |
> |---|---|---|---|
> | 1 | `Expr #` | `id--id((id))#` | ③ Expr→Var ExprTail |
> | 2 | `Var ExprTail #` | `id--id((id))#` | ⑥ Var→id VarTail |
> | 3 | `id VarTail ExprTail #` | `id--id((id))#` | 匹配 id |
> | 4 | `VarTail ExprTail #` | `--id((id))#` | ⑧ VarTail→ε |
> | 5 | `ExprTail #` | `--id((id))#` | ④ ExprTail→-Expr |
> | 6 | `- Expr #` | `--id((id))#` | 匹配 - |
> | 7 | `Expr #` | `-id((id))#` | ① Expr→-Expr |
> | 8 | `- Expr #` | `-id((id))#` | 匹配 - |
> | 9 | `Expr #` | `id((id))#` | ③ Expr→Var ExprTail |
> | 10 | `Var ExprTail #` | `id((id))#` | ⑥ Var→id VarTail |
> | 11 | `id VarTail ExprTail #` | `id((id))#` | 匹配 id |
> | 12 | `VarTail ExprTail #` | `((id))#` | ⑦ VarTail→(Expr) |
> | 13 | `( Expr ) ExprTail #` | `((id))#` | 匹配 ( |
> | 14 | `Expr ) ExprTail #` | `(id))#` | ② Expr→(Expr) |
> | 15 | `( Expr ) ) ExprTail #` | `(id))#` | 匹配 ( |
> | 16 | `Expr ) ) ExprTail #` | `id))#` | ③ Expr→Var ExprTail |
> | 17 | `Var ExprTail ) ) ExprTail #` | `id))#` | ⑥ Var→id VarTail |
> | 18 | `id VarTail ExprTail ) ) ExprTail #` | `id))#` | 匹配 id |
> | 19 | `VarTail ExprTail ) ) ExprTail #` | `))#` | ⑧ VarTail→ε |
> | 20 | `ExprTail ) ) ExprTail #` | `))#` | ⑤ ExprTail→ε |
> | 21 | `) ) ExprTail #` | `))#` | 匹配 ) |
> | 22 | `) ExprTail #` | `)#` | 匹配 ) |
> | 23 | `ExprTail #` | `#` | ⑤ ExprTail→ε |
> | 24 | `#` | `#` | **接受** ✓ |
>
> 9 个输入符号全部匹配、栈归约到 `#`，分析成功。
